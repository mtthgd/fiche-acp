# Pneumopathies interstitielles diffuses secondaires

> Liens : [[01.12-2  Pneumopathies interstitielles idiopathiques (1) (UIP NSIP)]] | [[01.12-07 Pathologie granulomateuse non inf]] | [[01.12-5 PNP Eo]]

## Généralités

Les **PID secondaires** sont de cause connue : elles peuvent partager des **patterns** histopathologiques avec les PID idiopathiques. Le diagnostic nécessite **toujours une confrontation anatomo-clinico-radiologique** (discussion multidisciplinaire).


---

# 1. Pneumopathies d'hypersensibilité (PHS)

## Définition

PID liée à l'**inhalation d'antigènes environnementaux** entraînant une réaction d'hypersensibilité. Exemples :
- **Poumon de fermier** (actinomycète du foin)
- **Maladie des éleveurs d'oiseaux** (déjections, plumes)
- Nombreux allergènes professionnels, domestiques, de loisirs

## Clinique

- Formes **aiguës** (dyspnée, malaise, récidive à chaque exposition)
- Formes **chroniques** (exposition persistante → fibrose)
- Interrogatoire + enquête environnementale

## Outils diagnostiques

| Examen | Apport |
|--------|--------|
| **TDM** | Micronodules, verre dépoli, piégeage expiratoire |
| **Précipitines** (IgG spécifiques) | Inconstants |
| **LBA** | **Lymphocytose avec chute du CD4/CD8** (augmentation CD8), macrophages spumeux, ± PNN + mastocytes si récent |
| **Biopsie** | Transbronchique / cryobiopsie / VATS |

## Histologie - PHS **subaiguë** (la mieux caractérisée)

Triade bronchiolo-centrée :

| Compartiment | Lésion |
|--------------|--------|
| **Bronchioles** | Inflammation chronique + **pseudo-granulomes / ébauches / vrais granulomes épithélioïdes et giganto-cellulaires** (souvent **lâches**, non compacts, pas de nécrose) |
| **Alvéoles** | Inflammation interstitielle chronique, macrophages **spumeux** en amas, cellules géantes, **bourgeons de pneumopathie organisée** |
| **Cloisons** | Pattern pseudo-NSIP cellulaire |

> **Granulomes lâches + bronchiolite + OP** = triade évocatrice de PHS subaiguë.

### DD de la PHS subaiguë

| DD | Distinction |
|----|-------------|
| **NSIP** | Pas de granulomes, pas de lésions bronchiolocentriques |
| **Sarcoïdose** | Granulomes + nombreux, **mieux formés**, compacts, avec topographie lymphatique |
| Pneumopathie médicamenteuse / RGO | Contexte |

## Histologie - PHS **chronique**

Continuum avec la forme subaiguë + **fibrose** qui peut persister malgré l'éviction.

| Élément | Caractéristique |
|---------|-----------------|
| **Fibrose centrolobulaire** | Très fréquente, associée à lésions périphériques |
| **Bridging fibrosis** | Fibrose en pont entre centrolobule et périphérie → évocateur de PHS |
| Foyers fibroblastiques / honeycomb | Possibles |
| **Granulomes / corps de Schaumann / cellules géantes isolées** | Grande valeur diagnostique |
| Alvéolite lymphocytaire, bronchiolite, hyperplasie lymphoïde | Associées |
| **Métaplasie péribronchiolaire / Lambertose** | Mutilation bronchiolaire |

### DD de la PHS chronique

- **UIP / FPI** +++ → le DD le plus difficile et le plus important (**traitements différents**)
  - En faveur PHS : topographie **centrolobulaire**, **bridging**, **granulomes**, **inflammation lymphoïde**, **Lambertose**

# 2. PID associées aux connectivites

Les atteintes pleuro-pulmonaires sont **fréquentes dans les connectivites** et peuvent **précéder/révéler** la maladie. Principales connectivites :

- **Polyarthrite rhumatoïde (PR)**
- **Lupus systémique**
- **Syndrome de Gougerot-Sjögren**
- **Sclérodermie**
- **Dermatopolymyosite**

Patterns histopathologiques observés : **NSIP, UIP, LIP, OP, DAD** (les mêmes que les PII).


## Polyarthrite rhumatoïde

- Atteinte respiratoire chez **jusqu'à 40%** des patients

| Atteinte | Caractère |
|----------|-----------|
| **Pleurale** | Pleurésie subaiguë / chronique non spécifique |
| **Petites voies aériennes** | **Bronchiolite folliculaire, bronchiolite constrictive** |
| **PID** | **UIP** > NSIP |
| **Nodules rhumatoïdes** | Nécrose centrale + bordure histiocytaire palissadique (DD : granulome tuberculoïde avec bordure giganto-cellulaire ; cancer au TDM) |

## Lupus systémique

- Atteinte **pleurale** (pleurésie) fréquente
- Atteinte parenchymateuse moins fréquente mais possiblement grave :
  - **Pneumopathie aiguë lupique = DAD**
  - **Hémorragie alvéolaire diffuse**
- **LBA** hémorragie alvéolaire : hématies + **sidérophages** (macrophages chargés en hémosidérine)
- Histologie : **capillarites** (PNN, leucocytoclasie, nécrose fibrinoïde) rares en pratique
- Intérêt de la **congélation** pour **immunofluorescence** (complexes immuns)

## Gougerot-Sjögren

- Atteinte respiratoire souvent **asymptomatique**
- **Voies aériennes** : bronchite/bronchiolite chronique, **bronchiolite folliculaire** (gros follicules lymphoïdes péribronchiolaires)
- **PID** : **NSIP**, **LIP** (infiltration interstitielle dense lymphocytaire avec follicules)
- **Risque de lymphome du MALT / BALT** : attention à une lésion massive, agressive pour l'épithélium, **lésions lymphoépithéliales**, excès de **CD20+**

## Dermatopolymyosite / Syndrome des antisynthétases

- Atteinte pulmonaire **fréquente et facteur de mauvais pronostic**
- Anticorps spécifiques (antisynthétases)
- Formes aiguës : **DAD, OP**
- Formes subaiguës / chroniques : **NSIP** (fibrosante ++)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/poumon-mediastin/pathologie_pulmonaire_non_tumorale/01.12-4%20PID%20secondaires%20sono/p24_00.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/poumon-mediastin/pathologie_pulmonaire_non_tumorale/01.12-4%20PID%20secondaires%20sono/p24_01.jpeg)


## Orientations vers une PID secondaire à connectivite

- Inflammation **lymphoïde importante** avec **follicules**
- Inflammation **débordant** les lésions de fibrose
- Inflammation **pleurale** associée
- Corréler à signes extra-thoraciques (articulaires, cutanés) + auto-immunité biologique

# 3. Pneumopathies toxiques / médicamenteuses

- Site de référence : **pneumotox.com**
- Histologie **peu spécifique**
- Éléments évocateurs : **éosinophilie** (LBA/tissu), **lymphocytose** au LBA, **inclusions** dans les macrophages

## Pneumopathie à l'amiodarone

- **Formes aiguës** : DAD
- **Formes subaiguës** : pattern **NSIP**
- Signe de **prise** d'amiodarone (≠ toxicité) : **macrophages micro-vacuolisés, spumeux** dans le LBA et les alvéoles

## Pneumonie lipidique exogène

- Inhalation chronique de graisses : laxatifs huileux + RGO, gouttes nasales huileuses, exposition professionnelle
- **PID inflammatoire et fibrosante grave**
- TDM : **densité graisseuse**
- LBA : **macro-vacuoles** dans les macrophages
- Histologie : vacuoles lipidiques (dissoutes en paraffine) entourées de réaction **giganto-cellulaire** + fibrose
- **Coloration Oil red O** sur tissu congelé ou LBA

## Drogues injectables

- Voie sanguine : accumulation de **particules exogènes insolubles** (talc, fécule, méthylcellulose) dans les vaisseaux
- Mélange : lésions vasculaires + réaction **à corps étranger** + inflammation + fibrose
- **Réfringence en lumière polarisée**

## 🔑 Points clés à retenir

1. **PID secondaires** partagent les **patterns** des PID idiopathiques : confrontation **multidisciplinaire** essentielle
2. **PHS subaiguë** : triade = bronchiolite chronique + **granulomes lâches / cellules géantes** + bourgeons d'OP
3. **PHS chronique** : fibrose **centrolobulaire**, **bridging fibrosis**, granulomes résiduels → DD majeur = **UIP**
4. **LBA** PHS : **lymphocytose à CD8+** ; **précipitines** inconstantes
5. **PR** pulmonaire : **UIP** > NSIP ; **bronchiolites**, **nodules rhumatoïdes** (nécrose + palissade histiocytaire)
6. **Lupus** : **pneumopathie aiguë lupique = DAD**, hémorragie alvéolaire, **capillarites** ; IF directe sur congélation
7. **Gougerot-Sjögren** : **LIP**, bronchiolite folliculaire, **risque de lymphome du MALT / BALT**
8. **Dermatopolymyosite / antisynthétases** : **NSIP fibrosante**, DAD, OP ; mauvais pronostic
9. **Amiodarone** : macrophages **spumeux** (prise) ; toxicité = DAD aigu ou pattern NSIP
10. **Pneumonie lipidique exogène** : macro-vacuoles + réaction giganto-cellulaire ; **Oil red O** sur congélation

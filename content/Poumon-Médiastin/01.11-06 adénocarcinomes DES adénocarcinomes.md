## Hyperplasie pneumocytaire atypique (= hyperplasie adénomateuse atypique, AAH)

- **Lésion pré-invasive** (comme AIS), contrepartie **glandulaire** des dysplasies malpighiennes
- **Pas de stadification TNM** (contrairement à l'AIS)
- Généralement **< 5 mm** (AIS > 5 mm), mais **c'est la morphologie** qui différencie, pas la taille
- **Périphérique**
- Cellules pneumocytaires atypiques **TTF1+** tapissant les parois alvéolaires
- **Présence de gaps** (séparation entre cellules) = critère distinctif vs AIS (où cellules **jointives**, avec chevauchements)
- **Pas de cellules ciliées ni mucosécrétantes**
- DD : **hyperplasie pneumocytaire non atypique réactionnelle** (pneumopathies, inflammation)

## Formes rares d'adénocarcinome

### Adénocarcinome fœtal

Tumeur **périphérique**. Deux grades :

| Grade | Âge | Morphologie | Nécrose |
|-------|-----|------------|---------|
| **Bas grade** | 30-40 ans | Glandes ressemblant aux **tubules fœtaux**, cellules cylindriques à **cytoplasme clair riche en glycogène**, **morules** squamoïdes (morula squamous nests) | Rare |
| **Haut grade** | Plus âgés | Glandes de taille variable, complexité architecturale, atypies marquées, **pas de morules** | **Fréquente** |

**IHC** : **TTF1+** (sauf morules), marqueurs neuroendocrines possibles, **β-caténine nucléaire** (bas grade), **α-fœtoprotéine** (haut grade).

### Adénocarcinome entérique (OMS 2015)

- **Diagnostic d'exclusion** : éliminer **métastase colorectale** (coloscopie obligatoire)
- Morphologie/cytologie/phénotype **identiques** à une métastase colorectale : aspect **cribriforme** avec **pseudo-stratification nucléaire**
- **En faveur du primitif pulmonaire** : architecture **hétérogène** avec secteurs non entériques, **TTF1+** et **CK7+**
- Mais **certaines métastases coliques sont partiellement CK7+**
- **Biologie moléculaire inutile** : mêmes mutations (**KRAS, NRAS**) que les métastases coliques
- Phénotype typique : TTF1 ± , **CK7 partielle**, **CK20 intense+**

### Adénocarcinome colloïde (= mucineux)

- Tumeur **macroscopiquement bien limitée**, **kystique**, **gélatineuse**, uni/multiloculaire
- **Parenchyme pulmonaire détruit** par des **flaques de mucus** pauvres en cellules tumorales
- Phénotype : **CK20+**, **CDX2+**, CK7±, **TTF1± ou négatif** (focal)
- DD : adénocarcinome mucineux invasif (**cloisons alvéolaires préservées**), métastases pancréatique/ovarienne

## Immunohistochimie des carcinomes pulmonaires

### Panel standardisé : TTF1 + p40

| Marqueur | Détails |
|----------|---------|
| **TTF1** | Clone **8G7G3/1** le plus **spécifique** (recommandé) ; clone **SPT24** sensible mais non spécifique (+ métastases ovariennes/coliques). **80-90 % ADK+**. Marquage nucléaire. **TTF1− = moins bon pronostic**. Souvent négatif dans ADK solides/mucineux |
| **Napsine A** | Sensibilité ≈ TTF1, **spécificité moindre**, marquage **cytoplasmique** |
| **p40** | À **privilégier sur p63** (plus spécifique). **20-30 % des ADK sont p63+**. **p40 toujours − dans CNE**. ADK réarrangés **ALK souvent p63+**. Marquage nucléaire |
| **CK5/6** | Complémentaire de p40, moins sensible et spécifique. Positif dans **10-20 % des ADK** |
| **CK7** | Peu d'intérêt seul |

### Bilan IHC selon le type

| Tumeur | TTF1 | Napsine A | p40 |
|--------|------|-----------|-----|
| **Adénocarcinome** | **+** | + | − |
| **Carcinome épidermoïde** | − | − | **+** |
| **CPC (à petites cellules)** | + | − | **−** |

### Algorithme si TTF1− / p40− (tumeur primitive non pulmonaire ?)

| Profil | Hypothèses | Marqueurs complémentaires |
|--------|-----------|---------------------------|
| CK7+ CK20− | Homme : **prostate** (PSA) / Femme : **sein** (GATA3, mammaglobine, GCDFP-15, RH) | + marqueurs neuroendocrines (Merkel) |
| CK7− CK20+ | **Côlon** | CDX2 |
| CK7+ CK20+ | Digestif, **urothélial** | |
| CK7− CK20− | **CHC, rein, prostate** | HepPar1, PAX8, PSA |
| Non épithéliale | **Mélanome** (SOX10), **lymphome** (CD45, CD3, CD20), **sarcome thoracique SMARCA4/BRG1-déficient** | |

## Modalités thérapeutiques

### Principaux outils

| Traitement | Détails |
|-----------|--------|
| **Chirurgie** | Carcinologique **≥ segmentectomie** (résection atypique non carcinologique) |
| **Chimiothérapie** | Base de **platine** ; anti-angiogéniques + **pémétrexed** (non épidermoïdes) |
| **Radiothérapie** | |
| **Thérapie ciblée** | AMM pour **EGFR, ALK, ROS1, BRAF** |
| **Immunothérapie** | **Anti-PD1 / PD-L1** |

### Stratégie par stade

| Stade | Prise en charge |
|-------|----------------|
| **I** | Chirurgie |
| **I N1 ou T3N0** | Chirurgie + **chimiothérapie adjuvante** (4-6 sem après) |
| **IIIA (N2)** | **Chimiothérapie néo-adjuvante** + chirurgie |
| **IIIB** | **Radio-chimiothérapie concomitante** ± immunothérapie |
| **IV métastatique** | Selon altérations moléculaires et **PDL1** |

### Stade IV selon profil

| Profil | Traitement 1ère ligne |
|--------|----------------------|
| **PDL1 ≥ 50 %** | **Anti-PD1** seul |
| **EGFR muté** | ITK (gefitinib, erlotinib, **osimertinib**) |
| **BRAF V600E muté** | **Anti-BRAF + anti-MEK** (dabrafenib + trametinib) |
| **ALK / ROS1 réarrangé** | ITK (**crizotinib**, puis 2-3ème génération) |
| **MET, HER2, RET, NTRK** | Essais thérapeutiques |
| Sans cible | Chimiothérapie ± immunothérapie |

Les **oligométastases** peuvent être opérées (discussion RCP).

## 🔑 Points clés à retenir

1. L'**hyperplasie pneumocytaire atypique (AAH)** est une **lésion néoplasique pré-invasive** distincte de l'hyperplasie réactionnelle ; **présence de gaps** entre cellules (vs AIS).
2. L'**adénocarcinome entérique pulmonaire** est un **diagnostic d'exclusion** : éliminer une origine **colorectale** (coloscopie). Moléculaire inutile (mêmes mutations KRAS/NRAS).
3. L'**adénocarcinome fœtal** : deux grades ; **morules squamoïdes** + **β-caténine nucléaire** (bas grade), α-fœtoprotéine (haut grade).
4. L'**adénocarcinome colloïde** : flaques de mucus détruisant les cloisons ; **CK20+, CDX2+, TTF1 variable**.
5. **80-90 % des ADK pulmonaires sont TTF1+** ; le **mucineux est souvent TTF1−**.
6. Panel IHC standard = **TTF1 + p40**. **TTF1+/p40− → ADK** ; **TTF1−/p40+ → épidermoïde** ; **TTF1+ (CPC) mais p40− (CPC)**.
7. **CK7 et CK5/6** ne sont **pas en première intention**.
8. **p40 > p63** (plus spécifique) ; les ADK **ALK-réarrangés** sont fréquemment **p63+**.
9. Chirurgie carcinologique = **segmentectomie minimum**.
10. Standards thérapeutiques des stades avancés conditionnés aux **altérations moléculaires ciblables (EGFR, ALK, ROS1, BRAF)** et au **statut PDL1**.

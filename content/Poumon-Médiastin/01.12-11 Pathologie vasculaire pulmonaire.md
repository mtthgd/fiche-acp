# Pathologie vasculaire pulmonaire

> Liens : [[01.12-07 Pathologie granulomateuse non inf]] | [[01.12-2  Pneumopathies interstitielles idiopathiques (1) (UIP NSIP)]] | [[01.12-1  Généralités en pathologie pulmonaire non tumorale]]

## Définition

- **Hypertension pulmonaire (HTP)** = PAP moyenne **> 25 mmHg** au repos.
- **HTAP** = hypertension artérielle pulmonaire (pré-capillaire, groupe 1).

## Classification clinique (Nice 2013) – 5 groupes

| Groupe | Entité | Mécanisme dominant |
|--------|--------|---------------------|
| **1** | **HTAP** idiopathique, héritable, toxiques, connectivites, VIH, HTP portale, cardiopathies congénitales, schistosomiase | Remodelage artériel pré-capillaire |
| **1'** | **MVOP** / hémangiomatose capillaire | Remodelage veino-capillaire |
| **2** | HTP post-capillaire (cardiopathie gauche) | Élévation pressions gauches |
| **3** | **HTP sur pathologie pulmonaire / hypoxie** (BPCO, fibrose, altitude) | Vasoconstriction hypoxique |
| **4** | **HTP post-embolique (HPPE)** | Thrombi organisés |
| **5** | Mécanismes multifactoriels / inconnus | — |

## I. Hypertension artérielle pulmonaire (HTAP) – Groupe 1

### Épidémiologie

- Incidence **≈ 2,4 cas/million/an** en France ; âge médian **≈ 50 ans** ; **sexe-ratio 2–3 F/1 H**.
- Sporadique ou **familiale** (80 % mutations germinales : **BMPR2**, ALK1, endogline).
- Formes idiopathiques : 15 % porteurs de mutations BMPR2.
- Associée à : **anorexigènes** (fenfluramine), connectivites, **VIH**, cardiopathies congénitales shunt G-D, HTP portale, schistosomiase.

### Lésions histologiques (artères pulmonaires **< 500 µm**)

| Lésion | Description |
|--------|-------------|
| **Hypertrophie médiale** | Muscularisation des petites artères et **artérioles** (< 70 µm) |
| **Fibrose intimale** | Concentrique, obstructive/sub-obstructive |
| **Infiltrats inflammatoires** | Lymphocytes T, B, macrophages, mastocytes péri-artériels |
| **Lésion plexiforme** | **Marque histologique de l'HTAP** : collection nodulaire de canaux vasculaires gorgés de sang, bordée d'endothélium, riche en fibroblastes/myofibroblastes ; aux **points de division** des petites artères |
| **Thromboses** organisées et perméabilisées | Fréquentes |

### Physiopathologie

- Prolifération anormale des **cellules endothéliales** et **cellules musculaires lisses** (EndoMT).
- Voies : **sérotonine** (récepteurs + transporteur), **PDGF**, **VEGF/KDR**, **HIF-1α**.

## II. Maladie véno-occlusive pulmonaire (MVOP) + hémangiomatose capillaire

### Généralités

- Forme **rare** d'HTP ; remodelage du lit **veino-capillaire**.
- **Sexe-ratio 1/1** ; tout âge.
- Sporadique, **familiale** (mutations bi-alléliques **EIF2AK4**, transmission autosomique récessive) ou induite (**chimiothérapies** : bléomycine, mitomycine, BCNU ; greffe de moelle).
- **Pronostic sombre** ; **pas de réponse** aux traitements spécifiques HTAP (risque d'**œdème pulmonaire**) → **transplantation pulmonaire**.

### Histologie

| Lésion | Localisation |
|--------|--------------|
| **Obstruction fibreuse diffuse** | **Veinules + veines septales** de petite taille |
| **Muscularisation** | Média des veines septales/pré-septales |
| Remodelage artériel | Fréquent, **pas de lésion plexiforme** |
| **Hémangiomatose capillaire** | Prolifération multifocale de capillaires → nodules intersticiels envahissant paroi vaisseaux/lymphatiques |
| **Hémosidérose** pulmonaire | Fréquente |
| Vaisseaux lymphatiques dilatés | Oui |

- L'**hémangiomatose capillaire** est associée à la MVOP dans **75 %** des cas (Lantuéjoul) → probablement 2 expressions d'une même maladie.


### Radiologie (TDM)

- Opacités en **verre dépoli** (hémangiomatose), **renforcement des septa** inter-lobulaires, **adénopathies médiastinales**.

## III. Hypertension pulmonaire post-embolique (HPPE) – Groupe 4

### Généralités

- Obstruction artérielle pulmonaire **proximale** ou **distale** par épisodes thrombo-emboliques organisés.
- Facteurs de risque : communication AV, **infection de pacemaker**, **splénectomie**, ostéomyélite, MICI, **anticorps anti-phospholipides**.
- Latence clinique **très variable** (mois → années).

### Histologie

| Forme | Lésion |
|-------|--------|
| **Proximale** | Thrombus fibro-cruorique **organisé** → « **séquestre** » : tissu conjonctif + fibres collagènes + myofibroblastes + néovascularisation de reperméabilisation |
| **Distale** | Remodelage artères de petit calibre avec **épaississement intimal excentrique** (différent du concentrique de l'HTAP), **pas de lésions plexiformes** |
| Associées | Hémangiomatose capillaire, hémosidérose, muscularisation artériolaire, atteinte vénulaire (moins que MVOP) |

## IV. HTP sur pathologie respiratoire / hypoxie – Groupe 3

### BPCO

- HTP fréquente à stade avancé, modérée, mauvais pronostic.
- Mécanisme : **vasoconstriction hypoxique chronique** (loi d'**Euler-Liljestrand**) + remodelage.
- Histologie : **muscularisation des artérioles intra-acinaires** (< 70 µm et jusqu'à 20 µm), peu/pas d'atteinte des artères broncho-accompagnantes.
- Médiateurs : **sérotonine (5-HT)**, polymorphisme **LL** du transporteur, dysfonction endothéliale, inflammation péri-vasculaire liée au **tabac**.

### Fibrose pulmonaire idiopathique (FPI)

- HTP fréquente au stade évolué, pronostic péjoratif.
- PAP moyenne habituellement **< 35 mmHg** ; « disproportionnée » si > 35–40 mmHg.
- Histologie : **fibrose intimale** + hypertrophie médiale ; **pas de lésion plexiforme** ; altération vénulaire avec rétrécissement fibro-œdémateux ; **hémangiomatose capillaire** + hémosidérose dans zones non fibrosées.

### Sarcoïdose

- HTP dans ≈ **50 %** si dyspnée + DLCO basse ; 74 % avant transplantation.
- Mécanismes : atteinte artérielle dans fibrose, **compression extrinsèque** par adénopathies/fibrose médiastinale, **vasculopathie granulomateuse** (granulomes dans la paroi), hypoxie.

## V. Malformations artério-veineuses pulmonaires (MAVP)

- Communication anormale directe **artère ↔ veine** pulmonaire via **sac anévrysmal**.
- **60–90 %** des cas = **maladie de Rendu-Osler-Weber** (THH, télangiectasie hémorragique héréditaire, angiodysplasie multiviscérale, **autosomique dominante**). Dépistage systématique + embolisation préventive des grosses MAVP.
- Formes acquises : Fanconi, traumatismes, chirurgie (opération de Glenn), hépatopathie chronique.
- Histologie : connexions anormales, branches **tortueuses, dilatées**, paroi anormalement **fine**, calcifications, thromboses.
- Complications : **hémoptysie majeure**, hémothorax (rupture), surtout pendant la grossesse.

## Points clés à retenir

1. **HTP** = PAP moyenne > **25 mmHg** ; **5 groupes** (Nice 2013).
2. **HTAP (groupe 1)** = lésions des **artères pulmonaires < 500 µm**, **sexe-ratio F/H = 2–3/1**, mutations **BMPR2**.
3. **Lésion plexiforme** = **marque histologique de l'HTAP**.
4. **MVOP (groupe 1')** = atteinte **veinulaire** + **hémangiomatose capillaire** ; mutation **EIF2AK4** ; **pas de plexiforme** ; **transplantation** seule efficace.
5. **HPPE (groupe 4)** = **thrombus organisé** (« séquestre »), fibrose intimale **excentrique** (≠ concentrique de l'HTAP), **sans plexiforme**.
6. **BPCO** : muscularisation des **artérioles** par vasoconstriction hypoxique (**Euler-Liljestrand**).
7. **FPI** + **sarcoïdose** : HTP secondaire à remodelage vasculaire, compression adénopathique, vasculopathie granulomateuse.
8. **MAVP** = 60–90 % associée à la **maladie de Rendu-Osler-Weber** (THH) ; risque **hémoptysie**, à dépister et **emboliser**.
9. Inflammation péri-vasculaire (lymphocytes, mastocytes, macrophages) contribue au remodelage dans l'HTAP.
10. Sur biopsie, éliminer systématiquement une **cause secondaire** (thromboembolique, gauche, hypoxique, veineuse) avant de parler d'HTAP idiopathique.

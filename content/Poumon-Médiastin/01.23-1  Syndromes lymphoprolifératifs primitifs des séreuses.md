# 01.23-1 Syndromes lymphoprolifératifs primitifs des séreuses

> Liens : [[01.21 Pathologie pleurale rappels anatomiques et histologiques gestion plvts]] | [[01.11-15 Lymphomes pulmonaires]]

## Généralités

- Lymphomes **rares**, s'intégrant dans la démarche plus large des **épanchements lymphocytaires** (lymphocytes > 50 % du liquide pleural)
- Étiologies fréquentes des pleurésies lymphocytaires : **tuberculose**, cancers solides, lymphomes
- Les **épanchements lymphomateux** sont le plus souvent **secondaires** à un lymphome extra-thoracique connu (**DLBCL** ++, lymphomes B à petites cellules : folliculaire, LLC, manteau, MALT ; lymphomes T)
- **Lymphomes primitifs des séreuses** = rares, **2 entités principales** :
  - **PEL** (Primary Effusion Lymphoma)
  - **DLBCL associé à une inflammation chronique**


## 1. PEL (Primary Effusion Lymphoma / Lymphome des épanchements primitif)

### Définition / contexte

- **Lymphome B à grandes cellules** se présentant sous forme d'**épanchement sans masse** initialement détectable
- **Toujours associé à HHV8 (KSHV)** et à l'**EBV**
- **Extension secondaire** possible : poumon, tissus mous, ganglions, moelle
- **Terrains** :
  - Sujet **jeune**, **VIH+** avec immunodépression sévère (**CD4 < 100/mm³**)
  - Sujet **âgé VIH−** originaire de zone de **haute prévalence HHV8** (bassin méditerranéen)
  - Greffés (moelle, organes solides)
- Touche une **cavité** (pleurale, péricardique, péritonéale), parfois cavité non physiologique (prothèse)
- **Variant extracavitaire** : tumeurs sans localisation séreuse (TGI, peau, poumon, SNC, rarement ganglions)
- **~30 %** des cas : **sarcome de Kaposi** associé ; plus rarement **maladie de Castleman multicentrique** (également HHV8)


### Cytologie (évocatrice)

- Grandes cellules d'aspect **variable** : **immunoblastique**, **plasmablastique**, **anaplasique**
- Noyaux larges, arrondis ou irréguliers, **nucléoles proéminents**
- **Différenciation plasmocytoïde** : cytoplasme abondant et basophile, **halo périnucléaire**
- Cellules **Reed-Sternberg-like** / Hodgkin-like possibles

### Histologie (biopsies de masse / forme extracavitaire)

- Aspect **plus uniforme**
- Cytoplasme en **faux-fil**, différenciation plasmocytoïde, noyaux volumineux irréguliers nucléolés
- **Nombreuses mitoses** (haute agressivité)
- Forme extracavitaire : **invasion des sinus lymphatiques et vasculaires**

### Phénotype IHC

| Marqueur | Résultat | Remarque |
|----------|---------|----------|
| **CD45** | + | Pan-leucocytaire |
| **CD20** | **Négatif** | Piège : programme B éteint |
| **CD79a** | Négatif | |
| **PAX5** | Négatif | |
| **CD138 / CD38** | + | **Différenciation plasmocytaire** |
| **EMA** | + | |
| **CD30** | + | Marqueur d'activation |
| **CD15** | Négatif | DD Hodgkin |
| **Ig** (membrane / cyto) | Négatif | |
| **Marqueurs T / NK** aberrants | Possible (formes extracavitaires) | |
| **HHV8 (LANA-1)** | **+ nucléaire** (indispensable) | |
| **EBV (EBER-ISH)** | + | Protéines de latence absentes |

### Génétique / pathogénie

- **Clone B** : réarrangement IGH avec **hypermutations somatiques** (parfois **"infidélité génotypique"** = réarrangement TCR)
- Génome **HHV8 toujours présent**, **EBV intégré** ; **MYC** dérégulé sans translocation
- **Pas** de translocations récurrentes **BCL2 / BCL6 / BCL1** (utile pour DD)
- Caryotype complexe : trisomie 12, trisomie 7, anomalies du 1, gains du 12
- **HHV8 nécessaire mais non suffisant** : perte du génome -> mort cellulaire ; événements secondaires requis
- **EBV** nécessaire (mécanisme incertain)
- Dialogue avec les **cellules mésothéliales** + échappement immunitaire

### Pronostic

- **Sombre** : survie globale **< 1 an**
- Rares réponses à la chimiothérapie / immunomodulation


### DD spécifique : Lymphome B diffus à grandes cellules HHV8+

- Sous-catégorie des lymphoproliférations HHV8 (OMS 2016)
- Associé à la **maladie de Castleman** et à la **séropositivité VIH**
- **Cellule d'origine = B naïve** (pas d'hypermutation somatique des Ig)
- Prolifération de **plasmablastes** exprimant **IgM lambda**
- **EBV négatif** (point clé vs PEL)

## 2. DLBCL associé à une inflammation chronique

### Définition / contexte

- **Lymphome B à grandes cellules** survenant dans un **contexte d'inflammation chronique** en **espace confiné**, **associé à l'EBV**
- **Tableau typique** : **pyothorax** chronique post-**pneumothorax artificiel** pour tuberculose pleurale/pulmonaire
- Autres contextes : **ostéomyélite chronique**, inflammation sur implant chirurgical, ulcère cutané chronique
- **Sex ratio 12/1** (homme > femme)
- Sujets **âge moyen / âgé**, **évolution ≥ 10 ans** classiquement
- Extension aux structures adjacentes fréquente


### Pathogénie

- **EBV** avec **latence de type III** (EBER+, LMP1+, EBNA2+)
- Immunodéficience **locale** liée à l'inflammation durable
- Rôle des médiateurs **IL-10**, **IL-6** / IL-6R

### Clinique

- Variable selon le site
- Plèvre : douleurs thoracodorsales, symptômes respiratoires, **masse parfois volumineuse**, extension pariétale
- Os, articulations, tissus mous, peau : douleurs et masses
- **LDH souvent élevés**

### Histologie

- Aspect peu spécifique, proche d'un **DLBCL classique** (centroblastique / immunoblastique)
- **Nécrose massive** fréquente
- **Angiocentrisme** fréquent

### Phénotype IHC

| Marqueur | Résultat |
|----------|---------|
| **CD45** | + |
| **CD20, CD79a** | + (négatifs si différenciation plasmocytaire, alors **CD38+**) |
| **Programme B** | Le plus souvent **conservé** |
| **CD30** | Possible (activation) |
| **Marqueurs T** aberrants | Parfois |
| **EBV (EBER)** | + |
| **EBV protéines** | **LMP1+, EBNA2+** (latence III) |
| **HHV8** | **Négatif** |

### Génétique

- Clone B, réarrangement IGH
- **MYC** parfois amplifié
- **Délétion TNFAIP3**, mutations **TP53**
- Caryotype complexe ; signature CGH distincte du DLBCL classique (gènes d'inflammation, échappement immunitaire)

### Pronostic

- **Agressif**, survie globale **20-35 %**


## Diagnostics différentiels

### DLBCL EBV+ (anciennement "du sujet âgé")

- Sujet âgé (extraganglionnaire) ou jeune (ganglionnaire)
- Patterns variables : monomorphe DLBCL-like ou polymorphe Hodgkin-like
- **Phénotype B conservé, non centro-germinatif, CD30+**
- EBV : **latence II** (EBER+, LMP1+, EBNA2 variable)
- **Pas de contexte d'inflammation chronique**

### DLBCL associé à la fibrine (OMS 2016)

- Généralement **asymptomatique**, découverte sur **pièce chirurgicale**
- Matériel fibrineux en/autour d'un **pseudo-kyste** (splénique, rénal, surrénalien, ovarien), hydrocèle, **thrombus**, hématome, matériel prothétique
- Grandes cellules en **petits îlots dans la fibrine**, **pas de fond inflammatoire polymorphe**
- Phénotype identique au DLBCL-inflammation chronique
- **Pronostic bon**, souvent résolutif après chirurgie
- Débat : forme débutante du DLBCL-inflammation chronique ?

### DLBCL type PEL HHV8−

- Épanchements péritonéaux, associés au **VHC** et à la cirrhose

### Lymphome de Burkitt VIH+ avec différenciation plasmocytoïde

- Peut se présenter sous forme d'épanchement pleural primitif (Jaffe)

### DD par morphologie plasmablastique

- **PEL** et variant extracavitaire
- **DLBCL associé à l'inflammation chronique**
- **Lymphome plasmablastique**
- **Myélome anaplasique**
- **Lymphome lymphoplasmocytaire**
- **DLBCL ALK+**
- **DLBCL intravasculaire**

## Synthèse comparative

| Critère | **PEL** | **DLBCL inflammation chronique** | **DLBCL + fibrine** |
|---------|---------|----------------------------------|---------------------|
| Contexte | VIH / sujet âgé zone HHV8 | Pyothorax ancien ≥ 10 ans | Pseudo-kyste / prothèse |
| Présentation | Épanchement sans masse | Masse tumorale | Découverte fortuite |
| **HHV8 (LANA-1)** | **+** | − | − |
| **EBV** | **+** (latence sans protéines) | **+** (latence III) | Variable |

| Pronostic | < 1 an | 20-35 % survie | **Bon** (chirurgie) |

## 🔑 Points clés à retenir

1. Épanchement lymphomateux = le plus souvent **secondaire** à un lymphome connu ; primitifs rares -> **PEL** et **DLBCL inflammation chronique**
2. **PEL** = lymphome B grandes cellules **sans masse**, **toujours HHV8+ ET EBV+**, terrain **VIH / sujet âgé zone HHV8** ; pronostic **< 1 an**
3. **PEL phénotype** : programme B éteint (**CD20−, CD79a−, PAX5−**), **CD138+/CD38+**, **EMA+**, **CD30+**, **LANA-1+** (HHV8), **EBER+**
4. **PEL génétique** : clone B, pas de translocation BCL2/BCL6/BCL1 (DD) ; "infidélité génotypique" possible (réarrangement TCR)
5. **30 %** des PEL associés à un **sarcome de Kaposi** ; variant **extracavitaire** possible
6. **DD PEL** : **DLBCL HHV8+** (Castleman, EBV−, cellule B naïve, plasmablastes IgM-λ)
7. **DLBCL inflammation chronique** : **pyothorax** chronique sur pneumothorax thérapeutique tuberculeux ≥ 10 ans, sex-ratio 12/1
8. **DLBCL IC phénotype** : **CD20+, CD79a+**, programme B conservé, **EBV+ latence III** (LMP1+, EBNA2+), **HHV8−**
9. **DLBCL IC génétique** : MYC amplifié, **TNFAIP3 délétée**, TP53 mutée ; pronostic sombre (20-35 %)
10. **DLBCL + fibrine** (OMS 2016) : pseudo-kyste/prothèse, asymptomatique, pronostic **bon**
11. Morphologie **plasmablastique** = diagnostics multiples : PEL, lymphome plasmablastique, myélome anaplasique, DLBCL ALK+, intravasculaire
12. Diagnostic = combinaison **clinique + morphologie + phénotype (HHV8, EBV) + génétique**

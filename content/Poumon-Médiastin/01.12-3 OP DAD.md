# Pneumopathie organisée (OP) et Dommage alvéolaire diffus (DAD)

> Liens : [[01.12-2  Pneumopathies interstitielles idiopathiques (1) (UIP NSIP)]] | [[01.12-1  Généralités en pathologie pulmonaire non tumorale]] | [[01.12-9 Pathologies infectieuses virales et bactériennes]]

## Généralités

Deux PID de présentation non chronique selon la classification ATS/ERS 2012 :

| Entité histo | Nom clinique | Évolution |
|--------------|--------------|-----------|
| **OP** (Organizing Pneumonia) | **COP** (Cryptogenic Organizing Pneumonia) - ex **BOOP** | **Subaigu** |
| **DAD** (Diffuse Alveolar Damage) | **AIP** (Acute Interstitial Pneumonia) | **Aigu** |

Cryptogénique = idiopathique.


---

# 1. Pneumopathie organisée (OP / COP / BOOP)

## Définition

Réaction inflammatoire **aiguë / subaiguë** à une agression des petites bronchioles et du parenchyme péribronchiolaire. Nombreuses étiologies → COP = diagnostic d'élimination.

## Clinique

- **Homme = femme**
- Début **subaigu** sur quelques semaines
- Toux + dyspnée + **fièvre** + **VS élevée** (syndrome inflammatoire)
- Trouble ventilatoire **restrictif**

## Imagerie (TDM)

- Opacités pulmonaires **limitées, floues, dispersées, bilatérales**
- **Caractère labile et migratoire dans le temps**


![[assets/poumon-mediastin/pathologie_pulmonaire_non_tumorale/01.12-3 FT-CD /p05_01.jpeg]]


## Histologie

### Lésion élémentaire : le fibrome végétant (bourgeon fibreux)

- **Comblement des espaces aériens distaux** (alvéoles ± bronchioles) par un tissu conjonctif fibro-inflammatoire
- **Cloisons alvéolaires subnormales**, architecture globalement conservée
- Forme et taille variables selon l'espace aérien
- Composition :
  - Centre : tissu conjonctif + fibroblastes/myofibroblastes allongés parallèles
  - Stroma lâche myxoïde, néovaisseaux
  - Périphérie : lymphocytes, plasmocytes, macrophages au pied
- **Toutes les lésions au même stade** (inflammation **homogène dans le temps**)


![[assets/poumon-mediastin/pathologie_pulmonaire_non_tumorale/01.12-3 FT-CD /p07_01.jpeg]]


### Topographie

- **Bronchiolocentrique** : chaque îlot lésionnel centré sur une bronchiole
- Extension par les **pores de Kohn** (alvéole-alvéole) → aspect en **aile de papillon / doigt de gant**
- Extension par les **pores de Lambert** (alvéole-bronchiole)
- Distribution **disséminée (patchwork)** : parenchyme normal entre les îlots

| Forme | Description |
|-------|-------------|
| **Foyer unique** | Type pneumonique, bien limité |
| **Foyers dispersés** | Dispersés bilatéraux |
| **Infiltrative diffuse** | Avec **bronchiolite proliférative** (= BOOP) |

## Étiologies de la pneumopathie organisée

| Catégorie | Exemples |
|-----------|----------|
| **Infections** | Bactériennes, virales |
| **Toxiques / médicamenteux** | Amiodarone, etc. |
| **Connectivites** | **Polyarthrite rhumatoïde** +++, Gougerot-Sjögren |
| **Lésion accompagnatrice** | Modification réactionnelle en bordure d'une autre lésion |
| **Composant d'autre PID** | NSIP, PHS, pneumopathie éosinophile |
| **Idiopathique** | **COP** (diagnostic d'élimination) |

## COP : critères diagnostiques

- Lésions microscopiques **prédominantes** de OP
- **Élimination de toutes les étiologies**
- Diagnostic **seulement sur biopsie chirurgicale** (VATS)
- Sur biopsies transbronchiques / ponctions : à interpréter dans le contexte clinique

## Traitement et pronostic

- **Corticothérapie** bien conduite (éviter le rebond à l'arrêt)
- **Bon pronostic** : survie à 5 ans > 80%

# 2. Dommage alvéolaire diffus (DAD)

## Définition

Réaction inflammatoire **aiguë** secondaire à l'agression/destruction du revêtement alvéolaire.

## Clinique (contexte **capital**)

- Dyspnée **brutale** + **hypoxémie**
- Prise en charge en **réanimation** : intubation / ventilation assistée
- Correspond au **SDRA** (poumon de choc, poumon des machines, **syndrome des membranes hyalines de l'adulte**)

## Imagerie

- Infiltrat diffus étendu bilatéral : **poumon blanc**

## Histologie - Stades du DAD

### Stade 1 : aigu / exsudatif / précoce (J1-J7)

- **Membranes hyalines** (J1-J3) : dépôts éosinophiles **laqués** tapissant la cloison alvéolaire **dénudée**
- Mélange de **fibrine + protéines sériques**
- **Œdème intra-alvéolaire et interstitiel** (1ère lésion)
- Cloisons alvéolaires épaisses, congestion capillaire
- Inflammation intra-alvéolaire **rare**

### Stade intermédiaire / de chevauchement (J3-J7)

- **Hyperplasie pneumocytaire** : pneumocytes en **clous de tapissier**, atypies nucléaires, mitoses
- Membranes hyalines présentes, incorporées aux cloisons
- Intense congestion capillaire

### Stade 2 : organisé / prolifératif / tardif (> J7, 1-2 sem)

- **Disparition des membranes hyalines**
- **Prolifération interstitielle** de fibroblastes / myofibroblastes → stroma **myxoïde**
- Épaississement **uniforme et diffus** des cloisons alvéolaires
- **Alvéoles collabés** piégés dans la fibrose
- Hyperplasie pneumocytaire ++
- Possible **métaplasie malpighienne** de l'épithélium bronchiolaire
- Thrombi fibrineux

## Diagnostic différentiel : OP vs DAD organisé

| Critère | **OP** | **DAD organisé** |
|---------|--------|------------------|
| **Topographie fibrose** | **Endoalvéolaire** (bourgeon) bronchiolocentrique | **Interstitielle**, parenchyme distal |
| **Rapport bronchioles** | Centré sur bronchioles | Pas de rapport avec bronchioles |
| **Cloisons alvéolaires** | Subnormales | Épaissies diffusément |
| **Membranes hyalines** | Absentes | Reliquats possibles |
| **Hyperplasie pneumocytaire** | Modérée | Majeure |
| **Contexte clinique** | Subaigu, pas de ventilation | **SDRA, réanimation** |

- Au stade aigu du DAD : DD quasi nul (membranes hyalines typiques)

## Physiopathologie

- Destruction **épithélium alvéolaire** → endothélium capillaire
- Hyperplasie pneumocytaire = réparation
- Prolifération fibroblastique = cicatrisation
- Progression → fibrose → **honeycomb** → décès
- Quelques cas de **régression** possible

## Étiologies du DAD

Liste à rechercher cliniquement (histologie souvent identique quelle que soit la cause) :

| Catégorie | Exemples |
|-----------|----------|
| **Infections** | Bactériennes, virales (effets cytopathiques), **pneumocystose** (chez l'immunodéprimé) |
| **Toxiques / médicaments** | Nombreux (amiodarone aiguë...) |
| **Inhalation** | Toxiques, liquide gastrique |
| **Sepsis extrapulmonaire** | |
| **Radiothérapie** | |
| **Choc** | |
| **Idiopathique** | **AIP** (= syndrome de **Hamman-Rich**) |

> Chez l'immunodéprimé : **colorations spéciales systématiques** (pneumocystis, agents fongiques...)

## AIP (Pneumonie aiguë interstitielle) / Hamman-Rich

- = **DAD idiopathique**, diagnostic d'élimination
- Adultes d'âge moyen en bonne santé
- Détresse respiratoire rapide → ventilation
- Histologie identique au DAD stade 2
- **Mortalité > 70%**

## 🔑 Points clés à retenir

1. **OP / COP / BOOP** : lésion élémentaire = **fibrome végétant / bourgeon fibreux** dans les espaces aériens
2. OP : **homogène dans le temps**, **bronchiolocentrique**, distribution **patchwork** (cloisons alvéolaires subnormales)
3. Extension du bourgeon par les **pores de Kohn** (alvéole-alvéole) et **Lambert** (alvéole-bronchiole)
4. **COP** = diagnostic d'**élimination** (infections, médicaments, connectivites, PID) ; bon pronostic, **corticoïdes**
5. **DAD** = contexte **SDRA / réanimation** (ne pas porter le diagnostic hors de ce contexte)
6. Stade aigu DAD : **membranes hyalines** éosinophiles laquées sur cloison dénudée (J1-J7)
7. Stade organisé DAD : fibrose **interstitielle** myxoïde + hyperplasie pneumocytaire ± **métaplasie malpighienne** bronchiolaire
8. DD OP vs DAD organisé : topographie **endoalvéolaire** (OP) vs **interstitielle** (DAD) + contexte clinique
9. Immunodéprimé en DAD : rechercher **pneumocystis** et agents infectieux par colorations spéciales
10. **AIP = Hamman-Rich** = DAD idiopathique, mortalité **> 70%**

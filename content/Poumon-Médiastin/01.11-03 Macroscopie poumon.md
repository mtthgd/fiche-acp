# Macroscopie poumon - Gestion des prélèvements tumoraux

> Liens : [[01.11-02  Généralités sur les cancers du poumon (2)]] | [[01.11-05 adénocarcinomes]] | [[01.11-07  Carcinomes malpighiens et leurs prénéoplasies]]

## Objectifs

- Connaître les différents **types de prélèvements**
- Maîtriser l'examen **extemporané**
- Gérer la **fixation** et la **macroscopie**
- Rédiger un **compte rendu** anapath conforme


## Types de prélèvements

### Cytologiques

- **Cytoponction à l'aiguille fine** (aiguille de Wang)
- **EBUS** (endobronchial ultrasound) : ponctions de ganglions médiastinaux, peu invasif
- Voir cours dédié cytologie

### Biopsies

| Type | Particularités |
|------|----------------|
| **Endobronchique** | Sous fibroscopie bronchique |
| **Transpariétale sous scanner** | Nodule périphérique |

> **Important** : économiser le matériel (petite taille) pour les analyses complémentaires à visée thérapeutique (**IHC, biologie moléculaire**).

### Pièces chirurgicales

| Pièce | Description |
|-------|-------------|
| **Wedge (résection atypique)** | Forme de coin, agrafée, **sans limite bronchique**, limite chirurgicale parenchymateuse uniquement |
| **Segmentectomie** | Unité anatomique avec section bronchique + vasculaire |
| **Lobectomie / bilobectomie** | Supérieure ou inférieure |
| **Pneumonectomie** | Totalité d'un poumon |
| **Résection élargie** | À la plèvre pariétale, péricarde, paroi thoracique |

## Examen extemporané

### Trois indications principales

1. **Nature tumorale** : découverte peropératoire, biopsie préalable non contributive
2. **État des limites chirurgicales** : bronchique ou parenchymateuse (sur wedge)
3. **Quantité/qualité** du matériel : biopsies chirurgicales pour biobanques

### Techniques

- Appositions cytologiques et/ou **cryostat**
- Au choix du pathologiste selon hypothèses et matériel


## Tumorothèque

- **Non obligatoire** pour les carcinomes pulmonaires (obligatoire : hémato, sarcomes, pédiatrie)
- **Fortement conseillée (INCa)** : alternative à la fixation pour l'**ARN**
- Utile si échec de biologie moléculaire sur FFPE
- **Essais cliniques** exigeant du tissu congelé

## Examen macroscopique - Étapes

### 1. Vérification de la conformité

- Type de pièce annoncée = pièce reçue (bilobectomie ≠ lobectomie)

### 2. Fixation

- Rapide (ADN, ARN, protéines se dégradent)
- **Formol uniquement** (pas d'AFA ni fixateurs alcooliques/acides → détruisent les acides nucléiques)
- **Insufflation de formol via la bronche** pour fixation homogène
- Tumeurs très volumineuses : ouverture en feuillets de livre pour fixer le centre

### 3. Inspection

- Séreuse, lésions particulières, nodules sous-pleuraux, ombilication pleurale
- **Encrer les limites chirurgicales** (notamment plèvre pariétale si résection élargie)
- Noter toute **ombilication pleurale** (suspecte d'atteinte pleurale)

### 4. Examen selon le type de pièce

#### Wedge résection

- Ablation de la **ligne d'agrafes**
- Coupes **perpendiculaires à la plèvre** (rapport tumeur/plèvre)
- Noter les 3 dimensions tumorales
- Prélever toute **ombilication pleurale** en totalité (stadification T)
- Donner l'état de la **limite chirurgicale parenchymateuse**

#### Segmentectomie/Lobectomie/Pneumonectomie

1. Prélever d'abord les **limites chirurgicales bronchique et vasculaire**
2. Couper la tumeur dans son **plus grand axe**, rapports avec les bronches
3. Sondes guides pour couper selon l'axe des bronches

### 5. À la coupe - éléments à rechercher

| Élément | Importance |
|---------|-----------|
| **Taille tumorale** (3 axes) | Majeur pour pTNM |
| **Rapport avec limites chirurgicales** | Bronchique, pariétale |
| **Localisation** | Périphérique / intermédiaire / proximale |
| **Tumeurs multiples** | Homolobaires vs autre lobe (conditionne pTNM) |
| **Autres lésions** | Hyperplasies, préinvasives |

### 6. Aspects macroscopiques

| Tumeur | Aspect |
|--------|--------|
| **Carcinome épidermoïde infiltrant** | Proximal bronchopulmonaire, induré, infiltrant |
| **Adénocarcinome in situ / lépidique** | Non induré, **difficile à palper** (attention à ne pas manquer !) |
| **Adénocarcinome avec contingent lépidique prédominant** | Zone périphérique lépidique + centre infiltrant |
| **Tumeur carcinoïde** | Nodule arrondi + **dilatation bronchique post-pneumopathie** en aval |

## Échantillonnage

### Que prélever ?

- **Toutes les limites chirurgicales** (vasculaires, bronchiques, parenchymateuses, pariétales)
- **Échantillonnage tumoral** : pas de nombre minimal, suffisant pour hétérogénéité
- **Tous les aspects macroscopiques différents** (contingent lépidique + invasif, etc.)
- **Ganglions lymphatiques visibles** sur la pièce
- Quelques prélèvements **non tumoraux**
- **Chaque lésion visible** macroscopiquement

### Pièges

- **Ganglions envahis par contiguïté** = **N1** (à bien prélever)
- Ganglions N2 laissés sur la pièce par le chirurgien : il doit les signaler
- Tumeurs avec **plusieurs contingents** : prélever tous les aspects

### Curage ganglionnaire

- Adressé **à part** dans flacons référencés par le chirurgien
- **Site du ganglion** envahi = ce qui compte pour pTNM (pas le nombre)


## Compte rendu anapath

### Données obligatoires (référentiels CAP + INCa)

| Catégorie | Items |
|-----------|-------|
| **Pièce** | Type, côté, lobe |
| **Type histologique** | Selon OMS en vigueur |
| **Grade** | Obligatoire pour carcinoïdes |
| **Extension loco-régionale** | Limites bronchique, vasculaires, parenchymateuses, pariétales |
| **pTNM** | Tous critères : taille, plèvre, nombre de tumeurs, ganglions (**site**) |
| **Tumeurs multiples** | Préciser si **apparentées** (histotype + critères morphologiques) |

### Facteurs pronostiques (non obligatoires)

- **Emboles vasculaires**
- **STAS** (spread through air spaces, dissémination endo-alvéolaire)
- **Effraction capsulaire ganglionnaire**
- Architecture prédominante (adénocarcinomes)

## 🔑 Points clés à retenir

1. **Économiser les petites biopsies** pour IHC et biologie moléculaire à visée thérapeutique
2. Fixation au **formol uniquement** (jamais AFA ni alcoolique) - **insufflation bronchique** pour homogénéité
3. 5 pièces chirurgicales : **wedge** (sans limite bronchique), **segmentectomie, lobectomie, bilobectomie, pneumonectomie**
4. **Encrer** les limites chirurgicales + toute **ombilication pleurale** à prélever intégralement
5. Taille tumorale = **3 axes**, déterminante pour pTNM
6. Adénocarcinome lépidique/in situ : **difficile à palper** → ne pas manquer à la coupe
7. Prélever **tous les aspects macroscopiques différents** d'une tumeur (hétérogénéité)
8. **Ganglions envahis par contiguïté = N1**
9. **pTNM du N = site** du ganglion, pas le nombre
10. **Congélation (tumorothèque) fortement conseillée** pour ARN et essais cliniques
11. Compte rendu : détailler tous les critères permettant la **pTNM dans la conclusion**
12. Facteurs pronostiques à mentionner : **STAS**, emboles, effraction capsulaire, architecture prédominante

# Catégorie maligne — Adénocarcinomes métastatiques et diagnostics différentiels

> Liens : [[11_7_0_fiche]] | [[11_7_1_fiche]] | [[11_7_2_3_bis]] | [[11_2_2_et 3]]

## Généralités

- **Adénocarcinome** = type tumoral malin **le plus fréquent** dans les séreuses
- Les autres entités : hémopathies, mésothéliome (< 1 %), mélanome, sarcomes
- Cytologie de séreuse = potentiellement diagnostic + théragnostique en un seul prélèvement
- Importance des **techniques** standardisées (cytospin + cytobloc)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/cytopathologie/sereuse/V2%2011.7-2-3bis/p01_03.jpeg)

## Techniques

### Préparation des prélèvements
- Tube avec **anticoagulant (EDTA)**
- Acheminement rapide à 4°C
- **Numération + estimation** des éléments nucléés à l'examen direct
- **Dilution** pour obtenir 200 éléments nucléés/μL
- **Cytocentrifugation** : 200 μL à 700 tours/min × 8 min → **cytospin**

### Cytobloc
- Falcon 50 → centrifugation 4000 tours × 8 min → **culot sec**
- Réactifs Shandon = **gel autour des cellules**
- Inclusion en **paraffine**
- Fixation en PreservCyt (alcoolique)

### Colorations de routine
- **MGG** (May-Grünwald-Giemsa)
- **Papanicolaou**
- **PAS**

> Les 3 colorations sont **systématiquement** réalisées sur cytospin.

## Orientation par site et terrain

| Site | Genre | Tumeurs à rechercher |
|------|-------|----------------------|
| **Pleural / péricardique** | H/F | **AdénoK bronchique** (TTF1) |
| **Pleural / péricardique** | F | + AdénoK mammaire (GATA3, RE) |
| **Péritonéal** | F | Tumeurs ovariennes + adénoK mammaire |
| **Péritonéal** | H | AdénoK gastro-intestinal (CDX2), pancréatique |

> Si vous voyez des cellules atypiques sur séreuse, le plus probable est un **adénocarcinome**.

## Critères morphologiques pour diagnostic de malignité

### Critère principal : taille des cellules

**Grandes cellules** (> 10 noyaux de lymphocytes dans le noyau, ou > 1 macrophage dans le noyau) :
- Diagnostic de malignité **facile**
- Origines fréquentes : **bronchique, ovarien**

**Petites/moyennes cellules** (< 10 noyaux de lymphocytes dans le noyau) :
- Diagnostic de malignité **plus difficile**
- Origines : mammaire, gastrique, autres


### Indices morphologiques majeurs (pour cellules petites/moyennes)

#### 1. Amas tridimensionnels
- À distinguer des amas plans des cellules mésothéliales
- 3D = inquiétant → investigations
- Plan/placard = mésothélium


#### 2. Réaction du PAS
| Aspect | Origine |
|--------|---------|
| **Couronne** péricellulaire | Mésothélium (bénin ou malin) |
| **Diffuse** intracytoplasmique | Carcinome |
| **Vacuole bien limitée rose fuchsia** | Carcinome (très spécifique) |

### Indices morphologiques de seconde catégorie (moins spécifiques)

| Indice | Limite |
|--------|-------|
| Population **monomorphe** | Aussi en mésothéliome, lymphome |
| **Microvésicules** cytoplasmiques | Aussi en mésothélial réactionnel |
| Macrovésicules | Aussi en macrophages |
| **Cytophagie** (cannibalisme) | Aussi en mésothéliome, mésothélial bénin |
| Sécrétions intracytoplasmiques | Variable |

## Études immunocytochimiques en première intention

### Panel de base (sur cytospin)

| Anticorps | Cible | Cellules positives |
|-----------|:---:|--------------------|
| **BerEP4** (anti-EpCAM) | Adénocarcinome | + |
| **MOC31** | Adénocarcinome | + |
| **Claudine-4** | Adénocarcinome | + |
| **Calretinine** | Mésothélium | + |
| **WT1** | Mésothélium | + |

> Si IHC sur cytospin non concluante → reprendre sur **cytobloc**.


### Pièges majeurs avec BerEP4

- **Cellules mésothéliales réactionnelles** peuvent exprimer BerEP4 (surtout péricarde et péritoine, **rarement plèvre**)
- **Mésothéliome malin** peut exprimer BerEP4 → ne pas confondre avec adénoK
- → Toujours **doubler** avec un marqueur mésothélial (calretinine, WT1)



## Recherche du site primitif

### Marqueurs d'origine usuels

| Marqueur | Origine principale |
|----------|--------------------|
| **TTF1** | Poumon (adénoK bronchique), thyroïde |
| **GATA3** | Sein (++), urothélium |
| **RE / RP** | Sein (++), endomètre, ovaire |
| **PAX8** | Gynécologique (ovaire, endomètre, col), rein, thyroïde |
| **CDX2** | Digestif (côlon, gastrique) |
| **CK20** | Côlon, urothélium |
| **CK7** | Poumon, sein, gynéco, biliaire |
| **PSA / NKX3.1** | Prostate |
| **CA-125** | Ovaire séreux |
| **WT1** | Ovaire séreux, mésothélium |

### Exemple : adénocarcinome mammaire métastatique
- Cellules micro-vacuolisées + atypies
- BerEP4 + → adénoK
- **GATA3 +** + **RE +** au noyau → mammaire confirmé


## Marqueurs théragnostiques (sur cytobloc obligatoire)

### PDL1 (adénoK bronchique)
- IHC sur cytospin possible mais **cytobloc obligatoire** (contrôle externe)
- Score TPS (Tumor Proportion Score) si ≥ 1 % ou ≥ 50 %
- À rendre dans le compte rendu


### ALK (adénoK bronchique non-fumeur)
- IHC ALK **3+** → translocation ALK probable
- Confirmation par **FISH break-apart** sur cytospin ou cytobloc
- Si translocation : signal vert et rouge **dissociés**, sinon fusionnés



### MET amplification
- Recherche en cas de rechute après TKI ALK ou EGFR
- FISH : clusters de points fluorescents sur le gène MET
- Aide à l'adaptation thérapeutique

## Biologie moléculaire

- **Liquide frais** = matériel **excellent** pour les acides nucléiques
- Analyses possibles :
  - PCR ciblée (KRAS, EGFR, BRAF, etc.)
  - **Séquençage NGS** ADN ou ARN
  - Fusion détection
- Travail en parallèle sur :
  - Liquide frais (culot sec congelé)
  - Cytobloc

> **Rendre le pourcentage de cellules tumorales** dans le CR = essentiel pour interprétation NGS.

## Diagnostics différentiels

| DD | Distinction |
|----|-------------|
| **Mésothélium réactionnel** | Calretinine + / BerEP4 − ; pas d'amas 3D vrai |
| **Mésothéliome malin** | Calretinine +, **BAP1 perdu**, MTAP perdu, BerEP4 ± |
| **Lymphome** | CD20+/CD3+, monotypie ; cellules isolées ; voir [[11_7_2_3_bis]] |
| **Mélanome** | HMB45+, SOX10+, MART1+ ; pigment mélanique au MGG |
| **Carcinome à petites cellules** | Cellules en piles d'assiettes, dot bleue périnucléaire ; synaptophysine + chromogranine ± TTF1 |
| **Macrophage à macro-vacuole** | CD68+ / CK− |

## Mésothélium

### Quand y penser ?
- Liquide pleural (préférentiellement)
- Cellules malignes en **« boules de neige »** systématiques
- Calretinine diffuse + claudine-4 négative

### Diagnostic
- IHC : **calretinine +**, **WT1 +**, **CK5/6 +**, **D2-40 +**
- **BerEP4** à doser (peut être faiblement +)
- **BAP1 perte** (50 % des mésothéliomes) = pathognomonique
- **MTAP perte** = corrélée à délétion CDKN2A (p16)
- **FISH p16 (CDKN2A)** : délétion homozygote = mésothéliome confirmé

> **Perte BAP1 OU délétion CDKN2A** = suffisant pour le diagnostic de mésothéliome malin (classification internationale TIS 2020).


![](https://pub-09a67500e45345d4babec28739403570.r2.dev/cytopathologie/sereuse/V2%2011.7-2-3bis/p08_04.jpeg)

## Conduite à tenir clinique

### Avant geste invasif
- Si liquide d'épanchement disponible → privilégier la cytologie
- Diagnostic + théragnostique en un seul geste peu invasif
- Éviter biopsie supplémentaire si non nécessaire

### Si MAL confirmé
- Catégorie : **MAL secondaire** ou **MAL primaire** (mésothéliome)
- Préciser type cellulaire + site primitif
- Communication directe avec l'oncologue

## 🔑 Points clés à retenir

1. **Adénocarcinome** = malignité la plus fréquente des séreuses ; cellules grandes ou petites
2. Critère de malignité majeur = **taille** ; > 10 noyaux de lymphocytes = facile, < 10 = difficile
3. Indices majeurs (cellules petites) : **amas 3D** + **PAS intracytoplasmique** ou en vacuole rose fuchsia
4. Indices secondaires (peu spécifiques) : monomorphisme, microvésicules, cytophagie, sécrétions
5. **Panel IHC de base** : **BerEP4 + MOC31 + claudine-4** (carcinome) vs **calretinine + WT1** (mésothélium)
6. **Piège BerEP4** : peut être + dans mésothéliome et mésothélial réactionnel ; toujours doubler
7. Recherche du site primitif : **TTF1** (poumon), **GATA3/RE** (sein), **PAX8** (gynéco/rein), **CDX2** (digestif)
8. **Théragnostique** sur cytobloc obligatoire : **PDL1**, **ALK** (FISH break-apart), MET
9. **Liquide frais** = excellent pour biologie moléculaire (NGS, mutations EGFR, KRAS, BRAF…)
10. Toujours **rendre le pourcentage de cellules tumorales** pour l'interprétation NGS
11. **Mésothéliome** : calretinine + WT1 + ; **perte BAP1** ou **délétion CDKN2A** = pathognomonique
12. La cytologie de séreuse permet souvent **diagnostic + théragnostique** sans biopsie supplémentaire

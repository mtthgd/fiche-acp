# Cytopathologie des séreuses — Classification internationale (TIS 2020)

> Liens : [[11_7_1_fiche]] | [[11_7_2_3_fiche]] | [[11_7_2_3_bis]] | [[11_2_2_et 3]]

## Généralités

- **TIS 2020** = *The International System for Reporting Serous Fluid Cytopathology*
- Publiée en **2020**, fruit de **41 experts de 18 pays**
- Traduite en français et résumée dans les **Annales de Pathologie**
- Concerne les **épanchements** : pleural, péritonéal, péricardique
- Objectif : **consensus terminologique** + stratification du **risque de malignité (ROM)**

![[assets/cytopathologie/sereuse/V2 11.7-0/p01_03.jpeg]]

## Cinq catégories TIS 2020

| Catégorie | Acronyme | Risque de malignité (ROM) |
|-----------|----------|---------------------------|
| **Non diagnostique** | **ND** | 17 % |
| **Négatif pour la malignité** | **NPM** | 21 % |
| **Atypies de signification indéterminée** | **AUS** | 66 % |
| **Suspect de malignité** | **SFM** | 82 % |
| **Malin** | **MAL** | **99 %** |

> Catégories **toujours en lettres** dans le compte rendu (jamais « catégorie 3 »)

### Hiérarchie diagnostique
- Le diagnostic doit être le **plus définitif possible**
- ND, AUS, SFM = catégories d'**exclusion** ou **provisoires**
- Si on les utilise → toujours **expliquer** + donner une CAT clinique

## Compte rendu — éléments minimums

1. **Site de ponction** : pleural / péritonéal / péricardique
2. **Convenance du prélèvement** (satisfaisant ou non satisfaisant pour évaluation)
3. **Diagnostic précis** (ex : adénocarcinome d'origine bronchique)
4. **Catégorie TIS** (ex : MAL secondaire)
5. **Justification** : aspect morphologique + techniques ancillaires
6. Pour adénocarcinome : **site primitif** présumé
7. **Pourcentage de cellules tumorales** (utile pour la biologie moléculaire)

![[assets/cytopathologie/sereuse/V2 11.7-0/p02_01.png]]

## Convenance du prélèvement

### Satisfaisant pour évaluation
- **Volume > 50 mL** = idéal (limite les faux négatifs)
- < 50 mL = peut être satisfaisant **si cellularité adéquate dans contexte clinique**
- Pas de cellularité minimale : 3 cellules malignes formelles peuvent suffire

### Non satisfaisant pour évaluation (= ND)
- Pauci-cellulaire + volume < 50 mL
- Cellules majoritairement dégénérées
- Hémodilution importante
- Artefacts masquants
- → Demander **un autre prélèvement**

## Catégorie négative pour la malignité (NPM)

- **Catégorie majoritaire** : **80 %** des diagnostics
- Cellules **bénignes attendues** (mésothéliales, macrophages, lymphocytes, PNN)
- Cellules **tumorales bénignes** possibles
- **Aucune cellule tumorale maligne**
- Diagnostic **formel et définitif**
- Études ancillaires **rarement nécessaires**

> ROM 21 % = lié à des erreurs d'échantillonnage (faux négatif), non à un risque intrinsèque

## Catégorie atypies de signification indéterminée (AUS)

- **Catégorie d'exclusion**
- Atypies cellulaires (nucléaires ou architecturales : amas papillaires, etc.) **limitées**
- Plutôt en faveur d'un processus **bénin / réactionnel / dégénératif**
- À cette catégorie : **tumeurs borderline** ou tumeurs à faible potentiel de malignité

### CAT
- Préciser dans la conclusion **vers quoi penche** l'atypie (réactionnel ? borderline ?)
- Recommander **nouveau prélèvement** selon contexte

## Catégorie suspect de malignité (SFM)

- **Catégorie d'exclusion** : preuves morphologiques + ancillaires **insuffisantes**
- Cellules « presque » certainement malignes mais :
  - Trop rares
  - Prélèvement dégénéré
  - IHC discordante
- Conclusion : « **prélèvement en faveur de la présence de cellules malignes mais ne pouvant être affirmées formellement** »
- Catégorie d'**attente** possible : SFM rapide → CR complémentaire formel après IHC

### CAT
- Recommander **nouveau prélèvement**
- Préciser la nature suspectée

## Catégorie maligne (MAL)

- Preuves morphologiques **seule** ou + IHC **suffisantes** pour affirmer la malignité
- Diagnostic **définitif**
- Préciser :
  - **Type cellulaire** (carcinome, lymphome, mésothéliome, mélanome…)
  - **Site d'origine** (pour adénocarcinomes)
- Possibilité d'orientation thérapeutique (ex : ALK, PDL1)

### Sous-catégories MAL
| Type | Caractère |
|------|-----------|
| **Mésothélial** | Tumeur primaire de la séreuse (mésothéliome) |
| **Non mésothélial** | Métastase (le plus fréquent) |

## Apport de la classification

| Avant | Après TIS 2020 |
|-------|----------------|
| Terminologie hétérogène | **Langage commun** |
| Communication aléatoire | Meilleure communication clinique |
| Enseignement disparate | Pédagogie uniforme |
| Pas de standardisation | Possibilité de gold standards |
| Études difficiles | Recommandations basées sur ROM |

## Exemples cliniques

### Diagnostic et théragnostic en un seul prélèvement
- Cellules atypiques de grande taille + anisocaryose dans liquide pleural
- IHC : **TTF1 +** → adénocarcinome pulmonaire
- FISH : **translocation ALK** → cible thérapeutique
- → Diagnostic + théragnostique **sans biopsie supplémentaire invasive**


### Prélèvement satisfaisant malgré < 50 mL
- Volume 30 mL + macrophages + cellules monstrueuses
- → Diagnostic possible
- Catégorie : **MAL**

### Prélèvement satisfaisant malgré pauci-cellularité
- Volume 30 mL + cellules monstrueuses claires (3-4 cellules)
- → Diagnostic possible si formel
- Catégorie : **MAL**

## Diagnostics différentiels par catégorie

| Catégorie | Pour ne pas la sous-utiliser |
|-----------|------------------------------|
| ND | Vrai prélèvement non interprétable, pas un « doute » |
| NPM | 80 % des cas ; ne pas surdiagnostiquer en AUS pour des cellules réactives |
| AUS | À utiliser pour vraies atypies bornées, pas pour la prudence excessive |
| SFM | Quand cellules très évocatrices mais preuve manquante |
| MAL | Si formel cytologiquement et/ou par IHC/FISH |

## Conduite à tenir clinique selon la catégorie

| Catégorie | CAT |
|-----------|-----|
| **ND** | Refaire un prélèvement |
| **NPM** | Pas d'investigation supplémentaire |
| **AUS** | Suivi + selon clinique nouveau prélèvement |
| **SFM** | Nouveau prélèvement / biopsie ; CR complémentaire à venir |
| **MAL** | Prise en charge oncologique selon type/origine |

## Liens utiles inter-catégories

- **AUS et SFM** = catégories de **dernière intention** (jamais en réflexe)
- **MAL** + diagnostic complet (origine) = idéal pour la prise en charge
- Importance de la **confrontation au contexte clinique** dans toutes les catégories

---

## 🔑 Points clés à retenir

1. **TIS 2020** = classification internationale en **5 catégories** (ND, NPM, AUS, SFM, MAL)
2. ROM par catégorie : **17 / 21 / 66 / 82 / 99 %**
3. **NPM** = 80 % des diagnostics ; cellules bénignes attendues, diagnostic formel
4. **ND, AUS, SFM** = catégories **d'exclusion** : toujours expliquer + CAT
5. **MAL** = diagnostic définitif + type cellulaire + **site primitif** pour adénocarcinome
6. **Volume > 50 mL** souhaité mais < 50 mL peut suffire si cellularité adéquate
7. Toujours **catégorie en lettres**, jamais en chiffres dans le compte rendu
8. Mentionner le **site de ponction** + convenance + diagnostic précis
9. **Pourcentage de cellules tumorales** utile pour la biologie moléculaire
10. Cytologie de séreuse permet **diagnostic + théragnostique** (IHC PDL1, FISH ALK, mutations) en un seul geste peu invasif
11. Éviter le geste biopsique invasif si la cytologie suffit
12. Confrontation au **contexte clinique** indispensable

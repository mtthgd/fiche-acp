# Grade des sarcomes selon la FNCLCC

> Liens : [[81_Classification moléculaire des tumeurs mésenchymateuses]] | [[80_CAT devant un prélèvement de tumeur des tissus mous]] | [[91_Liposarcomes]]

## Généralités

- Le **grade** est un **facteur pronostique** (risque métastatique et de décès)
- Basé sur les **caractéristiques intrinsèques** de la tumeur
- Système **FNCLCC** (Fédération Nationale des Centres de Lutte Contre le Cancer) = **le plus performant**
- S'applique aux **sarcomes des tissus mous NON traités** (pas aux sarcomes osseux, pas aux sarcomes post chimio/radiothérapie)
- Déterminé sur **coloration HES standard** ; pas d'IHC/biomol nécessaire


## Sarcomes qui NE se gradent PAS

> Le type histologique est lui-même le facteur pronostique.

- **Angiosarcomes**
- **Sarcomes épithélioïdes**
- **Sarcomes à cellules claires**
- **Sarcomes alvéolaires**
- **Tumeurs d'Ewing**
- **Tumeurs desmoplasiques à petites cellules rondes**

> Néanmoins, les **3 items du grade doivent figurer dans le compte-rendu** même si le sarcome ne se grade pas.


## Principe du grade (somme de 3 scores)

| Grade FNCLCC | Somme |
|--------------|-------|
| **Grade 1** (bas) | 2-3 |
| **Grade 2** (intermédiaire) | 4-5 |
| **Grade 3** (haut) | **≥ 6** |

## Item 1 — Différenciation (score 1, 2 ou 3)

| Score | Définition |
|-------|-----------|
| **1** | Sarcome ressemblant à un **tissu adulte normal** |
| **2** | **Type histologique certain** sans ressembler à du tissu normal |
| **3** | **Type incertain / indifférencié** |

### Exemples clés

| Sarcome | Score de différenciation |
|---------|--------------------------|
| **Liposarcome bien différencié** | **1** |
| **Léiomyosarcome bien différencié** | **1** |
| **Liposarcome myxoïde** (sans cellules rondes) | **2** |
| Chondrosarcome myxoïde extra-squelettique | 2 |
| **Liposarcome pléomorphe** | **3** |
| **Liposarcome dédifférencié** | **3** |
| **Sarcome synovial** | **3** |
| **Sarcomes indifférenciés fusiforme/pléomorphe (UPS)** | **3** |
| Rhabdomyosarcome | 3 |
| MPNST | 3 |

> Pour les scores de **2** difficiles : se référer aux **recommandations FNCLCC** (implique que le **type histologique soit certain**).

## Item 2 — Index mitotique (score 1, 2 ou 3)

Comptage sur **10 champs consécutifs** à l'objectif × 40 (**zone la plus mitotique**, repérée à moyen grandissement, souvent en périphérie).

| Score | Nombre de mitoses / 10 CFG |
|-------|----------------------------|
| **1** | 0-9 |
| **2** | 10-19 |
| **3** | **≥ 20** |

### Règles méthodologiques

- **Surface d'un CFG × 40 doit être de 0,1734 mm²**
  - Calcul : (oculaire / 2 × objectif)² × π
  - Si différent → appliquer un **facteur de correction**
  - Exemple : oculaire 23 mm → CFG = 0,259 mm² → diviser le nombre de mitoses par **1,5**
- Éviter zones nécrotiques, stromales abondantes
- **Exclure** noyaux pycnotiques et mitoses douteuses
- Toutes les phases comptées (prophase, métaphase, anaphase, télophase)
- **Mitoses anormales** comptées
- Si compte borderline → **recompter** (pas de sous-évaluation)

### Pièges

| À compter | À ne PAS compter |
|-----------|------------------|
| Prophase, métaphase, anaphase, télophase | **Corps apoptotiques** (noyau ET cytoplasme denses) |
| Mitoses anormales (tripolaires, asymétriques) | Lymphocytes |
| | Polynucléaires neutrophiles |
| | Noyaux pycnotiques |

## Item 3 — Nécrose tumorale (score 0, 1 ou 2)

| Score | Nécrose |
|-------|---------|
| **0** | **Absente** |
| **1** | **< 50 %** du volume tumoral |
| **2** | **≥ 50 %** du volume tumoral |

### Évaluation

- **Macroscopique** (idéal : pièce complète) : plage molle grisâtre/jaunâtre
- **Microscopique** : à faible grandissement, plages rosées avec **fantômes cellulaires** (souvent à distance des vaisseaux)
- **Imagerie** (IRM T2 + gadolinium) : zone centrale sans rehaussement

## Limites du grade FNCLCC

- **Sur microbiopsie** (petit volume) :
  - **Index mitotique** possiblement sous-évalué
  - **Nécrose** sous- ou surévaluée
  - **Différenciation** possiblement discordante → reclassification possible sur la pièce
- **Variabilité inter-observateur**
- Grade sans intérêt si la tumeur a **déjà métastasé**
- Ne s'applique PAS aux sarcomes **post-traitement** (chimio/radio préopératoire)

## Grading moléculaire (CINSARC)

- Profil d'expression de **67 gènes**
- Classe les tumeurs en **bas** ou **haut risque métastatique**
- Très **reproductible**, applicable sur paraffine
- Plus coûteux que le FNCLCC

## 🔑 Points clés à retenir

1. **FNCLCC** = système de grading des sarcomes des **tissus mous non traités** (pas osseux, pas post-traitement)
2. Grade = **somme de 3 scores** : **différenciation (1-3) + mitoses (1-3) + nécrose (0-2)**
3. **G1 (2-3), G2 (4-5), G3 (≥ 6)**
4. **Différenciation** : 1 = tissu normal ; 2 = type certain ; **3 = indifférencié**
5. Mitoses comptées sur **10 CFG consécutifs à × 40 (0,1734 mm²)**, **zone la plus mitotique** — attention au **facteur de correction** microscope
6. Nécrose seuil **50 %** ; évaluation **macro + micro + imagerie**
7. **Sarcomes qui ne se gradent pas** : angiosarcome, sarcome épithélioïde, cellules claires, alvéolaire, Ewing, DSRCT
8. **Les 3 items restent dans le compte-rendu** même si non gradés
9. Grade **sous-évalué** sur microbiopsie (petit volume, tumeur hétérogène)
10. **CINSARC** = grading moléculaire émergent (67 gènes), très reproductible

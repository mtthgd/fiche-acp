# CAT devant un prélèvement de synoviale

> Liens : [[10b_Synoviale normale]] | [[21_Analyse biopsie et liquide synovial]] | [[22_Pathologies microcristallines]] | [[23_Lésions kystiques articulaires]] | [[24_Pathologie des prothèses]]

## Types de prélèvements reçus

> ⚠️ **Tout prélèvement articulaire doit être couplé à un examen bactériologique.**

### Modalités de prélèvement
- Sous **arthroscopie**
- Sous **imagerie** (radio, échographie)
- **Voie chirurgicale**

### Types tissulaires
| Type | Remarques |
|------|-----------|
| **Synoviale articulaire** | Le plus fréquent |
| **Ténosynoviale** (gaines tendineuses) | — |
| **Capsule** | Souvent prélevée avec la synoviale |
| Ligaments, tendons, **enthèses** | Enthèses = zones d'insertion, jamais prélevées isolément |
| **Corps étrangers intra-articulaires** | — |
| **Lésions kystiques**, nodules juxta-articulaires | Pièce d'exérèse |
| Cartilage, **fibrocartilages** (ménisques), fragments de disques intervertébraux | — |
| Liquide articulaire | Cytologie (cours dédié) |

**Pathologie ostéo-articulaire non tumorale** : le plus souvent **ponctions-biopsies** ou pièces d'exérèse (arthrose, pose de prothèse).

## Acheminement et réception

| Étape | Modalités |
|-------|-----------|
| Contenant | **Sec**, jamais de compresse ni liquide (abîme les cellules) |
| État | **Non fixé** si possible |
| Température | Ambiante ou **+4°C** quelques heures (réfrigérateur OK) |
| À l'arrivée | Description macroscopique + mesure avant fixation |

## Macroscopie

Éléments à décrire :
- **Hyperplasie** de la synoviale
- **Couleur** (orangée/rouille = hémarthrose ou synovite villo-nodulaire ; noirâtre = métallose)
- **Dépôts identifiables** (crayeux blanchâtres = microcristallins ; noirs/gris/jaunes = débris prothétiques ; framboisés = chondromatose)
- **Franges**, vaisseaux congestifs (congestion = quasi systématique en cas d'hyperplasie)
- Corps étrangers

## Fixation — règle capitale

> ⚠️ **Fixateur non acide OBLIGATOIRE** : formol **neutre ou tamponné**.
>
> Raison : un fixateur acide dissoudrait les **dépôts calciques** (pyrophosphate de calcium +++) et ferait manquer le diagnostic.

### Prélèvements mixtes
Lorsqu'un prélèvement contient tissu mou + os (ex. tête fémorale + synoviale) :
- **Séparer** les deux
- Tissus mous → circuit habituel
- Tissus osseux/minéralisés → **décalcification** (uniquement sur fragment bien fixé, cycles fixation-décalcification sous surveillance)

## Échantillonnage et techniques

- **Congélation rarement utile** (bactériologie particulière, recherche)
- **Échantillonnage attentif** à l'état frais ou après fixation (plus facile après fixation : synoviale rigide, couleurs qui tranchent)
- **Multiplier les prélèvements** : lésions hétérogènes
- Cibler : **foyers d'hyperplasie**, zones de coloration anormale, dépôts, corps étrangers, zones différentes de la synoviale adjacente
- Inclusion paraffine standard, **HES suffit le plus souvent**
- **Niveaux de coupe supplémentaires** si hétérogénéité ou suspicion de lésion focale
- **Immunohistochimie rarement nécessaire**
- **Microscope à lumière polarisée indispensable** : microcristaux, corps étrangers, débris prothétiques

## Correspondances macroscopiques — synthèse

| Aspect macro | Orientation diagnostique |
|--------------|-------------------------|
| Longues franges avec vaisseaux congestifs | Banal, non spécifique |
| **Couleur orangée / rouille** | **Hémarthrose** ou **synovite villo-nodulaire** |
| Plages / dépôts **crayeux blanchâtres** | Dépôts **microcristallins** |
| Franges infiltrées "en corail" | Dépôts cristallins diffus |
| **Zones noires / grises / jaunâtres** péri-prothétiques | **Métallose** (débris d'usure prothétique) |
| Petits foyers **framboisés** | **Chondromatose synoviale** |

## 🔑 Points clés à retenir

1. **Bactériologie systématiquement couplée** à tout prélèvement articulaire
2. **Non fixé**, contenant sec, pas de compresse ni liquide
3. **Fixateur NEUTRE ou TAMPONNÉ obligatoire** (un fixateur acide dissout les cristaux de **pyrophosphate de Ca**)
4. Si mélange tissu mou + os : **séparer** avant décalcification
5. **Échantillonnage multiple** ciblant zones hétérogènes (hyperplasie, dépôts, couleur anormale)
6. **HES standard + niveaux de coupe** ; immunohistochimie rarement utile
7. **Lumière polarisée indispensable** (microcristaux, débris prothétiques)
8. Macro-signaux : **orangé = hémarthrose/SVN** ; **crayeux = microcristaux** ; **noir/gris = métallose** ; **framboisé = chondromatose**
9. Congestion des franges = constante dès qu'il y a hyperplasie
10. Biopsie synoviale surtout utile dans la **monoarthrite chronique inexpliquée**

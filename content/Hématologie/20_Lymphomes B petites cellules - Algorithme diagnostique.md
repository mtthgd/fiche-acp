# Algorithme diagnostique des lymphomes B à petites cellules

> Liens : [[03_Ganglion - Ontogénie lymphocytaire et réarrangement de gènes]] | [[21_Lymphome folliculaire - Formes usuelles]] | [[23_LLC-B]] | [[24_Lymphome du manteau]] | [[25_Lymphomes zone marginale et LPL]] | [[26_Lymphome MALT]]

## Classification OMS 2016

47 sous-types de lymphome B dont **28 à petites cellules** (inclut certaines entités provisoires).

**Principaux LBpc ganglionnaires** :
- Lymphome folliculaire (LF)
- Lymphome lymphocytique / LLC-B
- Lymphome du manteau (MCL)
- Lymphome lymphoplasmocytaire / Waldenström
- Lymphome ganglionnaire de la zone marginale (NMZL)

**Extra-ganglionnaires** : lymphome MALT

**Spléniques** : splénique zone marginale (SMZL), leucémie à tricholeucocytes (HCL), lymphome splénique de la pulpe rouge

### Épidémiologie (répartition des LNH)

B-NHL = **78 %** des LNH, T-NHL 6 %, Hodgkin 14 %. Parmi les B-NHL : DLBCL le plus fréquent, puis **LF (19,6 %)**, MALT (7,5 %), **LLC/SLL (7,1 %)**, **MCL (5,5 %)**.

## Cellule d'origine

| Stade de différenciation B | Lymphomes dérivés |
|---------------------------|-------------------|
| Cellule B immature (moelle) | LAL-B |
| **B naïf** (pré-CG) | LLC-B, **MCL** |
| **Centre germinatif** (centroblaste/centrocyte) | **LF**, DLBCL GCB, Burkitt |
| **Post-CG** (B mémoire, plasmocyte) | NMZL, MALT, SMZL, Waldenström, HCL |
| DLBCL non-GCB | Post-CG |
| Plasmocyte | Myélome |

Chaque entité possède un profil mutationnel propre (NOTCH1/XPO1 pour LLC/MCL ; CREBBP/EZH2 pour LF ; MYD88/CXCR4 pour WM ; BRAF pour HCL...).

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/lymphome_b_petites_cellules/Diaporama%2007-321_Algorithme%20diagnostique%20des%20lymphomes%20B%20%C3%A0%20petites%20cellules_FINAL/p06_02.jpeg)

## Marqueurs immunohistochimiques

### Pan-B à vérifier d'emblée
**CD20, CD79A, PAX5, Oct2, Bob1** → positifs dans tous les LBpc
CD3 → **négatif** (élimine lymphome T)

### Marqueurs orientateurs

| Marqueur | Signification | Positif dans |
|----------|--------------|-------------|
| **CD10** | Centre germinatif | LF (++), Burkitt, DLBCL GCB |
| **BCL6** | CG | LF, DLBCL GCB |
| **BCL2** | Anti-apoptotique | LF (++), LLC, MCL (physiologique dans manteau) |
| **CD5** | Marqueur T aberrant | LLC, MCL |
| **CD23** | Récepteur IgE, FDC | LLC, réseau FDC |
| **Cycline D1** | Cycle cellulaire | **MCL** (spécifique), faible/hétérogène dans HCL, myélome |
| **SOX11** | Facteur transcription | MCL (++, y compris cycline D1−) |
| **MUM1/IRF4** | Post-CG/plasmocytaire | NMZL, DLBCL non-GCB, plasmocytes |
| **CD38** | Plasmocytaire | Myélome, LPL |
| **Annexine A1** | Spécifique | Leucémie à tricholeucocytes |
| **BRAF V600E** | Mutation BRAF | HCL (+++) |
| **DBA44, CD103** | HCL | HCL |

Distinguer :
- **SMZL** (splénique zone marginale) : infiltrat biphasique, cellules centrales + zone marginale, **MYD88 L265P** parfois +
- **HCL** (leucémie à tricholeucocytes) : pulpe rouge diffusément envahie, cytoplasme clair, **Annexine A1+, BRAF V600E+, DBA44+, CD103+**
- **Lymphome splénique diffus de la pulpe rouge** : entité distincte

## Anomalies moléculaires / FISH

| Lymphome | Anomalie | Technique |
|---------|---------|-----------|
| **LF** | t(14;18) *BCL2-IGH* (90%) | FISH, IHC BCL2 |
| **MCL** | t(11;14) *CCND1-IGH* | FISH, IHC cycline D1 |
| **MALT** | t(11;18), t(14;18), t(3;14) *MALT1, BCL10, FOXP1* | FISH |
| **HCL** | Mutation **BRAF V600E** | PCR, IHC BRAF-V600E |
| **LPL/Waldenström** | Mutation **MYD88 L265P** | PCR |
| LLC-B | Délétions 13q, 11q, 17p (TP53) | FISH/hémato |

## Algorithme décisionnel

```
Lymphoprolifération B à petites cellules (CD20+ CD3−)
             │
             ├─ CD5 positif ?
             │      ├─ OUI + Cycline D1+ → LYMPHOME DU MANTEAU
             │      ├─ OUI + Cycline D1− + CD23+ → LLC-B
             │      └─ OUI + Cycline D1− + CD23− + SOX11+ → MCL cycline D1−
             │      └─ OUI + Cycline D1− + CD23− + SOX11− → LLC
             │
             ├─ CD5− + CD10+ ?
             │      → LYMPHOME FOLLICULAIRE
             │        (BCL2+, réseau FDC CD21+/CD23+, FISH BCL2 si BCL2−)
             │
             ├─ CD5− + CD10− + IgM+ + CD38+ + MYD88 L265P ?
             │      → WALDENSTRÖM / LPL
             │
             ├─ CD5− + CD10− + MUM1+ (ganglion) ?
             │      → LYMPHOME GANGLIONNAIRE ZONE MARGINALE
             │
             ├─ CD5− + CD10− + cytokératine lympho-épithéliales (muqueuse) ?
             │      → LYMPHOME MALT
             │
             └─ CD5− + CD10− + BRAF V600E / Annexine A1 / CD103+ ?
                    → LEUCÉMIE À TRICHOLEUCOCYTES
```

## Utilité de l'étude de clonalité B

- Si morphologie + IHC ne permettent pas un diagnostic formel de lymphome
- Recherche de réarrangement VJ IgH (FR1/FR2/FR3) par PCR
- **Attention** : monoclonalité ≠ malignité (voir [[03_Ganglion - Ontogénie lymphocytaire et réarrangement de gènes]])

## 🔑 Points clés à retenir

1. Classer d'abord en **B (CD20+)** vs T (CD3+), puis en **petites** vs grandes cellules
2. **CD5** est le premier marqueur discriminant : CD5+ → LLC ou MCL ; CD5− → LF, NMZL, MALT, LPL, HCL
3. **Cycline D1** = MCL (vérifier systématiquement si CD5+ lymphome B)
4. **SOX11** = outil pour les rares MCL cycline D1− (CCND2/CCND3)
5. **CD10 + BCL2** = lymphome folliculaire (90% t(14;18))
6. LF BCL2− : tester plusieurs clones (E17, SP66) puis FISH BCL2, voire BCL6/IRF4
7. **MYD88 L265P** = Waldenström/LPL (hautement sensible)
8. **BRAF V600E** = HCL, révolutionné le diagnostic (IHC + PCR)
9. MALT : translocations *MALT1/BCL10/FOXP1* (11;18), (14;18), (3;14)
10. CD79A est le seul marqueur pan-B couvrant toute la lignée (incluant plasmocyte)

# Lymphadénites virales, auto-immunes et dysimmunitaires

> Liens : [[10_Lymphadénites - Lésions élémentaires]] | [[11_Lymphadénites - Granulomateuses]] | [[12_Lymphadénites - Histiocytaires]] | [[32_Lymphomes B EBV]]

## A. Lymphadénites virales

### 1. Lymphadénite VIH

Le virus infecte : **lymphocytes CD4+**, macrophages, cellules folliculaires dendritiques.

**Clinique** : lymphadénopathie persistante généralisée (LPG).

**4 types histologiques** :

| Type | Aspect histologique |
|------|---------------------|
| **1** (le + fréquent) | Hyperplasie folliculaire floride, CG bizarres, **folliculolyse**, cellules plurinucléées, atrophie du manteau, plasmocytose |
| **2** | Angio-immunoblastique-like : effacement folliculaire, immunoblastes + plasmocytes + histiocytes + hyperplasie vasculaire |
| **3** | **Déplétion lymphoïde** T et B, disparition des follicules, fibrose |
| **4** (rare) | Castelman multicentrique-like |

**Pathologies associées** : infections opportunistes, lymphomes (DLBCL, Burkitt, primaire cavités), **sarcome de Kaposi**, Castelman HHV8+.

### 2. Mononucléose infectieuse (primo-infection EBV)

**Clinique** : sujet jeune/adolescent, polyadénopathies + fièvre + asthénie + angine ± splénomégalie.

**Histologie** :
- Hyperplasie immunoblastique interfolliculaire avec cellules **Reed-Sternberg-like**
- Aspect Piringer-like possible (hyperplasie B monocytoïde, petits nids épithélioïdes)
- Territoires de nécrose → aspect SPC-like
- Parfois hémophagocytose

**Diagnostic** : hybridation in situ **EBER+** (ou LMP1 en IHC)

**DD** : lymphome de Hodgkin, lymphomes non hodgkiniens.

![[assets/hematologie/lymphadenites/Diaporama 07-225_lymphadenite infectieuses, dysimmunitaires/p08_05.jpeg]]

### 3. Lymphadénite herpétique (HSV)

**Clinique** : lésions cutanéo-muqueuses, surtout chez l'immunodéprimé.

**Histologie** :
- Nécrose suppurée + couronne histiocytaire
- ± hyperplasie immunoblastique, folliculaire, lymphocytose B sinusale
- **Inclusions nucléaires** caractéristiques :
  - Homogènes en verre dépoli
  - Ou éosinophiles entourées d'un halo clair
- Mise en évidence par IHC anti-HSV

![[assets/hematologie/lymphadenites/Diaporama 07-225_lymphadenite infectieuses, dysimmunitaires/p09_06.jpeg]]

![[assets/hematologie/lymphadenites/Diaporama 07-225_lymphadenite infectieuses, dysimmunitaires/p09_07.jpeg]]

### 4. Lymphadénite à CMV

**Clinique** : primo-infection CMV, syndrome pseudo-grippal, polyadénopathies, hépatosplénomégalie, diarrhée.

**Histologie** :
- Hyperplasie folliculaire, immunoblastique, B monocytoïde ± petits amas histiocytaires
- **Inclusions cytomégaliques** caractéristiques :
  - Basophiles, intranucléaires, grandes
  - Entourées d'un halo clair → **aspect en "œil de hibou"** (piège DD Hodgkin !)
  - Présentes surtout dans les **cellules endothéliales**
- Confirmation par IHC anti-CMV

**DD principal** : lymphome de Hodgkin (cellules Reed-Sternberg-like).

## B. Lymphadénopathies auto-immunes

### Polyarthrite rhumatoïde
- Adénopathies dans 50% des cas
- Hyperplasie folliculaire + dépôts **PAS+** dans les CG
- Infiltration capsulaire/péri-ganglionnaire par lymphocytes
- DD : lymphome

### Lupus érythémateux disséminé
- Hyperplasie folliculaire
- Amas de PNN + plasmocytose
- **Corps hématoxyliques** dans les sinus (caractéristique)
- Parfois aspect Kikuchi-like (mais PNN présents + corps hématoxyliques)
- Fibrose lamellaire péri-artériolaire

### Autres (sclérodermie, dermatomyosite, Sjögren, PAN)
- Aspects superposables à la PR

## C. Lymphadénopathies dysimmunitaires

### 1. Hypersensibilité médicamenteuse (DRESS)

**Médicaments** : hydantoïnes, paracétamol, phénylbutazone...

**Délai** : quelques jours à plusieurs semaines

**Clinique** : polyadénopathies + rash cutané + fièvre

**Histologie** :
- Hyperplasie immunoblastique floride
- **Nombreux PNN éosinophiles** + plasmocytes + PNN neutrophiles
- ± nécrose fibrinoïde avec cristaux de Charcot-Leyden

**DD** : maladie de Kimura, lymphadénite parasitaire, Hodgkin, lymphome T type AITL.

![[assets/hematologie/lymphadenites/Diaporama 07-225_lymphadenite infectieuses, dysimmunitaires/p13_12.jpeg]]

### 2. Déficits immunitaires congénitaux

| Déficit | Histologie ganglionnaire |
|---------|-------------------------|
| **DICV** (humoral) | Hyperplasie folliculaire + immunoblastique ± lésions granulomateuses (Kikuchi-like possible) |
| **Ataxie-télangiectasie** (cellulaire) | **Hypoplasie** des zones corticales profondes |
| **Syndrome de Purtilo / XLP** | Mononucléose-like sévère, hémophagocytose (EBV gravissime) |

### 3. Syndrome lymphoprolifératif auto-immun (ALPS)

**Étiologie** : mutation **FAS** → déficit apoptose médiée par FAS.

**Clinique** : enfant/adulte jeune, adénopathies + splénomégalie + manifestations auto-immunes + hypergammaglobulinémie.

**Histologie** :
- Hyperplasie folliculaire floride + immunoblastique + plasmocytose
- **Lymphocytes T double négatifs (CD4− CD8−) CD56+** dans les zones interfolliculaires et périfolliculaires (**caractéristique IHC**)

**Risque** : évolution vers **lymphome** (Hodgkin ou non Hodgkin)

**Diagnostic** : lymphocytes DN dans le sang + auto-anticorps

![[assets/hematologie/lymphadenites/Diaporama 07-225_lymphadenite infectieuses, dysimmunitaires/p15_14.png]]

### 4. Maladie à IgG4

**Clinique** : atteinte multi-organes (pancréas, glandes salivaires, voies biliaires, fibrose rétropéritonéale) + adénopathies médiastinales/intra-abdominales/axillaires.

**Biologie** : IgG4 sériques > 135 mg/dL.

**5 types histologiques** :
1. Hyperplasie folliculaire
2. Castelman-like
3. Expansion lymphoplasmocytaire interfolliculaire
4. Transformation progressive des CG
5. Pseudo-tumeur inflammatoire

**Critères diagnostiques** :
- **> 50 cellules IgG4+/champ (×400)** OU
- **Ratio IgG4/IgG > 40%**

**DD** : lymphome, maladie de Castelman.

## 🔑 Points clés à retenir

1. VIH : 4 types histologiques — type 1 (folliculolyse) le plus fréquent, **type 4 (Castelman-like)** rare
2. **MNI** → hybridation **EBER systématique** devant toute lymphadénite à cellules Reed-Sternberg-like chez un jeune
3. Herpès : inclusions nucléaires en verre dépoli ou éosinophiles avec halo
4. **CMV : inclusions en "œil de hibou"** dans les cellules endothéliales → piège DD Hodgkin
5. Lupus : PNN + **corps hématoxyliques** (absents dans Kikuchi)
6. **ALPS = lymphocytes T double négatifs CD4−/CD8−/CD56+** + mutation FAS
7. **Maladie IgG4** : > 50 cellules IgG4+/champ OU ratio IgG4/IgG > 40%
8. Devant toute "lymphadénite du jeune" : penser Kikuchi, MNI, lupus, ALPS — et toujours rechercher un lymphome caché

# Hémopathies myéloïdes — Classification OMS 2017/2022

> Liens : [[70_BOM normale]] | [[71_BOM - Lésions réactionnelles]] | [[75_NMP Philadelphie négatives]] | [[76_MDS, LA et syndromes de chevauchement]] | [[77_Mastocytoses médullaires]] | [[72_BOM - Lymphomes]] | [[73_BOM - Néoplasies plasmocytaires]]

## Généralités

- **Classification OMS 2017** = révision majeure de l’OMS 2008, publiée dans *Blood* 2016
- Résultat de **4 ans de travaux** internationaux (1ère réunion à Chicago en 2014)
- Justification : accumulation de **nouvelles données moléculaires** (NGS), **cytométrie en flux** étendue, intégration biologie/cytologie/histologie/cytogénétique
- L’OMS 2022 (5e édition) prolonge cette intégration en accentuant les bases **génétiques** des entités

### Historique des classifications

| Année | Classification |
|-------|----------------|
| 1966 | Première classification du système hématopoïétique |
| 1976-82 | **FAB** (French-American-British) — morphologique |
| 2000 | **1ère OMS** — intégration multi-paramètres |
| 2008 | OMS 4e édition |
| **2017** | **OMS 4e édition révisée** (référence du cours) |
| 2022 | OMS 5e édition |

## Données intégrées au diagnostic

Chaque diagnostic d’hémopathie myéloïde repose désormais sur **5 piliers** :

| Pilier | Apport diagnostique |
|--------|--------------------|
| **Clinique / NFS** | Cytopénies, hyperleucocytose, monocytose, éosinophilie, thrombocytose |
| **Cytologie** (myélogramme) | Morphologie, **% blastes** (référence) |
| **Histologie** (BOM) | Cellularité, fibrose, clusters CD34+, mégacaryocytes |
| **Cytométrie en flux** | Phénotype des blastes, dysplasie, lignée |
| **Cytogénétique + biologie moléculaire** | Translocations, mutations driver/pronostiques |


![[assets/hematologie/hemopathies-myeloides/Diaporama 07-550_Classification OMS 2017  myeloide DES/p04_07.jpeg]]

## Architecture de la classification OMS 2017

7 grands chapitres :

1. **Néoplasies myéloprolifératives chroniques (NMP)**
2. **Mastocytoses** (chapitre indépendant depuis 2017, voir [[77_Mastocytoses médullaires]])
3. **Néoplasies myéloïdes/lymphoïdes avec éosinophilie** et anomalies *PDGFRA / PDGFRB / FGFR1 / PCM1-JAK2*
4. **Néoplasies MDS/MPN** (chevauchement)
5. **Syndromes myélodysplasiques (MDS)**
6. **Néoplasies myéloïdes avec prédisposition germinale** (*nouveau chapitre*)
7. **Leucémies aiguës myéloïdes (LAM)** et leucémies aiguës de lignée ambiguë



## 1. Néoplasies myéloprolifératives chroniques (NMP)

| Entité | Anomalie clé |
|--------|--------------|
| **LMC** (BCR-ABL1+) | **t(9;22)(q34;q11)** — gène de fusion *BCR-ABL1* (Philadelphie) |
| Leucémie chronique à neutrophiles (LCN) | *CSF3R* T618I |
| **Polyglobulie de Vaquez (PV)** | **JAK2 V617F** (>95 %) ou exon 12 |
| **Myélofibrose primitive (MFP)** | *JAK2 / CALR / MPL* |
| **Thrombocytémie essentielle (TE)** | *JAK2 / CALR / MPL* |
| Leucémie chronique à éosinophiles, NOS | – |
| NMP non classables (NMP-U) | – |

→ Voir [[75_NMP Philadelphie négatives]] pour PV / TE / MFP



### Arbre décisionnel diagnostique des NMP Phi-négatives

```
Suspicion de NMP Phi-négative (BCR-ABL1 négatif)
              │
              ├─ JAK2 V617F + ?
              │     ├─ Polyglobulie ? → PV (confirmer EPO basse)
              │     ├─ Thrombocytose isolée ? → TE
              │     └─ Fibrose médullaire ? → MFP
              │
              ├─ JAK2 V617F − → tester JAK2 exon 12 (PV)
              │                 ou CALR / MPL W515 (TE/MFP)
              │
              └─ Triple négatif (JAK2/CALR/MPL −)
                    → Reclassement, séquençage NGS étendu
```



## 2. Néoplasies myéloïdes/lymphoïdes avec éosinophilie

- Entités **rares** mais à reconnaître : pouvant **répondre aux inhibiteurs de tyrosine kinase** (imatinib, ruxolitinib)
- Anomalies récurrentes obligatoires :

| Anomalie | Gène |
|----------|------|
| t(5;12) ou variant | ***PDGFRB*** |
| del(4)(q12) cryptique | ***PDGFRA*** (*FIP1L1-PDGFRA*) |
| t(8;13) ou variant | ***FGFR1*** |
| **t(8;9)** | ***PCM1-JAK2*** (*entité provisoire*) |

> Le pathologiste évoque le diagnostic devant une moelle hyper-cellulaire avec **éosinophilie franche** ; la confirmation est moléculaire.



## 3. Néoplasies MDS/MPN (chevauchement)

Entités présentant à la fois **dysplasie** ET **prolifération** :

| Entité | Caractéristique |
|--------|-----------------|
| **LMMC** (leucémie myélomonocytaire chronique) | **Monocytose persistante > 1 G/L** (≥10 % des leucocytes) |
| **LMC atypique** (BCR-ABL1−) | Prolifération granuleuse + dysplasie, pas de monocytose |
| Leucémie myélomonocytaire juvénile (LMMJ) | Enfant, *PTPN11 / NRAS / NF1 / CBL* |
| **MDS/MPN-RS-T** | Sidéroblastes en couronne **+ thrombocytose** ; *SF3B1* + *JAK2* (entité distincte depuis 2017) |
| MDS/MPN-U | Inclassable |

## 4. Syndromes myélodysplasiques (MDS) — OMS 2017

| Sous-type OMS 2017 | Critères |
|--------------------|----------|
| **MDS-SLD** (single-lineage dysplasia) | Dysplasie 1 lignée, < 5 % blastes |
| **MDS-MLD** (multilineage) | Dysplasie ≥ 2 lignées |
| **MDS-RS-SLD** | Sidéroblastes en couronne, dysplasie 1 lignée |
| **MDS-RS-MLD** | Idem + multilignées |
| **MDS-EB-1** | Excès de blastes : 5-9 % moelle / 2-4 % sang |
| **MDS-EB-2** | Excès de blastes : 10-19 % moelle / 5-19 % sang |
| **MDS del(5q)** | Délétion 5q isolée, mégacaryocytes monolobés |
| MDS-U (inclassable) | – |
| Cytopénie réfractaire de l’enfant | Pédiatrique |

→ Détails dans [[76_MDS, LA et syndromes de chevauchement]]





## 5. Néoplasies myéloïdes avec prédisposition germinale (nouveau OMS 2017)

- Majorité des hémopathies myéloïdes = clonales **acquises**
- Petit sous-groupe d’**origine familiale**, mutation **germinale**
- À noter à côté du diagnostic principal
- 11 mutations établies depuis 1999 (ordre de découverte) : *RUNX1*, *CEBPA*, *DDX41*, *GATA2*, *ANKRD26*, *ETV6*, *SAMD9*, *SAMD9L*, *MBD4*, *ATG2B/GSKIP*, etc.

| Indication potentielle de screening |
|-------------------------------------|
| Histoire familiale de plusieurs cancers hématologiques |
| Enfants / jeunes adultes (11-24 % des séries pédiatriques) |
| Antécédent de **PTI / thrombopénie** au long cours |
| Infections inhabituelles, déficit immunitaire |

![[assets/hematologie/hemopathies-myeloides/Diaporama 07-550_Classification OMS 2017  myeloide DES/p12_00.png]]



## 6. Leucémies aiguës myéloïdes (LAM)

4 sous-groupes OMS 2017 :

| Sous-groupe | Exemples |
|-------------|----------|
| **LAM avec anomalies génétiques récurrentes** | **t(8;21)** *RUNX1-RUNX1T1* ; **inv(16)/t(16;16)** *CBFB-MYH11* ; **t(15;17)** *PML-RARA* (LAP) ; **NPM1** muté ; *CEBPA* biallélique ; *RUNX1* muté (provisoire) |
| **LAM avec anomalies associées à myélodysplasie** (LAM-MRC) | Caryotype complexe, monosomie 5/7, antécédent MDS |
| **LAM secondaires post-thérapeutiques** | Mutation **TP53** fréquente |
| **LAM, NOS** (sans autre spécification) | LAM mégacaryoblastique, érythroïde pure, etc. |

![[assets/hematologie/hemopathies-myeloides/Diaporama 07-550_Classification OMS 2017  myeloide DES/p14_00.jpeg]]




### Mutations pronostiques majeures dans les LAM

| Mutation | Impact pronostique |
|----------|--------------------|
| **NPM1** (sans FLT3-ITD) | **Favorable** |
| ***FLT3-ITD*** (haut ratio allélique) | **Défavorable** (cible midostaurine) |
| *CEBPA* biallélique | Favorable |
| **TP53** | Très défavorable, post-thérapeutique++ |
| *ASXL1, RUNX1, SRSF2* | Défavorables |
| Caryotype complexe (≥ 3 anomalies) | Défavorable |


![[assets/hematologie/hemopathies-myeloides/Diaporama 07-550_Classification OMS 2017  myeloide DES/p16_01.jpeg]]

## 7. Leucémies aiguës de lignée ambiguë

- Inchangées par rapport à 2008
- **Marqueurs définissant la lignée** :

| Lignée | Marqueur défini |
|--------|------------------|
| **Myéloïde** | **Myéloperoxydase (MPO)** |
| **T** | **CD3 cytoplasmique ou membranaire** |
| **B** | **CD19 fort** + CD79a / CD22 cytoplasmique / CD10 |

- **LA de phénotype mixte** (MPAL) :
  - 2 populations distinctes (chacune d’une lignée), OU
  - 1 population co-exprimant des marqueurs de plusieurs lignées (ex : MPO + CD19)
- LA indifférenciée (rare) : aucun marqueur de lignée



## Tableau de synthèse — algorithme global

| Étape | Question | Outil |
|-------|----------|-------|
| 1 | Cytopénie ou hyperleucocytose ? | NFS |
| 2 | % blastes ≥ 20 % ? | Myélogramme + BOM |
| 3 | Si oui : LAM (sous-typer par cytogénétique) | Caryotype + NGS |
| 4 | Si < 20 % : dysplasie ? | Cytologie + BOM |
| 5 | Dysplasie isolée → MDS | Caryotype |
| 6 | Dysplasie + prolifération → MDS/MPN | NFS (monocytes) |
| 7 | Prolifération sans dysplasie → NMP | JAK2/CALR/MPL/BCR-ABL1 |
| 8 | Éosinophilie inexpliquée → tester PDGFRA/B, FGFR1, JAK2 | FISH/PCR |
| 9 | Mastocytose suspecte → tester KIT D816V | Voir [[77_Mastocytoses médullaires]] |

## Diagnostics différentiels

| DD | Distinction |
|----|-------------|
| Dysplasie réactionnelle (carence B12/folates, alcool, médicaments, infections) | Réversible, **éliminer avant de poser MDS** |
| Hématopoïèse extramédullaire réactionnelle | Pas de prolifération clonale, pas de blastes |
| Métastases médullaires d’un carcinome | Cytokératines+, pan-B/T négatifs |
| Infiltration lymphoïde (lymphome, plasmocytome) | Voir [[72_BOM - Lymphomes]] et [[73_BOM - Néoplasies plasmocytaires]] |

## Pronostic

- Scores spécifiques selon l’entité : **IPSS-R / IPSS-M** (MDS), **MIPI**-like ELN (LAM), **DIPSS** (MFP)
- Intégration **mutationnelle** : *TP53*, *ASXL1*, *SRSF2*, *RUNX1* = défavorables
- Évolution possible **MDS → LAM** (≈ 30 % des MDS)

## 🔑 Points clés à retenir

1. **OMS 2017 = intégration multimodale** : clinique + cytologie + histologie (BOM) + cytométrie + cytogénétique + biologie moléculaire
2. **7 chapitres** : NMP, mastocytoses (chapitre **propre** depuis 2017), néoplasies avec éosinophilie, MDS/MPN, MDS, prédisposition germinale, LAM
3. **Seuil 20 % de blastes** = frontière MDS / LAM
4. **JAK2 V617F** dépisté en 1ère intention dans toute NMP Phi-négative ; CALR / MPL si JAK2−
5. **BCR-ABL1 (t(9;22))** = LMC ; toujours l’éliminer avant de poser une autre NMP
6. **Anomalies récurrentes des LAM** définissant l’entité : t(8;21), inv(16), t(15;17), NPM1, CEBPA biallélique
7. **Mastocytoses** = entité OMS indépendante depuis 2017 (avant : NMP)
8. **MDS/MPN-RS-T** : nouveau chapitre 2017, *SF3B1* + *JAK2* / sidéroblastes + thrombocytose
9. **Prédisposition germinale** = nouveau chapitre 2017 (RUNX1, CEBPA, DDX41, GATA2…) → screening familial
10. **TP53** muté = LAM post-thérapeutiques, pronostic défavorable
11. **ASXL1 / SRSF2 / RUNX1** = facteurs pronostiques défavorables transversaux
12. La BOM est **indispensable** dans les MDS hypoplasiques, fibrosés, ou inclassables sur myélogramme

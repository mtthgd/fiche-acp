# Histologie fonctionnelle du ganglion lymphatique

> Liens : [[01_Ganglion - CAT biopsie ganglionnaire]] | [[03_Ganglion - Ontogénie lymphocytaire et réarrangement de gènes]] | [[10_Lymphadénites - Lésions élémentaires]]

## Architecture générale

Le ganglion lymphatique (≈ 1000 chez l'homme, taille normale ≤ 1 cm) filtre la lymphe et permet l'activation lymphocytaire.

### Compartiments

| Zone | Phénotype dominant | Structures clés |
|------|-------------------|-----------------|
| **Corticale externe** | B (CD20+) | Follicules lymphoïdes primaires/secondaires |
| **Corticale profonde (paracortex)** | T (CD3+, CD4++) | Vénules post-capillaires (HEV) |
| **Médullaire** | Mixte | Cordons (plasmocytes), sinus (macrophages) |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/ganglion_lymphatique_generalites/Diaporama%2007-120_Histologie%20fonctionnelle%20ganglion%20tjm%200812/p06_01.jpeg)

### Circulation

- Lymphe afférente (convexité) → sinus sous-capsulaire → sinus corticiaux → lymphatique efférent (hile)
- Vascularisation sanguine terminale → vénules post-capillaires (HEV) en paracortex

## Follicule lymphoïde

### Follicule primaire (quiescent)
- Petits lymphocytes B IgM+ IgD+ CD20+ BCL2+
- Réseau de cellules folliculaires dendritiques (FDC) CD21+ CD23+

### Follicule secondaire (actif)
Structure **polarisée** :
- **Zone sombre** : centroblastes (grandes cellules, nucléoles périphériques) → prolifération + hypermutation somatique
- **Zone claire** : centrocytes (noyaux clivés irréguliers, chromatine dense) → switch isotypique, cellules mémoire, précurseurs plasmocytes
- **Manteau** : petits lymphocytes IgD+ BCL2+
- **Zone marginale** (rare dans le ganglion) : cellules cytoplasme plus abondant

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/ganglion_lymphatique_generalites/Diaporama%2007-120_Histologie%20fonctionnelle%20ganglion%20tjm%200812/p07_03.jpeg)

### Phénotype centre germinatif réactionnel
- CD10+ BCL6+ **BCL2−** (critère de réactivité)
- Index prolifératif Ki67 élevé avec **répartition zonale**
- Macrophages à corps tingibles (corps apoptotiques) → aspect ciel étoilé

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/ganglion_lymphatique_generalites/Diaporama%2007-120_Histologie%20fonctionnelle%20ganglion%20tjm%200812/p10_07.jpeg)

## Paracortex (zone T)

- Lymphocytes CD4++ (> CD8), ratio CD4/CD8 élevé
- **Cellules dendritiques interdigitées** : noyaux très irréguliers/chiffonnés, S100+ CD68+ CD1a+/−
- **Vénules post-capillaires (HEV)** : cellules endothéliales turgescentes, marqueur d'activation

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/ganglion_lymphatique_generalites/Diaporama%2007-120_Histologie%20fonctionnelle%20ganglion%20tjm%200812/p17_15.jpeg)

## Médullaire

- Cordons : **plasmocytes** + macrophages (sécréteurs d'Ig)
- Sinus médullaires : lymphocytes, quelques plasmocytes, macrophages

## Cellules accessoires

| Type | Localisation | Phénotype |
|------|-------------|-----------|
| Cellules dendritiques interdigitées | Paracortex, zone T | CD68+ S100+ CD1a+/− |
| Cellules folliculaires dendritiques (FDC) | Centre germinatif + manteau | CD21+ CD23+ (réseau) |
| Cellules dendritiques plasmocytoïdes | Près HEV, sinus | CD123+ CD68+(dot) GrzB+ |
| Histiocytes/macrophages | Sinus, centres germinatifs | CD68+ |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/hematologie/ganglion_lymphatique_generalites/Diaporama%2007-120_Histologie%20fonctionnelle%20ganglion%20tjm%200812/p26_29.jpeg)

> ⚠️ GranzB marque aussi les cellules dendritiques plasmocytoïdes (pas uniquement les lymphocytes T cytotoxiques !)

## Variantes topographiques normales

- Ganglions **mésentériques** : sinus souvent très distendus (normal)
- Ganglions **inguinaux** : fibrose fréquente (normal)

---

## 🔑 Points clés à retenir

1. Le ganglion comprend toujours des **sinus lymphatiques** (critère d'identification)
2. Corticale externe = **phénotype B**, corticale profonde = **phénotype T**
3. Centre germinatif réactionnel = **polarisé** (zone sombre centroblastes + zone claire centrocytes) + **BCL2−**
4. BCL2 est physiologiquement **positif dans le manteau**, négatif dans le CG réactionnel
5. Cellules FDC (CD21/CD23) : présentes dans le CG **et** le manteau
6. Macrophages à corps tingibles = signe de réactivité (apoptose physiologique)
7. Cellules dendritiques plasmocytoïdes : CD123+ marquage CD68 en dot

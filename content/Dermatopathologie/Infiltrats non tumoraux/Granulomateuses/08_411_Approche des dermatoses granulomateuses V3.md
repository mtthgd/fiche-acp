# Approche diagnostique des dermatoses granulomateuses

> Liens : [[08_412_Granulomes épithélioïdes V2]] | [[08_413_Granulomes palissadiques avec ou sans nécrobiose V2]] | [[08_415_Granulomes à CE- pdts comblements V2]]

## Définition du granulome

Le terme « granulome » a 2 acceptions :
1. **Sens large** : ensemble des éléments cellulaires d'une réaction inflammatoire (ex : « granulome de Lever » = infiltrat polymorphe lymphocytes/plasmocytes/PNN/éosinophiles/histiocytes)
2. **Sens restrictif** ++ : infiltrat **majoritairement constitué d'histiocytes / macrophages**, disposés en :
   - **Nodule / follicule** bien limité
   - **Plage** moins bien délimitée

Selon l'étiologie : ± lymphocytes, plasmocytes, PNN/éosinophiles, fibroblastes / fibrose (selon stade évolutif).

## Types d'histiocytes (non Langerhansiens)

### Histiocytes mononucléés

| Type | Cytologie | Contexte |
|------|-----------|----------|
| **Classique** | Cytoplasme modéré, noyau finement nucléolé | Variable |
| **Xanthomisé** | Cytoplasme **finement spumeux abondant** (lipides) | Xanthomes, xanthogranulomes |
| **Épithélioïde** | Grande taille, cytoplasme abondant, **limites peu nettes**, noyau **allongé** | Macrophages ayant **perdu** pouvoir de déplacement et de phagocytose, disposés de façon **cohésive** (« épithélium ») |

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p05_00.jpeg]]

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p05_01.jpeg]]

### Histiocytes plurinucléés (fusion d'histiocytes épithélioïdes)

| Type | Description | Contexte |
|------|-------------|----------|
| **Cellule de Langhans** | Noyaux disposés en **couronne** (Théodore Langhans, pathologiste allemand) | **Tuberculose**, sarcoïdose |
| **Cellule à corps étrangers (Müller)** | Noyaux **éparpillés au hasard** | Granulomes à corps étrangers |
| **Cellule de Touton** | Noyaux **en cercle au centre** + cytoplasme micro-vacuolé en périphérie (lipides) | **Xanthogranulomes** |

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p06_00.jpeg]]


## Classification des granulomes

Plusieurs approches :
- **Clinique** : localisé (granulome annulaire) vs disséminé (sarcoïdose)
- **Topographie** : cutané pur vs cutané + extra-cutané (sarcoïdose, infections)
- **Étiologique** : corps étranger, infectieuse, idiopathique
- **Architecturale** ++ (retenue ici)

### Architecture
- **Nodulaire**
- **Palissadique** (couronne d'histiocytes autour d'une zone centrale **modifiée** — collagène remanié)
- **Interstitiel** (histiocytes dispersés entre les faisceaux collagènes)

### + Caractéristiques associées
- Présence de **nécrose centrale** (caséeuse, fibrinoïde…)
- Phénomènes **suppuratifs** (PNN)
- Détection de **corps étrangers**
- **Nécrobiose** du collagène
- Autres cellules inflammatoires associées

## Algorithme classification

```
Granulome
   │
   ├─ ARCHITECTURE NODULAIRE
   │      ├─ Nu, sans nécrose, petit/ovalaire → SARCOÏDOSIQUE
   │      │      → sarcoïdose, corps étrangers, Crohn métastatique, granulomatose oro-faciale
   │      ├─ Mal limité, couronne lymphoplasmocytaire ± nécrose caséeuse → TUBERCULOÏDE
   │      │      → mycobactéries (TB, atypiques, lèpre), syphilis, leishmaniose, rosacée granulomateuse
   │      └─ Centré par PNN → SUPPURATIF
   │             → infections (mycoses, mycobactéries atypiques, parasites), kystes rompus (kératine)
   │
   ├─ ARCHITECTURE PALISSADIQUE
   │      ├─ Centre BLEU (mucine, débris nucléaires) → granulome annulaire, vasculite rhumatoïde, GPA
   │      └─ Centre ROUGE (fibrine, collagène hyalinisé, éosinophiles) → nodule rhumatoïde, nécrobiose lipoïdique, Churg-Strauss
   │
   ├─ ARCHITECTURE INTERSTITIELLE
   │      → granulome annulaire interstitiel, dermatose interstitielle granulomateuse (DIG)
   │      ⚠️ Bleu alcian indispensable
   │
   └─ CORPS ÉTRANGER identifié → granulome à corps étranger
          → biréfringence en lumière polarisée
```

## Granulomes sarcoïdosiques (cf 08-412)

- Petits granulomes **arrondis ou ovalaires**, **bien limités**
- Histiocytes épithélioïdes + quelques cellules plurinucléées (Langhans ou corps étranger)
- **Adossés mais non confluents**
- Inclusions parfois présentes : **corps conchoïdes de Schaumann**, **corps astéroïdes** (NON spécifiques)
- Couronne lymphoplasmocytaire **discrète, voire nulle** (= **« granulomes nus »**)

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p15_00.jpeg]]


### Étiologies
- **Sarcoïdose** ++
- Corps étrangers (tatouages)
- **Maladie de Crohn métastatique**
- **Granulomatose oro-faciale**
- Plus rarement, granulome annulaire sarcoïdosique


## Granulomes tuberculoïdes (cf 08-412)

- **Mal limités**, parfois **confluents**
- Centrés ou non par une **nécrose caséeuse** (mycobactérioses)
- Cellules épithélioïdes + plurinucléées (Langhans, corps étranger)
- **Importante couronne lymphoplasmocytaire** (≠ sarcoïdose nue)

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p20_00.jpeg]]

### Étiologies
| Cause | Spécificités |
|-------|--------------|
| **Tuberculose** | Nécrose caséeuse, **Ziehl** |
| **Mycobactéries atypiques** (avium, marinum) | Distribution sporotrichoïde possible |
| **Lèpre tuberculoïde / borderline** | Tropisme **péri-nerveux**, **Fite-Faraco** |
| **Syphilis** secondaire/tertiaire | Plasmocytes |
| **Leishmaniose** | Corps amastigotes intracellulaires, **MGG / Giemsa** |
| **Rosacée granulomateuse / dermatite périorificielle** | Localisation visage |
| **Corps étrangers** | À rechercher |

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p22_00.jpeg]]


## Granulomes nécrobiotiques (cf 08-413)

Granulomes développés **autour d'une zone de collagène altérée** :
- Dépôts de **mucine** (granulome bleu — ex : granulome annulaire)
- Dépôts de **fibrine** (granulome rouge — ex : nodule rhumatoïde)
- Débris cellulaires (PNN ou éosinophiles)


## Granulomes interstitiels (cf 08-413)

Infiltrat histiocytaire **entre les faisceaux de collagène** (pas en couronne).

> ⚠️ **Bleu alcian obligatoire** : différencie granulome annulaire interstitiel (mucine+) vs **dermatose interstitielle granulomateuse (DIG)** (mucine−).

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p25_00.jpeg]]

## Granulomes suppuratifs

- Granulomes épithélioïdes **mal limités**
- Centrés par un **abcès à PNN**
- Cellules plurinucléées parfois

### Étiologies
| Cause | Exemple |
|-------|---------|
| **Infections** | **Mycoses** (alternariose, blastomycose), **mycobactéries atypiques**, parasitoses, **Bartonella henselae** (maladie des griffes du chat) |
| **Corps étrangers** | **Kystes épidermiques rompus** (kératine libérée → réaction) |

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p26_00.jpeg]]

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p27_00.jpeg]]

#### Exemple : alternariose
Patient 70 ans, immunosupprimé, lésions cutanées + nodules pulmonaires/rétropéritonéaux. **PAS** et **Grocott** : spores et **filaments septés de taille variable** → typage par microbiologistes.

#### Maladie des griffes du chat
Lésions hauteur du derme + hypoderme avec granulomes suppuratifs.

![[assets/dermato/infiltrats-cutanees-non-tumoraux/dermatoses-granulomateuses/08-411 Approche des dermatoses granulomateuses V3 sono/p29_00.jpeg]]

## Granulomes à corps étranger (cf 08-415)

Désignation = corps étranger **identifié** (matériel endogène ou exogène).
- Souvent **biréfringent en lumière polarisée**
- Histiocytes ± épithélioïdes + cellules géantes à corps étranger ± Langhans


## Autres granulomes plus rares

- **Mycosis fongoïde granulomateux**
- **Désordres immunodéficients**
- **Xanthogranulomes** (cellules de Touton)

## Réflexes diagnostiques

| Réflexe | Justification |
|---------|---------------|
| **Recouper le bloc** | Une lésion peut apparaître plus nette en profondeur |
| **Colorations spéciales** : **PAS, Grocott, Ziehl, Giemsa** | Recherche d'agent infectieux |
| **Lumière polarisée** (biréfringence) | Recherche de **corps étranger** |
| **Bleu alcian** | Mucine (granulome annulaire vs DIG) |
| **Perls** | Hémosidérine (capillarites) |
| **Anatomoclinique** | Pattern granulomateux = lésion sentinelle (sarcoïdose, infection systémique) |

## Clés diagnostiques par localisation

| Localisation | Évoque |
|--------------|--------|
| **Péri-nerveuse** | **Lèpre** tuberculoïde / borderline |
| **Péri-pilaire** | **Rosacée**, ses variants |
| **Visage médian** | Rosacée, dermatite périorificielle |
| **Membres inférieurs prétibiaux** | Nécrobiose lipoïdique |
| **Avant-bras / dos des mains** | Granulome annulaire |

## Diagnostics différentiels (à intégrer dans la démarche)

| DD | Distinction |
|----|-------------|
| Lymphome cutané | Atypies cellulaires, monoclonalité |
| Histiocytose | Marqueurs Langerhansiens (CD1a, langérine) ou non |
| Granulome de Lever (sens large) | Polymorphisme cellulaire, pas d'histiocytose dominante |

## 🔑 Points clés à retenir

1. **Granulome = infiltrat majoritairement histiocytaire**, ± autres cellules selon étiologie et stade
2. **3 types d'histiocytes** : classique, xanthomisé, **épithélioïde** (cohésif, perd phagocytose) ; **3 types de cellules géantes** : **Langhans** (couronne), **corps étranger** (au hasard), **Touton** (cercle central + lipides périphériques)
3. **Classification architecturale** : **nodulaire** (sarcoïdosique vs tuberculoïde) / **palissadique** (bleu/rouge) / **interstitiel** ± **corps étranger**
4. **Sarcoïdosique** = nu, bien limité, **adossé non confluent** ; **tuberculoïde** = mal limité, **couronne lymphoplasmocytaire**, ± nécrose caséeuse
5. **Suppuratif** = abcès central → toujours rechercher **infection** (mycose, mycobactérie atypique) ou **kyste rompu**
6. **Palissadique** = histiocytes en couronne autour d'une **zone centrale modifiée** (mucine bleue / fibrine rouge)
7. **Interstitiel** : faire **bleu alcian** (granulome annulaire interstitiel vs **DIG**)
8. **Cellules géantes plurinucléées** + corps astéroïdes/Schaumann **NON spécifiques** (peuvent se voir dans toutes les granulomatoses)
9. Réflexes : **recouper, colorations spéciales (PAS/Grocott/Ziehl/Giemsa), lumière polarisée, bleu alcian, anatomoclinique**
10. Penser à la **lèpre devant tout granulome péri-nerveux**, à la **rosacée devant tout granulome péri-pilaire du visage**

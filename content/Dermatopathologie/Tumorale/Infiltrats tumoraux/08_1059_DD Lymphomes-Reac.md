# Diagnostic différentiel : lymphomes cutanés vs infiltrats lymphoïdes réactionnels

> Liens : [[08_1056_Lymphomes T cutanés rares, commenté]] | [[08_1057_Lymphomes B à petites cellules]] | [[08_1058_LPCT B gdes cell]] | [[08_1060_Localisation cutanée dhémopathies malignes systémiques (myéloïdes et lymphoïdes)]]

## Généralités

Question **quotidienne** en dermatopathologie : différencier **lymphome cutané** d'un **infiltrat lymphoïde réactionnel** (= **pseudolymphome**).

### Trois grandes situations cliniques

| Présentation clinique | DD principal |
|----------------------|--------------|
| **Plaques** érythémato-squameuses | MF vs eczéma / toxidermie |
| **Papules** | LP CD30+ / piqûre / B vs T réactionnel |
| **Tumeur unique** | Lymphome B (PCFCL/PCMZL/leg-type) vs hyperplasie lymphoïde |

### Règles générales

- **Pas d'urgence diagnostique** : MF est indolent
- **Confronter** : histologie + clinique + temps + clone B/T
- **Biopsies multiples** dans l'espace et le temps
- Le **clone identique sur plusieurs biopsies** est un argument fort

# I. Plaques : MF vs Eczéma / Toxidermie

## Critères en faveur du **mycosis fongoïde**

| Critère | MF |
|---------|:---:|
| **Lymphocytes épidermotropes ATYPIQUES** ⭐ (taille ≥ kératinocytes adjacents) | + |
| **Pas de modification épidermique au contact** des lymphocytes | + |
| **Pas de spongiose** au contact des lymphocytes | + |
| **Pas de nécrose kératinocytaire** | + |
| Derme superficiel : **fibrose** plutôt que œdème | + |
| Phénotype | **CD3+, CD4+** |
| **CD20** | **−** (rares B) |

## Importance du **CD20**

- **Indispensable** dans le panel
- MF **ne contient PAS de B**
- Beaucoup de B dans un infiltrat épidermotrope superficiel → penser **réactionnel** (médicament, piqûre d'insecte) ou **autre lymphome** (MF transformé avec CD20+)

# II. Papules : analyse selon le phénotype

## A. Phénotype B + T mélangé

→ Penser :
- Infiltrat **réactionnel** (banal)
- **Lymphome B de la zone marginale** (souvent T abondant, voir [[08_1057_Lymphomes B à petites cellules]])
- **Lymphoprolifération T-helper folliculaire** (infiltrat mixte BT)

## B. Phénotype CD30+ → Papulose lymphomatoïde vs piqûre

### Papulose lymphomatoïde

- Lésions papuleuses, **régression spontanée**, **récidivantes**
- Histologie : **lésion triangulaire à pointe inférieure**, ulcération épidermique
- Vaisseaux entourés de lymphocytes **CD30+** atypiques

### Diagnostics différentiels réactionnels

| DD | Distinction |
|----|-------------|
| **Pityriasis lichénoïde** (PLEVA) | Moins récidivant, pas d'atypies majeures |
| **Réaction médicamenteuse** | Anamnèse |
| **Piqûre d'insecte** | Éosinophiles +, contexte clinique |

→ La **clinique** + suivi tranchent.

# III. Infiltrat dermique mixte B + T (papule ou tumeur)

## Cas 1 — Présence de **gros nodules B dans un fond T**

→ Hypothèses :
- **Hyperplasie lymphoïde réactionnelle** (lymphocytome cutané, Borrelia ++)
- **Lymphome B de la zone marginale (PCMZL)**

### Démarche

1. **CD20 + CD3** → confirmer nodules B dans fond T
2. **CD21** → étudier le réseau folliculaire dendritique
   - **Régulier, bien rond** → follicules **réactionnels**
   - **Désorganisé, lâche** → follicules **lymphomateux** (PCFCL ou colonisés par PCMZL)
3. Si follicules réactionnels → **kappa / lambda en HIS** :
   - **Monotypie** → **PCMZL**
   - **Polytypie** → étude de **clonalité B** (BIOMED, **IgH + chaînes légères**) → trancher

## Cas 2 — Mélange B + T **intriqué** (PAS de nodules B distincts)

→ Hypothèses :
- **Hyperplasie lymphoïde réactionnelle**
- **Lymphoprolifération T-helper folliculaire** (TFH)

> DD **non grave** : si lésion unique, **pronostic excellent** dans les deux cas.

### Démarche

1. Marqueurs T : CD3, CD2, CD5, CD7 → rechercher **trou phénotypique** (CD7−)
2. **Clonalité T** par PCR
3. Si clone T → **panel TFH** : **CXCL13, PD1, ICOS, BCL6, CD10**
4. Si TFH+ + clone T → **lymphoprolifération TFH clonale** (lésion unique = pronostic excellent)

# IV. Pseudolymphomes — entités classiques

## Lymphocytome cutané (lymphocytoma cutis / Spiegler-Fendt)

- **Hyperplasie lymphoïde réactionnelle** B
- **Borrelia burgdorferi** ++ (sérologie ; antibiothérapie souvent efficace)
- **Lésion souvent unique**, papule/nodule
- Topographie typique : **lobe oreille**, mamelon, scrotum
- Folliculaire B + CG bien organisés (Ki67 élevé, BCL2−, réseau CD21 régulier)

## Pseudolymphome médicamenteux

- **Antiépileptiques** (phénytoïne ++), antihypertenseurs (β-bloquants), psychotropes…
- DD avec MF / lymphome T : **anamnèse**, régression à l'arrêt
- Histologie variable, peut **mimer MF**

## Acral pseudolymphoma (acral pseudolymphomatous angiokeratoma — APACHE)

- Enfants, lésions acrales (doigts, oreilles)

## Lupus tumidus (Jessner-Kanof, LIP)

- Plaques érythémateuses faciales / cou
- Infiltrat lymphocytaire **superficiel + profond** péri-vasculaire
- **Mucinose** dermique caractéristique
- Cellules dendritiques **CD123+** abondantes

# V. Critères généraux de différenciation

| Critère | **Pseudo-lymphome** | **Lymphome** |
|---------|:---:|:---:|
| Taille (clinique) | < 1 cm | > 1 cm volontiers |
| Lésions | Souvent **unique** | Souvent multiples (MF/PCMZL) ou tumeur dominante |
| Architecture | **Top-heavy** (sup > prof) | Souvent **bottom-heavy** (PCFCL profond) |
| Polymorphisme | **+** (mélange réactionnel) | Monomorphe |
| Clonalité | Polyclonale | Monoclonale (mais nuances) |
| Persistance | Régression possible | **Persistance** / récidive |
| CG réactionnels | Avec Ki67 ↑, macrophages tingibles, mitoses, BCL2− | Pathologiques (Ki67 ↓, désorganisés, BCL2+) |

⚠️ **Polyclonalité ≠ bénin** ; **monoclonalité ≠ malin** → contexte clinique + suivi indispensables.

---

## 🔑 Points clés à retenir

1. Le DD lymphome cutané vs pseudolymphome est **quotidien**, **pas urgent** ; suivi évolutif et **biopsies répétées** précieuses
2. **MF vs eczéma** : critères positifs pour MF = **lymphocytes atypiques épidermotropes** + **absence de spongiose au contact** + **fibrose dermique** ; CD20 absent dans MF
3. **CD20 abondant dans un infiltrat épidermotrope** → penser réactionnel (médicament, piqûre) ou autre lymphome (MF transformé)
4. **Papules CD30+** : papulose lymphomatoïde vs PLEVA / piqûre → confronter à la clinique (récidives, régression spontanée)
5. **Nodules B dans fond T** : hyperplasie réactionnelle (lymphocytome — Borrelia) vs PCMZL → CD21 (régulier vs désorganisé) + kappa/lambda HIS + clonalité B
6. **Polyclonalité B n'élimine PAS le PCMZL** — toujours étudier **chaînes légères** en plus de IgH
7. **Mélange B + T intriqué** sans nodules B : hyperplasie vs **TFH clonale** (lésion unique = pronostic excellent)
8. **CD21** = pivot du diagnostic des infiltrats nodulaires B : régulier rond = réactionnel, désorganisé = lymphome
9. Toujours **vérifier le témoin interne kératinocytaire BCL6+** avant d'affirmer une négativité
10. **Aucun critère unique** ne tranche : **confrontation anatomo-clinique-moléculaire-évolutive** est la règle ; le pathologiste a souvent le **dernier mot**, mais la confiance dans le clone repose sur **son identité sur plusieurs biopsies**

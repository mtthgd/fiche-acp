# Métastases cutanées — comment les reconnaître

> Liens : [[08_1022_Carcinome epidermoide]] | [[08_1024_Carcinome à cellules de Merkel]] | [[08_1028_Carcinomes annexiels lessentiel, Réseau CARADERM]] | [[08_1027_Lesions sudorales eccrines benignes]]

## Généralités

- **Métastases cutanées** = **0,7 à 2 %** des tumeurs cutanées malignes (lésions **non rares**).
- Origines :
  - **Cutanées en transit / à distance** : **mélanome**, **carcinome neuroendocrine de Merkel**, **carcinome épidermoïde** cutané
  - **Viscérales** :
    - **Sein** (premier rang chez la femme)
    - **Poumon**, côlon (premier rang chez l'homme)
    - ORL, rein, estomac, thyroïde, etc.

---

## Présentations cliniques

### Topographies typiques par primitif

| Primitif | Site cutané préférentiel |
|----------|--------------------------|
| **Sein** | **Paroi thoracique**, sein controlatéral |
| **Poumon** | **Cuir chevelu**, paroi thoracique |
| **Estomac, côlon, ovaire, pancréas, endomètre** | **Nodule de Sœur Marie-Joseph** (nodule ombilical) |

### Aspects cliniques

| Aspect | Fréquence / particularité |
|--------|---------------------------|
| **Nodule** (isolé, multiple groupé ou disséminé) | **95 % des cas** |
| **Plaque infiltrée** | Cuir chevelu (alopécie), sein |
| **Lésion érysipélatoïde** | Dissémination lymphatique (sein, ORL) |
| **Nodule ombilical** | **Nodule de Sœur Marie-Joseph** = primitif intra-abdominal (gastrique, colique, ovarien, pancréatique, endométrial) |

### Métastase de primitif inconnu

| Sexe | Origine prioritaire à évoquer |
|------|-------------------------------|
| **Homme** | **Pulmonaire**, colique, ORL |
| **Femme** | **Mammaire** très majoritairement |

## Histologie

### Signes généraux

- Tumeur **dermique et hypodermique**, **bien limitée** ou non.
- Possible **embols vasculaires** (lymphatiques surtout).
- **Beaucoup moins fréquemment épidermotropes** (≠ tumeurs primitives cutanées).

### Aspects particuliers

| Aspect | Origine évocatrice |
|--------|---------------------|
| **Disposition interstitielle peu dense ("bee-sting")** | **Sein** ++ |
| **Lymphangite carcinomateuse cutanée** (purement endolymphatique) | Sein, autres |
| **Cellules plasmocytoïdes en files indiennes** dans le collagène | **Carcinome lobulaire mammaire** |

### Cas particulier : métastase de carcinome épidermoïde cutané

> Pas d'outil immunohistochimique discriminant : **même phénotype** que le CE primitif.

**Arguments en faveur d'une métastase** :
1. **Absence de connexion épidermique ou folliculaire**
2. **Histoire clinique** : antécédent de CE connu, lésions multiples synchrones
3. **Bilan radiologique**
4. Lésion en **zone non chroniquement photo-exposée** = **suspect++**

---

## Diagnostic différentiel : adénocarcinome cutané primitif vs métastase

### Outil le plus sensible et spécifique : **bilan d'extension clinique et paraclinique**

- Interrogatoire (ATCD de cancer)
- Bilan radiologique à la recherche d'un primitif viscéral
- L'**IHC est parfois utile** mais avec **peu de marqueurs spécifiques** d'organe et beaucoup de marqueurs **non différentiels**.

### IHC — marqueurs spécifiques d'organes (toujours négatifs dans les tumeurs cutanées primitives)

| Marqueur | Origine |
|----------|---------|
| **TTF1, thyroglobuline, calcitonine** | Thyroïde, poumon |
| **PSA, PLAP, PAP** | Prostate |
| **PAX8** | Rein, thyroïde, gynécologique |
| **RCC** | Rein |
| **HepPar1** | Hépatique |


### IHC — marqueurs **NON différentiels** (exprimés dans primitifs cutanés ET métastases)

> C'est malheureusement la **plus longue liste**.

- EMA
- **Récepteurs aux œstrogènes (RE), à la progestérone (RP), HER2**
- Récepteur aux androgènes (RA)
- **GCDFP-15, mammaglobine** (marqueurs apocrines)
- **MUC1, MUC2**
- CDX2
- **GATA3**

> **Tous ces marqueurs sont INUTILES** pour distinguer une métastase d'adénocarcinome **mammaire** d'un **adénocarcinome sudoral primitif**.

### IHC — marqueurs résiduels **utiles** dans la peau

| Marqueur | Primitif sudoral cutané | Métastase mammaire/pulmonaire |
|----------|:---:|:---:|
| **CK20** | **− (quasi 100 %)** | + dans certains digestifs |
| **CK5/6** | + souvent | − souvent |
| **CK15** | + souvent | − souvent |
| **P63 / P40** | **+ très souvent** | **− souvent** |
| **D2-40** | + | − |

> **CK20+ dans un adénocarcinome cutané = quasiment 100 % spécifique d'une origine extra-cutanée**.

> **Attention** : ce panel **ne distingue pas** des métastases de **carcinomes salivaires** (profil très proche des adénocarcinomes sudoraux cutanés — proximité embryologique).

---

## Outils moléculaires

- Approches transcriptomiques pour prédire le tissu d'origine (carcinomes de primitifs inconnus).
- **Limite** : **overlap** entre profils d'expression **sudoral / sein / salivaire** (proximité embryologique).
- **Les carcinomes annexiels cutanés ne sont pas reconnus indépendamment** dans les tests commercialisés actuels.

---

## Algorithme diagnostique pratique

```
Lésion cutanée nodulaire/plaque/érysipélatoïde
            │
            ├─ Antécédent oncologique connu ?
            │       OUI → Comparer morphologie + IHC à la tumeur primitive
            │
            ├─ Topographie évocatrice ?
            │       Ombilic → Sœur Marie-Joseph (intra-abdominal)
            │       Cuir chevelu (femme) → poumon ; (homme) → variable
            │       Paroi thoracique femme → sein
            │
            ├─ Architecture évocatrice ?
            │       Files indiennes / cellules plasmocytoïdes → lobulaire sein
            │       Lymphangite carcinomateuse pure → sein
            │       Pas de connexion épidermique → métastase (CE)
            │
            └─ IHC :
                  CK20+ adénocarcinome → extra-cutané
                  CK5/6+ CK15+ P63+ → primitif sudoral cutané
                  TTF1+, thyroglobuline+ → thyroïde
                  PSA+ → prostate
                  RCC+/PAX8+ → rein
                  HepPar1+ → foie
            
            → BILAN CLINIQUE ET RADIOLOGIQUE = OUTIL LE PLUS IMPORTANT
```

| Cellules en files indiennes | Lobulaire du sein | (rare en peau) |

| Carcinome épidermoïde sans connexion épidermique | CE pulmonaire, ORL, col | CE cutané |
| Cellules à vacuoles de signet | Estomac, sein | Variante de CE cutané (bleu Alcian−) |

| Carcinome cribriforme/glandulaire | Sein, prostate | **Carcinome adénoïde kystique cutané** (MYB+) |

## 🔑 Points clés à retenir

1. **Métastases cutanées = 0,7 à 2 %** des tumeurs cutanées malignes, **non rares**.
2. **Origines** : intra-cutanée en transit (mélanome, Merkel, CE) + viscérale (sein, poumon, côlon ++).
3. **Présentation = nodule** dans 95 % des cas ; aussi plaque infiltrée, érysipélatoïde, ombilical.
4. **Nodule de Sœur Marie-Joseph** = nodule **ombilical** = primitif **intra-abdominal** (estomac, côlon, ovaire, pancréas, endomètre).
5. **Topographies évocatrices** : paroi thoracique (sein), cuir chevelu (poumon).
6. **Origine de primitif inconnu** : femme = sein ; homme = poumon, côlon, ORL.
7. **Histologie** : tumeur dermo-hypodermique, embols, **épidermotropisme rare** ; cellules en **files indiennes / disposition interstitielle (bee-sting)** = sein lobulaire.
8. **Métastase de CE cutané** : **pas d'outil IHC**, distinction par **absence de connexion épidermique**, contexte clinique, **zone non photo-exposée = suspect**.
9. **Marqueurs spécifiques d'organe** (négatifs en peau primitive) : **TTF1, thyroglobuline, PSA, PAX8, RCC, HepPar1**.
10. **Marqueurs INUTILES** pour distinguer adénocarcinome mammaire / sudoral cutané : **EMA, RE, RP, HER2, RA, GCDFP-15, mammaglobine, GATA3, MUC1**.
11. **Marqueurs UTILES** : **CK20** (presque 100 % spécifique d'origine extra-cutanée si + dans adénocarcinome), **CK5/6, CK15, P63/P40, D2-40** (souvent + dans primitifs sudoraux cutanés).
12. **Bilan clinique et radiologique = outil le plus important** ; les outils transcriptomiques actuels ne reconnaissent pas indépendamment les annexiels cutanés (overlap **sudoral/sein/salivaire**).

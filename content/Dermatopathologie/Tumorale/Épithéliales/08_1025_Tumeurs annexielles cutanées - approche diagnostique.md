# Tumeurs annexielles cutanées — approche diagnostique

> Liens : [[08_1023_Carcinome basocellulaire]] | [[08_1026_Tumeurs annexielles bénignes - Lésions folliculo-sébacées]] | [[08_1027_Lesions sudorales eccrines benignes]] | [[08_1028_Carcinomes annexiels lessentiel, Réseau CARADERM]] | [[08_1029_Métastases cutanées comment les reconnaître]]

## Généralités

Les tumeurs annexielles cutanées sont classées en **4 grandes familles** selon leur histogenèse :

| Famille | Contenu |
|---------|---------|
| **Tumeurs pilaires (folliculaires)** | Bien définie |
| **Tumeurs sébacées** | Bien définie |
| **Tumeurs sudorales eccrines** | Souvent difficile à différencier de l'apocrine |
| **Tumeurs sudorales apocrines** | Souvent difficile à différencier de l'eccrine |

> L'OMS 2018 regroupe désormais les tumeurs eccrines et apocrines en **"tumeurs sudorales"**.

**Démarche** : retrouver des **fins signes histologiques et cytologiques d'orientation** vers l'une des 4 catégories.


---

## I. Signes d'orientation par catégorie

### 1. Tumeurs sébacées

**Diagnostic = mise en évidence des sébocytes matures + sécrétion holocrine.**

| Élément | Description |
|---------|-------------|
| **Sébocytes matures** | Cellules **claires, multivacuolées**, noyau central pycnotique |
| **Sébocytes immatures** | Basophiles, en grand nombre dans certaines tumeurs (sébéome) |
| **Sécrétion holocrine** | Aspect éosinophile en "cadres membranaires" = fantômes des cellules éliminées (≠ nécrose tumorale, **pas un signe de malignité**) |


**5 lésions sébacées** :
- Kyste sébacé (= **stéatocystome**)
- **Hyperplasie sébacée** (lésion hyperplasique non tumorale)
- **Adénome sébacé** (bénin)
- **Sébéome** (= sébéocome) (bénin)
- **Carcinome sébacé** (malin)

### 2. Tumeurs apocrines

**Signes de différenciation apocrine** :

| Signe | Description |
|-------|-------------|
| **Sécrétion par décapitation** | Désintégration du **pôle apical** vers la lumière |
| **Lumières glandulaires** | Étirées, ramifiées, **labyrinthiques** |
| **Double assise cellulaire** | Couche périphérique **myo-épithéliale P63+** + couche luminale CK7/CK8/CK19+ |
| **Cellules à mucus** | Possibles (attention : aussi vues dans hidradénome eccrine) |

**Signes évocateurs supplémentaires** :
- **Sécrétion plus colorée par l'HES** que la sécrétion eccrine (non pathognomonique).
- **Stroma riche en plasmocytes** → évocateur d'un **syringocystadénome papillifère (SCAP)**.
- **Stroma chondroïde** → évocateur d'un **syringome chondroïde**.

**Lésions apocrines** :
- Kystes : **hidrocystome**, **cystadénome apocrine**
- Bénignes : **hidradénome papillifère**, **SCAP**, adénome tubuleux apocrine, **syringome chondroïde**
- Maligne : **carcinome apocrine**


### 3. Tumeurs sudorales eccrines

**Classification par site d'origine** sur le système eccrine (acrosyringium → canal excréteur → peloton sécrétoire).


| Site | Tumeur(s) bénigne(s) | Tumeur maligne |
|------|----------------------|----------------|
| **Surface (acrosyringium)** | **Tumeurs porales** (porome eccrine, hidradénome poroïde, hydroacanthome simplex, dermal duct tumor) | **Porocarcinome** |
| **Canal excréteur** | **Syringomes** | **Carcinome syringomateux** |
| **Peloton sécrétoire** | **Hidradénomes nodulaires** ; **spiradénomes** ; **cylindromes** | Hidradénocarcinome, spiradénocarcinome, cylindrocarcinome |

**Cellule porale** = petite cellule à noyau central rond/ovale, formant des nappes homogènes, **limites cytoplasmiques mal visibles**.
**Stroma hyalin** + **nécrose en masse** = signes orientateurs porales.

**Spiradénome vs cylindrome** :
- Cellules **identiques** (double cytologie : grandes claires + petites sombres)
- **Spiradénome** = un ou quelques nodules
- **Cylindrome** = nodules s'**emboîtant comme les pièces d'un puzzle**

### 4. Tumeurs pilaires (folliculaires)

Famille la plus nombreuse.

**Origines anatomiques** :
- **Infundibulum** : porome folliculaire, kyste épidermique
- **Isthme** : tumeur de l'infundibulum, **trichilemmome**
- **Matrice** : **pilomatricome**
- Origine difficile à préciser : **trichoblastome**

**Critères architecturaux** :
- Architecture **verticale ou discrètement oblique** (comme les follicules pileux)
- Possible **plateau sous-épidermique** ou multiples nodules dermiques
- Organisation autour d'**une cavité dilatée** (trichofolliculome)
- Architecture **rubanée ou réticulée** (labyrinthique) évocatrice

**Critères cytologiques** :
- **Kératinisation épidermoïde** (tumeurs superficielles, parfois en enroulements)
- **Kératinisation folliculaire** : grains éosinophiles, comme la gaine pilaire interne
- **Kératinisation matricielle** : cellules transitionnelles → cellules **fantômes** anucléées
- **Stroma riche en fibroblastes fusiformes** (rappelle la papille pilaire), parfois s'invaginant dans les massifs (trichoblastome)

**Aphorisme** : **"Calcifié = pilaire"** (calcifications fréquentes, surtout dans pilomatricome) — pas valable à 100 %.

**Cytologie variable** :
- Cellules **claires en palissade** noyau apical → trichilemmome
- Cellules **basophiles** + palissade discrète → trichoblastome (DD CBC)
- **Cellules fantômes** + cellules matricielles → pilomatricome

## II. Critères de malignité

| Critère | Note |
|---------|------|
| **Architecture** | Tumeur **grande**, **mal limitée**, infiltrant l'hypoderme et structures sous-jacentes |
| **Mitoses** | Nombreuses, anormales |
| **Index Ki-67** | Élevé |
| **Atypies cytologiques** | Présentes |
| **Engainements périnerveux** | **Signe formel de malignité** |
| **Embols vasculaires** | **Signe formel de malignité** |

> **Aucun cutoff précis n'est défini** ; chacun de ces critères peut être observé dans des tumeurs bénignes. C'est **l'ensemble du tableau histologique** qui retient la malignité.

## III. Apport de la clinique (topographie)

| Topographie | Penser à |
|-------------|----------|
| **Vulve** | **Hidradénome papillifère** |
| **Hamartome verrucosébacé** | **Syringocystadénome papillifère (SCAP)** |
| **Doigt / orteil** | **Adénocarcinome papillaire digital** |
| **Paupières** | Syringome, hidrocystome, **carcinome sébacé** (lésion peu différenciée) |
| **Tumeur douloureuse** | **Spiradénome** (seule tumeur annexielle douloureuse) |
| **Cuir chevelu (multiples turbans)** | **Cylindromes** (Brooke-Spiegler) |

## IV. Syndromes génétiques associés

> Le bon diagnostic d'une tumeur annexielle peut révéler un **syndrome génétique** — à mentionner dans la **conclusion** du compte rendu.

| Syndrome | Gène | Tumeurs cutanées | Risque profond |
|----------|------|------------------|----------------|
| **Muir-Torre** (= Lynch) | **MMR** (MLH1, MSH2, MSH6, PMS2) | **Tumeurs sébacées** + KA multiples | Côlon, endomètre, voies urinaires |
| **Cowden** | **PTEN** | **Trichilemmomes** multiples | Sein, thyroïde, endomètre |
| **Birt-Hogg-Dubé** | **FLCN** (folliculine) | **Fibrofolliculomes / trichodiscomes / fibromes péri-folliculaires** | **Rein**, pneumothorax récidivants |
| **Gardner** | **APC** | Kystes hybrides (épidermique + matriciel), pilomatricomes multiples | **Polypose colique adénomateuse**, ostéomes, tumeurs desmoïdes |
| **Brooke-Spiegler** | **CYLD** | **Spiradénomes, cylindromes, trichoblastomes** multiples + grains de milium | **Pas de cancer profond** ; **risque = transformation maligne** des annexielles |

## V. Algorithme de synthèse

```
Tumeur annexielle suspecte
        │
        ├─ Sébocytes matures + sécrétion holocrine ?
        │      → SÉBACÉE  (penser Muir-Torre)
        │
        ├─ Décapitation, lumières labyrinthiques, double assise ?
        │      → APOCRINE  (vulve = hidradénome papillifère ;
        │                  hamartome verrucosébacé = SCAP)
        │
        ├─ Cytologie porale, stroma hyalin, nécrose en masse ?
        │      → ECCRINE PORALE  (porome / hidradénome poroïde / 
        │                       hydroacanthome simplex)
        │
        ├─ Tubes en têtard, derme moyen, paupières ?
        │      → SYRINGOME
        │
        ├─ Cellules claires + stroma hyalin épais ?
        │      → HIDRADÉNOME NODULAIRE
        │
        ├─ Double cytologie (claires + sombres), nodules emboîtés ?
        │      → CYLINDROME (vs spiradénome si uninodulaire douloureux)
        │
        └─ Cellules basophiles palissadiques + stroma fibroblastique
           dense + invaginations stromales ?
                → TRICHOBLASTOME (DD CBC ; PHLDA1+)
                  Cellules claires noyau apical : TRICHILEMMOME (Cowden)
                  Cellules fantômes : PILOMATRICOME
                  Cavité dilatée + poils : TRICHOFOLLICULOME
```

## VI. Panel IHC d'orientation

| Marqueur | Utilité |
|----------|---------|
| **CK7 / CK8 / CK19** | Couche luminale glandulaire (apocrine) |
| **P63 / P40** | Couche myo-épithéliale, basaloïde |
| **EMA** | + dans tumeurs sébacées matures, glandulaires |
| **CEA** | + dans différenciations ductulaires (porocarcinome) |
| **BerEP4** | + diffus dans CBC ; **hétérogène miroir** dans trichoblastome |
| **PHLDA1** | + dans trichoblastome ; − dans CBC |
| **Récepteur aux androgènes** | + dans tumeurs **sébacées** (sébocytes immatures) |
| **GCDFP-15, mammaglobine** | Différenciation apocrine ; communs avec sein |
| **MMR** (MLH1, MSH2, MSH6, PMS2) | Dépistage Muir-Torre devant toute tumeur sébacée |

## 🔑 Points clés à retenir

1. **4 familles** : pilaire, sébacée, sudorale eccrine, sudorale apocrine — l'**OMS 2018** regroupe eccrine + apocrine en **"sudorales"**.
2. **Tumeur sébacée = sébocytes matures + sécrétion holocrine** ; la sécrétion holocrine n'est **pas une nécrose**.
3. **Apocrine = décapitation + lumières labyrinthiques + double assise + plasmocytes (SCAP) ou stroma chondroïde (syringome chondroïde)**.
4. **Eccrine porale** : cellules porales, stroma hyalin, **nécrose en masse**.
5. **Cylindrome** = nodules **en pièces de puzzle** ; **spiradénome** = uninodulaire et **douloureux** (seule tumeur annexielle douloureuse).
6. **Tumeur pilaire** = architecture verticale + stroma fibroblastique dense + kératinisation type folliculaire/matricielle ; **calcifications** fréquentes.
7. **Critères de malignité** : architecture infiltrante mal limitée, atypies, mitoses, **engainements PN, embols** (les 2 derniers = formels).
8. **Topographie clinique** : vulve = hidradénome papillifère ; doigt = adénocarcinome papillaire digital ; tumeur douloureuse = **spiradénome**.
9. **Syndromes** à mentionner en conclusion : **Muir-Torre** (sébacée → MMR/Lynch), **Cowden** (trichilemmome → PTEN), **Birt-Hogg-Dubé** (fibrofolliculome → FLCN/rein), **Gardner** (kyste hybride → APC), **Brooke-Spiegler** (cylindrome/spiradénome/trichoblastome → CYLD).
10. **Aphorisme** : *"Calcifié = pilaire"* (pilomatricome++).

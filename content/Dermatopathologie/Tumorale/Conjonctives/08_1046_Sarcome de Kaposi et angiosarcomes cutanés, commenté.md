# Sarcome de Kaposi et angiosarcomes cutanés

> Liens : [[08_1043_Principales lésions vasculaires]] | [[08_1045_Sarcomes cutanés Panorama et orientation diagnostique, outils]] | [[08_1047_Dermatofibrosarcome (DFSP), commenté]] | [[08_1049_Sarcomes cutanés rares, commenté]]

## Généralités — tumeurs vasculaires malignes cutanées

Deux entités principales :
1. **Sarcome de Kaposi** (associé à **HHV8**)
2. **Angiosarcomes cutanés** (4 formes anatomocliniques)

> Tumeurs vasculaires de **malignité intermédiaire** pouvant envahir la peau : hémangioendothéliomes (épithélioïde, pseudomyogénique, rétiforme).

## Hémangioendothéliomes (rappel)

### Hémangioendothéliome épithélioïde
- Cellules **épithélioïdes** avec **canalisation intracellulaire** (différenciation vasculaire incomplète, parfois hématies)
- Réseau myopéricitaire incomplet
- **Translocation WWTR1-CAMTA1**
- Spectre : indolent → agressif (proche d'un angiosarcome)

### Hémangioendothéliome pseudomyogénique
- Très rare
- Cellules épithélioïdes/fusiformes en plages, cordons, nodules
- **Translocation FOSB-SERPINE1**
- Coexpression **endothéliale + épithéliale** (CK +)

### Hémangioendothéliome rétiforme
- Vaisseaux **ramifiés** bordés de cellules épithélioïdes en **clous de tapissier**
- Aspect rappelant le **rete testis** (organes génitaux externes masculins)

## ANGIOSARCOMES cutanés — 4 formes anatomocliniques

| Forme | Caractéristiques |
|-------|------------------|
| **Cutané primitif classique** | **Sujet âgé**, **visage / cuir chevelu** |
| **Cutané primitif épithélioïde (Wilson-Jones)** | Adulte plus jeune, **membres / tronc**, cellules épithélioïdes |
| **Secondaire post-radique / lymphœdème** | Sein traité, **Stewart-Treves** ; **amplification MYC** |
| **Sein / tissus mous profonds avec extension cutanée** | « Iceberg » émergeant en peau |

### Forme classique du sujet âgé (visage / cuir chevelu)

#### Histologie
- Cavités vasculaires à **contour géographique**, **sans bordure myopéricytaire**
- **Dissociation du collagène dermique**
- Atypies nucléaires, nucléoles, anisocaryose
- Mitoses présentes
- Bien différencié : architecture vasculaire reconnaissable
- Plus indifférencié : nappes cellulaires épithélioïdes ou fusiformes

#### IHC
- **CD31 +** (marquage **membranaire continu**)
- **ERG + nucléaire** (forte sensibilité, excellente spécificité)
- **FLI1 +** nucléaire (variante US)
- CD34 + variable

### Forme épithélioïde (Wilson-Jones)

- Sujet plus jeune
- Membres/tronc
- Cellules épithélioïdes en plages, foyers hémorragiques
- Aspects nodulaires ulcérés
- **Cocktail piège : expression de cytokératines** (au niveau de l'épiderme parfois) → DD avec **carcinome**
- **CD31, ERG, FLI1** redressent le diagnostic

### Formes secondaires (post-radique / lymphœdème — Stewart-Treves)

- Femmes traitées pour **cancer du sein** (chirurgie + radiothérapie)
- Stade débutant : peut ressembler à une **lésion vasculaire atypique** (LVA)
- Prolifération vasculaire disséquente, ± inflammatoire

#### Marqueur clé pour DD avec LVA
- **Amplification MYC** (FISH + ou IHC nucléaire +) → **angiosarcome**
- **MYC −** → lésion vasculaire atypique
- ATTENTION : sensibilité non totale → MYC − n'élimine pas l'angiosarcome

### Diagnostic différentiel des angiosarcomes cutanés

| DD | Distinction |
|----|-------------|
| **Lésion vasculaire atypique** (post-radique) | MYC − / MYC + |
| **Lymphangiome progressif, tumeur de Dabska** | Bénin, contexte clinique |
| **Mélanome épithélioïde** | S100, SOX10, Mélan-A + |
| **Carcinome (primitif/secondaire)** | CK fort/diffus, P63 + ; mais piège : angiosarcome épithélioïde CK + |
| **Sarcome épithélioïde** | **Perte INI1** ; ERG peut être + dans les 2 → piège |
| **Hyperplasie angiolymphoïde avec éosinophilie** | Lésion bénigne, paroi musculaire conservée, inflammation |
| **Hémangioendothéliome épithélioïde** | Translocation WWTR1-CAMTA1, plus délimité |
| **Sarcome de Kaposi** | **HHV8 + (LANA1)** |

> Au moindre doute en contexte d'**immunodépression** ou d'origine **africaine** : faire **HHV8** systématiquement.

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/tumorale/tumeurs-conjonctives-cutanees/08-1046%20Sarcome%20de%20Kaposi%20et%20angiosarcomes%20cutan%C3%A9s/p15_00.jpeg)

### Piège : interprétation du CD31

- CD31 = antigène membranaire exprimé aussi par : **inflammatoires, hématopoïétiques, plasmocytes, mégacaryocytes, histiocytes**
- Marquage diffus possible dans des tumeurs non vasculaires (carcinomes sarcomatoïdes par exemple, par cellules inflammatoires intriquées)
- **Marquage tumoral significatif = membranaire continu** sur cellules tumorales (pas granuleux/cytoplasmique)
- Préférer **ERG ou FLI1** (facteurs de transcription nucléaires) — meilleure spécificité


## SARCOME DE KAPOSI

### 4 formes anatomocliniques

| Forme | Population / Caractéristiques |
|-------|-------------------------------|
| **Méditerranéenne (classique)** | Hommes > 50 ans, pourtour méditerranéen ; **membres inférieurs** ± lymphœdème ; peu agressive |
| **Africaine (endémique)** | Variante agressive multilésionnelle, sous-cutanée ; forme **ganglionnaire pédiatrique** |
| **Iatrogène (transplantation, immunosuppression)** | Sujets sous corticoïdes / immunosuppresseurs / greffés |
| **Épidémique (SIDA)** | VIH, hommes homosexuels (mais pas exclusivement) ; cutanée + muqueuse + viscérale (digestive, pulmonaire) ; **traitement = HAART** (lever l'immunosuppression) |

### Aspects cliniques

| Stade | Aspect |
|-------|--------|
| **Patch** (débutant) | Macule violine ou brunâtre |
| **Plaque** | Plaque infiltrée |
| **Nodule (tumoral)** | Nodule violacé, parfois ulcéré, aspect bourgeon charnu |
| **Lymphœdème** | Gonflement chronique du membre |

### Histologie

#### Stade débutant (patch)
- Prolifération de **petits vaisseaux disséquants** difficiles à voir
- **Signe du promontoire** : vaisseau capillaire/artério-veinulaire entouré d'une cavité vasculaire disséquante (NON spécifique)
- Inflammation lymphoplasmocytaire (parfois au premier plan)
- Hémosidérine présente
- **Pas de thrombose**

#### Stade tumoral
- Prolifération cellulaire dense de **cellules fusiformes** peu atypiques
- Faisceaux serrés, regroupés en nodules
- Prolifération vasculaire au second plan
- Aspects débutants en périphérie (utile au diagnostic)
- Différenciation vasculaire parfois difficile à identifier dans les zones les plus denses

### Immunohistochimie

| Marqueur | Sarcome de Kaposi |
|----------|:---:|
| **HHV8 / LANA-1** | **+ NUCLÉAIRE** (gold standard, hétérogène mais significatif) |
| CD31 | + |
| **ERG** | + |
| **D2-40 / Podoplanin** | + (différenciation lymphatique) |
| AML | + (peut mimer cellules musculaires lisses) |

> **HHV8/LANA-1 = standard absolu** pour le diagnostic, dans les 4 formes cliniques.

### Diagnostics différentiels selon le stade

#### Stade débutant
| DD | Distinction |
|----|-------------|
| **Lésion vasculaire atypique** | Pas de signe du promontoire, contexte post-radique |
| **Lymphangiome progressif** | Bénin, lymphatiques disséquantes mais HHV8 − |
| **Hémangiomes intramusculaires** | Contingent adipeux, vaisseaux artério-veineux, **thromboses** (jamais dans Kaposi) |
| **Angiodermite de stase** | Capillaires lobulés non disséquants, dépôts hémosidérine intenses, HHV8 − |
| **Histiocytofibrome cellulaire pigmenté** | Pas de vaisseaux disséquants vrais, HHV8 − |

#### Stade tumoral
| DD | Distinction |
|----|-------------|
| Tumeurs mésenchymateuses fusiformes (bénignes/malignes) | HHV8 − |
| **Angiosarcome cutané primitif** | HHV8 −, atypies marquées |
| Métastase d'angiosarcome profond | HHV8 − |

## Tableau de synthèse — Kaposi vs Angiosarcome

| Critère | Sarcome de Kaposi | Angiosarcome cutané |
|---------|-------------------|---------------------|
| Population | 4 formes (méditerranéenne, africaine, iatrogène, SIDA) | Sujet âgé visage/scalp / post-radique sein |
| **HHV8** | **+ (LANA-1)** | − |
| Architecture | Vaisseaux disséquants + plages fusiformes | Cavités géographiques + nappes pléomorphes |
| Atypies | Discrètes | **Marquées** |
| Mitoses | Rares (formes débutantes) | **Fréquentes** |
| Inflammation | Lymphoplasmocytaire | Variable |
| Thromboses | **Non** | Possible |
| **MYC** (post-radique) | − | **+ (amplification)** |
| Pronostic | Variable selon la forme (HAART en SIDA) | **Mauvais** (faible survie globale) |

## Pronostic et traitement

### Sarcome de Kaposi
- Forme méditerranéenne : peu agressive, traitement local
- Forme **épidémique** : levée de l'immunosuppression (**HAART** = trithérapie antirétrovirale)
- Forme **iatrogène** : adaptation des immunosuppresseurs
- Lésions étendues : chimiothérapie (Doxorubicine liposomale, paclitaxel)

### Angiosarcomes
- **Pronostic sombre** (faible survie globale)
- Chirurgie large + radiothérapie
- Chimiothérapie : taxanes ; rôle des **thérapies anti-angiogéniques**
- Stewart-Treves : pronostic particulièrement mauvais

## 🔑 Points clés à retenir

1. **2 entités malignes vasculaires cutanées** : sarcome de Kaposi (HHV8 +) et angiosarcomes (HHV8 −)
2. **4 formes de Kaposi** : méditerranéenne (classique), africaine (endémique), iatrogène, épidémique (SIDA)
3. **HHV8 / LANA-1** = gold standard immunohistochimique pour Kaposi, quel que soit le stade ou la forme
4. **Stades du Kaposi** : patch (signe du promontoire) → plaque → nodule (cellules fusiformes au premier plan) → lymphœdème
5. **Pas de thromboses dans le Kaposi** (utile pour DD avec hémangiome intramusculaire)
6. **4 formes d'angiosarcome cutané** : classique du sujet âgé (face/scalp), épithélioïde (Wilson-Jones), post-radique/lymphœdème (Stewart-Treves), extension d'un angiosarcome profond
7. **Angiosarcome post-radique** : rechercher **amplification MYC** pour distinguer d'une lésion vasculaire atypique
8. **Angiosarcome épithélioïde (Wilson-Jones)** : exprime **CK** → DD redoutable avec carcinome (utiliser ERG, CD31, FLI1)
9. **Marqueurs vasculaires** : préférer **ERG / FLI1 nucléaires** (spécifiques) à CD31 (piège : inflammation, plasmocytes, mégacaryocytes)
10. **Traitement Kaposi épidémique** = HAART ; **angiosarcomes** = pronostic sombre, chirurgie + RT, chimiothérapie palliative

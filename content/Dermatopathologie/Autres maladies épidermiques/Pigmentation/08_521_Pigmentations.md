# Hyper- et hypopigmentations — approche diagnostique

> Liens : [[08_513_Porokératoses]] | [[08_241_Dermatoses bulleuses approche diagnostique, commenté]]

## Généralités

Les troubles pigmentaires regroupent les **hyperpigmentations** et les **hypopigmentations**. Pour chacune, distinguer :
- **Lésions tumorales** vs **non tumorales** (essentiellement inflammatoires)
- **Pigment mélanique** vs **non mélanique**

## I. Hyperpigmentations — démarche en 3 questions

### Question 1 — Pigment mélanique ou non mélanique ?

| Pigment non mélanique | Cause / contexte |
|----------------------|------------------|
| **Argyrie** | Dépôts d'**argent** → teinte grisâtre |
| **Tatouage** | Pigments exogènes |
| **Hémosidérine (fer)** ⭐ | **Extravasation des hématies** ; ex. **dermite ocre** par stase veineuse |

**Coloration de Perls** = met en évidence les **dépôts de fer**.

![[assets/dermato/autres-maladies-epidermiques/trouble-pigmentation/08-521-Pigmentations/p04_00.jpeg]]

### Question 2 — Hyperplasie mélanocytaire ou augmentation de la production de mélanine ?

#### Hyperplasie mélanocytaire (= ↑ nombre de mélanocytes)

= lésions **tumorales mélaniques** :

| Lésion | Localisation des mélanocytes |
|--------|-----------------------------|
| **Nævus jonctionnel** | Prolifération à la **DEJ** uniquement |
| **Nævus composé** | DEJ + **derme** (souvent peu pigmenté en histologie) |
| **Nævus dermique** | Dans le derme |
| **Mélanome** | Prolifération maligne |

→ Voir fiches dédiées (lésions mélanocytaires).

![[assets/dermato/autres-maladies-epidermiques/trouble-pigmentation/08-521-Pigmentations/p07_00.jpeg]]

#### Augmentation de la production de mélanine sans hyperplasie mélanocytaire

##### Tumeurs non mélanocytaires hyperpigmentées
- **Kératose séborrhéique** (la plus typique) : hyperplasie épidermique + kystes cornés + **kératinocytes hyperpigmentés**
- **Carcinome basocellulaire** pigmenté
- **Maladie de Bowen** pigmentée
- **Carcinome épidermoïde** pigmenté
- **Métastases épidermotropes** (sein notamment)

##### Pigmentations non tumorales

→ **Inflammatoires** essentiellement, par mécanisme d'**incontinence pigmentaire** :

**Mécanisme** : agression des **assises basales** (cellules basales + mélanocytes) par des **lymphocytes cytotoxiques** = **dermatoses lichénoïdes** → **vacuolisation et nécrose** des cellules basales/mélanocytes → **libération du pigment** capté par des **mélanophages dermiques**.

| Cause | Particularité |
|-------|---------------|
| **Toxidermies lichénoïdes** ⭐ | Très pigmentantes |
| **Lichen plan** ⭐ | Très pigmentant |
| Lupus | Moins pigmentant |
| **Acné** post-inflammatoire | Facteurs de croissance kératinocytaires |
| **Eczéma de contact**, dermatite atopique | Idem |
| **Brûlures**, plaies | Pigmentation résiduelle |
| **Phytophotodermatoses** | Photosensibilité aux plantes (psoralènes) |
| **Médicaments photosensibilisants** | — |

![[assets/dermato/autres-maladies-epidermiques/trouble-pigmentation/08-521-Pigmentations/p12_00.jpeg]]

### Question 3 — Mélanocytes dermiques ou kératinocytes pigmentés (en cas de doute) ?

Sur HES seul, distinction parfois difficile entre :
- **Hyperplasie mélanocytaire** (cellules mélanocytaires nombreuses)
- **Kératinocytes basaux pigmentés** (mélanocytes en nombre normal)

**Astuce morphologique** : si le pigment se met en **chapeau au-dessus du noyau** de la cellule basale → **kératinocyte pigmenté**.

**Immunohistochimie** : marquage **Melan-A / SOX10** avec **chromogène rouge** (le brun de la DAB serait masqué par la mélanine).

#### Cas typique = lésion pigmentée du sujet âgé sur peau photoexposée

DD difficile :
- **Kératose actinique pigmentée** (= kératinocytes pigmentés)
- **Mélanome de Dubreuilh** in situ ou invasif (= hyperplasie mélanocytaire lentigineuse)
- ⚠ Les deux **peuvent coexister** chez le même patient

→ **Melan-A** indispensable.

## Algorithme diagnostique des hyperpigmentations

```
Hyperpigmentation
       │
       ├─ Pigment NON mélanique ?
       │       ├─ Argyrie / tatouage
       │       └─ Fer (Perls +) → dermite ocre
       │
       └─ Pigment MÉLANIQUE
              │
              ├─ Hyperplasie mélanocytaire ?
              │       └─ Lésion tumorale (nævus, mélanome)
              │
              └─ Pas d'hyperplasie, ↑ production de mélanine
                      ├─ Tumorale (kératose séborrhéique, CBC pigmenté…)
                      └─ Non tumorale = INFLAMMATOIRE
                             ├─ Dermatoses lichénoïdes ++
                             │  (toxidermie, lichen plan, lupus)
                             ├─ Acné, eczéma, dermatite atopique
                             ├─ Brûlures, plaies (post-traumatiques)
                             └─ Phytophotodermatoses
```

## II. Hypopigmentations

### Hypopigmentations héréditaires (rôle pathologiste **nul** — diagnostic clinique)

| Distribution | Étiologies |
|--------------|-----------|
| **Diffuses** | **Albinisme**, maladies des mélanosomes, **phénylcétonurie** |
| **Localisées** | **Sclérose tubéreuse de Bourneville** (taches en feuille de sorbier), **piébaldisme**, **nævus achromique** |

### Hypopigmentations acquises

| Cause | Rôle du pathologiste |
|-------|---------------------|
| **Vitiligo** ⭐ | OUI — confirmer + évaluer l'inflammation |
| Dépigmentations physiques/chimiques (brûlure, hydroquinone…) | Aucun |
| **Lèpre** | OUI — confirmer infection |
| **Syphilis secondaire** (leucomélanodermie) | OUI |
| **Pityriasis versicolor** | OUI parfois (filaments mycéliens dans la cornée) |
| **Lichen scléreux** | OUI |
| **Pityriasis lichénoïde** | OUI |
| **Eczématide** hypochromiante | Diagnostic souvent clinique |
| **Morphée / sclérodermie** | OUI |
| **Halo nævus** vs **mélanome régressif** ⭐ | OUI — DD important |
| **Mycosis fongoïde** achromiant ⭐ | OUI — phénotype **CD8+**, surtout enfant |

## Vitiligo

### Mécanisme

Maladie **inflammatoire auto-immune** : **lymphocytes CD8+** agressant les **mélanocytes basaux** → disparition des mélanocytes.

### Rôle de la biopsie

- **Confirmer le diagnostic** (perte des mélanocytes basaux)
- **Évaluer l'état inflammatoire** : présence d'un **infiltrat lymphocytaire** → indication de **bolus de corticoïdes** (efficaces si vitiligo encore inflammatoire)


![[assets/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-232-Psoriasis/p21_00.jpeg]]

### Histologie

- **Disparition des mélanocytes** de la couche basale (à confirmer par **Melan-A / SOX10**)
- ± Infiltrat lymphocytaire en bordure de lésion

## Halo nævus vs halo mélanome

| Critère | **Halo nævus** | **Halo mélanome** |
|---------|---------------|-------------------|
| Terrain | Sujet **jeune ++** | Adulte |
| Clinique | Halo dépigmenté autour d'une **petite** lésion pigmentée | Zones de **dépigmentation au sein** d'une lésion pigmentée parfois irrégulière |
| Évolution | Régression **spontanée complète** | Régression partielle, lésion résiduelle suspecte |
| Histologie | **Pas d'atypie mélanocytaire**, **infiltrat lymphocytaire massif** du derme papillaire (couleur bleutée, limite nette inférieure) | **Mélanocytes atypiques** ; **tumeur à mélanophages** = quasi pathognomonique d'une régression mélanomateuse |
| Pronostic | **Bénin** | **Mauvais** (mélanome agressif) |

## Algorithme diagnostique des hypopigmentations

```
Hypopigmentation
       │
       ├─ Héréditaire ?
       │       ├─ Diffuse : albinisme, phénylcétonurie
       │       └─ Localisée : Bourneville, piébaldisme, nævus achromique
       │
       └─ Acquise
              ├─ Vitiligo (CD8+ → mélanocytes basaux)
              │       → biopsie pour évaluer inflammation
              ├─ Infectieuse : lèpre, syphilis II, pityriasis versicolor
              ├─ Inflammatoire : lichen scléreux, pityriasis lichénoïde,
              │   eczématide hypochromiante, morphée
              └─ Tumorale : halo nævus vs halo mélanome,
                  mycosis fongoïde achromiant CD8+
```

## Diagnostics différentiels — pièges

| Situation | Piège | Solution |
|-----------|-------|---------|
| Lésion pigmentée sujet âgé | Kératose actinique pigmentée vs Dubreuilh | **Melan-A en rouge** |
| Halo de dépigmentation | Halo nævus (bénin) vs halo mélanome | **Atypies mélanocytaires + mélanophages** |
| Mycosis fongoïde achromiant | Vitiligo / eczéma | **Phénotype CD8+** + clonalité TCR |
| Hyperpigmentation diffuse | Origine non mélanique (Perls, ME) | **Coloration de Perls** |

## Pronostic / Traitement

- Cause-dépendant
- **Vitiligo** : photothérapie, corticoïdes locaux, **bolus de corticoïdes** (formes inflammatoires actives), JAK inhibiteurs
- Hyperpigmentations post-inflammatoires : **photoprotection**, dépigmentants (hydroquinone), traitement de la dermatose causale

---

## 🔑 Points clés à retenir

1. Devant une hyperpigmentation : **3 questions** : pigment mélanique ? hyperplasie mélanocytaire ? — sinon : tumoral ou inflammatoire ?
2. **Pigment non mélanique** : argyrie, tatouage, **fer** (Perls = dermite ocre)
3. **Hyperplasie mélanocytaire** = nævus / mélanome
4. **Augmentation de production sans hyperplasie** : tumoral (kératose séborrhéique +++) ou **inflammatoire** (incontinence pigmentaire)
5. **Mécanisme inflammatoire principal** : **dermatoses lichénoïdes** (lichen plan, toxidermies)
6. **DD difficile sujet âgé** : kératose actinique pigmentée vs **Dubreuilh** → **Melan-A en chromogène rouge**
7. Le pigment **en chapeau** au-dessus du noyau = **kératinocyte basal pigmenté** (pas un mélanocyte)
8. **Vitiligo** : maladie auto-immune **CD8+** détruisant les mélanocytes basaux → biopsie pour **inflammation** = guide thérapeutique
9. **Hypopigmentations héréditaires** : **pas de rôle pour le pathologiste** (diagnostic clinique)
10. **Halo nævus** (jeune, bénin, lymphocytes ++) vs **halo mélanome** (atypies, mélanophages, mauvais pronostic)
11. **Mycosis fongoïde achromiant CD8+** chez l'enfant → DD vitiligo
12. **Coloration de Perls** systématique devant suspicion de pigment ferrique

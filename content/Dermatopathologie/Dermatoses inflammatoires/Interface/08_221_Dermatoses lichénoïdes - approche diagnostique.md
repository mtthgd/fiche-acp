# Approche diagnostique des dermatoses lichénoïdes (dermites de l'interface)

> Liens : [[08_222_Lichen plan]] | [[08_224_Lupus érythémateux]] | [[08_211_Approche Diagnostique Dans Les Dermatoses Spongiotiques]] | [[08_231_CAT Dermatoses psoriasiformes]]

## Définition

- **Dermatose lichénoïde** = pattern d'**interface**
- = agression d'origine inflammatoire de la **jonction dermo-épidermique (DEJ)** provoquant des dommages des kératinocytes basaux → **apoptose kératinocytaire** + **vacuolisation** de la DEJ
- Synonyme : **dermite de l'interface** (terme préféré quand vacuolisation prédominante)

## Quatre éléments histologiques à rechercher

1. **Cellules apoptotiques** = **corps de Civatte** (corps cytoïdes)
   - Éléments éosinophiles ronds, ± débris nucléaires
   - Présents dans les couches basales **ou** dans le derme superficiel
2. **Vacuolisation** de la jonction dermo-épidermique (continue ou discontinue)
3. **Incontinence pigmentaire** (mélanophages dermiques) secondaire à la mort des kératinocytes basaux
4. **Infiltrat inflammatoire** du derme superficiel, abondance et composition variables

## Classification en 3 types

| Type | Anomalies prédominantes | Modèle |
|------|--------------------------|--------|
| **Lichénoïde vraie** | Infiltrat lymphocytaire **en bande** + apoptose marquée | **Lichen plan** |
| **Vacuolaire** | Vacuolisation basale + infiltrat lymphocytaire **discret** | **Lupus érythémateux** |
| **Avec apoptose étagée** | Apoptoses nombreuses étagées ± confluentes | **Érythème polymorphe** |

## Démarche diagnostique

### Étape 1 — Déterminer le type d'interface

- **Lichénoïde vraie** ?
- **Vacuolaire** prédominante ?
- **Apoptose étagée** prédominante ?

### Étape 2 — Pour les dermatoses lichénoïdes vraies

#### **Hyperplasie épidermique lichénienne** présente ?

**OUI** → orienter selon le contexte :
- Lésions **multiples** → **lichen plan** (cf. [[08_222_Lichen plan]])
- Lésion **unique** → **kératose lichénoïde solitaire**
- **Allogreffe** → **GVH chronique**

**NON** → autres signes orientateurs :

| Signes additionnels | Diagnostic |
|---------------------|-----------|
| **Pustules** + parakératose | **Pityriasis lichénoïde chronique** (parapsoriasis en gouttes) |
| **Pustules** + plasmocytes dermiques + PNN en migration | **Syphilis secondaire** |
| Lymphocytes T **atypiques**, trou phénotypique | **Mycosis fongoïde** |
| **PNN + PNE**, lymphocytes T CD8 atypiques | **Toxidermie** (DRESS, exanthème maculo-papuleux, **érythème pigmenté fixe**) |
| **PNN dans l'infiltrat dermique** + autres signes lupiques | **Lupus érythémateux** |

> ⚠️ **Pas de PNE dans le lupus érythémateux** (utile en DD).

![[assets/dermato/dermatoses-inflammatoire-epiderme/dermatoses-interfaces/08-221 - Dermatoses lichénoïdes - approche diagnostique/p07_01.jpeg]]

### Étape 3 — Pour les dermatoses lichénoïdes vacuolaires

| Signes | Diagnostic |
|--------|-----------|
| Lésions vacuolaires + atrophie épidermique + mucine | **Dermatomyosite**, **lupus aigu** |
| Infiltrat formant un **amas** dans une papille dermique | **Lichen nitidus** |
| **Lamelle cornoïde** | **Porokératose** |
| Allogreffe (forme aiguë) | **GVH aiguë** |

### Étape 4 — Pour les dermatoses lichénoïdes avec apoptose étagée

Affections nombreuses, dominées par les **toxidermies** et les **maladies bulleuses** :

- **Toxidermies** : érythème pigmenté fixe, exanthème maculo-papuleux, **DRESS**, **syndrome de Stevens-Johnson**, **NET (Lyell)**
- **GVH aiguë de grade 4** (clivage dermo-épidermique)
- **Lupus érythémateux bulleux**
- **Érythème polymorphe**
- **Pityriasis lichénoïde aigu** (varioliforme, PLEVA, maladie de Mucha-Habermann)

## Entités spécifiques détaillées

### Pityriasis lichénoïde chronique (PLC, parapsoriasis en gouttes)

- Dermatose **éruptive** : papules à squame très adhérente "**en pain à cacheter**"
- Évolution sur plusieurs mois
- Histologie :
  - Lésion bien limitée (important)
  - DEJ obscurcie par un **infiltrat lymphocytaire dense** avec **hématies extravasées** (très évocateur)
  - **Nécroses kératinocytaires éparses**
  - Parakératose avec **PNN** en surface
  - Inflammation lymphocytaire prédominant **autour des vaisseaux** (vasculite lymphocytaire pour certains)
- **Phénotype CD4 > CD8** → DD avec **mycosis fongoïde** parfois difficile

![[assets/dermato/dermatoses-inflammatoire-epiderme/dermatoses-interfaces/08-221 - Dermatoses lichénoïdes - approche diagnostique/p11_01.jpeg]]

![[assets/dermato/dermatoses-inflammatoire-epiderme/dermatoses-interfaces/08-221 - Dermatoses lichénoïdes - approche diagnostique/p11_02.jpeg]]

### Pityriasis lichénoïde aigu (PLEVA, maladie de Mucha-Habermann)

- Dermatose éruptive : papules à croûte/squame, cicatrice **varioliforme** post-guérison
- Durée quelques mois à années avec accalmies
- Histologie : signes du PLC mais **plus marqués**
  - Nécroses kératinocytaires plus nombreuses, **confluentes**
  - Inflammation s'étendant au plexus vasculaire **moyen**
- Phénotype **CD8 > CD4**

### Érythème polymorphe (EP)

- Étiologies : **infectieuse** (mycoplasme, HSV+++) ou **médicamenteuse**
- Clinique : **cocardes** à centre bulleux, lésions bulleuses, atteintes muqueuses, érosions
- Histologie : dermatose vacuolaire **avec apoptose étagée**, peut aboutir à un décollement bulleux par **nécrose épidermique** quand l'apoptose devient confluente
- DD principal : toxidermies type **SJS/Lyell** et **érythème pigmenté fixe**

![[assets/dermato/dermatoses-inflammatoire-epiderme/dermatoses-interfaces/08-221 - Dermatoses lichénoïdes - approche diagnostique/p13_02.jpeg]]

### Réaction du greffon contre l'hôte (GVH)

- Maladie systémique post-allogreffe de cellules souches hématopoïétiques
- Lésions cutanéo-muqueuses prédominantes

#### GVH aiguë — 4 stades

| Stade | Histologie |
|-------|-----------|
| 1-2 | Dermatose vacuolaire + apoptose étagée |
| 3 | Apoptose plus étendue |
| **4** | Bulles, **clivage dermo-épidermique** par confluence |

#### GVH chronique
- Phase initiale : aspect de **lichen plan**
- Phase d'état : aspect **sclérodermiforme**

## Diagnostics différentiels (résumé)

| DD | Distinction |
|----|-------------|
| Lichen plan vs lupus chronique | LP : hypergranulose, dents de scie, IFD fibrinogène DEJ ; lupus : atrophie épidermique, mucine, IFD bande lupique IgG/C3 |
| EP vs SJS/Lyell | EP : cocardes typiques + muqueuses ; SJS/Lyell : décollement étendu, contexte médicamenteux |
| PLC vs mycosis fongoïde | MF : atypies lymphocytaires, abcès de Pautrier, perte CD7 |
| Lupus vs dermatomyosite | DM : atrophie épidermique, hématies extravasées, mucine, IFD souvent négative |

## 🔑 Points clés à retenir

1. **Dermite d'interface = dermatose lichénoïde** : lésion de la **DEJ** (apoptose + vacuolisation)
2. **4 éléments histo** : corps de Civatte, vacuolisation DEJ, incontinence pigmentaire, infiltrat dermique
3. **3 types** : lichénoïde vraie (lichen plan), vacuolaire (lupus), apoptose étagée (érythème polymorphe)
4. **Pas de PNE dans le lupus** → présence de PNN possible
5. **Hyperplasie lichénienne** + lésions multiples → lichen plan ; unique → kératose lichénoïde solitaire ; allogreffe → GVH chronique
6. **PLC** : papules en "**pain à cacheter**", hématies extravasées, lymphocytes CD4
7. **PLEVA** : papules cicatricielles varioliformes, nécroses confluentes, lymphocytes CD8
8. **Érythème polymorphe** = vacuolaire + apoptose étagée → confluente = bulle
9. **GVH** : aiguë (4 stades, vacuolaire → bulleuse) ; chronique (lichen plan → sclérodermiforme)
10. **Toxidermies** = polymorphisme des patterns, dont apoptose étagée (SJS/Lyell, EPF, DRESS)

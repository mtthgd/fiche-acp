# CAT devant une dermatose psoriasiforme — Approche diagnostique

> Liens : [[08_232_Psoriasis]] | [[08_211_Approche Diagnostique Dans Les Dermatoses Spongiotiques]] | [[08_221_Dermatoses lichénoïdes - approche diagnostique]] | [[08_212_DERMATITE ATOPIQUE-revuMB]]

## Définition de l'hyperplasie psoriasiforme

- **Allongement régulier** des crêtes épidermiques + **amincissement du toit** épidermique en regard des papilles dermiques
- C'est le caractère **régulier** + l'amincissement du toit qui définit la véritable hyperplasie psoriasiforme
- Limites des crêtes épidermiques nettes
- À distinguer de la **lichénification** : crêtes irrégulières, **pas d'amincissement** du toit

## Causes des hyperplasies psoriasiformes

### Causes constantes (de novo)

| Pathologie | Caractéristiques |
|------------|------------------|
| **Psoriasis** | cf. [[08_232_Psoriasis]] |
| **Dermatose psoriasiforme du sujet VIH** | Psoriasis floride résistant, fait évoquer une infection VIH |
| **Pityriasis rubra pilaire** (PRP) | Érythrodermie sèche orangée + atteinte du visage |
| **Syndrome de Fiessinger-Leroy-Reiter** | DD avec psoriasis pustuleux |

### Causes occasionnelles (au cours de l'évolution)

- **Toute dermatose spongiotique** chronique (eczéma)
- Candidoses chroniques, dermatophytie
- **Toxidermies** (notamment **anti-TNF alpha**)
- **Mycosis fongoïde / syndrome de Sézary**
- **Prurigo** (lichen simplex chronique)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p04_01.jpeg)

## Méthodologie diagnostique en 2 étapes

### Étape 1 — Régularité de l'hyperplasie

| Type | Description | Évoque |
|------|-------------|--------|
| **Régulière** + amincissement du toit | Crêtes parfaitement régulières, plateau aminci sur papilles | **Psoriasis**, dermatose psoriasiforme du VIH |
| **Irrégulière** sans amincissement | Plutôt lichénification | PRP, eczéma chronique, toxidermies, prurigo, mycosis fongoïde |

### Étape 2 — Analyse de la couche cornée

| Couche cornée | Évoque |
|---------------|--------|
| **Parakératose étendue sèche** + disparition de la couche granuleuse | **Psoriasis**, dermatose psoriasiforme du VIH |
| **Alternance ortho/parakératose** | **Pityriasis rubra pilaire** ++ ; aussi eczéma chronique, toxidermies |
| **Squame humide** (sérosités, "sero-croûte") | Dermatose chronique avec **spongiose** (eczéma subaigu/chronique) |
| **Plusieurs patterns associés** sur la même biopsie | **Toxidermie** (souvent anti-TNF) |
| **Lésions de grattage + collagène verticalisé** | **Prurigo** (lichen simplex chronique) |

## Algorithme diagnostique

```
Hyperplasie épidermique psoriasiforme ?
        │
        ├─ Régulière + amincissement du toit ?
        │       │
        │       ├─ Parakératose sèche étendue, disparition couche granuleuse
        │       │   + microabcès Munro / pustule Kogoj / vaisseaux dilatés / mitoses suprabasales
        │       │   → PSORIASIS (cf. 08-232)
        │       │
        │       └─ Pattern lichénoïde / nécrose kératinocytaire / infiltrat polymorphe
        │              (PNN, PNE, plasmocytes)
        │           → DERMATOSE PSORIASIFORME du sujet VIH (sérologie)
        │
        ├─ Irrégulière, sans amincissement
        │       │
        │       ├─ Alternance ortho/para + bouchons cornés folliculaires + parakératose péri-folliculaire
        │       │   + clinique érythrodermie orangée
        │       │   → PITYRIASIS RUBRA PILAIRE
        │       │
        │       ├─ Squame humide + foyers de spongiose
        │       │   → DERMATOSE CHRONIQUE AVEC SPONGIOSE (eczéma)
        │       │
        │       ├─ Plusieurs patterns différents (lichénoïde / spongiose / nécrose)
        │       │   sur la même biopsie ou différentes biopsies
        │       │   → TOXIDERMIE (anti-TNF α ?)
        │       │
        │       ├─ Lésions de grattage + collagène verticalisé + hypergranulose
        │       │   → PRURIGO / LICHEN SIMPLEX CHRONIQUE
        │       │
        │       └─ Lymphocytes atypiques épidermotropes (taille noyau > kératinocytes)
        │           → MYCOSIS FONGOÏDE / SYNDROME DE SÉZARY
```

## Entités spécifiques

### Psoriasis (forme typique)

Cf. [[08_232_Psoriasis]] pour les détails.
- Hyperplasie psoriasiforme régulière, amincissement du toit
- **Parakératose sèche étendue** + disparition couche granuleuse
- **Microabcès de Munro** dans la couche cornée
- **Pustules spongiformes de Kogoj**
- **Vaisseaux dilatés** dans les papilles dermiques
- Mitoses suprabasales, exocytose lymphocytaire

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p07_00.jpeg)

### Dermatose psoriasiforme du sujet VIH

- Contexte clinique : **apparition récente** d'un psoriasis **floride résistant** au traitement → faire **sérologie VIH**
- Histologie : hyperplasie psoriasiforme + signes additionnels :
  - **Spongiose** parfois
  - **Nécroses kératinocytaires**
  - Pattern **lichénoïde** possible
  - Infiltrat dermique **polymorphe** (PNN + PNE + plasmocytes + lymphocytes)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p08_00.jpeg)

### Pityriasis rubra pilaire (PRP)

#### Clinique
- **Érythrodermie sèche orangée**
- Atteinte du **visage**
- Kératodermie palmoplantaire orangée
- Îlots de peau saine ("nappage")

#### Histologie
- Hyperplasie épidermique **moins marquée**, **moins régulière** que le psoriasis
- **Aspect en damier** = alternance d'ortho et de parakératose **horizontale et verticale** (très caractéristique)
- **Bouchons cornés folliculaires** : hyperkératose feuilletée + **parakératose péri-folliculaire** (signe spécifique +++)


![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p09_06.jpeg)

### Dermatoses chroniques avec spongiose

- Contexte clinique : eczéma subaigu/chronique, dermatite atopique
- Histologie :
  - **Squame humide** imbibée de sérosités → **séro-croûte**
  - **Foyers de spongiose** (rechercher attentivement)
  - Acanthose irrégulière
  - **PAS systématique** pour éliminer candidose/dermatophytie

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p10_03.jpeg)

### Toxidermies (anti-TNF α en particulier)

- Contexte : chronologie médicamenteuse
- Histologie : **plusieurs patterns coexistent** soit sur biopsies différentes, soit sur la même biopsie :
  - Pattern **lichénoïde** (interface)
  - Pattern **spongiotique** (œdème)
  - Pattern de **nécrose kératinocytaire**
- L'**association de patterns** est un **argument fort** pour une toxidermie

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p11_03.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p12_03.jpeg)

### Prurigo / Lichen simplex chronique

- Clinique : plaques liées au **grattage**, prurit chronique
- Histologie :
  - **Alternance ortho et parakératose**
  - Lésions de grattage : **érosions, ulcérations**
  - **Hypergranulose** fréquente
  - Acanthose souvent **irrégulière**
  - **Collagène verticalisé** dermique +++ (signe quasi-spécifique)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p13_03.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p15_03.jpeg)

### Mycosis fongoïde / syndrome de Sézary avec aspect psoriasiforme

- Contexte clinique : plaques chroniques, érythrodermie de l'adulte
- Histologie :
  - Hyperplasie psoriasiforme
  - **Toujours analyser la cytologie des lymphocytes** intraépidermiques
  - **Lymphocytes atypiques épidermotropes** : noyaux dont la taille **dépasse celle des noyaux des kératinocytes adjacents**
  - **Abcès de Pautrier** (amas intra-épidermiques de lymphocytes)
  - **Halos clairs** péri-lymphocytaires
- IHC/biologie moléculaire : perte de CD7, **clonalité TCR**

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/dermato/dermatoses-inflammatoire-epiderme/dermatoses-psoriasiformes/08-231-CAT%20Dermatoses%20psoriasiformes/p16_03.jpeg)

## 🔑 Points clés à retenir

1. **Hyperplasie psoriasiforme** = allongement **régulier** des crêtes + **amincissement du toit** sur papilles
2. **Étape 1** : régularité de l'hyperplasie (régulière → psoriasis/VIH ; irrégulière → autres)
3. **Étape 2** : analyse de la couche cornée (parakératose sèche → psoriasis ; alternance → PRP ; humide → eczéma)
4. **Psoriasis** : parakératose sèche étendue + microabcès de Munro + vaisseaux dilatés + mitoses suprabasales
5. **PRP** : alternance ortho/parakératose "**en damier**" + **bouchons cornés folliculaires** + parakératose péri-folliculaire + clinique érythrodermie orangée
6. **Toxidermie** : suspecter si **plusieurs patterns histologiques associés** (lichénoïde + spongiose + nécrose), surtout sous **anti-TNF α**
7. **Prurigo / lichen simplex chronique** : grattage + **collagène verticalisé** + hypergranulose
8. **Dermatose psoriasiforme du VIH** : faire **sérologie VIH** si psoriasis floride résistant + infiltrat polymorphe
9. **Toujours regarder la cytologie lymphocytaire** pour éliminer un **mycosis fongoïde** (lymphocytes atypiques épidermotropes)
10. **PAS systématique** devant toute parakératose pour éliminer une **mycose** (candidose, dermatophytie)

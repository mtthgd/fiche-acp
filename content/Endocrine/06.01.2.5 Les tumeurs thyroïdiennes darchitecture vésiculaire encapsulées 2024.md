# Tumeurs thyroïdiennes d'architecture vésiculaire encapsulées (OMS 2022)

> Liens : [[06.01.2.3 Le carcinome papillaire de la thyroïde 1 2024]] | [[06.01.2.4 sous types du carcinome papillaire thyroïdien 2024]] | [[06.01.2.2 Adénomes et carcinomes vésiculaires thyroïdiens 2024]]

## Généralités et classification OMS 2022

Les tumeurs **vésiculaires encapsulées** se répartissent en trois catégories :

| Catégorie | Entités |
|-----------|---------|
| **Bénignes** | Adénome vésiculaire |
| **Faible risque** | **NIFTP** (non-invasive follicular thyroid neoplasm with papillary-like nuclear features), **tumeur thyroïdienne de potentiel de malignité incertain (WDT-UMP / FTUMP)** |
| **Malignes** | **Carcinome vésiculaire**, **carcinome oncocytaire**, **carcinome papillaire sous-type folliculaire encapsulé invasif (EFVPTC invasif)** |

Ce cours se concentre sur la **NIFTP**, les **UMP** et l'**EFVPTC invasif**. Les carcinomes vésiculaire et oncocytaire sont traités ailleurs.


## Principe diagnostique : l'invasion avant tout

La **capsule** est l'élément-clé. Diagnostic = recherche de signes d'**invasion capsulaire** ou d'**angio-invasion**.

### Macroscopie : sections perpendiculaires à la capsule


- Analogie de la **pomme** : **NE PAS couper en saucisson** (tranches irrégulières → coupes tangentielles → fausses images)
- Couper le nodule en deux, puis **tranches fines perpendiculaires à la capsule**
- **Inclusion exhaustive de TOUTE la capsule** = obligatoire
- Le nodule entier dans une cassette = INTERDIT

- 2016 : étude de 25 pathologistes internationaux. Les **FVPTC totalement encapsulés non invasifs** suivis 10-26 ans : tous vivants sans maladie.
- Groupe avec invasion : 12 évènements, 5 métastases, 2 décès.
- Le seul critère différenciant = **présence/absence d'invasion**.
- Reclassement vers une entité **non cancéreuse** (article NYT).


### Critères diagnostiques (OMS 2022)

| Critère | Exigence |
|---------|----------|
| **Taille** | Toute taille (3 mm à 50 mm) |
| **Encapsulation** | Capsule ± épaisse OU contours arrondis, bien limités |
| **Architecture** | Vésiculaire ; **< 1% papilles** tolérées ; **pas de psammomes** |
| **Noyaux** | **Grade nucléaire ≤ 2** (cf. ci-dessous) |
| **Invasion** | **AUCUNE** invasion capsulaire ni vasculaire (capsule incluse en totalité) |
| **Nécrose** | Interdite |
| **Mitoses** | **< 3/2 mm²** |
| **Architecture solide/insulaire/trabéculaire** | **< 30%** |
| **Sous-types agressifs** | Interdits (cellules hautes, etc.) |

![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p07_00.jpeg]]
![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p07_01.png]]

> Diagnostic **impossible en extemporané** (nécessite capsule incluse en totalité). Diagnostic **d'élimination** strict.

### Grade nucléaire (2016)

Trois catégories de critères :

| Critère | Détails |
|---------|---------|
| **1. Taille/forme** | Noyau plus gros qu'un thyréocyte normal, allongé, superpositions |
| **2. Irrégularités de membrane** | Contours irréguliers, **rainures (grooves)**, **pseudo-inclusions** |
| **3. Chromatine** | Clarifiée, margination chromatinienne, noyaux "en verre dépoli" |

- **0** : bénin
- **1** : équivoque
- **≥ 2** : noyaux de type papillaire → compatible NIFTP
- **3** : attention, rechercher critères d'exclusion → possible carcinome papillaire

> Beaucoup de **pseudo-inclusions** → chercher les papilles, probablement pas une NIFTP.

### IHC / Biologie moléculaire

- **IHC non obligatoire**. **BRAF négatif** (NIFTP n'est pas un cancer).
- L'absence de mutation BRAF **ne suffit PAS** à porter le diagnostic (appliquer strictement tous les critères).
- **Mutations RAS** dans 50-60% des cas.

### Compte-rendu et pronostic

- Décrire **taille + marges**, **pas de TNM** (non maligne)
- **Pas de récidive**, pas de potentiel invasif, pas d'augmentation de mortalité
- **Désescalade thérapeutique** (lobectomie suffit)
- > 1500 cas suivis : < 1% d'évènements, aucun décès
- Reco **SFE 2022** (recommandation 916) : pas de surveillance au long cours systématique, éventuellement échographie

## Tumeur de potentiel de malignité incertain (WDT-UMP / FTUMP)

![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p11_00.png]]

- **Rare** : 0,5 à 3% des lésions thyroïdiennes. Si diagnostic > 5% → critères mal appliqués.
- Lésion encapsulée, bien limitée, d'architecture vésiculaire
- Maître-mot : **invasion DOUTEUSE** (capsulaire, rarement vasculaire)
- Pas d'atypies franches, pas de nécrose, index mitotique normal
- **Recoupes sur les zones inquiétantes** avant de conclure
- Mutations de type **RAS**
- **Lobectomie** suffit, pas de traitement complémentaire

## Carcinome papillaire sous-type folliculaire encapsulé invasif (EFVPTC invasif)

![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p13_00.png]]
![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p13_01.png]]
![[assets/endocrine/thyroide_tumorale/06.01.2.5 Les tumeurs thyroïdiennes darchitecture vésiculaire encapsulées/p13_03.png]]

### Définition

Tous les mots comptent :
- **Carcinome papillaire** → **noyaux de type papillaire**
- **Sous-type folliculaire** → architecture folliculaire
- **Encapsulé**
- **Invasif** → invasion **capsulaire** et/ou **vasculaire**

> Préciser **type d'invasion** (angio-invasion >> invasion capsulaire en gravité).

### Points communs / différences

| Élément | NIFTP | EFVPTC invasif | Carcinome folliculaire encapsulé invasif |
|---------|-------|----------------|------------------------------------------|
| Architecture folliculaire | Oui | Oui | Oui |
| Encapsulé | Oui | Oui | Oui |
| Noyaux papillaires | Oui | Oui | **Non** |
| Invasion | **Non** | **Oui** | **Oui** |

Les EFVPTC invasifs et les carcinomes folliculaires encapsulés invasifs sont très proches : fusion probable dans les futures classifications. **L'invasion classe en malin**. Tous ont des mutations **RAS**.

## 🔑 Points clés à retenir

1. **Macroscopie +++** : couper le nodule en tranches **perpendiculaires à la capsule**, **inclusion de la capsule en totalité**.
2. **L'invasion est LE critère majeur** qui classe ces tumeurs : capsulaire ou angio-invasion.
3. **NIFTP** = lésion **non invasive**, encapsulée, d'architecture vésiculaire, avec noyaux **de type papillaire (grade 2)**, sans critères d'agressivité → **pas un cancer**, lobectomie suffit.
4. Critères stricts NIFTP : taille quelconque, **pas de papilles (< 1%)**, **pas de psammomes**, **< 30% solide/insulaire/trabéculaire**, **< 3 mitoses/2 mm²**, pas de nécrose, pas de sous-types agressifs.
5. **NIFTP = diagnostic d'élimination**, **impossible en extempo**. BRAF négatif, mutations **RAS** dans 50-60%.
6. **BRAF négatif ≠ NIFTP** : appliquer strictement tous les critères.
7. **WDT-UMP / FTUMP** : rare (0,5-3%), invasion **douteuse** malgré recoupes ; lobectomie suffit.
8. **EFVPTC invasif** = carcinome papillaire d'architecture folliculaire encapsulé AVEC invasion (capsulaire et/ou vasculaire). Très proche du carcinome folliculaire encapsulé invasif (tous RAS).
9. **Angio-invasion** >> invasion capsulaire seule en pronostic.
10. **Algorithme** : 1) invasion ? 2) noyaux papillaires ? → 6 diagnostics possibles.

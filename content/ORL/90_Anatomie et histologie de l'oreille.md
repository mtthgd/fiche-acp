# Anatomie et histologie de l'oreille

> Liens : [[91_Pathologie inflammatoire de l'oreille]] | [[92_Tumeurs bénignes de l'oreille]] | [[93_Tumeurs malignes de l'oreille]]

## Généralités

L'oreille est un **convertisseur d'ondes sonores en signal électrique**. Elle comporte 3 grandes zones de structure et de fonctions différentes :

| Zone | Composants principaux | Fonction |
|------|----------------------|----------|
| **Oreille externe** | Pavillon, conduit auditif externe (CAE), tympan | Capture, conduction, vibration |
| **Oreille moyenne** | Caisse du tympan, osselets, trompe d'Eustache, mastoïde | Amplification, transmission |
| **Oreille interne** | Labyrinthe osseux + labyrinthe membraneux (cochlée, vestibule, canaux semi-circulaires) | Transduction neurosensorielle |

## Physiologie rapide
Pavillon (capteur/résonateur) → CAE (conduction) → tympan (vibration) → chaîne ossiculaire (amplification) → fenêtre ovale → endolymphe → cils des cellules de **l'organe de Corti** (cellules neuroépithéliales) → signal électrique au nerf cochléaire.

## Oreille externe

### Pavillon
- Armature **cartilagineuse élastique** (sauf le **lobule**, uniquement adipocutané)
- Revêtement cutané : épiderme + derme, **hypoderme très réduit**
- Subdivisions : hélix, anthélix, conque, lobule, **tragus** (petite saillie protectrice du CAE)

![[assets/ORL/oreille/introduction/10-511 anatomie histologie oreille/p05_00.jpeg]]

### Conduit auditif externe
- Portion **fibro-cartilagineuse** externe (1/3 externe)
- Portion **osseuse** interne : épithélium malpighien kératinisant directement sur l'os
- **Tiers externe** : peau avec **annexes pilosébacées** + **glandes apocrines modifiées = glandes cérumineuses**

#### Glandes cérumineuses — histologie clé
Double assise :
- **Assise basale** aplatie périphérique (myoépithéliale)
- **Assise endoluminale** cylindrique avec :
  - petites **hernies apicales (decapitation secretion)**
  - cytoplasme **éosinophile**
  - **pigment brun-jaunâtre** caractéristique

**Importance** : reconnaître cette différenciation **apocrine** permet d'identifier les tumeurs cérumineuses (voir [[92_Tumeurs bénignes de l'oreille]], [[93_Tumeurs malignes de l'oreille]]).

![[assets/ORL/oreille/introduction/10-511 anatomie histologie oreille/p07_00.jpeg]]
![[assets/ORL/oreille/introduction/10-511 anatomie histologie oreille/p08_00.jpeg]]

### Tympan
- Membrane très fine : **0,1 mm** d'épaisseur, convexe en dedans
- **3 couches** :

| Couche | Description |
|--------|-------------|
| Externe | Épithélium malpighien kératinisant (continuité CAE) |
| Moyenne | Couche **fibreuse** (fibres radiaires + circulaires) |
| Interne | Épithélium de la caisse (aplati ou cubique) |

- Sépare oreille externe/moyenne
- Le **manche du marteau** est entièrement intégré dans l'épaisseur du tympan

## Oreille moyenne

### Parois de la caisse du tympan
| Paroi | Structure |
|-------|-----------|
| Externe | **Tympan** |
| Interne | Paroi **labyrinthique** (avec fenêtre ovale et ronde) |
| Antérieure | **Trompe d'Eustache** |
| Postérieure | **Mastoïde** |
| Toit | **Tegmen tympani** |
| Plancher | Proéminence styloïde (sus-jacente à la fosse jugulaire) |

### Épithélium de la caisse
- Assise **cubique ou aplatie** (uni- ou pluristratifié)
- Devient **cylindrique cilié** vers la trompe d'Eustache

### Cellules mastoïdiennes
Espaces aériques creusés dans la mastoïde, tapissés par l'épithélium de la caisse.

### Trompe d'Eustache
- Épithélium de **type respiratoire** (cylindrique cilié pseudo-stratifié)
- Corion : **glandes sous-muqueuses sero-muqueuses**, parfois **tissu lymphoïde**

![[assets/ORL/oreille/introduction/10-511 anatomie histologie oreille/p12_00.jpeg]]
![[assets/ORL/oreille/introduction/10-511 anatomie histologie oreille/p14_00.jpeg]]

### Osselets — les 3 plus petits os du corps humain
1. **Marteau** (manche inclus dans le tympan) — s'articule avec...
2. **Enclume** — s'articule avec...
3. **Étrier** — platine appuyée sur la **fenêtre ovale (vestibulaire)**

## Oreille interne

### Labyrinthe osseux
- **Antérieur** : cochlée (en limaçon)
- **Postérieur** : vestibule + canaux semi-circulaires (3 : latéral, postérieur, supérieur)

### Labyrinthe membraneux (dans le labyrinthe osseux)
- **Membrane basilaire** remplie d'**endolymphe**
- Revêtue de **cellules ciliées**
- **Vestibule membraneux** : **saccule** et **utricule**
- **Ampoules** des canaux semi-circulaires
- **Cochlée membraneuse** : contient l'organe de Corti

### Organe de Corti (organe de l'audition)
- **Cellules ciliées externes** et **internes** (cellules neuroépithéliales)
- Reposent sur des **cellules de soutien**
- Cilia → contraction → signal électrique au **nerf cochléaire (VIII)**

## Tableau synthétique des épithéliums

| Localisation | Type épithélial | Caractéristiques |
|--------------|-----------------|------------------|
| Pavillon | Épiderme cutané + cartilage élastique | Lobule = pas de cartilage |
| CAE externe | Épithélium malpighien kératinisant + annexes pilosébacées + **glandes cérumineuses (apocrines)** | |
| CAE interne | Malpighien kératinisant sur os | |
| Tympan externe | Malpighien kératinisant | |
| Tympan moyen | Fibreux | |
| Tympan interne / Caisse | Cubique ou cylindrique cilié | |
| Trompe d'Eustache | Respiratoire (cilié pluristratifié) + glandes séromuqueuses | |
| Oreille interne | Neuroépithélium (cellules ciliées) | Organe de Corti |

## Intérêt pour l'anatomopathologiste

- **Connaître la différenciation apocrine** des glandes cérumineuses → clé pour les adénomes/adénocarcinomes cérumineux
- **Reconnaître l'épithélium de la caisse** et ses modifications dans les otites chroniques (**pseudoglandes**)
- **Savoir différencier** l'épithélium malpighien du CAE (normal) de celui présent anormalement dans la caisse (= **cholestéatome**)
- **Tympanosclérose** : reconnaissance de la couche fibreuse du tympan épaissie/calcifiée

## 🔑 Points clés à retenir
1. Oreille = **3 zones** : externe (pavillon + CAE + tympan), moyenne (caisse + osselets + trompe + mastoïde), interne (labyrinthe)
2. Pavillon = **cartilage élastique** (sauf **lobule** = pas de cartilage)
3. Glandes **cérumineuses** = glandes **apocrines modifiées** avec **double assise** (basale + endoluminale avec hernies apicales et pigment brun-jaune)
4. Tympan = **3 couches** (malpighien kératinisant, fibreuse, caisse) d'épaisseur **0,1 mm**
5. Le **manche du marteau** est inclus dans le tympan
6. Caisse du tympan = épithélium **cubique/aplati**, devient cylindrique cilié vers la trompe d'Eustache
7. Trompe d'Eustache = épithélium **respiratoire** avec glandes séromuqueuses et tissu lymphoïde
8. Les **3 osselets** : marteau → enclume → étrier (platine sur fenêtre ovale)
9. Labyrinthe osseux = **cochlée** (antérieure) + **vestibule** + **3 canaux semi-circulaires**
10. Labyrinthe membraneux contient **endolymphe** et les cellules ciliées
11. **Organe de Corti** = cellules ciliées externes/internes → signal au **nerf VIII**
12. Reconnaître la différenciation **apocrine** des glandes cérumineuses = clé diagnostique pour les tumeurs de l'oreille

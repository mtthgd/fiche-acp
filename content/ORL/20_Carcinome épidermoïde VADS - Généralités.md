# Carcinome épidermoïde des VADS — Généralités et épidémiologie

> Liens : [[21_Lésions précancéreuses des VADS]] | [[22_Carcinome épidermoïde larynx pharynx cavité buccale]] | [[23_Carcinome épidermoïde oropharynx]] | [[24_Carcinome nasopharyngé]] | [[25_Outils moléculaires VADS]]

## Généralités

Les carcinomes épidermoïdes (CE) sont le type histologique largement majoritaire (> 70 %) des cancers ORL.
- **4 %** des cancers masculins, **2 %** des cancers féminins
- **4ème cancer** chez l'homme (après prostate, poumon, côlon)
- **3 %** des décès par cancer masculin, **1 %** féminin
- Diagnostic souvent à un **stade avancé**

## Évolution épidémiologique

- **Larynx** : incidence en **baisse** depuis les années 1980 (baisse de la consommation alcoolo-tabagique)
- **Oropharynx** : incidence en **augmentation** (~ **+5%/an**) en lien avec l'**infection HPV**
- Cavité buccale / lèvres : incidence en baisse
- Différences régionales importantes

## Survie globale par localisation

| Site | Survie 5 ans |
|------|:---:|
| **Larynx** | ~60 % (T1 : 80-85 % ; T4 : 50 %) |
| Hypopharynx | ~60 % (intermédiaire) |
| **Pharynx** | 25-52 % |
| **Cavité buccale** | ~60 % |
| **Oropharynx** | ~50 % |
| Nasopharynx | ~50 % |
| Fosses nasales / sinus | ~60 % |
| **Trachée** | **25 %** (très mauvais) |

## Épidémiologie par localisation

### 1. Fosses nasales et sinus (FNS)

- **1 %** de toutes les tumeurs, **3 %** des cancers ORL
- **Sinus maxillaires +++** (60 %), puis cavité nasale, sinus ethmoïde, sinus frontal, sinus sphénoïde
- Homme, **50-70 ans**
- Mortalité 5 ans ≈ **40 %**, pronostic plus péjoratif pour les sinus que pour la cavité nasale
- **Facteurs de risque** :
  - Tabac, alcool
  - **Métaux lourds** : nickel, chrome
  - **Expositions professionnelles** : poussières de bois (adénocarcinome ethmoïdal), textiles

### 2. Nasopharynx

- **0,5 %** de tous les carcinomes (rare)
- Incidence **très élevée** : **Chine (jusqu'à 18%)**, Afrique du Nord, Asie du Sud-Est
- **Facteurs de risque** :
  - **Virus Epstein-Barr (EBV) +++**
  - Nourriture riche en **nitrosamines** (poissons/viandes fumés)
  - Tabac, produits chimiques, formaldéhyde
- **Classification OMS 2017** — 3 sous-types :
  - **CE non kératinisant** (avec formes différenciées / indifférenciées)
  - **CE kératinisant**
  - **CE basaloïde**
- Homme 40-60 ans, mortalité 5 ans ≈ 50 %

### 3. Larynx

- **1 %** des cancers dans le monde
- **Homme +++** (sex-ratio 6:1), 50-70 ans
- Localisation la plus fréquente : **glottique** et **supraglottique**
- **Pronostic** :
  - **T1 : 90 %** de survie à 5 ans
  - T4 : 50 %
  - Sous-glottique = pronostic plus mauvais
- **Facteurs de risque** :
  - **Tabac + alcool +++**
  - Reflux gastro-œsophagien (discuté)
  - **HPV et EBV rarement impliqués** dans cette localisation

### 4. Cavité buccale

- **3 %** de tous les cancers
- Sex-ratio 3:1, âge médian ~**60 ans**
- Survie 5 ans : 60 %
- **Facteurs de risque** :
  - **Tabac +++** (facteur principal)
  - Alcool
  - **Mastication de bétel / chique** (Asie du Sud-Est)
  - Hygiène dentaire
  - UV (pour les lèvres)

### 5. Oropharynx

- **Fréquence en augmentation : +5 %/an** (HPV)
- Âge médian **50-60 ans** (plus jeunes, -5 ans vs autres localisations)
- Localisations préférentielles : **amygdales palatines, base de langue**
- Pourquoi ? Épithélium **cryptique** dans le tissu lymphoïde = cible de l'HPV (anneau de Waldeyer)
- Patients **HPV+ : 60 % non-fumeurs** ; HPV− : quasi tous alcoolo-tabagiques
- Survie 5 ans ≈ 50 %
- **80 % de métastases ganglionnaires d'emblée**

## Profil génétique des CE VADS

- Profil **très complexe**, nombreuses anomalies génétiques apparaissant **dès le stade de dysplasie**
- Mutations récurrentes : **TP53, CDKN2A, FAT1, NOTCH1, PIK3CA, KMT2D**
- CE HPV+ : **TP53 sauvage**, mutations PIK3CA, **surexpression de p16**
- CE HPV− (alcoolo-tabagique) : **TP53 muté**, CDKN2A inactivé
- **Pas de biomarqueur pronostique/prédictif validé** à ce jour

## Principaux sites et variantes histologiques

| Site | Variantes principales |
|------|----------------------|
| Larynx / pharynx / cavité buccale | CE conventionnel, verruqueux, basaloïde, sarcomatoïde (à cellules fusiformes), papillaire, adénosquameux, lymphoépithélioma-like, acantholytique |
| Oropharynx | CE non kératinisant **HPV+** vs CE kératinisant **HPV−** |
| Nasopharynx | CE non kératinisant (indifférencié/différencié) **EBV+**, CE kératinisant, CE basaloïde |
| FNS | CE kératinisant, non kératinisant, NUT carcinoma, SMARCB1-déficient, HPV-related carcinoma with adenoid cystic features |

## Diagnostics différentiels génériques

| DD | Distinction |
|----|-------------|
| Mélanome | **Mélan A, HMB45, SOX10 +** |
| Carcinome neuroendocrine | **Chromogranine, synaptophysine +**, CK8/18+ |
| Lymphome | **CD45, CD3, CD20 +** |
| Sarcome | Desmin, actine, autres |
| Hyperplasie pseudo-épithéliomateuse | Pas d'atypies, pas de mitoses anormales |

## 🔑 Points clés à retenir

1. CE = type histologique **> 70 %** des cancers ORL
2. Le **tabac + alcool** sont les facteurs de risque principaux (90 % des CE larynx/pharynx/cavité buccale)
3. **HPV16/p16** : facteur de risque dominant de l'**oropharynx** (amygdale, base de langue), incidence en **augmentation +5%/an**
4. **EBV** : oncogène majeur du **carcinome nasopharyngé** (zones d'endémie : Chine, Maghreb, Asie du Sud-Est)
5. Carcinogènes professionnels FNS : **nickel, chrome, poussières de bois, textiles**
6. Localisation **glottique** = meilleur pronostic (T1 : 85 %) ; **sous-glottique/trachée** = pire
7. CE HPV+ de l'oropharynx = **meilleur pronostic**, plus chimio/radiosensible
8. Profil génétique complexe avec anomalies dès la dysplasie : **TP53, CDKN2A, FAT1, NOTCH1, PIK3CA**
9. Pas de biomarqueur pronostique/prédictif validé en routine
10. 80 % des CE oropharyngés HPV+ présentent des métastases ganglionnaires d'emblée
11. Le TNM UICC/AJCC 8e éd. distingue un **TNM spécifique pour les CE oropharyngés p16+**
12. Toujours éliminer les DD (mélanome, sarcome, lymphome, NET) par panel IHC sur CE peu différencié

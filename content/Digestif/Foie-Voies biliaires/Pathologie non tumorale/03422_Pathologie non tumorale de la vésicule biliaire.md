# Pathologie non tumorale de la vésicule biliaire

> Liens : [[03416_Prise en charge macroscopique dune pièce de résection hépatique ou de voie biliaire]] | [[03426_Pathologie hépatique auto-immune]] | [[03414_Lésions élémentaires en pathologie hépatique]]

## Rappels anatomiques et histologiques

### Anatomie

- **Vésicule biliaire** = sac piriforme **7-10 cm** de long, diamètre corporel **~3 cm**
- Paroi fine **1-3 mm**, contient **40-70 mL** de bile
- Accolée à la **face inférieure des segments 4 et 5** = **lit vésiculaire** (pas de feuillet péritonéal à ce niveau)
- 3 zones :
  - **Col / collet** (après le canal cystique) → ganglion satellite parfois présent
  - **Corps**
  - **Fond vésiculaire**


### Histologie normale

3 couches :
| Couche | Composition |
|--------|-------------|
| **Muqueuse** | Franges + épithélium **cubo-cylindrique de type biliaire**, chorion peu abondant avec rares éléments inflammatoires |
| **Musculeuse** | Couche **fibro-musculaire** |
| **Séreuse / adventice** | Tissu conjonctivo-adipeux richement vascularisé |

### Sinus de **Rokitansky-Aschoff**
- Petites **invaginations** de la muqueuse dans la couche fibro-musculaire
- **Quasi-physiologiques**, fréquents
- ⚠️ **Piège diagnostique majeur** : ne pas confondre avec un **adénocarcinome infiltrant**

## 1. Lithiases biliaires

- **25 %** de la population de **> 50 ans**
- **80-90 %** asymptomatiques
- Si symptomatique → **colique hépatique**
- Facteurs favorisants : composition anormale de la bile, **stase biliaire**, **infections**

### Types de calculs

| Type | % | Composition |
|------|---|-------------|
| **Cholestéroliques (jaunes)** | **60-70 %** | Cholestérol → composition anormale de la bile |
| **Pigmentaires noirs / bruns** | **10-25 %** | Bilirubine ; **bruns liés à infections** |
| **Mixtes** | reste | |

## 2. Cholécystite aiguë

### Clinique
- **Apparition brutale et persistante** de douleur de type colique hépatique + **fièvre**
- **Signe de Murphy** = défense en hypocondre droit en inspiration
- **Hyperleucocytose**
- Échographie : **épaississement pariétal**
- **90 % d'origine lithiasique** ; alithiasique surtout chez les patients de réanimation

### Macroscopie
- Paroi **épaissie**, souvent **hémorragique**
- Muqueuse **ulcérée**
- **Toujours vérifier la présence de calcul** (sinon possible **migration lithiasique**)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/foie-voie_biliaire/non-tumorale/03.4.2.2%20Pathologie%20non%20tumorale%20de%20la%20v%C3%A9sicule%20biliaire/p10_00.jpeg)

### Histologie

Phase précoce → tardive :
1. **Vasculo-exsudative / hémorragique** : remaniements œdémato-congestifs
2. **PNN + nécrose muqueuse**
3. Évolution selon la gravité :

| Forme | Caractéristique |
|-------|----------------|
| **Purulente** | Nécrose **purulente extensive** |
| **Gangréneuse** | Nécrose **acidophile transmurale** |
| **Emphysémateuse** | Vacuoles optiquement vides → **dégagement gazeux** (germes anaérobies) |

> Toujours rechercher des signes de **cholécystite chronique associée** sous-jacente.

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.6%20L%C3%A9sions%20et%20tumeurs%20kystiques%20du%20pancr%C3%A9as/p12_03.png)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/foie-voie_biliaire/non-tumorale/03.4.2.2%20Pathologie%20non%20tumorale%20de%20la%20v%C3%A9sicule%20biliaire/p15_00.png)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.12%20Pathologie%20tumorale%20et%20pseudo-tumorale%20de%20lampoule%20de%20Vater/p15_02.png)

### ⚠️ Piège : épithélium **dystrophique**
Lors de cholécystite, l'épithélium peut présenter :
- Ascensions de noyaux
- Noyaux volumineux, parfois nucléolés
- **Exocytose** d'éléments inflammatoires

→ **Ne pas confondre avec une dysplasie** !

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.8%20Tumeurs%20intracanalaires%20pancr%C3%A9atiques/p13_01.jpeg)

## 3. Cholécystite chronique

### Clinique
- **95 %** associée à **lithiase**
- **Pas de corrélation** entre intensité des lésions inflammatoires et nombre/taille des calculs
- Coliques hépatiques **récidivantes**

### Macroscopie
Décrire :
- **Contenu** : nombre + couleur des calculs
- **Paroi** : normale / atrophique / hypertrophique
- **Muqueuse** : normale / **fraise** / ulcérée / nécrotique / végétante / polypoïde

### Histologie

| Compartiment | Lésion |
|--------------|--------|
| **Muqueuse** | Atrophique (perte du relief), laminée, hyperplasique, villeuse, pseudo-adénomateuse |
| **Chorion** | Infiltrat inflammatoire **chronique** (lymphocytes, plasmocytes, ± histiocytes, PNE) |
| **Stroma** | **Fibrose** focale ou diffuse |
| **Musculeuse** | **Hypertrophie** ± marquée |
| | Lésions de **métaplasie** : **gastrique pylorique** (++), intestinale |
| | **Endartérite fibreuse** + **hyperplasie nerveuse** |

## 4. Formes particulières de cholécystite chronique

### Cholécystite à **IgG4**

- **Rare**, presque jamais isolée
- Associée dans **50-90 %** des cas à une **atteinte pancréatique** (pancréatite auto-immune type 1)
- **Hommes ~60 ans**

| Aspect | Macroscopie | Microscopie |
|--------|-------------|-------------|
| Paroi | **Épaississement circonférentiel et homogène** | Très épaissie par fibrose **storiforme** par place |
| Infiltrat | | **Lympho-plasmocytaire dense** transmural |
| Vaisseaux | | **Phlébite oblitérante** |
| IHC | | **> 50 plasmocytes IgG4+** par champ ×40 |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.12%20Pathologie%20tumorale%20et%20pseudo-tumorale%20de%20lampoule%20de%20Vater/p22_01.png)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.12%20Pathologie%20tumorale%20et%20pseudo-tumorale%20de%20lampoule%20de%20Vater/p22_03.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.6%20L%C3%A9sions%20et%20tumeurs%20kystiques%20du%20pancr%C3%A9as/p22_04.png)

### Autres formes rares

| Forme | Caractéristique |
|-------|----------------|
| **Folliculaire** | Hyperplasie lymphoïde folliculaire diffuse |
| **À éosinophiles** | Infiltrat à **PNE** prédominant |
| **Xanthogranulomateuse** | Macroscopie : paroi très épaissie, **jaunâtre** ; histologie : nappes d'**histiocytes spumeux** + lymphocytes + plasmocytes |
| **Malacoplakie** | Très rare ; nappes de macrophages éosinophiles, ± **corps de Michaelis-Gutmann (PAS+)** |

## 5. Adénomyose

- **Lésion fréquente** : **> 90 %** associée à un calcul
- 3 formes :
  - **Localisée** au fond vésiculaire = **adénomyome**
  - **Segmentaire**
  - **Diffuse**
- Histologie : **multiples sinus de Rokitansky-Aschoff** + **hyperplasie** musculaire s'étendant dans la séreuse

⚠️ Possibles images de **pseudo-infiltration nerveuse** → ne pas confondre avec un **adénocarcinome infiltrant** !



---

## 6. Cholestérolose

- Très fréquente : **10-25 %** des cholécystectomies
- Souvent associée à une cholécystite chronique
- **Macroscopie** : aspect **"vésicule fraise"** (petits points jaunes sur muqueuse rouge)
- **Microscopie** : amas d'**histiocytes spumeux** dans le chorion élargissant les franges
- Parfois sous forme de **polypes cholestéroliques**

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/foie-voie_biliaire/non-tumorale/03.4.2.2%20Pathologie%20non%20tumorale%20de%20la%20v%C3%A9sicule%20biliaire/p27_00.png)

## 7. Hétérotopies

- **Très rares**, asymptomatiques, découverte fortuite
- Macroscopie : **nodules**
- Microscopie : tissu normal **d'un autre organe** dans la paroi vésiculaire
- Types : **gastrique**, **pancréatique**, **hépatique**, thyroïdienne, cortico-surrénalienne

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/pancreas/tumorale/03.3.3.12%20Pathologie%20tumorale%20et%20pseudo-tumorale%20de%20lampoule%20de%20Vater/p28_01.png)

## Diagnostics différentiels — pièges majeurs

| À ne **PAS** confondre avec | Lésion bénigne |
|---------------------------|----------------|
| Adénocarcinome infiltrant | **Sinus de Rokitansky-Aschoff** |
| Adénocarcinome infiltrant | **Adénomyose** (pseudo-infiltration nerveuse) |
| Dysplasie épithéliale | **Épithélium dystrophique** d'une cholécystite |

## 🔑 Points clés à retenir

1. Vésicule biliaire = **7-10 cm**, paroi **1-3 mm** ; histologie : muqueuse cubo-cylindrique + musculeuse + séreuse
2. **Sinus de Rokitansky-Aschoff** = invaginations physiologiques ; **piège** = ne pas confondre avec adénocarcinome infiltrant
3. **Lithiase** = **25 % des > 50 ans**, asymptomatique 80-90 % ; calculs **cholestéroliques 60-70 %** (jaunes), pigmentaires (noirs/bruns) 10-25 %
4. **Cholécystite aiguë** : **90 % lithiasique**, signe de Murphy + fièvre + hyperleucocytose ; formes purulente / gangréneuse / **emphysémateuse**
5. Cholécystite chronique : **95 % lithiasique**, infiltrat lympho-plasmocytaire + fibrose + métaplasie pylorique fréquente
6. **Cholécystite à IgG4** : associée à pancréatite AI dans 50-90 % ; fibrose **storiforme** + **phlébite oblitérante** + **> 50 plasmocytes IgG4+/champ ×40**
7. Cholécystite **xanthogranulomateuse** : paroi jaunâtre, histiocytes spumeux ; ne pas confondre avec carcinome
8. **Adénomyose** : > 90 % avec calcul, multiples sinus + hyperplasie musculaire ; pseudo-infiltration nerveuse possible
9. **Cholestérolose** = **vésicule fraise** macroscopique + histiocytes spumeux dans le chorion
10. **Hétérotopies** : surtout gastrique, pancréatique, hépatique ; asymptomatiques
11. Toujours différencier **épithélium dystrophique** (cholécystite) de la **dysplasie** vraie
12. Décrire systématiquement en macroscopie : **contenu** (calculs) + **paroi** (épaisseur) + **muqueuse** (aspect)

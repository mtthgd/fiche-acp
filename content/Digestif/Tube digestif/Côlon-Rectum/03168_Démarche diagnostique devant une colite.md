# Démarche diagnostique devant une colite

> Liens : [[03162_Les colites aigues]] | [[03164_Les maladies inflammatoires chroniques intestinales (MICI)]] | [[03166_Colites chroniques hors MICI]]

## Objectifs

1. Affirmer une colite (éliminer côlon normal / artefacts)
2. Définir un **pattern lésionnel** : inflammatoire vs ischémique
3. Si pattern inflammatoire → colite **aiguë**, **chronique** ou **chronique active**
4. Proposer une orientation étiologique (clinique + endoscopie)

## Prérequis pour interprétation

### Renseignements endoscopiques indispensables
- Type de lésions : érosion, ulcération, creusante ou non
- Distribution : diffuse vs segmentaire, continue vs intervalle sain
- Segments atteints + statut iléal
- Endoscopie haute associée

### Échantillonnage
- **Minimum 4 fragments par segment colique** dans des **pots séparés**
- Pot iléon séparé

## Histologie normale du côlon

- Épithélium plat, non festonné
- Glandes parallèles, non atrophiques, touchant la musculaire muqueuse
- **Cellularité décroissante** du côlon droit vers le rectum
- Plasmocytose **modérée**, plutôt **superficielle** (gradient plasmocytaire normal)
- **Cellules de Paneth** : possibles jusqu'à l'angle gauche (au-delà = métaplasie)
- Nodules lymphoïdes **physiologiques** (refoulent les cryptes contiguës, lymphocytose accrue en regard — ne pas compter à ce niveau)
- Lymphocytose intra-épithéliale normale **< 5-10 %**
- Muciphages, hémosidérine peuvent être présents
- **Pseudolipomatose** = artefact d'insufflation = pas une colite

## Affirmer une colite

= lésions significatives de l'épithélium (surface ou cryptes).

## Définir le pattern

| Pattern | Caractère |
|---------|-----------|
| **Inflammatoire** | Lamina propria **dense, hypercellulaire** ± lésions épithéliales |
| **Ischémique** | Lésions épithéliales **majeures** + lamina propria **peu cellulaire** |
| **Mixte** (aigu pseudomembraneuse) | Endotoxine bactérienne, post-infectieuse |

| Pattern | Type | Étiologies prépondérantes |
|---------|------|----------------------------|
| Inflammatoire | **Aiguë** | Infectieuse (1ʳᵉ cause), médicamenteuse |
| Inflammatoire | **Microscopique** | Auto-immune, médicamenteuse |
| Inflammatoire | **Chronique active (MICI)** | Crohn, RCH, indéterminée |
| Inflammatoire | **Chronique pseudo-MICI** | Diverticulaire, dérivation, DICV, GVH, médicamenteuse |
| Ischémique | Aiguë / chronique | Vasculaire, médicamenteuse, radique |
| Ischémique | Pseudomembraneuse | *C. difficile*, EHEC, neutropénique |

## Colite inflammatoire aiguë

**Étiologie principale** : infectieuse (*acute self-limited colitis*).

**Histologie** :
- Lésions diffuses, homogènes, sans intervalle sain
- Infiltrat à prédominance **PNN**
- **Œdème + congestion superficielle**
- Sous-muqueuse intacte, musculaire muqueuse intacte
- **PAS de signe de chronicité** : pas de plasmocytose basale, pas de désordre architectural, pas d'atrophie

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p11_03.jpeg]]

> ⚠️ *Campylobacter*, *Salmonella* peuvent donner des **diarrhées prolongées** > 6 semaines avec quelques signes de chronicité.

### Lésions de spécificité (rares)

- *Yersinia* (granulomes), CMV (inclusions intra-nucléaires sur IHC), schistosomes (œufs), tuberculose (caséum)

### Pseudomembraneuse

Pas spécifique d'un agent. Plusieurs bactéries (par sécrétion d'endotoxines) :
- ***C. difficile*** (toxine A/B) — le plus fréquent
- *E. coli* entérohémorragique (EHEC)

## Colite microscopique

**Triade** : diarrhée hydrique chronique bien tolérée + **endoscopie normale** + histologie spécifique.

| Type | Critère |
|------|---------|
| **Lymphocytaire** | **> 20 LIE/100** cellules épithéliales de surface |
| **Collagène** | **Bande basale ≥ 10 µm** (HES + safran ou trichrome) |
| Lymphocytaire paucicellulaire | 10-20 LIE/100 + diarrhée |

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p13_02.jpeg]]


### Pièges

- **Pas de passage** lymphocytaire ↔ collagène, ni vers MICI
- Cryptiteà PNN possible dans 30 % (n'exclut pas une colite microscopique)
- Métaplasie de Paneth possible dans formes sévères / réfractaires
- **Endoscopie toujours normale** ; si anormale → MICI à rechercher

### Spirochétose colique

Si diarrhée chronique + endoscopie normale + histologie normale → penser à la **spirochétose** : bactéries fusiformes plantées dans l'épithélium de surface, **mieux vues au PAS**, contexte HSH ou HIV, traitement uniquement si symptomatique.

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p16_03.png]]

## Colite chronique active (MICI)

**Diagnostic = confrontation clinique + endoscopie + histologie.**

### 2 signes de chronicité à rechercher
1. **Distorsion glandulaire** (cryptes branchées, dilatées, horizontalisées, atrophiques, hiatus, surface festonnée/villeuse)
2. **Plasmocytose basale** (perte du gradient plasmocytaire normal, plasmocytes denses contre la musculaire muqueuse)

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p20_01.jpeg]]

### Activité

| État | Signes |
|------|--------|
| **Active** | PNN dans le chorion, cryptite, abcès, érosions/ulcérations |
| **Quiescente** | Distorsion + plasmocytose résiduelle, **pas de PNN** |

### Type de MICI

| Critère | **Crohn** | **RCH** |
|---------|-----------|---------|
| Distribution | Focale, patchy, hétérogène | **Diffuse, homogène** |
| Rectum | Épargné possible | **Toujours atteint** |
| Granulomes | 30 % (à rechercher) | Absents |
| Distorsion | Modérée | **Marquée** |
| Plasmocytose | Modérée | **Majeure** |
| Lésions ano-périnéales | OUI | NON |

> **Gastrite focale active** *H. pylori* négative : aide d'orientation Crohn mais **non spécifique** (vue dans RCH chez l'adolescent).

## Colite chronique pseudo-MICI (non MICI)

À évoquer devant pattern inflammatoire chronique sans confirmation MICI :

- **Infection prolongée** (cf. colites infectieuses)
- **Médicaments** (anamnèse !)
- **Diverticulaire** (sigmoïde au contact de diverticules)
- **Dérivation** (segment exclu)
- Colite d'amont d'un obstacle chronique (pullulation bactérienne)
- **DICV** (déficit immunitaire commun variable)
- **GVH** (greffe de moelle)

### Signe d'alerte : apoptoses cryptiques nombreuses

→ 4 diagnostics à évoquer :
1. **GVH**
2. Médicament (sartans, AINS, **5-FU** = pseudo-GVH avec PNE et apoptoses)
3. **DICV**
4. Entérocolite auto-immune (rare, adulte)

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p23_03.jpeg]]

## Colite de pattern ischémique

### Contexte
- Sujet âgé athéromateux ou jeune (cocaïne, AINS, marathonien)
- Atteinte segmentaire **angle splénique / côlon gauche**, rectum **épargné** (vascularisation différente)

### Histologie
- Lésions épithéliales majeures + chorion peu inflammatoire
- Œdème, hémorragie, dépôts fibrineux
- Athrophie / nécrose glandulaire selon sévérité
- Phase chronique : **fibrose profonde**, hémosidérine (Perls +), microthrombi

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p26_04.jpeg]]

![[assets/digestif/tube_digestif/colon-rectum/03.1.6.8 Démarche diagnostique devant une colite/p27_04.jpeg]]

> **Colite radique chronique** = pattern ischémique chronique avec fibrose profonde, dystrophie glandulaire, angiogenèse.

### Variantes ischémiques particulières

| Type | Contexte |
|------|----------|
| **Pseudomembraneuse** | ATB → ***C. difficile*** (toxines A/B), EHEC |
| **Neutropénique** (typhlite) | Chimio + neutropénie profonde, prédominance **droite**, peu/pas de PNN |
| Colite EHEC | Hamburgers infectés, microthrombi multiples |

## Vocabulaire à éviter dans les CR

| Terme à éviter | Raison |
|----------------|--------|
| Colite « subaiguë » | Ne correspond ni à aiguë ni à chronique |
| Colite « interstitielle » | Pas de signification |
| Colite « chronique non spécifique » | Donner une orientation : ischémique vs inflammatoire, ou « indéterminée » |

## Algorithme synthétique

```
Biopsie colique
   │
   ├─ Lamina propria hypercellulaire ?
   │     ├─ OUI = pattern inflammatoire
   │     │     ├─ Signes de chronicité ? (distorsion + plasmocytose basale)
   │     │     │     ├─ NON → COLITE AIGUË (infectieuse, médicamenteuse...)
   │     │     │     └─ OUI → COLITE CHRONIQUE → MICI ?
   │     │     │           ├─ Confrontation clinico-endoscopique
   │     │     │           └─ Si pas MICI → diverticulaire, dérivation, GVH, DICV
   │     │     └─ Endoscopie normale + diarrhée hydrique → COLITE MICROSCOPIQUE
   │     │           ├─ LIE > 20/100 → lymphocytaire
   │     │           └─ Bande ≥ 10 µm → collagène
   │     │
   │     └─ NON = pattern ischémique
   │           ├─ Topographie : angle gauche +++
   │           ├─ Aigu vs chronique selon sévérité atrophie/fibrose
   │           └─ Variantes : pseudomembraneuse, neutropénique, radique
```

## 🔑 Points clés à retenir

1. **Renseignements cliniques + endoscopiques indispensables** : siège, distribution, durée des symptômes, traitements
2. **Échantillonnage** : ≥ 4 fragments par segment, **pots séparés**, iléon prélevé
3. Affirmer la colite = lésions épithéliales significatives ; éliminer le côlon droit normal (plus cellulaire), pseudolipomatose
4. **Pattern inflammatoire** : LP hypercellulaire ± lésions épithéliales ; **pattern ischémique** : lésions épithéliales majeures, LP peu inflammatoire
5. Colite aiguë → **pas de signe de chronicité** (distorsion, plasmocytose basale)
6. **Colite microscopique** = triade : diarrhée hydrique chronique + endoscopie normale + LIE > 20/100 (lymphocytaire) ou bande collagène ≥ 10 µm
7. **MICI** = colite chronique active : distorsion + plasmocytose basale (RCH +++)
8. Distinguer Crohn (focal, patchy, granulomes 30 %, anale 20 %) vs RCH (diffuse, homogène, rectum constant)
9. **Apoptoses cryptiques nombreuses** → GVH, médicaments (5-FU, sartans), DICV, auto-immune
10. **Termes à proscrire** : « subaiguë », « interstitielle », « chronique non spécifique » — toujours donner une orientation

# Polyposes digestives

> Liens : [[031610_Polypes colorectaux]] | [[031614_Adenocarcinome colorectal]] | [[031616_Biologie moléculaire des cancers colo-rectaux]] | [[031618_Les lésions pré-cancéreuses et cancers développés sur MICI]]

## Principes de classification

Les polyposes sont classées selon :
- **Type histologique** des polypes
- **Nombre** de polypes
- **Associations syndromiques** (digestives + extra-digestives)
- **Caractère héréditaire** (génétique)

> Identifier une polypose = **conseil génétique**, dépistage des apparentés, **programme de prévention** des cancers (endoscopies, imagerie, chirurgie prophylactique) adapté à chaque type.

## Classification synthétique

| Groupe | Polyposes |
|--------|-----------|
| **Adénomateuses** | PAF (APC), MAP (MUTYH), PPAP (POLE/POLD1), polypose festonnée |
| **Hamartomateuses** | Polyose juvénile (SMAD4/BMPR1A), Peutz-Jeghers (STK11), Cowden (PTEN) |
| **Autres** | Inflammatoires, lymphoïdes, *cap polyposis* |

| Nombre | Catégorie |
|--------|-----------|
| **> 100 polypes** = polypose **profuse** | PAF, MAP |
| **15-100** = polypose **atténuée** | PAF atténuée, MAP, autres |
| **< 20-30** = **oligopolypose** | PPAP, Lynch (peu d'adénomes) |

## Polyposes adénomateuses

### 1. Polypose adénomateuse familiale (PAF / FAP)

| Item | Caractère |
|------|-----------|
| **Gène** | ***APC*** (voie Wnt/β-caténine) |
| **Transmission** | **Autosomique dominante** |
| **Pénétrance** | **100 %** |
| **Risque cancer colorectal** | Quasi constant, jeune |
| **Phénotype colique** | Polypose **profuse**, **centaines** de polypes, tout le cadre |
| **Histologie polypes** | Adénomes classiques (tubuleux/villeux) ; lésion débutante = **1-2 cryptes aberrantes isolées** (pathognomonique) |
| **Atteinte duodénale** | Ampoule de Vater +++ |
| **Atteinte gastrique** | Polypes **glandulo-kystiques**, adénomes pyloriques/intestinaux |

#### Atteintes extra-digestives

- **Cancer de la thyroïde** : forme particulière = **carcinome papillaire cribriforme et morulaire**
- Hépatoblastome (enfant)
- Tumeurs de la surrénale, ostéomes, kystes épidermoïdes, tumeurs desmoïdes

#### Phénotypes / syndromes associés

| Syndrome | Particularité |
|----------|---------------|
| **PAF classique** | > 100 polypes, début précoce (adénomes 16 ans, ADK 39 ans) |
| **PAF atténuée** | < 100 polypes, début plus tardif |
| **GAPPS** *(Gastric Adenocarcinoma and Proximal Polyposis of the Stomach)* | Atteinte gastrique proximale prédominante |
| **Syndrome de Gardner** | PAF + tumeurs **desmoïdes** + ostéomes + kystes épidermoïdes |
| **Syndrome de Turcot** | PAF + tumeurs cérébrales (**médulloblastomes**) |

### 2. Polypose associée à MUTYH (MAP)

| Item | Caractère |
|------|-----------|
| **Gène** | ***MUTYH*** (système BER, réparation lésions oxydatives) |
| **Transmission** | **Autosomique récessive** |
| **Risque CCR à 60 ans** | 40-45 % |
| **Fréquence** | Rare, ≈ 0,7 % des CCR |
| **Phénotype** | **Polypose atténuée** (15-100 polypes), tout le cadre |
| **Histologie** | Majoritairement adénomes classiques + **lésions festonnées distales** possibles |
| **Atteinte digestive** | Duodénum, estomac |
| **Extra-digestive** | Cancers ovaire, sein, endomètre |
| **Signature moléculaire** | Transversions G→T (mutation G12C de KRAS) — non utilisée en routine |

### 3. Polypose associée aux polymérases correctrices (PPAP)

| Item | Caractère |
|------|-----------|
| **Gènes** | ***POLE* (epsilon)** et ***POLD1* (delta)** — polymérases réplicatives à activité correctrice |
| **Transmission** | **Autosomique dominante** |
| **Risque CCR** | > 60 %, **avant 40 ans** |
| **Fréquence** | Rare, ≈ 0,3 % des CCR |
| **Phénotype** | **Oligopolypose** (15-30 polypes adénomateux), cadre colique + duodénum |
| **Extra-digestif** | Endomètre, sein, tumeurs cérébrales |
| **Marqueur moléculaire** | **Charge mutationnelle très élevée** = prédicteur d'**immunothérapie** chez patients métastatiques |

> Présentation clinique parfois **proche du syndrome de Lynch**.

### 4. Syndrome de polypose festonnée

| Item | Caractère |
|------|-----------|
| **Critères OMS 2010** | Nombre / taille / localisation des lésions festonnées |
| **Génétique** | Aucun gène identifié, formes sporadiques > familiales (transmission hétérogène) |
| **Âge médian de diagnostic** | ≈ 60 ans (souvent sous-diagnostiquée) |
| **Risque CCR à vie** | **30-50 %** |
| **Cancers extra-digestifs** | Prostate, testicule, glandes salivaires |
| **Polypes** | **Festonnés de tous types** (HP, SSL, TSA), souvent grands, à droite ; adénomes classiques fréquemment associés |
| **Signature moléculaire des CCR** | Mutations **BRAF**, **CIMP-H**, **MSI** (= signature des cancers festonnés, non spécifique du syndrome) |

## Polyposes hamartomateuses

**Généralités** : 10× moins fréquentes que les polyposes adénomateuses, risque de cancer plus faible, contexte familial souvent absent → diagnostic difficile.

### 1. Polypose juvénile (JPS)

| Item | Caractère |
|------|-----------|
| **Gènes** | ***SMAD4*** et ***BMPR1A*** (voie TGF-β) |
| **Transmission** | Autosomique dominante |
| **Âge** | Sujet **< 20 ans** |
| **Polypes** | **Polypes juvéniles** identiques aux sporadiques |
| **Histologie** | Polype pédiculé, ulcéré, stroma inflammatoire abondant, **glandes kystiques mucosécrétantes** |
| **Topographie** | Tout le tube digestif, surtout **côlon, estomac, grêle** |
| **Marqueur moléculaire / IHC** | **Aucun** spécifique de la forme syndromique |
| **Risque cancer** | **Côlon 30-40 %** ; estomac 10-15 % |
| **Critères dx** | ≥ 5 polypes juvéniles coliques OU plusieurs polypes juvéniles + atteinte digestive haute |

> Atteinte gastrique : polypes juvéniles **+ hyperplasiques + Peutz-Jeghers** mêlés. Peut mimer une **gastropathie hypertrophique**.

### 2. Syndrome de Peutz-Jeghers (PJS)

| Item | Caractère |
|------|-----------|
| **Gène** | ***STK11* (LKB1)** |
| **Transmission** | Autosomique dominante |
| **Diagnostic** | Sujet jeune, **invagination** sur polype gastro-intestinal |
| **Signe associé** | **Lentiginose cutanéo-muqueuse** (quasi constante — à rechercher) |
| **Polypes** | **Arborescence de trousseaux musculaires** dissociant les glandes |
| **Topographie** | **Grêle** (jéjunum +++), côlon, estomac |
| **Critères dx** | Plusieurs polypes de Peutz-Jeghers OU 1 polype + lentiginose OU 1 polype + autres polyps hamartomateux |
| **Marqueur moléculaire / IHC** | **Aucun** |

#### Risque de cancer
- **Côlon 40 %**, estomac 30 %, grêle 13 %
- **Cancer du sein** : risque accru
- → Rechercher la **dysplasie** dans les polypes (P53)

### 3. Syndrome de Cowden (PHTS)

| Item | Caractère |
|------|-----------|
| **Gène** | ***PTEN*** (voie PI3K/AKT) |
| **Diagnostic** | Polymorphe — sujet jeune ou plus âgé |
| **Atteintes** | Hamartomes digestifs, lésions muco-cutanées (trichilemmomes), **macrocéphalie**, cancers (sein +++ chez la femme) |
| **Polypes coliques** | **Multiples polypes hétérogènes** : **lipomes, ganglioneuromes, hyperplasies lymphoïdes**, polypes inflammatoires, hyperplasiques, adénomes |
| **Œsophage** | **Acanthose glycogénique** (orientation) |
| **Risque cancer côlon** | Seulement 16 % (mais cancers extra-digestifs ++) |
| **Marqueur moléculaire / IHC** | Aucun |

## Polyposes non adénomateuses non hamartomateuses

| Entité | Particularité |
|--------|---------------|
| **Localisations coliques de lymphomes** | Ex : **lymphome du manteau** (polypose lymphomateuse multiple) |
| **Hyperplasie lymphoïde** | Multiples petits polypes sessiles |
| **Polyposes digitiformes** | Inflammatoires, sur MICI évoluée |
| ***Cap polyposis*** | Polypes sessiles distaux (sigmoïde, rectum), **coiffe purulente caractéristique au sommet**, contexte infectieux (*H. pylori*) ou médicamenteux |

## Démarche du pathologiste

1. **Compter les polypes** (profus, atténué, oligopolypose)
2. **Typer histologiquement** chaque polype (adénomateux / hamartomateux / festonné / autres)
3. **Échantillonner abondamment**, rechercher la **dysplasie** dans les hamartomateux
4. **Chercher des associations syndromiques** (digestives + extra-digestives, archives endoscopiques)
5. Bien connaître les **particularités gastriques** des polyposes (souvent révélatrices, polymorphes)

## 🔑 Points clés à retenir

1. **PAF** : ***APC***, AD, polypose **profuse** > 100, atteinte duodénale (ampoule) + gastrique (glandulokystiques) + **carcinome thyroïdien cribriforme et morulaire**
2. **Syndromes** PAF : **Gardner** (desmoïdes, ostéomes, kystes), **Turcot** (médulloblastome), **GAPPS** (gastrique proximale)
3. **MAP** : ***MUTYH***, **autosomique récessive**, polypose atténuée 15-100, signature G→T (KRAS G12C)
4. **PPAP** : ***POLE/POLD1***, oligopolypose, **charge mutationnelle très élevée** = immunothérapie
5. **Polypose festonnée** : pas de gène, polypes festonnés multiples, BRAF + CIMP + MSI, risque CCR 30-50 %
6. **Polypose juvénile** : ***SMAD4/BMPR1A***, polypes ulcérés à kystes mucosécrétants, atteinte gastrique polymorphe
7. **Peutz-Jeghers** : ***STK11***, **arborescence musculaire** + **lentiginose** cutanéo-muqueuse, grêle +++
8. **Cowden (PHTS)** : ***PTEN***, polypes coliques **hétérogènes** (lipomes, ganglioneuromes, hyperplasies lymphoïdes), acanthose glycogénique œsophage, cancer du sein
9. **Aucun marqueur IHC ou moléculaire** ne distingue un polype hamartomateux syndromique de son équivalent sporadique
10. ***Cap polyposis*** : coiffe purulente sommitale ; **lymphome du manteau** : polypose lymphomateuse multiple → DD à connaître

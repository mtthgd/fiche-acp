# Lésions précancéreuses et cancers développés sur MICI

> Liens : [[03164_Les maladies inflammatoires chroniques intestinales (MICI)]] | [[031610_Polypes colorectaux]] | [[031614_Adenocarcinome colorectal]] | [[031616_Biologie moléculaire des cancers colo-rectaux]]

## Généralités

- **MICI** = Crohn + RCH = ≈ **200 000 patients en France**
- Pic de fréquence ≈ **30 ans**
- Risque accru de **cancers digestifs** : adénocarcinome colorectal, ADK grêle, lymphomes intestinaux, cancers anaux, **cholangiocarcinome**
- Risque également accru de **cancers extra-intestinaux** (état inflammatoire chronique)

## Facteurs de risque de CCR sur MICI

| Facteur | Précision |
|---------|-----------|
| **Cholangite sclérosante primitive (CSP)** associée | Risque majeur |
| **Étendue de la maladie** | Pancolite ≫ rectite |
| **Durée d'évolution > 8-10 ans** | À partir de cette ancienneté → surveillance |
| **Intensité de l'inflammation** | Facteur indépendant (récent) |
| **Antécédent familial de CCR** | À considérer |

## Concept de continuum lésionnel

```
Inflammation → Dysplasie → Adénocarcinome
```

> **Dysplasie** (Riddell, 1983) = transformation néoplasique de l'épithélium, **univoque**, **non invasive** (limitée par la membrane basale).

C'est le **meilleur marqueur du risque augmenté** de CCR dans les MICI.

## Particularités moléculaires

### Cancérogénèse classique sporadique vs MICI

| Anomalie | CCR sporadique | CCR sur MICI |
|----------|----------------|--------------|
| **Voies majeures** | CIN 85 %, MSI 15 % | Idem proportions |
| ***TP53*** mutation | **Tardive** (60 %) | **Précoce** (60 %), même observée en muqueuse non dysplasique |
| ***APC*** mutation | **Précoce** (70 %) | **Tardive** (13 %) |
| **KRAS** mutation | 40 % | 20 % |
| **iNOS** (inducible NOS) | Normale | **Augmentée** (témoin des dommages oxydatifs) |
| Spectre TP53 | Mutations classiques | Mutations particulières liées à l'inflammation |

### Gènes spécifiques MICI

- **SOX9, EP300** (voie Wnt non canonique)
- **IL-16** (cytokine chémoattractante)

### Mécanisme inflammation → cancer

**Stress oxydatif chronique** → ROS/RONS produites par les cellules inflammatoires → altérations génétiques + épigénétiques → **dysplasie** → **cancer**.

> Notion de ***field effect / field cancerisation*** : altérations multifocales sur de larges territoires.

Contribution également : **microbiote**, immunité innée + adaptative, hyperprolifération + apoptose.

## Histologie de la dysplasie

### Types morphologiques

| Type | Description |
|------|-------------|
| **Type intestinal** ou « adénomateuse » | Le plus fréquent, identique à un adénome |
| **Type villeuse hyperémucineuse** | Critères non parfaitement consensuels |
| **Type festonnée** | Architecture festonnée |

(Les types villeuse et festonnée ont été ajoutés à la classification OMS 2010.)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/digestif/tube_digestif/colon-rectum/03.1.6.18%20Les%20l%C3%A9sions%20pr%C3%A9-canc%C3%A9reuses%20et%20cancers%20d%C3%A9velopp%C3%A9s%20sur%20MICI/p17_03.jpeg)

### Grades

| Grade | Critères |
|-------|----------|
| **Bas grade (BG)** | Atypies cytologiques modérées, polarité globalement conservée |
| **Haut grade (HG)** | Atypies marquées, perte de polarité, structures cribriformes possibles, mitoses anormales |
| **Indéterminée pour la dysplasie** | Difficulté à distinguer d'authentiques lésions de modifications réactionnelles → **biopsies de contrôle après renforcement du traitement anti-inflammatoire** |


> **Identique** entre RCH et Crohn.

### Variabilité diagnostique

- Variabilité **inter** et **intra-observateur** importante, même chez les pathologistes spécialisés
- Variabilité maximale pour la **dysplasie de bas grade**
- Variabilité minimale aux extrêmes (lésions non dysplasiques / dysplasie HG)
- → **Double lecture recommandée** par les sociétés savantes

### Apport de l'IHC P53

- **Surexpression P53 forte** ou pattern **« absent »** = mutation TP53 → **argument pour la dysplasie**
- Utile pour distinguer dysplasie / régénération
- Utile pour distinguer dysplasie BG / HG
- Approche **non consensuelle** mais reconnue

## Classification macro/endoscopique

### Ancienne (à abandonner)

| Terme ancien | À ne plus utiliser |
|--------------|--------------------|
| **DALM** (*Dysplasia Associated Lesion or Mass*) | Trop ancien |
| **Adenoma-like / non adenoma-like** | Trop ancien |
| Dysplasie « plane » vs « polypoïde » | Simplifié |

### Classification SCENIC (2015)

*Surveillance For Colorectal Endoscopic Neoplasia detection and management in IBD*

| Type | Description |
|------|-------------|
| **Visible** | Détectée en endoscopie |
| → Polypoïde | Saillie > 2,5 mm dans la lumière (sessile / pédiculée) |
| → Non polypoïde | Saillie < 2,5 mm (plane / déprimée) |
| **Invisible** | Identifiée sur biopsies aléatoires en muqueuse normale |

> **Critère endoscopique majeur** : présence/absence d'une **bordure lésionnelle distincte** = faisabilité d'une résection endoscopique complète.

**Terminologie pathologiste recommandée** :
- « Dysplasie **endoscopiquement résécable** »
- « Dysplasie **non endoscopiquement résécable** »
- Alternative : « **lésion dysplasique associée à des lésions de colite** »

> Les lésions dysplasiques polypoïdes survenant **en zone non inflammatoire** sont des **adénomes sporadiques** (sans rapport avec la MICI), pris en charge comme tels.


## Algorithme de prise en charge (SCENIC)

```
Dysplasie
   │
   ├─ VISIBLE (polypoïde ou non)
   │     ├─ Résécable endoscopiquement → EXÉRÈSE ENDOSCOPIQUE + surveillance étroite
   │     └─ Non résécable (bords mal limités) → CONFIRMATION par endoscopiste expert
   │              → CHIRURGIE
   │
   └─ INVISIBLE (sur biopsies aléatoires)
         ├─ Confirmation par pathologiste expert
         ├─ Adresser au centre expert (chromo-endoscopie HD)
         │     → Chercher lésion bien circonscrite résécable
         │     → Chercher autres lésions
         ├─ Bas grade → 2 stratégies : surveillance accrue OU chirurgie (1ʳᵉ coloscopie)
         └─ Haut grade → CHIRURGIE
```

## Dysplasie festonnée dans les MICI

### Rappel : voie festonnée sporadique
- HP, TSA, SSL ± dysplasie
- 30 % des CCR sporadiques
- BRAF +, **CIMP-H**, MSI

### Lésions festonnées sur MICI
- Identiques morphologiquement aux sporadiques
- Surtout **HP** majoritaires, puis **SSL**, **TSA exceptionnels**
- Localisations : **côlon gauche + rectum** dans zones atteintes
- Souvent **détectables en endoscopie** (> 50 %)
- Peuvent être **multiples** (= polypose festonnée)

### Dysplasie festonnée
- **Aspect différent** de la dysplasie « conventionnelle »
- **Type 1 (« conventionnelle ») :** noyaux allongés, pénicillés, pseudo-stratifiés, mitoses
- **Type 2 (OMS 2010 / festonnée) :** noyaux ronds/ovoïdes, **basaux**, vésiculeux, **nucléole proéminent**

### Évolution
- **HP** sur MICI : faible risque, surveillance non accrue
- **Lésions festonnées avec dysplasie BG** ou indéfinies : **augmentation du risque** de néoplasie synchrone et métachrone

### *Serrated epithelial change*
- Modifications épithéliales d'architecture festonnée
- Critères dx anatomopathologiques mal définis
- Rôle précancéreux non établi

## Particularités cliniques et pathologiques des CCR sur MICI

| Caractère | CCR sporadique | CCR sur MICI |
|-----------|----------------|---------------|
| **Âge moyen** | ≈ 70 ans | ≈ **50 ans (-20)** |
| **Précurseur** | Adénome polypoïde résécable | Dysplasie polymorphe (planaire, polypoïde, festonnée) |
| **Multifocalité** | Rare | **Volontiers plurifocaux** |
| **Types histologiques** | Lieberkühnien | Plus fréquents : **mucineux**, **bague à chaton** |
| **Nécrose tumorale** | Souvent + | Souvent **absente** |
| **Aspect Crohn-like** (TILs périphériques) | Rare | **Fréquent** |
| **Différenciation** | Variable | **Bien différencié** plus souvent |
| **Hétérogénéité** | Variable | Marquée |

## Surveillance pratique

| Item | Recommandation |
|------|-----------------|
| Début surveillance | Après **8-10 ans** d'évolution (ou immédiatement si CSP associée) |
| Modalités | **Coloscopie + chromo-endoscopie**, **biopsies ciblées** sur les lésions visibles |
| Fréquence | Selon facteurs de risque (étendue, CSP, durée, antécédents familiaux) |
| Diagnostic dysplasie | **Double lecture** par pathologiste expert |
| CAT | Algorithme SCENIC (cf. ci-dessus) |

## 🔑 Points clés à retenir

1. **CCR sur MICI** : âge -20 ans vs sporadique (50 ans), volontiers **plurifocal**, types **mucineux/bague à chaton/médullaire** plus fréquents
2. **Facteurs de risque** : **CSP associée**, étendue (pancolite), durée > 8-10 ans, intensité de l'inflammation
3. **Dysplasie** = meilleur marqueur de risque ; 2 grades (**BG / HG**) + catégorie **« indéterminée »**
4. 3 types morphologiques OMS 2010 : intestinal, villeuse hypermucineuse, **festonnée**
5. **Variabilité diagnostique +++** (BG surtout) → **double lecture obligatoire** ; **IHC P53** utile (surexpression ou pattern absent)
6. Cancérogénèse MICI : ***TP53* mutation précoce** ≠ sporadique ; APC tardif, gènes spécifiques (SOX9, EP300, IL-16)
7. **Stress oxydatif (ROS)** + iNOS + microbiote + ***field cancerisation*** = mécanismes
8. **Classification SCENIC** : **visible** (polypoïde / non polypoïde) vs **invisible** ; abandonner DALM, adenoma-like
9. **Algorithme** : visible résécable → endoscopie + surveillance ; non résécable → chirurgie ; HG invisible → chirurgie ; BG invisible → discussion
10. Polype dysplasique en muqueuse non inflammatoire = **adénome sporadique** (pas une dysplasie sur MICI)

# Angiomyolipome (AML) du rein

> Liens : [[41_IHC et tests moléculaires des tumeurs du rein]] | [[48_Oncocytome rénal]] | [[50_Adénome métanéphrique]]

## Généralités

- Tumeur **mésenchymateuse** rare (**< 1 %** des tumeurs du rein)
- Appartient à la famille des **PEComas** (perivascular epithelioid cell tumor) : dérive des **cellules périvasculaires épithélioïdes**
- **Double différenciation** : **myogénique** (actine, desmine) + **mélanocytaire** (HMB45, Melan-A)
- Sites : rein ++, mais aussi **foie, poumon, ganglions, rétropéritoine**

## Sclérose tubéreuse de Bourneville (STB)

- Maladie autosomique dominante : mutations **TSC1** ou **TSC2**
- **50-90 %** des patients STB développent un AML (rénal/hépatique, **souvent bilatéraux et multiples**)
- Mais seulement **5-10 %** des AML surviennent dans un contexte de STB
- Autres manifestations : lymphangioléiomyomatose, rhabdomyomes cardiaques, angiofibromes cutanés


---

# 1. AML classique triphasique

## Macroscopie
- Aspect de **tumeur adipeuse** (jaune), peut occuper tout le rein
- Taille : quelques cm à plusieurs dizaines de cm


## Histologie — 3 composants en proportions variables

1. **Adipocytaire** (adipocytes matures, taille variable)
2. **Musculaire lisse** (faisceaux de cellules fusiformes)
3. **Vasculaire** : vaisseaux à paroi épaisse avec **prolifération péri-vasculaire** caractéristique (cellules HMB45+)

# 2. AML épithélioïde — forme à ne pas méconnaître

## Généralités
- **30 % donnent des métastases** → potentiel malin
- Surviennent **majoritairement dans la STB**
- Définition : **≥ 80 % de composante épithélioïde** (forme triphasique associée possible)

## Histologie
- **Grandes cellules éosinophiles**, très atypiques, **pléomorphisme marqué**
- Cellules **géantes multinucléées** de type ostéoclaste possibles
- Cellules fusiformes associées
- **Chromatine mottée**, nucléoles proéminents, noyaux bilobés
- **Nombreuses mitoses**
- Évoque en 1re intention un **carcinome de haut grade inclassable**

## IHC — **clé diagnostique**

| Marqueur | Résultat |
|----------|:---:|
| **PAX8** | **Négatif** (exclut RCC) |
| **HMB45** | **+** (hétérogène, possible sur plusieurs blocs) |
| **Melan-A** | **+** (hétérogène) |
| Desmine / actine | + |
| Vimentine | + |
| CK | Négative |
| GATA3 | Négative (exclut carcinome urothélial) |
| CD117 | Possible + (piège !) |

> **Devant une tumeur rénale inclassée de haut grade PAX8−** → demander **HMB45 + Melan-A** sur plusieurs blocs.

## Score prédictif de progression (AML épithélioïde) — 6 critères

| Critère |
|---------|
| **Sclérose tubéreuse de Bourneville** |
| **Nécrose tumorale** |
| **Taille > 7 cm** |
| **Extension graisse périrénale / hilaire** |
| **Embol veineux rénal** |
| **Aspect "carcinoma-like"** |

| Critères | Risque de progression |
|---|---|
| 1 | **~15 %** |
| 2-3 | **~64 %** |
| ≥ 4 | **~100 %** |

## Démarche devant une tumeur rénale inclassée

1. **PAX8** (en 1re intention) → si **positif**, RCC → CK7, CA9, P504S…
2. Si **PAX8 négatif** : **GATA3** (urothélial), **HMB45 + Melan-A** (AML épithélioïde)
3. Ne pas hésiter à **répéter HMB45/Melan-A** sur plusieurs blocs (marquage très hétérogène)


---

## 🔑 Points clés à retenir

1. AML = **PEComa**, double différenciation **myogénique + mélanocytaire**.
2. Forme **classique triphasique** (adipeux + musculaire + vasculaire) = diagnostic facile, **bénigne**.
3. **AML épithélioïde = ≥ 80 % composante épithélioïde** → **30 % métastasent**.
4. AML épithélioïde : grandes cellules atypiques, cellules géantes ostéoclast-like, mitoses +++, évoque un carcinome haut grade.
5. **IHC clé** : **PAX8−, HMB45+, Melan-A+** (hétérogène → multiples blocs).
6. Attention : **CD117 peut être + dans l'AML** (piège).
7. **Sclérose tubéreuse** (**TSC1/TSC2**) : 50-90 % développent un AML, souvent **bilatéraux/multiples**, jeunes.
8. **5-10 %** des AML sont associés à une STB.
9. **Score prédictif** (6 critères) : STB, nécrose, > 7 cm, extension périrénale, embol veineux, aspect carcinoma-like.
10. Devant toute **tumeur rénale inclassée haut grade** → penser à l'AML épithélioïde (PAX8−, HMB45+).

# Diagnostic des carcinomes épidermoïdes de la verge

> Liens : [[90_Compte rendu biopsies et pièces opératoires - verge]] | [[92_Facteurs pronostiques des tumeurs de la verge]]

## Présentation clinique

- **Lésion indurée** du pénis, portion distale → **gland** ou **prépuce** dans **95 %** des cas
- Parfois : écoulement, **adénopathie inguinale** palpable (extension loco-régionale)
- Bilan :
  - **IRM** : extension en profondeur
  - **TDM abdomino-pelvienne** + **TEP-FDG** si adénopathies (extension à distance)


---

# Classification OMS 2016 — Dichotomie HPV +/−

La classification **OMS 2016** sépare les carcinomes épidermoïdes selon le **lien à HPV** (le plus souvent **HPV 16**).

## Détection HPV

- **PCR** (référence)
- **Immunomarquage p16** (surexpression = marqueur de substitution de l'HPV)

# 1. Carcinomes épidermoïdes NON liés à HPV

## Mécanismes moléculaires

- **Mutation TP53** → p53 fortement positif en IHC
- Ou **instabilité chromosomique** marquée

## Sous-types

- **Habituel** (usual SCC)
- **Pseudo-hyperplasique**
- **Pseudo-glandulaire**
- **Verruqueux** (verrucous)
- **Cuniculatum**
- **Papillaire**
- **Adénosquameux**
- **Sarcomatoïde**
- **Mixte** (2 sous-types intriqués)

## Profil IHC typique

| Marqueur | Résultat |
|----------|----------|
| **p53** | **Fortement positif** (CIS de surface + composante infiltrante) |
| **p16** | **NÉGATIF** |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/urologie/verge/05-522%20Diagnostic%20des%20carcinomes%20epidermo%C3%AFdes%20de%20la%20verge/p06_00.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/urologie/verge/05-522%20Diagnostic%20des%20carcinomes%20epidermo%C3%AFdes%20de%20la%20verge/p06_01.jpeg)

## Aspects histologiques particuliers

- **Carcinome papillaire** : papilles à axe **élargi**
- **Carcinome verruqueux** : très peu infiltrant (DD hyperplasie verruqueuse)
- **Carcinome sarcomatoïde** : cellules indifférenciées fusiformes, parfois rhabdoïdes

# 2. Carcinomes épidermoïdes LIÉS à HPV

## Sous-types

- **Basaloïde**
- **Papillaire basaloïde**
- **Condylomateux** (warty)
- **Condylomateux basaloïde** (warty basaloid)
- **À cellules claires**
- **Lympho-épithélial**

## Profil IHC typique

| Marqueur | Résultat |
|----------|----------|
| **p16** | **FORTEMENT POSITIF** (diffus, bloc) |
| **p53** | **NÉGATIF** ou faible |

## Aspects histologiques

- **Condylomateux** : axes vasculaires épais, koïlocytose, **p16 fortement +**
- **Basaloïde** : cellules hyperchromatiques, indifférenciées, **densité cellulaire élevée**

# 3. Grade — Rappel et importance clinique

| Grade | Description | Impact thérapeutique |
|-------|-------------|----------------------|
| **Grade 1** | Bien différencié (DD hyperplasie, ponts intercellulaires visibles) | Surveillance simple possible |
| **Grade 2** | Intermédiaire : atypies, kératinisation réduite, désorganisation | - |
| **Grade 3** | Indifférencié, pléomorphisme nucléaire prononcé | **Curage ganglionnaire** imposé |
| **Grade 4** | Forme **sarcomatoïde** | - |

> **À mentionner : pourcentage de composante de grade 3** (impact thérapeutique).

# 4. Groupes pronostiques selon sous-type

| Risque | Sous-types |
|--------|-----------|
| **Faible** (verruciformes) | **Verruqueux**, **papillaire**, **condylomateux (warty)**, **pseudo-hyperplasique**, **cuniculatum** |
| **Intermédiaire** | **Habituel** (usual), formes **hybrides/mixtes** |
| **Haut** | **Basaloïde**, **sarcomatoïde**, **indifférencié** |

## Différenciation des carcinomes verruciformes (DD fins)

Critères : aspect des papilles, axes vasculaires, base tumorale, **koïlocytes**, type de croissance, grade, **lien HPV**.

---

# 5. Diagnostics différentiels sur biopsie

| Lésion bénigne (DD) | Tumeur maligne (à exclure) |
|---------------------|-----------------------------|
| **Hyperplasie verruqueuse** | Carcinome verruqueux |
| **Hyperplasie papillaire** | Carcinome papillaire |
| **Hyperplasie pseudo-épithéliomateuse** | Carcinome pseudo-hyperplasique |
| **Condylome** | Carcinome condylomateux (warty) |

## Critères de malignité

- **Parakératose de surface**
- **Altération de la maturation** épithéliale
- **Kératinocytes atypiques large**, hyperchromatiques
- **Perles kératosiques** atypiques
- **Spongiose**
- **IHC d'appoint** : **p16** (HPV), **Ki-67** (prolifération), **p53** (mutation)

## 🔑 Points clés à retenir

1. Localisation : **95 %** gland/prépuce ; lésion indurée.
2. Classification **OMS 2016** = **HPV +** vs **HPV −**.
3. Détection HPV : **PCR** + **p16** en IHC.
4. **HPV −** : mutation **TP53** (p53 fortement +), instabilité chromosomique ; inclut habituel, verruqueux, papillaire, pseudo-hyperplasique, cuniculatum, sarcomatoïde, adénosquameux.
5. **HPV +** : p16 fortement + ; inclut **basaloïde**, **condylomateux (warty)**, cellules claires, lympho-épithélial.
6. **p16 +/p53 −** = HPV + ; **p16 −/p53 +** = HPV −.
7. Grade 1 (bien diff.) → surveillance simple ; Grade 3-4 → curage ganglionnaire.
8. Rapporter le **% de composante grade 3** (impact thérapeutique).
9. **Faible risque (verruciformes)** : verruqueux, papillaire, condylomateux, pseudo-hyperplasique, cuniculatum.
10. **Haut risque** : basaloïde, sarcomatoïde, indifférencié.
11. **DD sur biopsie** : hyperplasies (verruqueuse / papillaire / pseudo-épithéliomateuse) vs carcinomes correspondants ; condylome vs CE condylomateux.
12. Critères de malignité : parakératose, altération maturation, kératinocytes larges atypiques, perles atypiques, spongiose + IHC (p16, Ki-67, p53).

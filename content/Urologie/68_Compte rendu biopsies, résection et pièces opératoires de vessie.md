# Compte rendu biopsies, résection et pièces opératoires de vessie

> Liens : [[66_CAT macroscopique prélèvements de vessie (cystectomie, RTUV)]] | [[71_Facteurs pronostiques des TVNIM]] | [[73_Facteurs pronostiques des TVIM]]

## 1. Items administratifs et cliniques

### Administratifs
- Nom + date de naissance + identification patient
- Date d'intervention, date(s) de réception
- Numéro de dossier

### Cliniques (indispensables)
- **Histoire de la maladie** : récidive, antériorités
- **Traitements antérieurs** : BCG, mitomycine, chimio néo-adjuvante, radiothérapie
- Aspect **cystoscopique** (multifocal, étendu, plan, papillaire)
- **Localisation** des prélèvements (trigone ≠ dôme : anatomie et épaisseurs différentes)
- **Type de procédure** : biopsie, RTUV monobloc/classique, cystectomie partielle/radicale, cysto-prostatectomie, pelvectomie

## 2. Type histologique

### Entités principales
- **Carcinome urothélial** (le plus fréquent)
- **Carcinome épidermoïde** (pur)
- **Adénocarcinome** (primitif vésical, ouraque, entérique, mucineux…)
- **Tumeurs müllériennes** : cellules claires, endométrioïde
- **Carcinomes neuroendocrines** : petites cellules, grandes cellules
- **Autres** (sarcomes, lymphomes, mélanome…)

### Carcinome urothélial avec différenciation divergente
- Rapporter comme **« carcinome urothélial avec différenciation X »** avec **% estimé**
- Différenciations : épidermoïde, glandulaire, trophoblastique, autres

### Mixtes neuroendocrines
- **Carcinome neuroendocrine associé à carcinome urothélial** avec estimation des **pourcentages** (ex : 70 % CNE à petites cellules + 30 % urothélial)

### Variantes histologiques (à rapporter impérativement)
Impact pronostique / moléculaire :
- **Plasmocytoïde**
- **Sarcomatoïde**
- **Micropapillaire**
- En **nids** (petits / grands = « nested / large nested »)
- **Lymphoepithelioma-like** (pronostic non péjoratif)
- Variante **pseudoglandulaire** (à ne pas confondre avec vraie glandulaire)

## 3. Lésions non infiltrantes / associées

À rapporter :
- **Non identifiée** / indéterminée (artéfacts)
- **CIS** focal / multifocal (préciser localisation)
- **TVNI papillaire** (PUNLMP, bas grade, haut grade)
- **Lésions épithéliales** : métaplasie, atypies réactionnelles
- **Présence de la muscularis propria** sur RTUV = **critère de qualité**

---

## 4. Grade (classification OMS)

| Type | Grades |
|------|--------|
| **Carcinome urothélial** (papillaire / invasif) | **Bas grade** / **Haut grade** (OMS 2016) |
| Carcinome épidermoïde pur | Grade 1 / 2 / 3 (bien / moy. / peu différencié) |
| Adénocarcinome pur | Grade 1 / 2 / 3 |
| Non déterminable (artéfacts) | **Grade X** |

## 5. Stadification pTNM

### Tumeur primaire (T)

| Stade | Définition | Procédure |
|-------|------------|-----------|
| **pTa** | Papillaire non invasive | Biopsie / RTUV / cystectomie |
| **pTis / CIS** | Lésion plane limitée à l'urothélium | Toutes |
| **pT1** | Infiltration de la **lamina propria** | Sous-stadification recommandée |
| **pT2a** | Muscle superficiel | Cystectomie uniquement |
| **pT2b** | Muscle profond | Cystectomie |
| **pT3a** | Graisse périvésicale **microscopique** | Cystectomie |
| **pT3b** | Graisse périvésicale **macroscopique** | Cystectomie |
| **pT4a** | Organes adjacents (prostate par contiguïté, vagin, utérus) | Cystectomie |
| **pT4b** | Paroi pelvienne / abdominale | Cystectomie |

⚠️ **Sur RTUV** : stade max **pT2** (la graisse sur RTUV ≠ pT3).
⚠️ **Diverticule** : pas de musculeuse → stades possibles **pTa / pT1 / pT3** seulement.


### Sous-stadification pT1 (OMS 2016 - recommandée, méthode non imposée)

Options acceptées par l'**ICCR** :
| Méthode | Seuil |
|---------|-------|
| **Profondeur d'infiltration** (mm) | à mesurer |
| **Dimension maximale** de la tumeur infiltrante | à mesurer |
| **pT1a / pT1b** (au-dessus / au-dessous de la muscularis mucosae) | Si MM identifiable |
| Si MM non visible : utiliser le **plexus vasculaire** |  |
| **pT1m / pT1e** | microscopique / extensif (> 1 champ × 40) |

Tous s'accordent : infiltration **profonde** = pronostic plus sévère que superficielle.

- **Pathologies coexistantes**
- **Études ancillaires** (IHC, moléculaire)

## 7. Compte rendu spécifique — cystectomie / cysto-prostatectomie / pelvectomie

### Macroscopie
- **Procédure** exacte (chirurgien)
- Pièces associées : utérus, cuff vaginal, annexes, uretères, prostate, VS
- **25 % des cysto-prostatectomies** = **CaP associé** → inclure et mentionner prostate, VS, urètre
- **Tumeur** : uni / multifocale, taille, localisation
- Infiltration macroscopique (graisse, séreuse péritonéale)
- **Marge péritonéale** : encrer si doute → rapporter positive/négative + distance

### Histologie
- Type + variante(s) + grade (cf supra)
- **Stade pTNM** complet
- **Réponse à la thérapie néo-adjuvante** :
  - Complète / incomplète / absence de réponse / pas de traitement
  - Marqueurs : cicatrice, fibrose, granules post-RTUV, cellules géantes
- **ILV**

### Marges chirurgicales (impératif)
- Recoupe **urétrale**
- Recoupes **urétérales** (D et G)
- Tissus mous péri-vésicaux
- Structure adjacente pour pelvectomie antérieure (vaginale, paramètres)
- **Positives macroscopique / microscopique** : distance en mm

### CIS associé
- Présence, localisation, focalité

## 8. Curage ganglionnaire

Items obligatoires :
- **Présence / absence** de curage
- **Nombre total** de ganglions examinés
- **Nombre envahis**
- **Taille de la plus grande métastase** (seuil 1 cm)
- **Rupture capsulaire** (oui / non)
- **Emboles** péri-ganglionnaires
- **Localisation anatomique**
- ⚠️ **UICC vs AJCC 8e** : ganglions **péri-vésicaux** comptés uniquement dans AJCC → toujours les rechercher

💡 Compter et mesurer les ganglions **sur lames** (et non en macroscopie, plus précis).


---

## 9. Classifications et préfixes

### Préfixes à utiliser (AJCC)
| Préfixe | Signification |
|---------|---------------|
| **y** | Tumeur ayant reçu un traitement (chimio / RT) |
| **r** | Tumeur **récurrente** |
| **m** | Tumeurs **multiples** |

⚠️ Préciser toujours la classification utilisée (**UICC ou AJCC**).

## 🔑 Points clés à retenir

1. **Renseignements cliniques indispensables** : histoire, traitements antérieurs (BCG, CNA), aspect cystoscopique, localisation.
2. Type histologique : carcinome urothélial (avec variante, différenciation divergente, %), ADK, épidermoïde, NE ; **rapporter les variantes** (plasmocytoïde, sarcomatoïde, micropapillaire…).
3. Grade OMS 2016 : **bas grade / haut grade** pour urothélial ; G1-G2-G3 pour ADK/épidermoïde purs.
4. **Présence de musculaire propre sur RTUV** = critère de qualité à mentionner.
5. **pT0-pT4** avec limites : RTUV max **pT2** ; diverticule pas de pT2.
6. **Sous-stadification pT1** recommandée (ICCR) : profondeur / dimension / pT1a-b (MM) / pT1m-e ; infiltration profonde = pronostic péjoratif.
7. Items obligatoires : **ILV, CIS associé, marges, réponse thérapeutique**.
8. Cystectomie : marges urétrale, urétérales, tissus mous ; 25 % de CaP associés → inclure/évaluer prostate.
9. **Après chimio néo-adjuvante** : préfixe **yp** ; documenter cicatrice/fibrose/granules pour un ypT0 authentique.
10. Ganglions : nb total + nb envahis + **taille max méta + rupture capsulaire + emboles** ; rechercher ganglions **péri-vésicaux** (AJCC 8e).
11. Toujours préciser la **classification utilisée** (UICC / AJCC) et les préfixes (**y, r, m**).

# Variantes des carcinomes urothéliaux

> Liens : [[67_IHC et tests moléculaires devant une tumeur de vessie]] | [[69_Classification des tumeurs papillaires non invasives]] | [[74_Adénocarcinome, carcinome épidermoïde et tumeurs neuroendocrines de vessie]] | [[73_Facteurs pronostiques des TVIM]]

## Généralités

- **OMS 2016** : reconnaît nombreuses **variantes** (mixtes +++) + **types** (épidermoïde, ADK, neuroendocrine)
- **Variante** = mélange avec carcinome urothélial classique
- **Type** = tumeur **pure > 95 %** (ex : carcinome épidermoïde pur)
- Importance : **pronostic différent**, **stade pT difficile** (nested), **traitements spécifiques**

### Classification moléculaire TCGA 2012

| Sous-type | Caractéristique |
|-----------|-----------------|
| **Basal** | Proche des carcinomes épidermoïdes ; **très bonne réponse à la chimio néo-adjuvante** |
| **Luminal** | **Meilleure survie globale** |

- Carcinomes urothéliaux **purs** : meilleur pronostic que ceux avec variantes
- Inflexion **épidermoïde** : pronostic peut-être meilleur que autres variantes

> Macroscopie et radiologie **non discriminantes**.


---

## Règle générale de rapport

- **Mentionner toute variante ≥ 10 %** (cut-off non consensuel)
- Préciser le **pourcentage** (urothélial classique vs variante)
- Pas de **grade** en variantes agressives (considérées haut grade d'emblée)

---

## 1. Carcinome urothélial micropapillaire

- **Agressif** ; concordance diagnostique bonne si typique (κ ~0,93), mauvaise si atypique
- Aspect : **petites papilles vraies** avec **artéfacts de rétraction** (halo clair)
- DD avec **LVI** : souvent, LVI associée **authentique**
- **Toujours haut grade**, **pas de grade** donné
- Traitement : BCG **inefficace** ; cystectomie radicale d'emblée discutée dès cT1
- Checkpoints : PD-L1 + dans ~10 %

## 2. Carcinomes « en nid » : nested, grand-nid, microkystique

### Nested
- **DD : hyperplasie des îlots de von Brunn** (bénin)
- Nids **réguliers, bien limités**, **peu d'atypies, peu de mitoses**
- Difficulté : tant que pas d'atteinte du muscle détrusor → doute
- **Muscle non vu** sur RTUV → **redemander des prélèvements**
- Pronostic : agressif au **même stade** que CU classique

### Grand-nid
- Décrit récemment, grands nids arrondis
- **Peu d'atypies, peu de mitoses**, pas d'inflammation ni réaction stromale
- Forme pure moins agressive ; souvent **mixte** → pronostic selon contingent associé

### Microkystique
- Probablement continuum avec nested / grand-nid
- DD : **cystites kystiques/glandulaires** (bénignes)

## 3. Carcinome plasmocytoïde (± bague à chaton, diffus)

- **EXTRÊMEMENT AGRESSIF** — pire pronostic de toutes les variantes
- **64 %** sont **pT3** et **23 %** sont **pT4** au diagnostic
- Croissance **diffuse, infiltrante**, détruit la paroi
- Cellules **indépendantes**, aspect **plasmocytoïde** ou **bague à chaton**, stroma œdémateux
- Inactivation **CDH1 (E-cadhérine)**
- Médiane de survie < 2 ans
- **OMS 2016** : regroupé avec **bague à chaton** et **diffus**
- Traitement : cystectomie + chimio → **décès fréquent** malgré tout

## 4. Carcinome lymphoépithéliome-like

- **< 3 %** des CU
- **Mélange** cellules tumorales + abondants lymphocytes
- **PIÈGE** : au 1er coup d'œil → évoque un **lymphome**
- Marqueurs épithéliaux **+** (confirment la nature carcinomateuse)
- **EBV toujours négatif** (≠ nasopharyngé)

## 5. Autres variantes rares

| Variante | Caractéristique |
|----------|----------------|
| **Sarcomatoïde** / **carcosarcome** | Cellules fusiformes ± éléments hétérologues (os, cartilage → ostéosarcome / chondrosarcome) ; calcul intravésical souvent associé |
| **À cellules géantes** | Rare, agressif |
| **Riche en lipides** (lipoïde) | Rare |
| **À cellules claires** | ≠ carcinome à cellules claires de l'urètre ; rare, agressif |
| **Rhabdoïde** | Rare, agressif |

## Variantes vs types purs : grade

| Forme | Grade |
|-------|:---:|
| CU classique | **Bas / haut grade** (OMS 2016) |
| CU avec variante | **Haut grade** d'emblée |
| **Carcinome épidermoïde pur** (> 95 %) | **1 / 2 / 3** (différencié / moyennement / peu) |
| **ADK vésical pur** | **1 / 2 / 3** idem |
| **Composante sarcomatoïde** associée | À mentionner (impact survie) |

## 🔑 Points clés à retenir

1. **Variante** = mixte ; **Type** = pur > 95 % (épidermoïde, ADK, NE).
2. **Mentionner toute variante ≥ 10 %** avec **pourcentage** dans le CR.
3. **Micropapillaire** : très agressif, toujours **haut grade**, BCG inefficace.
4. **Nested / grand-nid / microkystique** : **peu d'atypies** — ne pas confondre avec von Brunn ; exiger **muscle vu** pour stade.
5. **Plasmocytoïde (± bague à chaton, diffus)** : **PIRE pronostic**, 64 % pT3, 23 % pT4 au diagnostic, **CDH1** inactivé, médiane < 2 ans.
6. **Lymphoépithéliome-like** : piège **lymphome**, **EBV négatif** (≠ nasopharynx).
7. **Sarcomatoïde / carcosarcome** : souvent sur calcul intravésical, mentionner composante hétérologue.
8. Si variante présente au **pT1** → **2e look** impératif (sous-stade fréquent).
9. **Épidermoïde pur / ADK pur** : grade **1/2/3** (pas bas/haut grade).
10. **IHC** : **GATA3, uroplakine** pour variantes luminales ; **CK14, CK5/6** pour basal/épidermoïde ; **β-caténine membranaire** pour DD ADK colique.

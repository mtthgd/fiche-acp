# Tumeurs germinales non séminomateuses (1ère partie)

> Liens : [[22_Néoplasies germinales non invasives, séminome, tumeur spermatocytaire]] | [[24_Tumeurs germinales non séminomateuses (2ème partie)]] | [[25_Facteurs pronostiques tumeurs du testicule]]

## Généralités

### Épidémiologie des tumeurs testiculaires
- **98%** des tumeurs malignes du testicule = **tumeurs germinales (TG)**
- Incidence mondiale ≈ **1,5 / 100 000 hommes**
- **Prédominance chez les Caucasiens** (0,5 en Asie/Afrique, > 12 en Norvège/Suisse)
- **~2300 nouveaux cas/an en France** ; ~90 décès
- **TGNS** ≈ 50% des TG testiculaires
- **Âge moyen** TGNS :
  - Sans séminome : **~25 ans**
  - Avec séminome : **~30 ans**

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/urologie/testicule_cordon_spermatique/05-423%20Tumeurs%20germinales%20non%20s%C3%A9minomateuses%20%281%C3%A8re%20partie%29/p07_00.png)

### Facteurs de prédisposition
- **Antécédent TG contro-latérale** : RR ≈ **25** (facteur majeur)
- **Cryptorchidie**
- **Infertilité**
- **Dysgénésie gonadique** (dont **syndrome de Klinefelter**)
- **Prédisposition familiale**

## Clinique et bilan

### Modes de découverte
- Augmentation de volume d'une bourse
- Masse intrascrotale **indépendante de l'épididyme**
- Gynécomastie, scrotum aigu
- Masse abdominale, ganglion sus-claviculaire, dyspnée, œdème des MI (formes avancées)

### DD cliniques
- Épididymite / orchite
- Torsion du cordon spermatique

### Bilan
- **Marqueurs sériques** : **AFP**, **β-HCG** totale, **LDH**
- **Échographie** scrotale
- **TDM thoraco-abdomino-pelvien**
- Geste = **orchidectomie totale par voie inguinale** ; **biopsie percutanée PROSCRITE**

## Classification OMS 2016 - Vocabulaire

| Type | Caractéristiques |
|------|------------------|
| **Type I** | Prépubertaire, **non dérivée de GCNIS** ; tératome prépubertaire, tumeur vitelline prépubertaire |
| **Type II** | Dérivée de **GCNIS** ; **séminome** + **TGNS** (carcinome embryonnaire, tumeur vitelline, choriocarcinome, tératome post-puberté), burn-out / régressive |
| **Type III** | **Tumeur spermatocytaire** ; non dérivée de GCNIS |

## Principes thérapeutiques (stade I)

| Type | Stade I - Options |
|------|-------------------|
| **Séminome stade I** | **Surveillance** (récidive 15-20%) ou chimio adjuvante **carboplatine** ; bon pronostic |
| **TGNS stade I** | Surveillance OU **chimiothérapie BEP** (1-2 cycles réduits pour toxicité bléomycine) selon LVI |

- TGNS = **pronostic et traitement différents du séminome** (plus lourd)
- **Choriocarcinome** et **carcinome embryonnaire abondant** : **mauvais pronostic** → importance du % des composantes dans le CR

## pTNM - Particularités

- **T** : invasion des composantes histologiques / enveloppes
- **N** : adénopathies régionales = **rétropéritonéales**
- **M** : M1a (ganglions non régionaux / pulmonaires), M1b (autres)
- **M1 particulier** : **trombus vasculaire tumoral discontinu dans le cordon** (AJCC)
- **Marqueurs sériques (S)** intégrés dans le stade clinique

## Tumeurs germinales MIXTES

- **Cas le plus fréquent** des TGNS
- Au **moins 2 composantes** différentes, avec ou sans séminome
- Suspectée sur : âge jeune + aspect **macroscopique hétérogène**
- Analyse systématique :
  - Reconnaître chaque contingent
  - **Estimer le % de chaque** (par tranches de 10)
  - Rechercher **LVI**
  - IHC **ciblée** par contingent

## Macroscopie des TGNS

- Tumeur hétérogène : zones blanches, kystiques, hémorragiques, nécrotiques
- **Échantillonnage guidé par l'aspect macro** : chaque zone différente
- **Inclusion totale** si petite ; sinon 1 bloc/0,5-1 cm par contingent

## Histologie - Aspects de TG mixtes

- Contingents intriqués : **carcinome embryonnaire + tumeur vitelline** fréquent
- Cellules syncytiotrophoblastiques isolées (β-HCG+)
- **Polyembryome** = carcinome embryonnaire + espace amniotique + **tumeur vitelline** + stroma fusiforme
- **Embryome diffus** = CE en collier de perles + tumeur vitelline aplatie parallèle
- Mixtes séminome + CE très fréquent


### IHC des TG mixtes - séparation séminome / CE
- **Séminome** : **CD117+, OCT4+, CK−, CD30−**
- **Carcinome embryonnaire** : **CD30+, CK+, OCT4+, CD117−**

## Algorithme diagnostique (Ulbright 2014)

- **OCT4 +** → séminome / CE → CD30 (+)/CK (+) différencient CE du séminome
- **OCT4 −** → tumeur vitelline / choriocarcinome / tératome / spermatocytaire → AFP, GPC3, β-HCG
- Algorithme utile si tous anticorps disponibles


## Compte rendu - Items

- Type OMS + **% de chaque composante**
- **LVI** intratesticulaire
- **GCNIS**
- Envahissement : rete testis, épididyme, hile, cordon, vaginale
- pTNM + marqueurs sériques
- Fiches synoptiques **ICCR** recommandées

## 🔑 Points clés à retenir

1. **TG = 98%** des tumeurs malignes testiculaires ; **TGNS ≈ 50%** des TG, **majoritairement mixtes**
2. Facteur de risque **majeur** : **antécédent de TG contro-latérale (RR ≈ 25)**
3. **Biopsie percutanée PROSCRITE** ; geste = **orchidectomie par voie inguinale**
4. Marqueurs sériques systématiques : **AFP + β-HCG + LDH**
5. **TGNS = pronostic et traitement distincts** du séminome (plus lourds)
6. **Composantes péjoratives** : **choriocarcinome** (hématogène) > carcinome embryonnaire abondant
7. **% de chaque contingent obligatoire** dans le CR (par tranches de 10%)
8. IHC ciblée : **OCT4, CD30, CK, AFP, β-HCG, GPC3, SALL4, CD117**
9. **Polyembryome / embryome diffus** = formes particulières CE + tumeur vitelline
10. **i(12p)** / amplification 12p = anomalie des TG type II (séminome + TGNS)

# 1. Compte rendu des biopsies prostatiques

## Items obligatoires

| Item | Précisions |
|------|------------|
| **Renseignements cliniques/radiologiques** | Âge, PSA, toucher rectal, IRM, biopsies antérieures |
| **Localisation** de chaque biopsie | Base / corps / apex, D/G, ciblée |
| **Type histologique** | Adénocarcinome **acineux conventionnel** le plus souvent |
| **Grade de Gleason** | Grade prédominant + grade le plus péjoratif |
| **Score de Gleason** | Somme (ex : 3+3=6, 4+3=7, 5+4=9) |
| **% grade 4 ou 5** | Entre parenthèses quand présent |
| **Grade Group (ISUP)** | Voir tableau ci-dessous |
| **Quantité tumorale** | Nb biopsies + / total ET % ou longueur mm |
| **Signes d'extension** | Tissu adipeux péri-prostatique (EEP), vésicules séminales |
| **Engainements nerveux (PNI)** | Présence / absence |
| **Embols lymphovasculaires (LVI)** | Présence / absence |
| **Autres** | HGPIN, inflammation |


## Table de conversion Gleason → Grade Group ISUP

| Score de Gleason | Grade Group |
|------------------|:-----------:|
| ≤ 6 (3+3) | **1** |
| 7 = **3+4** | **2** |
| 7 = **4+3** | **3** |
| 8 (4+4, 3+5, 5+3) | **4** |
| 9-10 (4+5, 5+4, 5+5) | **5** |


## Format tableau SFP (société française de pathologie)

| Site | Longueur biopsie (mm) | Longueur cancer (mm) | Score Gleason | Grade Group | EEP | PNI |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| Apex droit | ... | ... | 3+4 | 2 | − | + |
| ... | | | | | | |

# 2. Compte rendu de prostatectomie radicale

## Items obligatoires

| Item | Précisions |
|------|------------|
| **Renseignements cliniques** | PSA, imagerie, traitement pré-op |
| **Macroscopie** | Poids (sans vésicules séminales), dimensions 3 axes |
| **Localisation tumeur** | Zone périphérique vs transition ; latéralité, apex, col |
| **Type histologique** | Acineux conventionnel +++ |
| **Grade Gleason + Grade Group** | Grade principal, secondaire ± **tertiaire** (spécifique pièce) |
| **Quantité tumorale** | % glandes / taille mm |
| **Extension extra-prostatique (EEP)** | Oui/non, **focale vs extensive**, localisation |
| **Invasion col vésical** | Oui/non |
| **Invasion vésicules séminales** | Oui/non (= **pT3b**) |
| **Marges chirurgicales** | Positives/négatives ; si + : **< 3 mm vs ≥ 3 mm** ou mesure linéaire ; uni/multifocale, localisation, Gleason au contact |
| **PNI / LVI** | Oui/non |
| **Curage ganglionnaire** | N envahi / N total, taille métastase en mm |
| **Classification pTNM** | **8e édition** |


## Marges chirurgicales — détails à préciser

- **Présence ou non** d'une marge positive
- **Longueur** : < 3 mm vs ≥ 3 mm (ou linéaire)
- **Unifocale vs multifocale**
- **Localisation anatomique** (apex, col, postérieure, latérale...)
- Association éventuelle à une **EEP**
- **Grade de Gleason au contact** de la marge (significatif si grade élevé)

## Exemple de conclusion — prostatectomie radicale

> **Adénocarcinome acineux**, zone périphérique gauche
> Gleason **3+4 = 7** (grade 4 : 30 %), **Grade Group 2**
> Grand axe tumoral : **20 mm**
> Intra-prostatique (absence d'EEP)
> Vésicules séminales : non envahies
> Col vésical : non envahi
> **Engainements nerveux présents**, absence d'embols
> **Marges négatives**
> Curage ganglionnaire : 0/N envahis
> **pT2 N0 R0** (8e édition)

## 🔑 Points clés à retenir

1. **Items communs** biopsie/prostatectomie : renseignements cliniques, type histo, **Gleason + Grade Group**, quantité tumorale, extension.
2. **Score de Gleason = grade principal + grade secondaire** ; pour **pièce de prostatectomie**, ajouter **grade tertiaire** si applicable.
3. **Grade Group ISUP 1-5** à mentionner systématiquement (obligatoire).
4. **% grade 4 ou 5** à préciser entre parenthèses.
5. Quantité tumorale : **nb biopsies + / total** ET % ou **longueur mm**.
6. Extension : **EEP, vésicules séminales (pT3b), col vésical, PNI, LVI**.
7. **Marges** : positives/négatives, < 3 mm vs ≥ 3 mm, uni/multifocale, localisation, **Gleason au contact**.
8. **Curage ganglionnaire** : nb envahis/total, taille métastase.
9. **pTNM 8e édition** obligatoire sur prostatectomie.
10. Format **tableau/fiche standardisée (ICCR, SFP)** recommandé = données requêtables.

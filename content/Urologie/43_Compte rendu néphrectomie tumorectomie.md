# Compte rendu : biopsie, tumorectomie et néphrectomie pour tumeur rénale

> Liens : [[40_CAT macroscopique tumeur rénale]] | [[42_Facteurs pronostiques cancer du rein]] | [[44_Carcinome à cellules claires du rein]] | [[45_Carcinomes papillaires du rein]]

## Généralités
Items communs à toute pièce :
- **Identité** du malade, **date** d'intervention et de réception, n° dossier
- **Type d'intervention** (mentionné par le clinicien)
- **Côté** (+++)
- **Unique / bilatéral**, **unifocal / multifocal**
- Nombre de prélèvements, longueur (biopsie), autres prélèvements associés
- **Renseignements cliniques** : prétraitement éventuel (**embolisation**, **cryoablation**, **radiofréquence**…) — change l'aspect de la lésion


---

## 1. Biopsie rénale pour tumeur

| Item | Détail |
|------|--------|
| **Localisation** | Précisée par le clinicien |
| **Type histologique** | Selon **OMS 2016** ; plusieurs histologies possibles si plusieurs biopsies/sites |
| **Grade ISUP** | **ccRCC** et **pRCC** (types 1 et 2) ; discutable pour les autres sous-types |
| **Sarcomatoïde / rhabdoïde** | **Impératif** à mentionner → tumeur très agressive, **grade 4 ISUP** |
| **Nécrose** | À mentionner (facteur de mauvais pronostic, surtout ccRCC) — % difficile, description qualitative |
| **Envahissement lymphovasculaire** (LVI) | Rare sur biopsie, à rapporter si présent |
| **Autres pathologies** | Rein non tumoral (glomérulaires, tubulo-interstitielles, vasculaires) |
| **Études ancillaires** | IHC, FISH — à mentionner |


---

## 2. Tumorectomie / néphrectomie partielle

### Renseignements cliniques
- Prétraitement : **embolisation**, **cryoablation**, **radiofréquence** ?
- Pièce **orientée** ou non ?

### Macroscopie
- **Mesures** pièce et **tumeur** (conditionne pT)
- Marge chirurgicale : si étroite, **encrage** fortement conseillé
- Description tumeur (taille, couleur, consistance, nécrose, limites)

### Microscopie (structurée comme la biopsie)
- Type histologique (OMS 2016), grade ISUP, sarcomatoïde/rhabdoïde, nécrose, LVI
- **Marge chirurgicale** : statut R0/R1
- Rein non tumoral


---

## 3. Néphrectomie (totale / élargie)

### Renseignements cliniques
- **Prétraitement** (embolisation, etc.)
- Type d'intervention : **radicale simple** ou **élargie** (surrénale, curage ganglionnaire, thrombectomie cave)
- Si néphrectomie élargie **sans surrénale** → **mentionner explicitement** son absence

### Macroscopie
- Radicale simple ou partielle
- **Mesures** du rein ET **de la tumeur** (conditionne pT)
- **Surrénale** présente ? Saine ou tumorale ? Contact avec la tumeur ?
- **Ganglions** (hilaires) : nombre
- Unifocal / multifocal — **dimensions de chaque** tumeur


### Stade pTNM 2017 (résumé)

| Stade | Critère |
|-------|---------|
| **pT1** | Limitée au rein, **< 7 cm** (a : ≤4 ; b : >4-7) |
| **pT2** | Limitée au rein, **≤ 10 cm** (a) / **> 10 cm** (b) |
| **pT3a** | Veine rénale/branches **(macro)** **OU** graisse péri-rénale / hilaire |
| **pT3b** | Veine cave **sous-diaphragmatique** |
| **pT3c** | Veine cave **sus-diaphragmatique** |
| **pT4** | **Fascia de Gerota** **OU** surrénale ipsilatérale **par contiguïté** |

> **Piège pT4 vs M1 surrénale** : contiguïté (continuité tumeur→graisse→surrénale) = **pT4** ; surrénale tumorale **sans contact** = **M1**. Une bonne macroscopie est indispensable.


---

### Microscopie (néphrectomie) — items obligatoires

| Item | Détail |
|------|--------|
| **Type histologique** | OMS 2016 |
| **Grade ISUP** | ccRCC / pRCC ; sarcomatoïde/rhabdoïde = **G4** |
| **Nécrose** | Macro + micro, **focale / extensive** |
| **Extension** | Capsule, **sinus**, **graisse péri-rénale**, **graisse hilaire**, **cavités pyélocalicielles**, **fascia de Gerota** |
| **Envahissement veineux** | Veine rénale, branches, veine cave — **adhérence** à la paroi ? |
| **Emboles lymphovasculaires** (LVI) | À rapporter (**ne fait pas** pT3a) |
| **Surrénale** | Présente ? Saine ? Envahie par contiguïté (pT4) ou métastatique (M1) ? |
| **Ganglions** | Nombre **examinés** / **envahis**, **rupture capsulaire** (mauvais pronostic), **taille** de la métastase (> 1 cm = péjoratif) |
| **Marges chirurgicales** | Parenchyme rénal, **graisse péri-rénale**, fascia (en général non envahi), **veine rénale**, **uretère** |
| **Rein non tumoral** | Pathologies glomérulaires, tubulo-interstitielles, vasculaires, **maladies kystiques** associées |

### Conclusion
- **Type histologique** + **grade ISUP** + **pTNM (année : 2017)**


---

## 🔑 Points clés à retenir

1. **Items communs** : identité, date, **côté**, uni/bilatéral, uni/multifocal, prétraitement (embolisation, cryo, RF).
2. **Biopsie** : type OMS 2016, **grade ISUP** (ccRCC/pRCC), **sarcomatoïde/rhabdoïde = G4**, **nécrose**, LVI, rein non tumoral, études ancillaires.
3. **Tumorectomie** : mentionner orientation, **encrage** si marge étroite ; statut des marges obligatoire.
4. **Néphrectomie élargie** : préciser si **surrénale présente/absente**, saine/tumorale, **contiguïté (pT4) vs métastase (M1)**.
5. **Mesure de la tumeur** = base du **pTNM** (cutoffs 4 / 7 / 10 cm).
6. **Extension à rapporter** : capsule, **sinus**, graisse péri-rénale, graisse hilaire, **cavités pyélocalicielles**, fascia de Gerota, veine rénale/cave, adhérence thrombus.
7. **Ganglions** : **nombre examinés / envahis**, **rupture capsulaire**, **taille de la métastase**.
8. **Marges** : parenchyme, graisse péri-rénale, fascia, **veine rénale, uretère**.
9. **Rein non tumoral** : toujours décrit — pathologie tubulo-interstitielle, vasculaire, kystique.
10. **Conclusion** : type OMS + grade ISUP + **pTNM 2017** (année précisée).

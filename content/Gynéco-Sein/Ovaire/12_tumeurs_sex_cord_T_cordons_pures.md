# Tumeurs ovariennes des cordons sexuels — formes pures

> Liens : [[13_tumeurs_sex_cord_T_mixtes_et_pseudo_tumeurs]] | [[14_tumeurs_sex_cord_stromales_pures]] | [[11_tumeurs_germinales_non_teratomateuses]] | [[09_teratomes_immatures]]

## Généralités

Tumeurs développées à partir du **mésenchyme/cordons** de la **gonade indifférenciée** → on retrouve dans l’ovaire des éléments **de la gonade testiculaire**.

- **6-7 %** des tumeurs ovariennes
- Tumeurs **rares** ; certaines entités **rarissimes**
- Clinique souvent **bruyante** : manifestations hormonales (**œstrogéniques** ou **androgéniques**) → **tumeurs fonctionnelles**
- Macroscopie : **unilatérales**, couleur **jaune / orange / chamois**
- Diagnostic souvent difficile → **revue obligatoire en réseau TMRG**

## Marqueurs IHC communs des cordons sexuels

| Marqueur | Caractéristique |
|----------|-----------------|
| **Inhibine** | Sensibilité moyenne, **spécificité bonne** ; cordons sexuels ± stroma |
| **Calretinine** | Plus sensible mais **moins spécifique** que inhibine |
| **FOXL2** (facteur de transcription folliculaire) | + dans granulosa, Sertoli, fibroblastes ; **− dans cellules stéroïdes et de Leydig** |
| **SF1** (Steroidogenic Factor 1) | **Plus sensible que l’inhibine** ; régule l’expression de l’inhibine ; cordons + stroma |
| **Mélan-A** | + cordons sexuels (attention : aussi mélanome) |
| **EMA** | **TOUJOURS NÉGATIF** dans ce groupe |

> ⚠️ La **réticuline** est très utile : elle entoure des **groupements cellulaires** dans la granulosa vs **cellule par cellule** dans les fibromes/thécomes.

- **Tumeur de Sertoli pure**

## 1. Tumeur de la granulosa ADULTE

### Généralités
- Tumeur la **plus fréquente** des tumeurs du stroma et des cordons sexuels
- **1-2 %** des tumeurs ovariennes
- Femme **péri/post-ménopause**, âge moyen **53 ans**
- Lésion **unilatérale**

### Clinique
- Masse ovarienne ± rupture / torsion
- **Signes d’imprégnation œstrogénique** : **métrorragies post-ménopausiques**, hyperplasie endométriale → **point d’appel diagnostique**
- Rares signes androgéniques

### Comportement
- **Tumeur maligne de bas grade**
- **Rechutes parfois très tardives** (> 20 ans) en péritonéal +++
- 10 % de rechute en stade I, **30 % tous stades confondus**
- Survie à 25 ans : **60 % stade I**, **40 % stade III**

### Macroscopie
- **Solide**, parfois kystisée, ou kystique pure
- **12 cm** en moyenne
- Couleur blanche, jaune, orange ou marron

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p06_01.jpeg]]

### Histologie

#### Cytologie
- Petites cellules ovalaires, **cytoplasme peu visible**
- **Noyaux incisurés réguliers en grain de café** (CARACTÉRISTIQUE)
- Si **lutéinisation** : noyaux **arrondis non incisurés**, petit nucléole
- Pas d’atypies, mitoses rares (max 5-10 / 10 champs forts)

#### Architectures (multiples — réaliser de nombreux plans de coupe)

| Architecture | Caractéristique |
|--------------|------------------|
| **Microfolliculaire** | **Corps de Call-Exner** (cavités contenant des débris cellulaires, aspect en rosette) |
| Macrofolliculaire | Grandes cavités |
| Trabéculaire | Aspect sertoliforme |
| Insulaire | Îlots cellulaires |
| Pseudo-papillaire | Papilles |
| Gyriforme / en zigzag | Cordons en moiré |
| Solide | DD avec fibrome |
| Cordonale | DD avec carcinome |

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p08_01.jpeg]]

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p10_01.jpeg]]

### Réflexe diagnostique : **réticuline**
- Granulosa : **groupes cellulaires** entourés (≠ fibrome où chaque cellule est entourée)

### IHC

| Marqueur | Granulosa adulte |
|----------|:---:|
| **FOXL2** | **+++** |
| **SF1** | **+++** |
| **Calretinine** | + |
| **Mélan-A** | + |
| **Inhibine** | + (parfois faible) |
| Récepteurs hormonaux | + |
| **EMA** | **−** |
| **CK7** | **−** |
| Cytokératine | parfois + |
| CD10, CD56, CD99 | + (peu spécifiques) |

### Biologie moléculaire — DIAGNOSTIQUE

**Mutation FOXL2 C134W** présente dans **96 %** des granulosa adultes (à rechercher en cas de doute morphologique ou de luthinisation importante).

### Diagnostics différentiels

| DD | Distinction |
|----|-------------|
| **Fibro-thécome** (formes solides) | Réticuline cellule par cellule ; FOXL2 mutation **absente** |
| **Carcinome endométrioïde** (architectures pseudo-cordonales) | **EMA+, CK+** ; PAX8+ |
| **Carcinome à petites cellules avec hypercalcémie** (femme jeune) | **EMA+ focal**, **perte BRG1 (SMARCA4)**, marqueurs cordons sexuels − |
| **Carcinoïde / strumal carcinoïde** | Marqueurs neuroendocrines, **TTF1** / **thyroglobuline** |
| **Carcinome indifférencié** | EMA+ |
| Métastases (carcinome, TNE, mélanome) | Attention au **Mélan-A** (aussi + cordons sexuels) → vérifier **HMB45, PS100** |
| **Sarcome stromal endométrial bas grade** (formes fusiformes) | Recherche **réarrangement JAZF1** en FISH |

> ⚠️ Si on a une tumeur du stroma/cordons sexuels (FOXL2/SF1/inhibine/calretinine +) sans pouvoir la classer (architecture atypique, luthinisation) → **rechercher la mutation FOXL2 C134W** : si + = granulosa adulte (avec implications de tumeur maligne et risque de récidive tardive).

## 2. Tumeur de la granulosa JUVÉNILE

### Généralités
- **5-15 %** des granulosa
- **Adolescentes / jeunes femmes**, âge moyen **15 ans** ; **97 % avant 40 ans**
- Lésion **unilatérale**

### Clinique
- Masse isolée ± rupture / torsion
- **Pseudo-puberté précoce** ou imprégnation œstrogénique (rarement androgénique)

### Macroscopie
- **Grande taille** (12 cm en moyenne), surface lisse
- Solide-kystique ou **kyste hémorragique unique**
- Jaune-orangé à marron, aspects œdémateux et hémorragiques

### Histologie
- Architecture **diffuse / nodulaire** avec **œdème** important → substance **myxoïde**
- Nombreux **pseudo-follicules** de taille variable contenant une **sécrétion éosinophile** (≠ corps de Call-Exner adultes)
- Cellules de **taille moyenne**, **noyau arrondi NON incisuré**, cytoplasme abondant
- **Atypies cytonucléaires parfois marquées**
- **Activité mitotique élevée** (jusqu’à **32 mitoses / 10 champs forts**)
- Aspect histologique pouvant simuler une tumeur très maligne (TG maligne)


### IHC

| Marqueur | Granulosa juvénile |
|----------|:---:|
| **FOXL2** | + |
| **SF1** | + |
| Marqueurs cordons sexuels | + |
| **BRG1 (SMARCA4)** | **+** (conservé) → DD avec petites cellules hypercalcémantes |
| Cytokératine | parfois + |
| EMA | − (rares + décrits) |
| CK7 | − |
| CD99, CD56, CD10 | + (non spécifiques) |

### Biologie moléculaire
- **Pas de mutation FOXL2** en général

### Comparaison adulte vs juvénile

| Critère | Granulosa **adulte** | Granulosa **juvénile** |
|---------|----------------------|------------------------|
| Âge | Péri/post-ménopause (53 ans) | Adolescente / < 20 ans |
| Architecture | **Microfolliculaire** (corps de Call-Exner) | **Pseudo-folliculaire**, œdème myxoïde |
| Cytologie | Noyaux **incisurés en grain de café** | Noyaux **arrondis NON incisurés** |
| Atypies / mitoses | Faibles | **Marquées** (32 mit/10 CFG possibles) |
| **Mutation FOXL2 C134W** | **96 %** | **Absente** |
| Comportement | Maligne, rechute **tardive** (> 20 ans) | Rechute **précoce** (< 3 ans) si rechute |
| Pronostic stade I | Bon | **Excellent** |

### Diagnostics différentiels (granulosa juvénile)

| DD | Distinction |
|----|-------------|
| **Granulosa adulte** | Cf. tableau supra |
| **Carcinome à petites cellules avec hypercalcémie** | EMA+ focal, **perte BRG1**, marqueurs cordons sexuels − |
| **Carcinome à cellules claires** | CK7+, **HNF1β+**, NapsineA+ |
| Métastases | Toujours à éliminer |
| Lésions bénignes (formes très kystiques) | **Kystes folliculaires**, grand follicule lutéinisé solitaire |

### Pronostic
- **Excellent en stade I** : **annexectomie unilatérale** (préservation fertilité), même si mitoses/atypies
- Risque de rechute : **< 3 ans**, augmenté en cas de **rupture, stade > I, cytologie péritonéale +**

## 3. Tumeur de Sertoli pure

### Généralités
- **Extrêmement rare**
- Femme jeune, âge moyen **30 ans**

### Histologie
- Cytologie variée : cellules de taille moyenne, cytoplasme éosinophile ou clarifié, parfois **lipidiques**
- Noyaux ovalaires parfois incisurés ; cellules fusiformes possibles
- **DIAGNOSTIC = présence de TUBES** caractéristiques (tubes sertoliens, comme dans le testicule) :
  - tubes ronds **solides** ou avec **lumière contenant une substance éosinophile**
- Architectures kystiques ou pseudo-papillaires possibles → DD **tumeur séreuse borderline**
- Aspect **rétiforme** possible (rete testis-like)
- Stroma fibro-hyalin abondant

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p18_01.jpeg]]

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p18_02.jpeg]]

### IHC

| Marqueur | Sertoli pure |
|----------|:---:|
| **SF1** | **+** |
| **Inhibine** | **+** |
| **Calretinine** | **+** |
| **FOXL2** | + (pas 100 %) |
| **Mélan-A** | souvent − |
| EMA | **−** |
| Cytokératine | parfois + |
| CK7 (DD séreuse borderline) | − (intéressant) |

### Biologie moléculaire
- Mutation **DICER1** caractéristique (Sertoli, plus fréquente dans Sertoli-Leydig — cf. [[13_tumeurs_sex_cord_T_mixtes_et_pseudo_tumeurs]])

### DD
- **Toujours vérifier l’absence de cellules de Leydig** avant de porter le diagnostic de Sertoli pure (rares cellules de Leydig possibles, mais très peu)

| DD | Distinction |
|----|-------------|
| **Tumeur de Sertoli-Leydig** | Cf. [[13_tumeurs_sex_cord_T_mixtes_et_pseudo_tumeurs]] : contingent de Leydig |
| **Carcinome endométrioïde** (formes glandulaires/cordonales) | **CK7+**, **EMA+**, PAX8+ |
| **Tumeur carcinoïde** | Chromogranine+, synaptophysine+ |
| **FATWO** (female adnexal tumor of probable Wolffian origin) | **GATA3+**, **SF1−** |
| Tumeur à cellules stéroïdiennes | **Mélan-A+**, **pas de tubes** |
| **Prolifération hilaire de cellules sertoliennes** | Pas de masse tumorale |

## 4. Tumeur des cordons sexuels à tubules annelés (SCTAT)

### Généralités
- < **1 %** des tumeurs des cordons sexuels
- Aspect très particulier : **tubules annelés** isolés ou associés à une tumeur de Sertoli

### Histologie : **tubules annelés**
- **Simples** : cylindres hyalins **cernés de noyaux**
- **Complexes** : cylindres hyalins cernés de noyaux + **couronne périphérique de noyaux** avec tubes simples à l’intérieur

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p21_01.jpeg]]

![[assets/gyneco-sein/ovaire/Ovaire cordons sexuels stroma cordons purs/p21_02.jpeg]]

### **2 formes cliniques**

| Critère | SCTAT **sporadique** | SCTAT **héréditaire** (Peutz-Jeghers) |
|---------|----------------------|-----------------------------------------|
| Âge moyen | 36 ans | **27 ans** |
| Latéralité | **Unilatérale** | **Bilatérale** |
| Présentation | Masse ± complications, signes hormonaux | **Découverte fortuite** (bilan PJS) |
| Taille | > 3 cm | **< 3 cm**, multifocal, **tumorlettes** |
| Calcifications | Rares | **Fréquentes** ++ |
| Mutation | **Pas** de mutation STK11 | **STK11 (LKB1)** germinale |
| Comportement | **Malin (jusqu’à 20-30 % rechutes)** | **Bénin** |

> ⚠️ Toute SCTAT bilatérale / multifocale + calcifications → **rechercher syndrome de Peutz-Jeghers** + **consultation d’oncogénétique** (mutation **STK11/LKB1**).

### Macroscopie sporadique
- > 3 cm, surface lisse, jaune-orangé à marron
- Femme jeune (≈ 36 ans), unilatérale
- Possibles signes œstrogéniques / progestéroniques

### Macroscopie syndromique (PJS)
- Ovaires d’aspect macroscopiquement normal **ou** multiples petits nodules < 3 cm
- Multifocal, bilatéral

### IHC

| Marqueur | SCTAT |
|----------|:---:|
| **Inhibine** | **+** |
| **Calretinine** | **+** |
| **WT1** | **+** |
| **FOXL2** | + |
| Cytokératine | parfois + |
| EMA, CK7, CK5/6 | − |
| CD56 | parfois + |

### Biologie moléculaire
- **Pas de mutation FOXL2** ni de mutation STK11 dans la tumeur sporadique elle-même (mais STK11 germinale dans la forme syndromique)

### DD

| DD | Distinction |
|----|-------------|
| **Granulosa** | Tubules annelés peuvent être pris pour des corps de Call-Exner ; rechercher **mutation FOXL2** (granulosa) ; SCTAT sporadique = aspect homogène monomorphe |
| **Gonadoblastome** | Contexte **dysgénésie gonadique** ; composante germinale **OCT4+** associée |
| **Tumeur de Sertoli** | Tubes simples, pas tubules annelés |

## 🔑 Points clés à retenir

1. Tumeurs des cordons sexuels = **6-7 %** des tumeurs ovariennes ; clinique souvent **fonctionnelle**
2. Marqueurs communs : **inhibine, calretinine, FOXL2, SF1, Mélan-A** ; **EMA toujours négatif**
3. **Granulosa adulte** = la + fréquente : **noyaux en grain de café**, **corps de Call-Exner**, **mutation FOXL2 C134W (96 %)**
4. Comportement granulosa adulte = **malin de bas grade**, rechutes **très tardives** (> 20 ans)
5. **Réflexe** : réticuline (entoure des groupes dans granulosa, cellule par cellule dans fibrome) + **mutation FOXL2** si doute morphologique
6. **Granulosa juvénile** : ado/jeune, noyaux **arrondis non incisurés**, atypies/mitoses **marquées**, **PAS de mutation FOXL2**
7. DD majeur granulosa juvénile = **carcinome à petites cellules avec hypercalcémie** (perte **BRG1**, EMA+ focal)
8. **Sertoli pure** : tubes sertoliens caractéristiques ; **DICER1** ; pas de cellules de Leydig
9. **SCTAT sporadique** : unilatérale, > 3 cm, **maligne** (20-30 % rechutes)
10. **SCTAT Peutz-Jeghers** : bilatérale, multifocale, calcifications, **STK11 germinale**, **bénigne**
11. Tubules annelés simples (cylindres hyalins cernés de noyaux) ou complexes
12. Toutes ces tumeurs doivent être **revues en réseau TMRG** (tumeurs malignes rares gynécologiques)

# Tumeurs des cordons sexuels MIXTES + Pseudo-tumeurs ovariennes

> Liens : [[12_tumeurs_sex_cord_T_cordons_pures]] | [[14_tumeurs_sex_cord_stromales_pures]] | [[09_teratomes_immatures]] | [[11_tumeurs_germinales_non_teratomateuses]]

## Généralités (rappel)

Tumeurs développées à partir du **mésenchyme/cordons** de la **gonade indifférenciée**.

- **6-7 %** des tumeurs ovariennes
- Cliniques fonctionnelles fréquentes (**œstrogéniques** ou **androgéniques**)
- Macroscopie : unilatérales, **jaune / orange / chamois**
- Marqueurs IHC communs : **inhibine, calretinine, FOXL2, SF1, Mélan-A** ; **EMA −** (sauf sous-types)
- **Revue obligatoire TMRG**

Cette fiche traite :
1. **Tumeurs de Sertoli-Leydig** (mixtes)
2. **Tumeurs des cordons sexuels INCLASSÉES**
3. **Pseudo-tumeurs** ovariennes (hyperthécose, lutéome de grossesse, œdème massif, fibromatose)

---

## 1. Tumeur de Sertoli-Leydig

### Généralités
- **Extrêmement rare** : **< 0,5 %** des tumeurs ovariennes
- Risque majeur de **sur-diagnostic**
- Définition : prolifération de **cellules de Sertoli + cellules de Leydig + cellules stromales** de la gonade primitive

### Clinique
- **Femmes jeunes**, âge moyen **25 ans**
- Tumeur **unilatérale** (97 %)
- Présentation : masse ± rupture/torsion
- **Signes androgéniques (virilisation)** dans **30-50 %** des cas
- Plus rarement signes œstrogéniques
- Adolescentes : **pseudo-puberté isosexuelle précoce**
- **80 % stade I** ; extension péritonéale dans 2-3 %

### Macroscopie
- Tumeur volumineuse **12-14 cm**, jaune-orangée
- Quelques kystes possibles
- **Remaniements hémorragiques / nécrotiques**

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/ovaire/Ovaire%20cordons%20sexuels%20stroma%20mixtes%20stroma%20et%20cordons/p06_01.jpeg)

### Histologie

#### Composants
- **Cellules de Sertoli** : tubes (pleins ou avec lumière éosinophile) selon différenciation
- **Cellules de Leydig** : grandes cellules **éosinophiles**, pôle périphérique mais peuvent être mêlées au Sertoli
  - **Cytoplasme abondant**, parfois **cristalloïdes de Reinke** (rares)
  - Aspect **constant** quel que soit le degré de différenciation

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/ovaire/Ovaire%20cordons%20sexuels%20stroma%20mixtes%20stroma%20et%20cordons/p07_01.jpeg)

#### Grading par différenciation

| Différenciation | Caractéristiques |
|-----------------|-------------------|
| **Bien différenciée** | Architecture **lobulée**, **tubes Sertoliens** ++ ; pas d’atypie, pas de mitose |
| **Moyennement différenciée** | Tubes parfois pleins + cordons / nappes / travées de Sertoli ; ± aspect "granulosa-like" |
| **Peu différenciée** | Architecture **sarcomatoïde**, **peu/pas de tubes** ; mitoses+++, œdème ; difficile à classer |

> Échantillonnage indispensable pour rechercher des **zones mieux différenciées avec tubes** dans les formes peu différenciées.

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/ovaire/Ovaire%20cordons%20sexuels%20stroma%20mixtes%20stroma%20et%20cordons/p08_01.jpeg)

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/ovaire/Ovaire%20cordons%20sexuels%20stroma%20mixtes%20stroma%20et%20cordons/p09_01.jpeg)

#### Formes particulières

| Forme | Caractéristique | Implication |
|-------|------------------|-------------|
| **Contingent rétiforme** | Aspect rete testis (papilles, fentes) — **15 %** des cas | **Pronostic moins bon**, DD avec tumeur séreuse borderline |
| **Contingent hétérologue** | **20 %** des cas | À reconnaître |
|   - Épithélial mucineux, carcinoïde, hépatocytaire | | |
|   - Mésenchymateux : **cartilage immature, muscle strié immature** | | DD : **tératome immature** |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/ovaire/Ovaire%20cordons%20sexuels%20stroma%20mixtes%20stroma%20et%20cordons/p10_01.jpeg)

### IHC

| Marqueur | Cellules de Sertoli | Cellules de Leydig |
|----------|:---:|:---:|
| **Inhibine** | + (moins intense) | **+** |
| **Calretinine** | + (moins intense) | **+** |
| **SF1** | **+** | **+** |
| **WT1** | **+** | + |
| **FOXL2** | + (≈ 50 % des cas) | **−** |
| **Mélan-A** | − | **+** |
| Pancytokératine | parfois + | parfois + |
| **EMA** | **−** | **−** |
| **CK7** | **−** | **−** |
| CD99, CD56, CD10 | + (peu spécifiques) | + |

### Biologie moléculaire
- **Mutation DICER1** : présente dans **30-50 %** des Sertoli-Leydig (vs > 50 % dans la Sertoli pure) → **caractéristique du diagnostic**
- Si mutation DICER1 : **consultation d’oncogénétique** (associations possibles : tumeurs thyroïdiennes, autres tumeurs)

### DD

| DD | Distinction |
|----|-------------|
| **Adénocarcinome endométrioïde (variante sertoliforme)** | **EMA+, CK7+** ; PAX8+ |
| **Carcinomes** divers | EMA+, CK+ |
| **Tumeur carcinoïde / TNE** | Chromogranine+, synaptophysine+ |
| **Tumeur séreuse borderline** (formes rétiformes) | EMA+, CK7+ ; **WT1 NON discriminant** (positif dans les 2) |
| **Carcinosarcome / tératome** (contingent hétérologue) | Contexte clinique, autres feuillets pour tératome |
| **Fibrosarcome** (formes peu différenciées fusiformes) | cf. [[14_tumeurs_sex_cord_stromales_pures]] |
| Tumeurs avec **stroma fonctionnel** (granulosa, mucineuse, **Krukenberg**) | Présence de cellules lutéinisées hormonosécrétantes ≠ vraie tumeur Sertoli-Leydig |

### Pronostic

| Différenciation | Survie |
|-----------------|--------|
| Bien différenciée | **100 %** |
| Moyennement / peu différenciée | **85-90 %** |

**Facteurs péjoratifs** :
- Stade
- **Rupture**
- **Contingent rétiforme**
- **Contingent hétérologue**

Rechutes **précoces** (< 2 ans), **péritonéales**.

## 2. Gynandroblastome (mention)

- Tumeur **mixte cordons sexuels** : composante de **type granulosa adulte/juvénile** + composante de **Sertoli-Leydig**
- Les deux contingents doivent être présents en quantité significative
- Très rare ; pronostic généralement bon

## 3. Tumeurs des cordons sexuels INCLASSÉES

### Généralités
- **5-10 %** des tumeurs des cordons sexuels
- **Diagnostic d’exclusion** après élimination des entités spécifiques (granulosa adulte/juvénile, Sertoli pure, Sertoli-Leydig, fibrothécome…)
- **Aspects variés** : cellules fusiformes, aspects de cordons sexuels…
- **Remaniements** importants liés à la **grossesse** (œdème, lutéinisation) qui masquent la tumeur sous-jacente

### Critères diagnostiques
1. Morphologie compatible cordons sexuels
2. **IHC** : expression variable des marqueurs (FOXL2, SF1, inhibine, calretinine, Mélan-A)
3. **Absence de mutation FOXL2** (DD granulosa adulte)
4. **Absence de mutation DICER1** habituellement (DD Sertoli/Sertoli-Leydig)

### Pronostic
- Relativement bon
- **90 %** survie à 5 ans (≈ granulosa adulte / Sertoli-Leydig)
- Rechutes possibles

## 4. Pseudo-tumeurs ovariennes

Lésions très fréquentes pouvant simuler une tumeur des cordons sexuels.

### 4.1 Hyperplasie stromale / Hyperthécose

#### Clinique
- Femmes **60-70 ans**
- Signes de **virilisation** ou imprégnation œstrogénique
- Contexte parfois spécifique : **obésité, HTA, diabète insulino-résistant**, **acanthosis nigricans** (syndrome HAIR-AN)

#### Macroscopie
- Ovaires hypertrophiés ou de taille normale, **bilatéraux**
- Pas de masse tumorale

#### Histologie
- Prolifération **stromale ± cellules lutéinisées**
- **Hyperthécose diffuse ou nodulaire** dans le cortex et la médullaire
- **Respect des structures ovariennes pré-existantes** ++

#### Traitement
- Agonistes LHRH ou **chirurgie**


### 4.2 Hyperplasie des cellules de Leydig (hilaire)

- Ménopause ou **grossesse**
- **Découverte fortuite**
- Hyperplasie **nodulaire ou diffuse** des cellules de Leydig au niveau du **hile ovarien**
- Possible association à hyperthécose ou fibrome
- **DD = tumeur à cellules de Leydig** (cf. [[14_tumeurs_sex_cord_stromales_pures]]) : virilisante, individualisable comme une **masse**

### 4.3 Lutéome de grossesse

#### Clinique
- **2ème moitié de la grossesse**
- Découverte fortuite (souvent **lors d’une césarienne**)
- Virilisation : **mère 25 %**, **fille 70 %**
- **Régression complète après l’accouchement**

#### Macroscopie
- Nodules solides multiples, **marrons**, bien limités
- Taille moyenne 6 cm
- **Bilatéral dans 1/3** des cas

#### Histologie
- **Nappes diffuses de cellules lutéinisées** avec mitoses
- Signes de régression : noyaux **pycnotiques**, **fibrose**
- Marqueurs cordons sexuels (**FOXL2, SF1, inhibine, calretinine**) +

#### DD
- **Hyperthécose** : femmes plus âgées, pas de grossesse
- **Tumeurs à cellules de Leydig / stéroïdiennes** : nodule unique, hors contexte de grossesse

### 4.4 Œdème massif de l’ovaire

#### Clinique
- **Femme jeune**, âge moyen **22 ans**
- Tableau **abdominal aigu** avec **torsion** → geste chirurgical
- **Unilatéral 90 %**

#### Macroscopie
- Ovaire augmenté (10 cm), surface lisse
- **Œdème majeur**, consistance **molle quasi liquidienne**

#### Histologie
- **Œdème diffus** de la structure ovarienne
- **Respect des structures ovariennes pré-existantes** ++
- 40 % : quelques cellules lutéinisées et fibroblastes

#### DD
- **Fibrome remanié par œdème** : pas de structures ovariennes pré-existantes
- **Tumeur stromale sclérosante** : coexistence de zones œdémateuses + fibreuses, pas de structures ovariennes pré-existantes


### 4.5 Fibromatose de l’ovaire

#### Clinique
- Femme en **période d’activité génitale**
- Douleurs abdominales, troubles des règles (non spécifique)

#### Macroscopie
- Ovaire augmenté, **unilatéral**
- Taille moyenne **8 cm**, ferme, **gris-blanc**

#### Histologie
- Prolifération **peu dense de fibroblastes** entrecroisés / storiformes
- **Respect des structures ovariennes pré-existantes** ++ (CARACTÉRISTIQUE)

#### Comportement
- **Bénin**, lésion limitée à l’ovaire (≠ fibromatose desmoïde des parties molles, qui n’a rien à voir)

## Diagnostics différentiels (Sertoli-Leydig)

| DD | Distinction clé |
|----|------------------|
| **Adénocarcinome endométrioïde** (variante sertoliforme) | EMA+, CK7+, **PAX8+** |
| **TNE / carcinoïde ovarien** | Chromogranine+, synaptophysine+ |
| **Tumeur séreuse borderline** (rétiforme) | EMA+, CK7+ |
| **Carcinosarcome** | Femme âgée, contingent malin franc |
| **Tératome immature** (contingent hétérologue) | 3 feuillets, tissu neuroectodermique immature |
| **Fibrosarcome** (peu différencié fusiforme) | Atypies+++, > 4 mit/10 CFG, cytologie maligne franche |
| **Métastase de Krukenberg** | Bilatérale, cellules en bague à chaton, contexte digestif |

## 🔑 Points clés à retenir

1. **Sertoli-Leydig** = **< 0,5 %** des tumeurs ovariennes → **risque majeur de sur-diagnostic**
2. Femme **jeune** (25 ans), unilatérale, **virilisation 30-50 %**
3. Histologie : **tubes Sertoliens** + **cellules de Leydig éosinophiles** ; échantillonner pour zones mieux différenciées
4. 3 niveaux de différenciation : bien / moyennement / peu différenciée → impact pronostique
5. Formes péjoratives : **contingent rétiforme** (15 %) et **contingent hétérologue** (20 %, dont cartilage/muscle immature)
6. IHC : **SF1+, WT1+, inhibine+, calretinine+ ; Mélan-A+ Leydig** ; **EMA−, CK7−**
7. **Mutation DICER1** dans 30-50 % → **consultation d’oncogénétique**
8. Pronostic : 100 % bien différencié, 85-90 % moyennement/peu ; rechutes péritonéales précoces (< 2 ans)
9. **Tumeurs inclassées des cordons sexuels** = 5-10 %, diagnostic d’exclusion ; pas FOXL2 ni DICER1 ; survie 90 %
10. **Hyperthécose** : femme âgée, bilatérale, virilisation, contexte HAIR-AN
11. **Lutéome de grossesse** : 2ème moitié de grossesse, **régression post-partum**, virilisation fille 70 %
12. **Œdème massif / Fibromatose** : **respect des structures ovariennes pré-existantes** (≠ fibrome) → bénin

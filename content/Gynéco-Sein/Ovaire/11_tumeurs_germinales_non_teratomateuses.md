# Tumeurs germinales non tératomateuses de l’ovaire

> Liens : [[09_teratomes_immatures]] | [[10_Teratomes_matures]] | [[08_Tumeur_de_Brenner_des_2018_H_Roussel_def]] | [[12_tumeurs_sex_cord_T_cordons_pures]]

## Généralités

- Tumeurs germinales = **2-4 %** des tumeurs du corps humain
- Survenue essentiellement chez l’**adulte jeune et l’enfant**
- Localisations : **gonades** (testicule, ovaire) **+ ligne médiane** (base du crâne, médiastin antérieur, rétropéritoine, région sacro-coccygienne) — trajet de migration des cellules germinales depuis le **sac vitellin**
- Quelles que soit la localisation, **morphologie identique**

## Place dans la classification

Les tumeurs germinales ovariennes se subdivisent en **2 grandes catégories** :

| Catégorie | Fréquence | Comportement |
|-----------|:---:|-------------|
| **Tumeurs germinales primitives non tératomateuses** | **3-5 %** | **Malignes**, aneuploïdes, **i(12p) + dans 80 %** |
| **Tératomes purs** (cf. [[10_Teratomes_matures]] / [[09_teratomes_immatures]]) | majoritaires | Diploïdes ; mature = bénin / immature = malignité variable |

![[assets/gyneco-sein/ovaire/04_58_02 Tératome immature MDS/p06_00.jpeg]]

## Correspondance embryologique

| Tumeur germinale | Cellule de référence |
|-----------------|----------------------|
| **Dysgerminome** | Gonies (ovogonie/spermatogonie) |
| **Carcinome embryonnaire** | Cellules souches (morula) |
| **Tumeur vitelline** | Sac vitellin |
| **Choriocarcinome** | Placenta (cyto- et syncytiotrophoblaste) |
| **Tératome / Polyembryome** | Tissu embryonnaire |


## Spécificités ovariennes (vs testicule)

| Aspect | Ovaire | Testicule |
|--------|--------|-----------|
| Tumeur germinale la + fréquente | **Tératome** (95 %) | **Séminome** (50 %) |
| Dysgerminome | **Rare** | Fréquent |
| Tératome mature | **Bénin** | Malin (post-puberté) |
| Tissus particuliers | **Thyroïde, plexus choroïde** | Tissu pancréatique |
| **i(12p)** | **80 %** des TG malignes | 80 % |

![[assets/gyneco-sein/ovaire/04_58_02 Tératome immature MDS/p08_00.jpeg]]

L’**isochromosome 12p** = chromosome 12 ayant perdu son bras long et dupliqué son bras court de part et d’autre du centromère (marqueur cytogénétique commun aux TG malignes).

---

## 1. Dysgerminome

### Clinique
- **Tumeur germinale maligne la plus fréquente** de l’ovaire
- **Femme jeune** ≈ 20-30 ans (rare avant 5 ans, rare après 50 ans)
- Souvent **unilatérale**

### Macroscopie
- Tumeur **solide**, **charnue**, **pêche / chamois** à la coupe

![[assets/gyneco-sein/ovaire/04_58_02 Tératome immature MDS/p10_00.jpeg]]

### Histologie
- Architecture **solide / trabéculaire / pseudo-papillaire** (par dissociation cellulaire)
- Cellules **primitives** ressemblant aux **ovogonies/spermatogonies** : grandes, **cytoplasme clarifié éosinophile**, **noyau central volumineux vésiculeux nucléolé**
- **Stroma lymphocytaire CARACTÉRISTIQUE** (petits lymphocytes T) ± histiocytes, **cellules épithélioïdes**, **granulomes à cellules géantes multinucléées**

![[assets/gyneco-sein/ovaire/04_58_02 Tératome immature MDS/p11_00.jpeg]]


### IHC

| Marqueur | Dysgerminome |
|----------|:---:|
| **OCT3/4** (= OCT4) | **+** |
| **SALL4** | **+** |
| **PLAP** | **+** |
| **CD117 (c-KIT)** | **+** |
| **D2-40** | **+** |
| Cytokératine | − (ou très focal) |
| EMA | **−** |
| AFP, glypican-3, hCG, CD30 | **−** |

## 2. Tumeur vitelline (yolk sac tumor)

### Clinique
- **2ème** tumeur germinale maligne de l’ovaire en fréquence
- Femme jeune / adolescente
- Rarement après 40 ans (et alors souvent associée à un **carcinome endométrioïde**)

### Macroscopie
- Tumeur **très hémorragique**
- Aspect **micro-kystique**


### Architecture (variées)

| Pattern | Caractéristique |
|---------|-----------------|
| **Microkystique / réticulaire** | Le plus classique, réseaux de cellules tumorales |
| **Polyvésiculaire vitellin** | Macrokystes |
| Solide | Plages de cellules tumorales |
| Myxoïde | Substance fondamentale myxoïde |
| Glandulaire (intestinal) | Glandes type intestinal, ± gobelets |
| **Pariétale** | Fibro-hyalinose |
| **Hépatoïde** | Cellules hépatocytaires (DD : CHC) |
| **Endométrioïde-like** | Cellules cylindriques avec sécrétion basale |

### Lésion pathognomonique : **corps de Schiller-Duval**
Papille centrée par un **axe vasculaire**, sur lequel se branchent les cellules tumorales, le tout dans une structure kystique → **aspect glomérulaire**.



### Cytologie
- Aspect primitif, cytoplasme éosinophile clarifié
- Noyaux **augmentés de volume**, vésiculeux, nucléolés
- **Index mitotique élevé**
- **Sécrétion hyaline** (boules éosinophiles intra/extracellulaires)
- **Cellules hépatocytaires dans 16 %** des cas

### IHC

| Marqueur | Tumeur vitelline |
|----------|:---:|
| **AFP (alpha-fœtoprotéine)** | **+** |
| **Glypican-3** | **+** |
| **SALL4** | **+** |
| Pancytokératine | + |
| **EMA** | **−** |
| CK7 | − (mais + dans glandes intestinales) |
| **OCT4** | **−** |
| CD117 | **−** |
| CD30 | **−** |

## 3. Carcinome embryonnaire

### Clinique
- **Très rare** dans l’ovaire (≠ testicule où il est fréquent et souvent pur)
- **JAMAIS pur** dans l’ovaire → toujours dans une **tumeur germinale mixte**

### Histologie
- Tumeur **hémorragique et nécrotique**
- Cellules d’**allure épithéliale très atypiques**, **mitoses+++**
- Cellules multinucléées **syncytiotrophoblastiques** souvent associées
- Structures glandulaires possibles


### IHC

| Marqueur | Carcinome embryonnaire |
|----------|:---:|
| **CD30** | **+** (caractéristique) |
| **OCT3/4** | **+** |
| **SALL4** | **+** |
| **PLAP** | + |
| Cytokératine | + |
| **CK7** | − |
| EMA | **−** |
| Glypican-3, AFP | en général **−** |

---

## 4. Choriocarcinome (non gestationnel)

### Clinique
- **Très rare** dans l’ovaire
- **JAMAIS pur** (toujours dans TG mixte)
- ≠ choriocarcinome **gestationnel** (post-môle, utérus)

### Histologie
- Tumeur **très hémorragique** : larges flaques de sang
- Population **biphasique** :
  - **Cellules mononucléées** : cytotrophoblaste + trophoblaste intermédiaire
  - **Cellules multinucléées syncytiotrophoblastiques** entourant les amas mononucléés

### IHC
- **β-hCG +++** (syncytiotrophoblaste)
- **GATA3+**, hPL+, SALL4+

---

## 5. Polyembryome

- **Exceptionnel**, **jamais pur**, dans une TG mixte
- Aspect = **disque embryonnaire** au stade précoce de l’embryogenèse

---

## 6. Tumeurs germinales mixtes

- **10 %** des TG malignes ovariennes
- Mélange de plusieurs contingents germinaux
- Le **carcinome embryonnaire** et le **choriocarcinome** sont **toujours retrouvés sous cette forme**
- Forme la plus fréquente chez l’**enfant** : **tératome immature + tumeur vitelline**

## DD : Dysgerminome ovarien vs Séminome testiculaire

| Critère | Dysgerminome (ovaire) | Séminome (testicule) |
|---------|------------------------|----------------------|
| Histologie | **IDENTIQUE** | IDENTIQUE |
| Stroma lymphocytaire | + | + |
| **OCT4 / CD117 / PLAP / D2-40** | + | + |
| Comportement | Maligne, **chimiosensible** | Maligne, chimiosensible |
| Marqueur cytogénétique | i(12p) 80 % | i(12p) 80 % |

→ Différenciation sur le contexte topographique (ovaire vs testicule).

## Diagnostics différentiels (dans l’ovaire)

| DD | Distinction |
|----|-------------|
| **Carcinome à cellules claires** | CK7+ diffus, EMA+, SALL4 ± focal, OCT4− CD117− |
| **Carcinome à petites cellules avec hypercalcémie** | Femme jeune, **perte de SMARCA4 (BRG1)**, EMA+ focal, SALL4 parfois + |
| Tumeur de la granulosa juvénile | cf. [[12_tumeurs_sex_cord_T_cordons_pures]] : marqueurs des cordons sexuels (inhibine, calretinine, FOXL2) + |
| Mélanome métastatique | S100+, HMB45+, MelanA+ |
| Lymphome (DD du dysgerminome via stroma) | CD45+ |

## Pronostic et traitement

- **Tumeurs germinales malignes ovariennes = très chimiosensibles**
- Chirurgie **conservatrice** chez la jeune fille : **annexectomie unilatérale suffisante** (pas d’hystérectomie ni d’annexectomie bilatérale)
- Chimiothérapie : **BEP** (Bléomycine, Étoposide, Cisplatine)
- Pronostic **excellent** sous traitement

---

## 🔑 Points clés à retenir

1. TG ovariennes malignes non tératomateuses = **3-5 %** ; femme jeune ; **i(12p) +** dans 80 %
2. **Dysgerminome** = TG maligne la + fréquente : cellules primitives + **stroma lymphocytaire ± granulomes**
3. Phénotype dysgerminome : **OCT3/4+ SALL4+ CD117+ PLAP+ D2-40+** ; EMA−
4. **Tumeur vitelline** = 2ème TG maligne ; **corps de Schiller-Duval** pathognomonique ; **AFP+ glypican-3+**
5. **Carcinome embryonnaire** : **CD30+ OCT4+ SALL4+** ; jamais pur dans l’ovaire (TG mixte)
6. **Choriocarcinome** non gestationnel : biphasique cyto/syncytio-trophoblaste, **β-hCG+++** ; jamais pur
7. **Polyembryome** : exceptionnel, jamais pur ; aspect de disque embryonnaire
8. **TG mixtes** = 10 % ; chez l’enfant, association la + fréquente = **tératome immature + tumeur vitelline**
9. **SALL4** = marqueur commun à toutes les TG (attention : aussi + dans cellules claires / petites cellules hypercalcémantes)
10. **EMA−** = argument fort en faveur d’une TG (vs tumeur épithéliale)
11. NANOG+/CD2−/AFP− = profil embryonnaire / CD2+ = embryonnaire / AFP+ = vitellin
12. **Chirurgie conservatrice** + **BEP** : très chimiosensibles, pronostic excellent

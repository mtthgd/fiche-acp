# Adénocarcinomes de l’endomètre II — Type endométrioïde

> Liens : [[04_Hyperplasies_de_l_endometre]] | [[05_adenocarcinomes_de_lendometre_I]] | [[12_ADK_endometre_III]]

## Généralités

L’**adénocarcinome endométrioïde** est composé d’un épithélium ressemblant au revêtement endométrial.

- **80 %** des cancers de l’endomètre.
- Cancer **hormonodépendant** (terrain d’**hyperestrogénie**, voir [[05_adenocarcinomes_de_lendometre_I]]).
- Précurseur : **EIN / hyperplasie atypique** (voir [[04_Hyperplasies_de_l_endometre]]).
- **Polypoïde endocavitaire**, infiltrant plus ou moins le myomètre.

## Macroscopie

- Habituellement au niveau du **fond utérin** ou des **cornes**.
- Dans **< 10 %** des cas : développement à la partie basse / **isthmique**.


## Histologie

Spectre allant des formes **très bien différenciées** (faux-amis avec hyperplasie complexe atypique) aux formes **très peu différenciées** (faux-amis avec carcinome séreux ou carcinosarcome).

### Aspects de base
- Structures **glandulaires** tassées les unes contre les autres ou **cribriformes**.
- Glandes bordées par un **épithélium cylindrique stratifié** de type endométrioïde.
- **Vraies papilles** à axe fibrovasculaire possibles.
- Plages **solides** de cellules tumorales.
- Architecture **villoglandulaire** souvent : axes très fins, cellules perpendiculaires.


## Variantes histologiques (OMS 2020)

L’adénocarcinome endométrioïde peut revêtir différents aspects :

| Variante | Caractéristiques |
|----------|------------------|
| **Avec différenciation malpighienne** | morules immatures **ou** malpighien mature ± kératinisant |
| **Sécrétoire** | vacuoles de sécrétion au pôle basal, focal |
| **Microglandulaire** | petites structures glandulaires + PNN (micro-abcès) |
| **Villoglandulaire** | papilles vermiformes axes fins |
| **Cellules ciliées / tubaire** | cellules avec cils apicaux |
| **Sex-cord-like avec hyalinisation** | cellules fusiformes en cordons/travées + hyalinisation/fibrose |
| **Avec différenciation mucineuse** | cellules cylindriques à mucosécrétion endocervicale (terme « ADK mucineux » abandonné OMS 2020) |

> ⚠️ La **différenciation malpighienne ne rentre pas en ligne de compte** pour le grade.

## Infiltration myométriale

### Mesure
- Distance de l’**interface endomètre normal / myomètre** au massif **le plus profond**.
- Rapportée à l’**épaisseur myométriale totale**.
- Seuil : **< 50 %** vs **≥ 50 %** d’épaisseur myométriale.

### Types d’infiltration

| Type | Caractéristiques |
|------|------------------|
| **Classique** | glandes anguleuses + **stromaréaction desmoplastique** |
| **MELF** (**M**icro-cystic **E**longated and **F**ragmented) | structures glandulaires fragmentées, irrégulières, infiltrat lymphocytaire dans le myomètre. **Plus volontiers associé à envahissement ganglionnaire** |

![[assets/gyneco-sein/corps_uterin/04_42_02_01 ADK endomètre I MDS/p15_00.jpeg]]
![[assets/gyneco-sein/corps_uterin/04_42_02_01 ADK endomètre I MDS/p16_00.jpeg]]

### Distinction infiltration vs extension à un foyer d’**adénomyose**

> Si la tumeur s’étend à un foyer d’adénomyose **sans infiltrer ailleurs le myomètre** = **carcinome intra-muqueux** (pas d’infiltration myométriale).

| Critère extension à adénomyose | Critère infiltration myométriale |
|--------------------------------|----------------------------------|
| Adénomiose **par ailleurs** dans l’utérus | absente / non topographique |
| Massifs **arrondis** entourés de **chorion cytogène** + glandes endométriales normales | massifs anguleux, stromaréaction desmoplastique |

> **CD10 inutile** : il peut être positif dans le stroma inflammatoire d’une infiltration myométriale.

### Emboles vasculaires
À signaler. Visualisés dans le myomètre, **toujours à distance de la tumeur**.

## Grade FIGO

### Architecture (% zones solides, hors différenciation malpighienne)

| Grade | % solide |
|-------|----------|
| **1** | < 5 % |
| **2** | 5-50 % |
| **3** | > 50 % |

### Majoration cytonucléaire
**Atypies cytonucléaires sévères sur > 50 % des noyaux** = grade **majoré de 1 point** :
- Grade 1 + atypies G3 → grade 2
- Grade 2 + atypies G3 → grade 3

![[assets/gyneco-sein/corps_uterin/04_42_02_01 ADK endomètre I MDS/p19_00.jpeg]]

## Immunohistochimie / classification moléculaire

### IHC obligatoire dans tous les ADK endométriaux

| Marqueur | Recherche |
|----------|-----------|
| **MMR (MSH6, PMS2, MLH1, MSH2)** | obligatoire (Lynch + classification TCGA) |
| **P53** | classification TCGA |
| **POLE** | mutation par séquençage (NGS) |

### Algorithme **ProMisE** (cf. [[05_adenocarcinomes_de_lendometre_I]])

```
1. IHC MMR
   - Perte d’1 protéine → MMR-D / MSI
2. Si MMR conservées → mutation POLE (NGS)
   - Mutée → POLE-ultramuté
3. Si POLE non muté → IHC P53
   - P53 muté (> 75 % +++ OU négativité totale OU positivité cytoplasmique) → P53-muté
   - P53 sauvage (rares noyaux + intensité variable) → NSMP
```

### Recherche de Lynch
- **Perte MLH1 ou PMS2** → tester **hyperméthylation du promoteur MLH1**.
- Si **pas d’hyperméthylation** → consultation oncogénétique (Lynch présumé).

## Pronostic — apport TCGA

| Groupe TCGA | Pronostic |
|-------------|-----------|
| **POLE ultramuté** | **excellent** (faible risque même si stade IB / stade II) |
| **MMR-D** (MSI hypermuté) | intermédiaire |
| **NSMP** (copy-number low) | intermédiaire à excellent |
| **P53 muté** (serous-like / copy-number high) | **péjoratif** (risque intermédiaire **dès le stade IA**) |

> Recommandations ESMO récentes : la classification moléculaire **module la prise en charge** (ex. ADK endométrioïde POLE-muté stade IB/II = **faible risque** ; ADK endométrioïde stade IA P53-muté = **risque intermédiaire**).

## Diagnostics différentiels

| DD | Distinction |
|----|-------------|
| **EIN / hyperplasie atypique** | **architecture** (cribriforme vrai, vraies papilles, stromaréaction desmoplastique, nécrose tumorale → ADK) |
| **Carcinome séreux** | atypies sévères, mitoses, **P53 muté**, **P16 +** intense, RH - |
| **Carcinome à cellules claires** | cellules claires diffuses, papilles axes hyalinisés, P53 sauvage, RH - |
| **Carcinosarcome** | composante mésenchymateuse maligne associée (voir [[12_ADK_endometre_III]]) |
| **Métastase** (sein, côlon, estomac) | architecture inhabituelle, embols, glandes endométriales préservées (voir [[12_ADK_endometre_III]]) |

## Pronostic / Traitement

- **Type le plus fréquent** (80 %), souvent **stade I** (80 %).
- Survie 5 ans globalement > 80 %.
- **Type histologique + grade FIGO + classification moléculaire** doivent être donnés dès la **biopsie / curetage préopératoire**.

## 🔑 Points clés à retenir
1. **ADK endométrioïde** = **80 %** des cancers de l’endomètre, hormonodépendant, précurseur **EIN**.
2. Histologie : structures glandulaires, **villoglandulaires**, cribriformes, cellules cylindriques stratifiées endométrioïdes.
3. Variantes OMS 2020 : **différenciation malpighienne** (la plus fréquente, 25 %, **ne change pas le grade**), sécrétoire, microglandulaire, ciliée, **sex-cord-like avec hyalinisation**, mucineuse.
4. **Infiltration myométriale** : mesurée de l’interface endo/myo au massif le plus profond, rapportée à l’épaisseur ; seuil **50 %**.
5. Pattern **MELF** (microcystic, elongated, fragmented) = associé à **envahissement ganglionnaire** plus fréquent.
6. Distinction extension à **adénomyose** vs infiltration myométriale = chorion cytogène + glandes endométriales normales autour des massifs.
7. **Grade FIGO** : architecture (% solide ; G1 < 5 %, G2 5-50 %, G3 > 50 %) + **majoration cytonucléaire** si atypies G3 sur > 50 % des noyaux.
8. La différenciation malpighienne **ne compte pas** dans le calcul du % solide.
9. **IHC obligatoires** : **MMR, P53** ; **POLE** par NGS = **ProMisE**.
10. **Lynch** : recherche systématique si perte MLH1/PMS2 → tester **hyperméthylation MLH1** d’abord, sinon onco-génétique.
11. **TCGA** : **POLE-muté** = pronostic **excellent** ; **P53-muté** = **péjoratif** dès stade IA → décisions thérapeutiques modulées.
12. **Donner le grade FIGO et la classification moléculaire dès le préopératoire** (biopsie / curetage).

# Adénocarcinomes de l’endomètre I — Généralités

> Liens : [[04_Hyperplasies_de_l_endometre]] | [[11_ADK_endometre_II]] | [[12_ADK_endometre_III]] | [[06_Les_Tumeurs_du_Stroma_Endometrial]]

## Généralités

- L’**adénocarcinome de l’endomètre** est **loin devant** les sarcomes utérins et les carcinosarcomes.
- **4ᵉ cancer** de la femme et **1er cancer du tractus génital** (> ovaire).
- France 2010 : **6 560 nouveaux cas/an**, **1 900 décès/an**.
- Plus fréquent dans les pays industrialisés.
- Cancer de la femme **ménopausée**, âge moyen **60 ans**.
- **3 %** surviennent avant **40 ans**.


## Facteurs de risque

### Hyperestrogénie (1er facteur)

| Mécanisme | Exemples |
|-----------|----------|
| Diminution exposition à la progestérone | **nulliparité**, pauciparité, ménopause tardive, puberté précoce |
| Œstrogènes exogènes | THS riche en œstrogènes, **tamoxifène** (estrogen-like) |
| Œstrogènes endogènes | **SOPK**, tumeurs ovariennes (thécome, granulosa adulte) |
| Métabolique | **obésité**, **HTA**, **hyperlipidémie** |

### Formes familiales (5-6 % des cas)

| Syndrome | Gène | Particularité |
|----------|------|---------------|
| **Cowden** | **PTEN** constitutionnel | risque × 3-5, risque cumulé ≈ **30 %** |
| **Lynch (HNPCC)** | **MSH6, PMS2, MLH1, MSH2** (par fréquence) | survenue **15 ans plus tôt** (≈ 40-45 ans) ; risque cumulé **40-70 %** ; **6 %** des cancers de l’ovaire associés |

> Devant un carcinome endométrial **avant 50 ans** ou avec antécédents personnels/familiaux Lynch (côlon, grêle, urothélium, voies biliaires, estomac, endomètre…) : **rechercher syndrome de Lynch**.
> Surveillance dès 30 ans, écho endovaginale tous les 2 ans, **annexectomie prophylactique** envisageable post-projet parental.

## Classification anatomo-clinique (Bokhman) — type 1 vs type 2

⚠️ Pas une classification OMS, mais **anatomo-clinique** historique (en partie obsolète depuis le **TCGA**).

| | **Type 1 (~ 80 %)** | **Type 2 (10-23 %)** |
|---|---|---|
| Hormonodépendance | **Oui** | Non |
| Terrain | péri-ménopause, hyperestrogénie, obésité | femme âgée (≈ **66 ans**), endomètre **atrophique** |
| Histologie | **endométrioïde** | **séreux**, à **cellules claires**, haut grade |
| Précurseur | **EIN / hyperplasie atypique** | **carcinome séreux intra-épithélial (SEIC)** |
| Mutations | **PTEN**, **CTNNB1** (β-caténine), **MSI** (1/3 sporadiques), Lynch | **P53** (>90 %), **HER2** (16-30 %), **P16** sur-exprimée |
| Stade au diagnostic | 80 % stade I | 60 % avec extension extra-utérine |
| Survie 5 ans | > 80 % | ≈ 40 % |

⚠️ Le terme « **carcinome in situ** » est à éviter (porte à confusion avec carcinome **intra-muqueux** = ADK n’envahissant pas le myomètre).

⚠️ Existence de **formes mixtes** et de cas intermédiaires (ex. ADK endométrioïde G3 avec mutation **P53**).

## Classification moléculaire TCGA 2013 (4 sous-groupes)

![[assets/gyneco-sein/corps_uterin/04_42_01hyperplasies de lendomètre MDS/p15_00.jpeg]]

| Groupe TCGA | Caractéristique moléculaire | Pronostic |
|-------------|------------------------------|-----------|
| **POLE ultramuté** | mutation **POLE** | **excellent** |
| **MSI hypermuté** | **MMR-D** (perte d’une des protéines MMR) | intermédiaire |
| **Copy-number low (NSMP)** | faible nombre de copies | intermédiaire |
| **Copy-number high (Serous-like)** | mutation **P53** + nombre élevé de copies | **péjoratif** |

> Détail moléculaire : voir [[12_ADK_endometre_III]].

### Algorithme **ProMisE** (Proactive Molecular Risk Classification Tool for Endometrial Cancers)

Réalisable en paraffine, en routine.

```
1. IHC MMR (MSH6, PMS2, MLH1, MSH2)
   → Perte d’une protéine = MMR-D / MSI
2. Si MMR conservé → mutation POLE
   → Mutée = POLE
3. Si POLE non muté → IHC P53
   → P53 muté (> 75 % positifs / négativité totale) = P53-muté
   → P53 sauvage = NSMP
```

## Carcinogénèse — type 1


```
Endomètre prolifératif → prolifératif persistant → hyperplasie simple
       (continuum physiologique = effet œstrogènes, réversible sous progestatifs)
              ↓ mutation PTEN préexistante
         hyperplasie atypique (EIN)
              ↓ accumulation de mutations
         adénocarcinome → infiltration myométriale
```

> Une fois rentré dans le processus néoplasique : rôle des œstrogènes ↓ et **réponse aux progestatifs ↓**.

## Circonstances de découverte

| Contexte | Présentation |
|----------|--------------|
| Femme ménopausée | **métrorragies post-ménopausiques** (signe majeur) |
| Femme jeune | bilan d’**infertilité** |
| Dépistage cervical | cellules glandulaires endométriales atypiques sur frottis |

## Bilan diagnostique

| Étape | Examen |
|-------|--------|
| Exploration | **échographie endovaginale** (endomètre **< 5 mm** chez ménopausée sans THS) |
| Doppler | hypervascularisation suspecte |
| Prélèvement | biopsie pipelle de Cornier (négative + signes cliniques persistants → **hystéroscopie + curetage**) |
| Référence | **hystéroscopie + curetage** : diagnostic préopératoire dans **> 95 %** |
| Bilan d’extension | **IRM** (invasion myométriale), TDM (loco-régional), CA 125 si extension extra-utérine |

## Stadification FIGO

| Stade | Description |
|-------|-------------|
| **I** | limité à l’utérus (IA < 50 % du myomètre, IB ≥ 50 %) |
| **II** | envahissement du **stroma cervical** |
| **III** | extension régionale (annexes, vagin, ganglions pelviens/lomboaortiques) |
| **IV** | vessie, rectum, métastases à distance |

> Cytologie péritonéale **non obligatoire** pour la stadification FIGO.

## Pronostic / Traitement

- **Type 1** : pronostic globalement bon (survie 5 ans > 80 %), souvent localisé.
- **Type 2** : pronostic réservé (survie 5 ans ~ 40 %), extension fréquente au diagnostic.
- Stratification thérapeutique désormais influencée par le **groupe moléculaire TCGA / ProMisE** (voir fiche III).

## 🔑 Points clés à retenir
1. **1er cancer du tractus génital** féminin (devant ovaire) ; **6 560 cas/an** en France ; âge moyen **60 ans**.
2. Facteurs de risque dominés par l’**hyperestrogénie** : nulliparité, ménopause tardive, **tamoxifène**, **obésité**, **SOPK**.
3. Formes familiales : **Lynch** (cancer 15 ans plus tôt, risque cumulé 40-70 %) > **Cowden** (**PTEN** constitutionnel).
4. Classification anatomo-clinique : **type 1 endométrioïde hormonodépendant** (≈ 80 %, EIN précurseur, **PTEN**) vs **type 2 séreux/cellules claires non hormono-dépendant** (SEIC précurseur, **P53**).
5. **Type 1** : pronostic bon (survie 5 ans > 80 %) ; **Type 2** : pronostic réservé (≈ 40 %).
6. **TCGA 2013** : 4 groupes moléculaires — **POLE ultramuté** (excellent) / **MSI hypermuté** (intermédiaire) / **NSMP copy-number low** (intermédiaire) / **P53 serous-like copy-number high** (péjoratif).
7. Algorithme **ProMisE** réalisable en paraffine : **IHC MMR → mutation POLE → IHC P53**.
8. Précurseur du type 1 = **EIN (hyperplasie atypique)** ; du type 2 = **SEIC** (carcinome séreux intra-épithélial).
9. Diagnostic préopératoire : **hystéroscopie + curetage** (> 95 % de fiabilité).
10. **IRM** = meilleur examen pour l’invasion myométriale ; FIGO = limité à l’utérus → I, stroma cervical → II, etc.
11. Toujours évoquer **Lynch** devant un cancer endométrial **avant 50 ans** ou avec antécédents familiaux évocateurs.

# Léiomyome utérin — Macroscopie et sémiologie

> Liens : [[08_Leiomyome_variantes_et_remaniements]] | [[09_les_STUMP]] | [[10_LMS_uterin]] | [[06_Les_Tumeurs_du_Stroma_Endometrial]]

## Généralités

Le **léiomyome utérin** est une **prolifération bénigne de cellules tumorales à différenciation musculaire lisse**.

- **Très fréquent** : **1 femme sur 2** à 50 ans.
- **800 fois plus fréquent** que le léiomyosarcome.
- **Hormono-dépendant**.
- Incidence accrue chez la femme **noire**.
- Modifications possibles sous traitement, remaniements variés, variantes morphologiques → pièges diagnostiques fréquents.

## Macroscopie — étape essentielle

### Aspect d’un léiomyome banal

| Critère | Description |
|---------|-------------|
| Couleur | **Blanc** |
| Consistance | **Ferme** |
| Limites | **Bien limitées** |
| Aspect de tranche | **Homogène, fasciculé** |
| Comportement | **Protrusion** à la tranchage à l’état frais |

![](https://pub-09a67500e45345d4babec28739403570.r2.dev/gyneco-sein/corps_uterin/04_45_01%20Leiomyome%20%20macro%20et%20s%C3%A9mio%20%282%29/p05_00.jpeg)

### Localisations

| Siège | Précision |
|-------|-----------|
| **Sous-muqueux** | polypoïde ou juste sous l’endomètre |
| **Intersticiel** (intramural) | dans le myomètre |
| **Sous-séreux** | sous la séreuse, parfois polypoïde |

Les léiomyomes peuvent être **uniques** ou **multiples**, de toutes tailles (de quelques mm à plusieurs dizaines de cm).

### Lésions associées à connaître

Un léiomyome **n’élimine pas** d’autres pathologies utérines coexistantes :
- **Léiomyosarcome**
- **Polype endométrial / carcinome endométrial**
- **Sarcome du stroma endométrial**
- **Adénomyose**

### Échantillonnage selon le type de prélèvement

| Prélèvement | Stratégie |
|-------------|-----------|
| **Hystéroscopie opératoire** | inclure **tout** le matériel |
| **Hystérectomie totale** | prélever surtout les myomes **dérogeant** aux critères banals |
| **Utérus morcelé** | difficile, échantillonnage multiple |

> Identifier les zones **suspectes** :
> - remaniement nécrotique / hémorragique / **myxoïde**
> - moins ferme, **perte de fasciculation**
> - couleur **non blanche**
> - léiomyome **mal limité**
>
> Toutes ces caractéristiques peuvent être observées dans un **LMS** ou un **sarcome du stroma endométrial**.

## Histologie — les 7 critères de Bell, Kempson, Hendrickson

| Critère | Détail |
|---------|--------|
| 1. Cellularité | par rapport au myomètre et à l’endomètre |
| 2. **Mitoses** | nombre, présence **figures atypiques** |
| 3. **Atypies cytonucléaires** | grade et disposition |
| 4. **Nécrose** | présence + **type** (tumoral vs ischémique) |
| 5. Limitation microscopique | bien limité ou infiltrant |
| 6. Extension intravasculaire | présente / absente |
| 7. (autres remaniements) | |

> **Critères majeurs** pour différencier léiomyome ↔ LMS = **mitoses, atypies, nécrose**.

### Comparaison Léiomyome / Léiomyosarcome

| Caractère | **Léiomyome bénin** | **Léiomyosarcome** |
|-----------|---------------------|---------------------|
| Limites | **Bien limitées** | Mal limitées, infiltrantes |
| Mitoses | **< 5/10 HPF** | **> 10/10 HPF** + figures atypiques |
| Atypies | Absentes | Marquées |
| Nécrose | Absente ou ischémique | **Tumorale** |
| Extension intravasculaire | Absente | Possible |

## Les 3 types de nécrose

| Type de nécrose | Caractéristiques | Signification |
|-----------------|------------------|---------------|
| **Ischémique** (la + fréquente) | type **infarctus** ; circonscrite par bande **fibreuse / hyaline** ± inflammation | **Aucune signification péjorative** |
| **Tumorale** | contours **abrupts en carte de géographie** ; sans inflammation ; **vaisseaux visibles** dans la zone nécrosée | **STUMP** au minimum, critère majeur de **LMS** |
| Aiguë de suppuration | exceptionnelle | (non détaillée) |


> **Nécrose tumorale** : transition **abrupte** zones viables → nécrose, **persistance de cellules autour des vaisseaux**.
> **Nécrose ischémique** : **fantômes cytoplasmiques** sans noyaux + remaniements fibreux/hyalins ± liseré inflammatoire.

## Atypies cytonucléaires — règle du fois 10

> Pour être **sémiologiquement significatives**, les atypies doivent être **visibles dès l’objectif × 10**.
> Si elles n’apparaissent qu’au × 40 → **pas de valeur sémiologique**.

| Grade | Disposition | Type |
|-------|-------------|------|
| Légères / modérées / sévères | diffuses / focales / multifocales | **pléomorphes** (visibles au faible grossissement) ou **monomorphes** (anomalies de chromatine récurrentes) |

## Activité mitotique — règles de comptage

- **10 champs contigus à l’objectif × 40**, dans les zones les plus mitotiquement actives (repérées au faible grossissement).
- Compter uniquement les **vraies mitoses** : absence de membrane nucléaire + chromosomes visibles.
- **NE PAS confondre avec** : apoptose, pycnose, cellules inflammatoires, caryorrhexis.
- Compte facilité dans les **faisceaux musculaires inclus longitudinalement**.
- Nécessite : bonne fixation, coupe fine, qualité technique.

## Immunohistochimie

| Marqueur | Tumeur musculaire lisse |
|----------|:---:|
| **h-Caldesmone** | + (préféré) |
| **Desmine** | + |
| **Actine musculaire lisse** | + |
| RE / RP | + (habituellement) |
| **CD10** | habituellement -, mais peut être + dans léiomyome bénin |

> ⚠️ **Aucune place de l’IHC** pour distinguer **léiomyome / STUMP / LMS**.
> - LMS souvent **P53 muté** et **P16 +**, mais P16 + possible dans léiomyomes (nécrose, noyaux bizarres).
> - Mutations P53 possibles dans léiomyomes à noyaux bizarres.
> → **Seule l’analyse morphologique** compte (atypies, mitoses, nécrose tumorale).

## Diagnostics différentiels

| DD | Distinction |
|----|-------------|
| **Tumeur du stroma endométrial** | CD10 + diffus, vasculaire artériolariforme, IHC muscle - ou focal |
| **STUMP** | voir [[09_les_STUMP]] |
| **Léiomyosarcome** | voir [[10_LMS_uterin]] : **≥ 10 mitoses/10 HPF**, atypies marquées, nécrose tumorale |
| **Léiomyome variantes** | voir [[08_Leiomyome_variantes_et_remaniements]] |

## Pronostic / Traitement

- Tumeur bénigne : **myomectomie** ou hystérectomie selon contexte.
- Hormonosensibilité : modifications possibles sous traitement (analogues LHRH, progestatifs) → connaître ces modifications pour ne pas porter à tort un diagnostic de STUMP.

## 🔑 Points clés à retenir
1. Le **léiomyome utérin** est très fréquent (**1/2** femme à 50 ans) et **800 fois plus fréquent** que le LMS.
2. Macroscopie banale : **blanc, ferme, bien limité, homogène, fasciculé**, **protrusion** au tranchage.
3. **Toujours prélever** les myomes dérogeant à ces critères (**nécrose**, **myxoïde**, hémorragique, mal limité, non blanc).
4. **7 critères de Bell-Kempson-Hendrickson** ; **3 critères majeurs** : **atypies + mitoses + nécrose**.
5. **3 types de nécrose** : **tumorale** (péjorative, contours abrupts en carte de géographie, vaisseaux visibles), **ischémique** (fibrose, fantômes, sans valeur péjorative), aiguë (rarissime).
6. **Atypies cytonucléaires** : visibles dès **× 10** pour avoir une valeur sémiologique.
7. **Mitoses** : compter **10 HPF contigus × 40** dans les zones les plus actives. **≥ 10/10 HPF** = critère LMS.
8. Léiomyome conventionnel : **< 5 mitoses/10 HPF**, sans atypie, sans nécrose tumorale, **bien limité**.
9. IHC = h-caldesmone, desmine, actine musculaire lisse positifs ; **aucune utilité** pour le DD léiomyome / STUMP / LMS.
10. Toujours rechercher des **lésions associées** : LMS, polype, ADK endométrial, sarcome stromal, adénomyose.
11. **Connaître les variantes** et les **modifications sous traitement hormonal** pour éviter un sur-diagnostic de STUMP.

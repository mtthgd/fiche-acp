# Cancers héréditaires du sein

> Liens : [[14_Recepteurs_hormonaux]] | [[15_TILs_NR]] | [[17_signatures_moleculaires]] | [[19_NST_et_lobulaires_finale_GB_AVS]] | [[20_TYPES_HISTOLOGIQUES_AUTRES_SEIN]] | [[24_pieges_triple_neg_vf]]

## Généralités

| Contexte | Fréquence |
|----------|-----------|
| Cancers du sein **sporadiques** | **85 %** |
| Cancers du sein à transmission héréditaire suspectée | **15 %** |
| Parmi héréditaires : mutations **BRCA1/2** identifiées | **20 %** |
| Sans mutation BRCA1/2 mais transmission héréditaire = **BRCAX** | **80 %** restants |

### Quand suspecter une prédisposition héréditaire ?
- Plusieurs cas de cancer du sein dans la **même famille**
- Survenue à un **âge jeune**
- **Cancer du sein chez l’homme** (forte indication BRCA2)

### Gènes étudiés en panel NGS

| Gène | Syndrome / Particularité |
|------|--------------------------|
| **BRCA1** | Sein, ovaire (haut risque) |
| **BRCA2** | Sein (femme, **homme**), ovaire, pancréas, prostate |
| **TP53** | **Syndrome de Li-Fraumeni** |
| **PTEN** | Syndrome de **Cowden** |
| **CDH1** | Cancer gastrique diffus + sein **lobulaire** |
| **STK11** | Syndrome de **Peutz-Jeghers** |
| **PALB2** | Sein, ovaire, pancréas |
| **ATM** | Sein, ataxie-télangiectasie |
| **CHEK2** | Sein |
| **BARD1** | Sein |
| **RAD51C/D** | Sein, ovaire |
| **BRIP1** | Ovaire, parfois sein |
| **MUTYH** | Sein (rare) |
| **BMPR1A** | — |

# 1. Tumeurs BRCA1

## Caractéristiques (85 % des cas)

| Caractéristique | Tumeurs BRCA1 |
|-----------------|---------------|
| Type histologique | NST le plus souvent |
| **Phénotype** | **Basal-like / triple négatif** |
| Grade | **Haut grade (3)** |
| Variante particulière | **NST stroma riche en lymphocytes** (anciennement "médullaire") = **10-15 %** |
| TILs stromaux | **Élevés** |
| **HER2** | **Pas d’amplification / surexpression** |
| Carcinome in situ associé | **Rare** (37 % vs 60-80 % sporadique) |

## Tumeurs BRCA1 luminales (15 % minoritaires)

- **Type luminal**, mais avec :
  - Cytokératines luminales (CK8/18) **plus faibles**
  - **Grade 3**, plutôt **luminal B** (PR faible, prolifération élevée)
  - **Pas de surexpression HER2**

> Pas de spécificité morphologique stricte.

---

# 2. Tumeurs BRCA2

| Caractéristique | Tumeurs BRCA2 |
|-----------------|---------------|
| Âge | **Jeune (~ 44 ans)** |
| Type histologique | Tous types : NST, **lobulaire (10-15 %)**, anciennement "médullaire" |
| **Grade** | Majorité **grade 3**, index mitotique élevé, anisocaryose marquée, peu de différenciation glandulaire |
| **Phénotype** | **ER+, PR+** (luminal B) |
| **HER2** | Possible mais **moins fréquent** que sporadique |
| Marges | **Refoulantes** (vs sporadique) |
| Emboles, CCIS associé | Identique aux sporadiques |

> **Cancer du sein chez l’homme** = **forte indication de mutation BRCA2** (après élimination de métastase ou lymphome).

---

# 3. Tumeurs BRCAX (héréditaires sans mutation BRCA1/2)

- Pas de spécificité morphologique nette
- Type **NST ou lobulaire**
- **Grade 3** ; ER+, PR+ (luminales)
- **Pas de HER2+**
- **TP53 négatif** en IHC

---

# 4. Syndrome de Li-Fraumeni (TP53)

| Caractéristique | Cancers Li-Fraumeni |
|-----------------|---------------------|
| **Âge médian** | **30,8 ans** (très jeune, < 35 ans) |
| Type histologique | **NST** dans > 80 % |
| **HER2 amplifié** | **~ 70 %** (caractéristique) |
| **ER, PR +** | ~ 42 % |
| Phénotype | **Luminal B HER2+** chez patiente très jeune |
| Antécédents associés | **Sarcome des tissus mous** ou **phyllode** dans 6,5 % |
| Autres cancers du spectre | 56 % |

> Devant une jeune femme < 35 ans avec une tumeur **HER2 amplifiée** + antécédent de sarcome → **rechercher TP53** systématiquement.

---

# 5. Tumeurs ATM

- Carcinome NST dans **83 %**
- **Grade 2-3** dans **89 %**
- **ER+, PR+** majoritairement → **Luminal B**, parfois HER2+
- Particularité : **TILs faibles** dans le stroma
- **Ne ressemblent pas** morphologiquement ni génétiquement aux BRCA1

---

# 6. Tumeurs CHEK2, PALB2, BMPR1A, BRIP1, MUTYH

| Caractéristique | Tumeurs |
|-----------------|---------|
| Type | **NST** |
| **Grade** | **1-2** |
| CCIS associé | **Fréquent** (84 %) |
| Stroma | **Fibreux / desmoplastique** |
| TILs | **Très peu** |

> **Contraste fort** avec BRCA1/2 et TP53 (qui ont TILs riches).

---

# 7. Cancer du sein chez l’homme

Avant de poser le diagnostic :
- **Éliminer une métastase**
- **Éliminer un lymphome**

Caractéristiques :
- Majorité = **Luminal B** (ER+, PR plus faible, prolifération élevée)
- Forte indication de **BRCA2** → consultation d’oncogénétique systématique

---

# Implications thérapeutiques

| Mutation | Implication |
|----------|-------------|
| **BRCA1/2** somatique ou germinal | **Inhibiteurs de PARP** (olaparib, talazoparib) |
| TP53 | Surveillance familiale, pas de cible thérapeutique directe |
| HER2+ | **Trastuzumab + pertuzumab** |
| ER+ | Hormonothérapie |

---

# Diagnostic différentiel — situations à signaler

| Situation | Conduite |
|-----------|----------|
| **Femme < 35 ans** avec cancer du sein | Consultation oncogénétique |
| Cancer du sein **TN** chez femme jeune | Penser **BRCA1** |
| Cancer du sein **HER2+** + sarcome | Penser **TP53 / Li-Fraumeni** |
| Cancer du sein **lobulaire bilatéral** + antécédent gastrique familial | Penser **CDH1** |
| Cancer du sein **chez l’homme** | Penser **BRCA2** |
| Carcinome stroma riche en lymphocytes ("médullaire") | Penser **BRCA1** |

---

## 🔑 Points clés à retenir

1. **15 %** des cancers du sein sont à transmission héréditaire ; **20 %** d’entre eux ont une mutation **BRCA1/2** identifiée ; les autres = **BRCAX**
2. **BRCA1** : **basal-like / triple négatif** (85 %), **grade 3**, **TILs+++**, **HER2−**, "médullaire" dans 10-15 %
3. **BRCA1 luminal** (15 %) : luminal B, CK8/18 faibles, pas de HER2+
4. **BRCA2** : âge jeune (~44 ans), tous types (NST, **lobulaire 10-15 %**), **grade 3, luminal B**, marges refoulantes
5. **Cancer du sein chez l’homme** = forte indication **BRCA2** (après éliminer métastase / lymphome)
6. **TP53 / Li-Fraumeni** : **< 35 ans**, NST, **HER2+ 70 %**, ER+ 42 %, **sarcomes associés**
7. **ATM** : luminal B, peu de TILs, ne ressemble pas aux BRCA1
8. **CHEK2, PALB2, BRIP1, MUTYH** : NST **bas grade (1-2)**, **stroma desmoplastique**, **très peu de TILs**, **CCIS associé 84 %**
9. **CDH1** : sein **lobulaire** + cancer gastrique diffus → syndrome HDGC
10. **Inhibiteurs PARP** = traitement ciblé des **BRCA1/2** muté
11. Toute femme **jeune** avec cancer TN ou HER2+ + sarcome → **consultation oncogénétique**
12. Phénotype **NST stroma riche en lymphocytes** ("médullaire") évocateur de **BRCA1**

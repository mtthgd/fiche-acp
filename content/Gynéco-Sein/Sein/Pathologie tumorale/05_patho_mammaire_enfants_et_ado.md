# Pathologie mammaire de l’enfant et de l’adolescent

> Liens : [[03_Sein_homme_Buob]] | [[06_IHCsein]] | [[02_principes_du_traitement_K_sein]]

## 1. Embryologie du sein


- **Crêtes mammaires** : épaississement de l’**ectoderme** à la **4e semaine** dans la région ventrale (axillaire → inguinale).
- Disparition rapide ne laissant que **2 bourgeons mammaires primitifs**.
- Migration ectoblastique dans le **mésenchyme sous-jacent** → ramification → anastomose au **sinus lactifère** (futur mamelon).
- À la naissance : bourgeon mammaire de quelques **millimètres**.

## 2. Anomalies du développement

### Anomalies du nombre / position

| Anomalie | Description |
|----------|-------------|
| **Polythélie** | Mamelon surnuméraire **sans tissu mammaire** ; fréquente, garçon et fille ; ligne mammaire (sillon sous-mammaire, axillaire) ; possibles anomalies urinaires associées |
| **Polymastie** | Glande mammaire surnuméraire ; **rare** ; souvent axillaire ; révélée à la puberté ou grossesse |
| **Athélie / amastie** | Absence de mamelon / de sein ; rarement bilatérale ; **syndrome de Poland** (aplasie mammaire + anomalie pectorale + anomalie de la main) |

### Développement post-natal

- Stade **pré-pubertaire** : quiescence.
- **Puberté** : croissance hormonale (œstrogènes → canaux + stroma + adipeux ; **progestérone** → unités lobulaires).
- **Classification de Marshall–Tanner** (5 stades).
- Sein adulte : **15–25 lobules**.

### Anomalies fréquentes du développement

| Anomalie | Description |
|----------|-------------|
| **Telarche prématuré** | Apparition des seins **< 2 ans** ; physiologique (hormones maternelles), peut secréter du lait ; **ne pas masser** (risque infection) |
| **Asymétrie mammaire** | Fréquente, hyperœstrogénie relative ; rechercher lésion sous-jacente si majeure (vasculaire, fibroadénome, syndrome de Goldenhar) |
| **Hypotrophie** | Si bilatérale → **dysgénésie gonadique**, **syndrome de Turner**, séquelle (chirurgie, radiothérapie, abcès) |
| **Hypertrophie** | Plastie mammaire de réduction ; aspect histologique fibreux + hyperplasie lobulaire |
| **Sein tubéreux** | Anomalie de forme (base d’implantation étroite) |
| **Ectasie galactophorique pubertaire** | Tuméfaction rétroaréolaire bleutée < 3 cm ; régresse spontanément |

## 3. Gynécomastie pubertaire

- **Fréquente** : ≈ **60 %** des garçons ; pic vers **14 ans**.
- Hyperœstrogénie relative (**ratio testostérone/œstradiol bas**).
- **Uni- ou bilatérale**, peut persister.
- À évoquer aussi dans : **Klinefelter**, tumeurs surrénaliennes, hépatoblastomes, médicaments, **NF1**.
- Histologie : **hyperplasie canalaire** (phase précoce) → **fibrose** (phase tardive) ± aspect de Paget.
- Voir [[03_Sein_homme_Buob]] pour détails.

## 4. Pathologie tumorale pédiatrique — vue d’ensemble

### Tumeurs fibroépithéliales (les plus fréquentes)

| Entité | Fréquence pédiatrique |
|--------|----------------------|
| **Fibroadénome** | **68 %** des tumeurs mammaires de l’enfant/ado |
| **Tumeur phyllode** | **0,5–1 %** ; rare |
| **Hamartome** | Tous âges, pas de spécificité pédiatrique |

### Tumeurs épithéliales (rares)

- **Carcinome canalaire NST** : exceptionnel → rechercher **syndrome de prédisposition**.
- **Carcinome sécrétoire juvénile** : rare, classique chez l’adolescente.
- **Papillomatose juvénile**.

### Tumeurs extra-mammaires

- **Lymphomes** : **Burkitt** (atteinte mammaire classique), lymphome anaplasique à grandes cellules, Hodgkin, **leucémie myéloblastique**.
- **Fibromatoses desmoïdes**.
- **Hamartome fibreux du nourrisson** (< 2 ans, axillaire).
- **Métastases** : **rhabdomyosarcome alvéolaire** (++).

## 5. Fibroadénome

### Données cliniques

- Tumeur mammaire **la plus fréquente** chez l’enfant et l’adolescent.
- **Filles post-pubères** (14–18 ans).
- **2–5 cm**, uniques ou multiples, uni- ou bilatérales.
- Multiples → penser **syndrome de Carney**.
- Exérèse non systématique : indiquée si **> 3 cm**, croissance, douleur.

### Histologie

![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p11_00.jpeg]]
![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p11_01.jpeg]]

- Prolifération **épithéliale + mésenchymateuse**.
- Architecture **intracanaliculaire** (mésenchyme dans structures épithéliales) ou **péricanaliculaire** (autour des canaux).

### Forme géante juvénile

![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p13_00.jpeg]]

- Tumeur **> 5 cm** (jusqu’à plusieurs cm), affecte tout le sein, douloureuse.
- Adolescente (parfois plus jeune).
- Histologie : **hyperplasie stromale + cellules multinucléées du stroma**.
- **NE PAS confondre** avec une tumeur phyllode bénigne.

## 6. Tumeur phyllode

- **0,5–1 %** des tumeurs mammaires pédiatriques.
- Définition identique à l’adulte.
- De novo ou sur fibroadénome.
- **75 %** = bénignes (grade 1).
- Architecture **intracanaliculaire poussée** → aspect **foliacé** ; **plus de mésenchyme que d’épithélium**.
- Récidive si exérèse incomplète.

### Tumeur phyllode de haut grade (très rare)

![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p15_00.jpeg]]

- Stroma **sarcomateux** : mitoses, atypies, bordure infiltrante.
- **Récidives locales** + **métastases** (souvent pulmonaires).

## 7. Hamartome intra-mammaire

![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p17_00.jpeg]]

- Tous âges, possible chez l’adolescente.
- **Asymptomatique** : « **sein dans le sein** ».
- Tissu **adipeux + fibreux + glandulaire** mammaire.
- Possibles aspects de **PASH** (hyperplasie stromale pseudo-angiomateuse) dans le stroma.

## 8. Carcinome sécrétoire juvénile

### Clinique

- **Rare** ; possible à tout âge mais **3–15 ans** chez la petite fille.
- Lésion **bien limitée**, près du **mamelon**, peut mimer un fibroadénome.
- **Carcinome de bas grade**.

### Histologie

- **Stroma hyalin** (grandes fibres hyalines).
- Cellules tumorales avec **vacuoles de sécrétion** (PAS+, bleu alcian+).
- Aspect **zonal** : fibrose centrale, microkystique ou pseudo-thyroïdien périphérique.
- **Mitoses rares**, pas de nécrose.
- Possible association : carcinome in situ de type sécrétoire ou carcinome de bas grade.

### Immunohistochimie

| Marqueur | Résultat |
|----------|:---:|
| **RE / RP / HER2** | **Triple négatif** |
| **EMA** | Positif |
| **Protéine S100** | Positif |
| **Pan-TRK** (NTRK) | **Positif** |
| **PAS / bleu alcian** | Positif (sécrétion) |

### Biologie moléculaire

- **Fusion ETV6–NTRK3** (oncoprotéine chimérique activatrice).
- FISH : **remaniement NTRK3**.
- **Cible thérapeutique** : inhibiteurs TRK (larotrectinib, entrectinib).
- Présent aussi dans :
  - **Fibrosarcome congénital infantile**
  - **Tumeur myofibroblastique inflammatoire ALK−**
  - **Carcinome papillaire de la thyroïde**
  - **Néphrome mésoblastique congénital cellulaire**
  - **Carcinome sécrétoire des glandes salivaires**

### Pronostic

- **Métastases ganglionnaires** dans **15 %** des cas.
- Récidives et métastases à distance **rares**.
- **Survie à 5 ans = 100 %**.

## 9. Diagnostics différentiels

### Carcinome adénoïde kystique

- N’existe **pas chez l’enfant**.
- Tumeur de bas grade des glandes salivaires.
- Triple négatif, **P63+**, **CKIT+**.
- Fusion **MYB–NFIB** (2009).
- À ne **pas confondre** avec carcinome sécrétoire juvénile (collagène membrane basale ≠ mucosécrétion).

### Sphérulose collagène

- Découverte fortuite (canaux/lobules).
- Amas de **membrane basale + collagène IV**.
- Lésion **bénigne**, parfois associée à papillome ou hyperplasie canalaire.

## 10. Papillomatose juvénile

![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p21_00.jpeg]]
![[assets/gyneco-sein/sein/pathologie_tumorale/pdf Chapitre 04-10-10 COULOMB SEIN PED/p22_00.jpeg]]

- ≈ **2 %** des séries pédiatriques.
- **Jeune fille < 20 ans**, région **aréolaire**.
- Clinique : masse **QSE**, écoulements.
- Échographie : aspect **kystique « fromage suisse »**.
- Histologie : **fibrose, kystes, hyperplasie épithéliale canalaire (parfois floride), métaplasie apocrine**.
- Quelques cas d’**hyperplasie atypique** ou d’**adénocarcinome associé** → surveillance.

## 11. Stratégie diagnostique pédiatrique

| Étape | CAT |
|-------|-----|
| **Examen clinique** | Important ; sein pubertaire peut paraître inquiétant |
| **Échographie mammaire** | Imagerie de référence |
| **Mammographie** | **CONTRE-INDIQUÉE** (dangereuse pour le développement) |
| **Endocrinologue pédiatre** | Si doute sur puberté précoce / anomalie hormonale |
| **Biopsie au moindre doute** | Surtout pour **lymphome** et autres tumeurs extra-mammaires |
| **Traitement** | **Conservateur** privilégié |

## 🔑 Points clés à retenir

1. **Crêtes mammaires** apparaissent en **S4** ; persistance de 2 bourgeons primitifs.
2. **Polythélie** = mamelon surnuméraire (anomalie la plus fréquente).
3. **Telarche prématuré** physiologique < 2 ans (hormones maternelles).
4. **Mammographie CONTRE-INDIQUÉE** chez l’enfant ; **échographie** = imagerie de référence.
5. **Pathologie mammaire pédiatrique** : essentiellement **bénigne**.
6. **Fibroadénome** = **68 %** des tumeurs mammaires pédiatriques ; multiples → **syndrome de Carney**.
7. **Fibroadénome géant juvénile** : > 5 cm avec hyperplasie stromale ± cellules multinucléées (à ne pas confondre avec phyllode).
8. **Tumeur phyllode** rare (**0,5–1 %**), **75 %** bénignes ; haut grade = sarcomateuse + métastases.
9. **Carcinome sécrétoire juvénile** : **triple négatif**, **S100+**, **EMA+**, **fusion ETV6–NTRK3**, **survie à 5 ans = 100 %**.
10. Métastases ganglionnaires **15 %** dans le carcinome sécrétoire juvénile.
11. **Papillomatose juvénile** : aspect **« fromage suisse »** ; possible cancer associé.
12. Tumeurs extra-mammaires de l’enfant : **lymphome de Burkitt**, anaplasique, **rhabdomyosarcome alvéolaire** → biopsier au moindre doute.

# Les différents types de prélèvements en pathologie mammaire

> Liens : [[04_10_2_IHCsein]] | [[04_10_4_03_CARCINOMES CANALAIRES IN SITU du sein]] | [[04_10_4_04_les ganglions prise en charge stadification ganglion sentinelle]] | [[04_10_4_06_pTNM _audio]]

## Généralités

Trois grands types de prélèvements en pathologie mammaire :
1. **Cytologie** (rare aujourd'hui)
2. **Biopsies** (microbiopsie 14G, macrobiopsie sous vide)
3. **Pièces opératoires** (tumorectomie, mastectomie partielle/totale, ganglions)

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p01_00.jpeg]]

---

# 1. Cytologie

## Indications (rares depuis l'ère des microbiopsies)

| Situation | But |
|-----------|-----|
| **Écoulement mamelonnaire** | Recherche de cellules atypiques (si hémorragique récidivant → pyramidectomie) |
| **Lésions kystiques** | Cellules atypiques + test diagnostique (affaissement post-ponction = rassurant) |
| **Caractérisation creux axillaire** | **Indication principale** : oriente vers curage vs ganglion sentinelle |

## Modalités d'envoi
- **Étalement séché à l'air** → coloration **MGG** (May-Grünwald-Giemsa)
- **Étalement fixé** (éthanol 95° ou laque fixante) → coloration **Papanicolaou**
- **Liquide en flacon** (milieu de conservation) → cytocentrifugation + Papanicolaou

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p02_00.jpeg]]

# 2. Biopsies mammaires

## Indications
Associer une **image radiologique** ou une **masse palpable** à un **diagnostic histologique précis** :
- Lésion bénigne → éviter une chirurgie inutile
- Lésion maligne → prise en charge optimale (chimiothérapie néoadjuvante éventuelle avant chirurgie)

## Deux types de biopsies

| Type | Calibre aiguille | Indication |
|------|------------------|-----------|
| **Microbiopsie** | Petit calibre (14G-16G) | **Masse** palpable ou radiologique |
| **Macrobiopsie** (sous vide, Mammotome) | **Plus gros calibre (8G-11G)** | **Microcalcifications** ou non-masse |

> Plus le **numéro de gauge est élevé**, **plus le calibre est petit**.



## Phase préanalytique (CRITIQUE)
- **Réduire le délai** entre biopsie et fixateur au maximum
- **Fixateur** : **formol tamponné**
- **Temps de fixation** : **6 à 48 h** (optimal)
- Surfixation > 48 h tolérée
- **Sous-fixation** = dommages **irréversibles de l'ADN** → compromet **FISH** et hybridation in situ

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p09_00.jpeg]]

## Déroulé technique

### Microbiopsie (masse)
- Radiologue place **immédiatement** les fragments dans le formol

### Macrobiopsie (microcalcifications)
- Radiographie des biopsies pour vérifier la cible
- Puis fixation au formol
- **Toujours fournir la radiographie** au pathologiste

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p10_00.jpeg]]

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p10_01.jpeg]]

## Mise en cassette
- **Plusieurs cassettes** : économiser le matériel pour CTN éventuelle, IHC, biologie moléculaire, essais
- Précieux si **chimiothérapie néoadjuvante** (peut être le seul matériel restant en cas de réponse complète)

## Niveaux de coupe
- **Microbiopsies** : minimum **2-3 niveaux**
- **Macrobiopsies** : minimum **4-5 niveaux**

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p11_00.jpeg]]

## CAS PARTICULIER : macrobiopsies pour microcalcifications

Le pathologiste doit préciser **à quelle lésion les microcalcifications sont associées**.

**Algorithme si microcalcifications absentes des coupes** :
1. Vérifier la présence de microcalcifications sur la **radiographie de la pièce**
   - Absentes → inutile de recouper (radiologue n'a pas pris la cible)
   - Présentes → recouper en niveaux supplémentaires
2. Ultime recours : **radiographier les blocs** pour identifier les fragments contenant les microcalcifications

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p13_00.jpeg]]

# 3. Pièces opératoires

## Principes généraux

La macroscopie s'**adapte** à :
- Le **type** de prélèvement (exérèse partielle vs mastectomie totale)
- Le **motif** (bénin vs malin)
- Les **renseignements clinico-radiologiques** (palpable vs infraclinique, taille, multifocalité, traitement néoadjuvant)
- L'**étiologie préopératoire**

> **Pas de bonne macroscopie sans renseignement clinique ni radiologique.**

## Types de pièces

| Type | Description |
|------|-------------|
| Tumorectomie / zonectomie | Exérèse partielle |
| Mastectomie sous-cutanée | Étui cutané sans mamelon |
| Mastectomie avec PAM | Avec plaque aréolo-mamelonnaire |
| Mastectomie totale | Glande mammaire complète |

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p16_00.jpeg]]

## Étapes communes

1. **Peser** la pièce
2. **Mesurer** dans les 3 axes
3. **Orienter** (repères du chirurgien)
4. **Encrer** les berges chirurgicales (avant ouverture)
5. **Ouvrir** la pièce
6. **Analyse macroscopique**
7. Examen extemporané ± **tumorothèque**
8. **Fixation** au formol

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p18_00.jpeg]]

## Description de la tumeur
- **Palper** : consistance, limites
- **Mesurer dans les 3 axes** → conditionne le **pT du pTNM**
- **Localiser** (cadran)
- Tumeurs multiples : **dénombrer**, taille de chacune, distance entre foyers
- Décrire la glande mammaire (adipeuse, mastosique)

## Multifocalité vs multicentricité

| Terme | Définition |
|-------|-----------|
| **Multifocale** | Plusieurs tumeurs **dans le même cadran** |
| **Multicentrique** | Tumeurs dans **cadrans différents** |

## Méthode de section

Deux méthodes (pas de consensus) :
- Tranches **parallèles** au plan superficiel/profond
- Tranches **perpendiculaires** au plan superficiel/profond

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p20_00.jpeg]]

## Fixation
- **Formol tamponné**, **10× le volume** de la pièce
- **Pénétration** : **1 mm/h**
- **Mastectomie partielle** : 24 h
- **Mastectomie totale** : 48-72 h
- **Ouvrir la pièce** pour pénétration du fixateur
- Éviter la **sous-fixation** (compromet IHC, FISH)

---

## Mastectomie totale

- Pesée + mesure (totalité + lambeau cutané)
- Description de la **peau** (rétraction, cicatrices) et du **mamelon** (rétracté ? eczématiforme = **maladie de Paget**)
- Ouverture de la pièce
- Localisation tumorale par cadran
- Mesure tumeur 3 axes, distance au mamelon
- **Pas d'évaluation des berges** (chirurgien enlève toute la glande, sauf atteinte macroscopique du muscle pectoral)

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p21_00.jpeg]]

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p21_01.jpeg]]

## Tumorectomie / mastectomie partielle

### Encrage
- **Avant ouverture** de la pièce
- **Encres indélébiles**, **identifiables sur coupes**
- **Couleurs différentes** adaptées à l'orientation
- Évaluation des **berges glandulaires latérales** uniquement (le chirurgien évalue seul les berges sous-cutanées et profondes)

### Tumorothèque (cryoconservation)
- **Tumeur fraîche**, ischémie froide **< 30 min** (idéal < 1h)
- Tumeur de **taille suffisante**
- **Ne doit pas compromettre le diagnostic** : refuser si lésion atypique, in situ, papillaire
- Ne pas intéresser le foyer infiltrant principal

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p25_00.jpeg]]

---

## Cas particuliers de macroscopie

### Exérèse partielle, lésion bénigne
- Encrer si pièce orientée
- Petite pièce → **inclusion totale**
- Pièce volumineuse → **1 prélèvement / cm**

### Mastectomie partielle, cancer infiltrant

**Objectifs** :
- Caractéristiques histologiques tumorales (au moins **1 bloc / cm**)
- Extension tumorale
- **Composante in situ** associée
- **Limites chirurgicales**

**Pièce petite** : tranches parallèles + inclusion totale
**Pièce volumineuse** : tranches de section, inclusion totale si possible, sinon 1 tranche complète + prélèvements orientés sur les berges

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p28_00.jpeg]]

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p28_01.jpeg]]

### Mastectomie partielle, lésions atypiques / in situ / microcalcifications

**Difficulté** : pas de traduction macroscopique → localisation difficile, berges non fiables.

**Démarche** :
- Disposer de la **radiographie de la pièce**
- Repérer la **cicatrice de biopsie** (hématome)
- Inclusion totale **idéale**
- Si trop volumineuse : prélèvements orientés sur l'**anomalie radiologique** + adjacents tous les cm

**Évaluation de la taille lésionnelle** par préments topographiés :
- Tranches sériées d'épaisseur connue (ex : 4 mm)
- Reconstitution de la taille = nombre de tranches positives × épaisseur

> Exemple : foyer in situ retrouvé sur 3 tranches sériées de 1 cm → taille reconstituée **3 cm**.

### Pyramidectomie
- Ablation d'un **canal galactophorique** dans sa totalité
- Indication : **écoulement mamelonnaire**
- Inclusion en totalité
- **Coupes perpendiculaires** à l'axe des canaux galactophoriques

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p35_00.jpeg]]

### Mastectomie totale en contexte de cancer
- **Mamelon** prélevé systématiquement
- **Carcinome infiltrant** : 1 prélèvement / cm
- **CCIS** : céder à la radiologie pour localiser le foyer + cicatrice de biopsies
- Berges non précisées (mastectomie complète)

### Mastectomie prophylactique avec conservation PAM
- **Région rétro-aréolaire en totalité**
- Au moins **2 prélèvements par cadran**

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p44_00.jpeg]]

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p44_01.jpeg]]

# 4. Curage axillaire et ganglion sentinelle

## Curage axillaire
- Disséquer le tissu pour individualiser **tous les ganglions**
- **Inclusion totale** de chaque ganglion (sauf macroscopiquement métastatique)
- Modalités selon taille :
  - **Volumineux** → fines tranches en plusieurs blocs
  - **Petite taille** → coupé en 2, 1 bloc
  - **Très petits** → plusieurs dans un même bloc

![[assets/gyneco-sein/sein/pathologie_tumorale/Les différents types de prélèvements-jh1/p46_00.jpeg]]

## Ganglion sentinelle
- Décrire, mesurer
- Préciser la présence de **bleu** (si bleu patenté utilisé)
- **Inclusion totale**
- Pas de consensus sur le nombre de niveaux de coupe ou l'IHC systématique (varie selon laboratoire)

> Voir [[04_10_4_04_les ganglions prise en charge stadification ganglion sentinelle]]

## 🔑 Points clés à retenir

1. **3 types de prélèvements** : cytologie (rare), biopsies (microbiopsie/macrobiopsie), pièces opératoires.
2. **Microbiopsie 14G** = masse ; **macrobiopsie sous vide (Mammotome)** = microcalcifications ou non-masse.
3. **Phase préanalytique critique** : fixation **formol tamponné 6-48 h** ; sous-fixation = perte ADN, échec FISH.
4. **Niveaux de coupe** : 2-3 (microbiopsie) à 4-5 (macrobiopsie) ; **plusieurs cassettes** pour préserver matériel.
5. **Macrobiopsie pour microcalcifications** : vérifier radiographie pièce → recouper → radiographie blocs si besoin.
6. **Macroscopie pièce opératoire** : peser + mesurer 3 axes + orienter + **encrer (avant ouverture)** + ouvrir + décrire + extempo/tumorothèque + fixer.
7. **Mesure tumeur dans 3 axes** = clé du **pT** ; **multifocale** (même cadran) ≠ **multicentrique** (cadrans différents).
8. **Ischémie froide < 1 h**, **fixation 24-72 h** selon type, **1 mm/h** de pénétration du formol.
9. **Lésions infracliniques (CCIS, microcalcifications, lobulaire infiltrant)** : prélèvements **topographiés sériés** pour reconstituer la taille.
10. **Curage** : ≥ 10 ganglions (qualité), inclusion totale ; **GS** : inclusion totale, modalités locales.

# Récepteurs hormonaux (ER / PR) dans le cancer du sein

> Liens : [[04_10_4_08_3_HER2]] | [[04_10_4_08_4_Ki67]] | [[04_10_4_08_6_TILs FPL NR]] | [[04_10_4_08_7_signatures moléculaires]] | [[10_classification_moleculaire]] | [[11_GRADE]] | [[14_Recepteurs_hormonaux]] | [[19_NST_et_lobulaires_finale_GB_AVS]]

## Généralités

Les **récepteurs hormonaux (RH)** = **récepteurs nucléaires** activés par leur ligand stéroïdien :

- **ER (récepteur des œstrogènes α)** : facteur de transcription nucléaire, activé par fixation de l'œstrogène → **croissance et différenciation** cellulaire.
- **PR (récepteur de la progestérone)** : régulé par la liaison de l'œstrogène sur l'ER → la **présence de PR témoigne indirectement de la fonctionnalité de la voie ER**.

Statut RH = **facteur pronostique** mais surtout **prédictif majeur** :
- **Prédictif de réponse à l'hormonothérapie** (relation quasi linéaire avec le taux d'expression)
- **Prédictif (négatif) de réponse à la chimiothérapie** : tumeurs RH+ moins chimiosensibles que les RH−
- **Définit le sous-type luminal** dans la classification moléculaire


## Hormonosensibilité selon le statut RH

| Statut | Hormonosensibilité |
|--------|--------------------|
| **ER+ / PR+** (doublement positif) | **+++** maximale |
| ER+ / PR− ou ER− / PR+ (dissocié) | + intermédiaire (souvent proche du triple négatif) |
| **ER− / PR−** | nulle |

## Épidémiologie & corrélations histologiques

- **70-80 %** des cancers du sein sont **RH+** (surtout ER+)
- **20-30 %** sont **RH−**
- Liaison forte avec certains types histologiques :

| Type histologique | Statut RH |
|-------------------|-----------|
| **Carcinome NST** | RH+ ≈ 70 % |
| **Carcinome lobulaire** | RH+ très fréquent |
| **Carcinome tubuleux** | RH+ ≈ 100 % |
| **Carcinome mucineux** | RH+ |
| **Carcinome apocrine** | RH− |
| **Carcinome médullaire** | RH− |
| **Carcinome métaplasique** | RH− |
| **Carcinome adénoïde kystique** | RH− |

> **Discordance type histo / RH** = remettre en cause le diagnostic OU la qualité de l'IHC.

## Technique IHC

### Méthodes (historique → actuel)
- **Biochimie** (historique) → IHC sur congelé → **IHC sur paraffine** (référence actuelle)
- **RT-PCR** possible
- **Avantages de l'IHC** : faisable sur petites tumeurs, **localisation cellulaire précise** (cible la composante infiltrante uniquement), **plus prédictive que la biochimie**

### Pré-analytique critique

| Paramètre | Recommandation |
|-----------|----------------|
| **Fixation** | **Formol tamponné 10 %**, ≥ **8 h** (sinon faux négatifs) |
| Surfixation | Possible jusqu'à **7 jours** si **prétraitement adapté** (validation labo : courbe en plateau, pas en cloche) |
| Pré-traitement (démasquage) | Critique : peut faire passer du faux négatif au vrai positif |
| **Témoin externe** | Indispensable (suivi qualité hebdomadaire) |
| **Témoin interne** | Glandes mammaires normales **doivent être positives** (sinon ajouter témoin externe) |

### Anticorps recommandés
- **ER** : clone **SP1** (Ventana, lapin monoclonal)
- **PR** : clone **1E2** (Ventana)

## Lecture & interprétation

### Règles de lecture
- **Uniquement la composante infiltrante** (pas le CCIS, pas les glandes normales)
- **Marquage nucléaire granuleux** uniquement (les noyaux gris « laqués » sont négatifs)
- **% de cellules positives** + **intensité** (1+ / 2+ / 3+)
- Lecture à **grossissement moyen**, comptage fin uniquement près du seuil
- Marquage généralement **homogène** dans la tumeur

### Cotation de l'intensité

| Score | Intensité | Aspect |
|-------|-----------|--------|
| **1+** | Faible | Hématoxyline reste visible (noyaux bleu-marron) |
| **2+** | Modérée | Hématoxyline atténuée |
| **3+** | Forte | Hématoxyline non visible, noyaux **brun foncé** |

> **Lien intensité / pourcentage** : tumeur 80-100 % de cellules marquées **mais 1+ faible** = **rare → suspecter défaut technique**.

## Seuils de positivité

| Référentiel | Seuil ER+ |
|-------------|-----------|
| **France (FNCLCC)** | **≥ 10 %** |
| **USA – ASCO/CAP 2020 / OMS 2012** | **≥ 1 %** |

### Catégorie « ER-low » (1-10 %)
- Situation **rare** (à signaler dans le compte rendu)
- Études récentes : ces tumeurs sont biologiquement **proches des triples négatives**
  - Souvent grade 3, agressives, PR−, profil non-luminal
  - Survie comparable aux triples négatives
- En cas d'**excès de cas ER-low** dans son labo → **suspecter une IHC sous-optimale**

> Problématique : un cas **ER-low classé négatif en France** peut être **classé positif** en essai international (seuil ASCO/CAP 1 %).

## Scores quantitatifs (compte rendu)

| Score | Calcul | Échelle |
|-------|--------|---------|
| **% cellules + intensité** (standard FR) | descriptif | – |
| **H-score** | Σ (% × intensité) | **0-300** |
| **Allred** (Quick score) | 4 niveaux d'intensité (0-3) + 5 niveaux de proportion (0-5) | **0-8** (positif si ≥ 3) |
| **IHC4** | Combine ER + PR + HER2 + Ki67 | pronostic |

### Score d'Allred — détail

| Proportion (PS) | Score |
|----------------|-------|
| 0 % | 0 |
| < 1 % | 1 |
| 1-10 % | 2 |
| 10-33 % | 3 |
| 33-66 % | 4 |
| > 66 % | 5 |

| Intensité (IS) | Score |
|----------------|-------|
| Aucune | 0 |
| Faible | 1 |
| Modérée | 2 |
| Forte | 3 |

**Score total = PS + IS (0-8)** → plus l'Allred est élevé, **meilleure la survie sous hormonothérapie**.

### Probabilité de réponse à l'hormonothérapie

| Score | Réponse à l'hormonothérapie |
|-------|------------------------------|
| Score élevé (3+ fort, > 50 %) | **~ 75 %** |
| Score modéré | **~ 50 %** |
| Score faible | **franchement moins** |

## Sur quel prélèvement ?

### Indications
- **TOUS** les carcinomes du sein **infiltrants**
- **PAS** d'AMM française pour l'hormonothérapie sur **CLIS** ou **CCIS** seul → pas d'indication d'IHC RH (hors essai)
- À refaire **systématiquement** sur :
  - **Récidive** locale ou métastase (évolution possible vers la perte des RH)
  - **Reliquat post-chimiothérapie néo-adjuvante**
    - Discordance ER : **7 %**
    - Discordance PR : **21 %** (souvent perte du clone PR+)

### Biopsie vs pièce
- **Préférer la biopsie** (préanalytique mieux maîtrisé, moins de faux négatifs)
- **Retester sur la pièce** si la biopsie est négative (tumeurs hétérogènes possibles)

## Pourquoi évaluer le PR

1. **Information pronostique et prédictive** : ER+/PR− = moins hormonosensible
2. Définit le statut **triple négatif** (ER− / PR− / HER2−)
3. Définit la distinction **luminal A vs luminal B** (avec Ki67) : voir [[10_classification_moleculaire]]

### Cas ER−/PR+
- **Très rares**
- Le plus souvent = **artefact technique** (faux négatif ER ou faux positif PR)
- Phénotype souvent basal, proche du triple négatif

## Récepteurs aux androgènes (AR)

- **Récepteur nucléaire** (comme ER/PR)
- Pas de seuil consensuel (1 % ou 10 % ?)
- **Positif dans 70-90 %** des cancers du sein, surtout luminaux
- Dans le **triple négatif** : 7-75 % (probablement < 30 %)
  - Tumeurs **AR+ triple négatives** : meilleur pronostic, moins chimiosensibles
  - Essais en phase métastatique avec **anti-androgènes**

## Implications transversales

- **TILs** : valeur pronostique uniquement dans **HER2+ et triple négatif**, pas dans les **luminaux** (cf [[04_10_4_08_6_TILs FPL NR]])
- Les **signatures moléculaires** (Oncotype DX, MammaPrint…) ciblent surtout les tumeurs **RH+ HER2−** (cf [[04_10_4_08_7_signatures moléculaires]])

## Contrôle qualité

- **EEQ FACAP / UK NEQAS** : participation **annuelle obligatoire**
- Témoin externe sur chaque lame
- Suivi du **% de tumeurs RH+** dans son labo (outil **Air France** FACAP)

## 🔑 Points clés à retenir

1. **ER** = facteur de transcription nucléaire ; **PR** = témoigne de la fonctionnalité de la voie ER.
2. RH+ = **70-80 %** des K du sein, surtout ER+ ; définit le **sous-type luminal**.
3. Anticorps : **ER clone SP1**, **PR clone 1E2** (Ventana).
4. Seuil **France ≥ 10 %**, **ASCO/CAP / OMS ≥ 1 %** → catégorie **ER-low (1-10 %)** = profil souvent triple négatif-like.
5. Lecture : **noyaux infiltrants uniquement**, **% + intensité (1/2/3+)**, marquage **granuleux**.
6. **Pré-analytique** : fixation **≥ 8 h** ; éviter sous-fixation et surfixation sans prétraitement adapté.
7. Scores : **% + intensité**, **H-score (0-300)**, **Allred (0-8)** ; positif si **Allred ≥ 3**.
8. **Réponse à l'hormonothérapie quasi linéaire** au taux de RH (75 % si scores élevés, 50 % si modérés).
9. **Refaire RH sur récidive, métastase et reliquat post-NAC** (perte fréquente du PR : 21 %).
10. **ER−/PR+ rare** → vérifier d'abord la technique avant de conclure.
11. **AR+** dans 70-90 % des K luminaux, < 30 % des triples négatifs (essais anti-androgènes).
12. **EEQ FACAP / UK NEQAS** + témoin externe sur **chaque lame** = obligatoire.

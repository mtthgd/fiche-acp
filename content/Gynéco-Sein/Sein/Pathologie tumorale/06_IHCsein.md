# Place de l’immunohistochimie en pathologie mammaire (visée diagnostique)

> Liens : [[12_HER2]] | [[10_classification_moleculaire]] | [[11_GRADE]] | [[07_CARCINOMES_CANALAIRES_IN_SITU_du_sein]] | [[01_METAS_INTRA_MAMMAIRES]]

## Généralités

- Ce cours porte sur l’IHC à **visée diagnostique** (la visée pronostique/théranostique : voir [[12_HER2]]).
- **La plupart des lésions mammaires** se diagnostiquent sur **HE simple**.
- L’IHC est plus utilisée sur **biopsies à l’aiguille** (matériel exigu).

## Situations d’usage de l’IHC

1. Affirmer le **caractère infiltrant** d’une lésion (présence/absence de cellules myoépithéliales)
2. Différencier **HCS** (hyperplasie canalaire simple) vs **HCA** (hyperplasie canalaire atypique) / **CCIS de bas grade**
3. Distinguer un **carcinome NST** d’un **carcinome lobulaire**
4. Affiner le classement des **lésions papillaires**
5. Mieux classer les **tumeurs à cellules fusiformes**
6. Distinguer un cancer **primitif mammaire** d’une **métastase**

## 1. Marqueurs des cellules myoépithéliales

![[assets/gyneco-sein/sein/pathologie_tumorale/04_10_2 DES_IHCsein_sept18_MPCNON SONO/p06_00.jpeg]]

- Présentes dans glandes normales et **CCIS** (parfois moins nombreuses).
- **Absentes** dans le carcinome **infiltrant**.
- Combinaison recommandée : **1 marqueur nucléaire + 1 marqueur cytoplasmique**.

| Marqueur | Localisation | Cible |
|----------|--------------|-------|
| **P63** | Nucléaire | Préféré |
| **Cytokératine 5/6 (CK5/6)** | Cytoplasmique | |
| **Alpha-actine du muscle lisse (αSMA)** | Cytoplasmique | Marque aussi péricytes/myofibroblastes |
| **Calponine** | Cytoplasmique | |
| **Chaîne lourde de la myosine** | Cytoplasmique | |
| **CD10** | Membranaire | |

### 2 exceptions où P63 est négatif sans invasion

1. **Adénose microglandulaire** (lésion bénigne sans cellules myoépithéliales)
2. **Carcinome papillaire encapsulé / solide** (in situ sans cellules myoépithéliales)

### Lésions bénignes simulant la malignité

| Lésion | Cellules myoépithéliales | Membrane basale | Autres |
|--------|:---:|:---:|--------|
| **Adénose sclérosante** | **Présentes** (P63+, αSMA+) | **Présente** | |
| **Adénose microglandulaire** | **Absentes** | **Présente** (collagène 4) | **PS100+** (cytopl. + nucléaire) |
| **Carcinome tubuleux** | **Absentes** | **Absente** | Glandes anguleuses |

## 2. HCS vs HCA vs CCIS de bas grade

![[assets/gyneco-sein/sein/pathologie_tumorale/04_10_2 DES_IHCsein_sept18_MPCNON SONO/p11_00.jpeg]]

| Lésion | **CK5/6** |
|--------|:---:|
| **Hyperplasie canalaire simple (HCS)** | **Patchwork +** |
| **HCA** | **Négatif** |
| **CCIS de bas grade** | **Négatif** |

> Pas de marqueur permettant de séparer **HCA** vs **CCIS bas grade** (entités très proches, prise en charge similaire).
> CK5/6 ne permet PAS de différencier **métaplasie cylindrique simple** vs **atypique**.

## 3. Carcinome NST vs carcinome lobulaire — E-cadhérine

![[assets/gyneco-sein/sein/pathologie_tumorale/04_10_2 DES_IHCsein_sept18_MPCNON SONO/p13_00.jpeg]]

### Perte d’E-cadhérine dans le carcinome lobulaire

| Variant | Perte E-cadhérine |
|---------|:---:|
| **Lobulaire classique** | **90 %** |
| **Lobulaire pléomorphe** | **80 %** |
| **Lobulaire histiocytoïde** | **70 %** |
| **Carcinomes non lobulaires (NST)** | Rarement E-cadhérine négatifs |

### Pour les néoplasies in situ

- **E-cadhérine perte** dès le stade **HLA** (hyperplasie lobulaire atypique).
- En cas de doute CCIS vs CLIS : combiner **E-cadhérine** + **CK 34βE12** :
  - CCIS : **E-cadhérine +** / CK34βE12 **−**
  - CLIS : **E-cadhérine −** / CK34βE12 **+**
  - Si discordants → in situ « hybride ».

## 4. Lésions papillaires — utilité de P63

![[assets/gyneco-sein/sein/pathologie_tumorale/04_10_2 DES_IHCsein_sept18_MPCNON SONO/p15_00.jpeg]]

| Lésion | P63 axes des papilles | P63 paroi du canal |
|--------|:---:|:---:|
| **Papillome bénin / colonisé par CIS** | **+** | **+** |
| **CCIS de type papillaire** | **−** | **+** |
| **Carcinome papillaire encapsulé / solide** | **−** | **−** (exception !) |

## 5. Tumeurs à cellules fusiformes

![[assets/gyneco-sein/sein/pathologie_tumorale/04_10_2 DES_IHCsein_sept18_MPCNON SONO/p17_00.jpeg]]

> **Toujours faire la pancytokératine** : ne pas méconnaître un **carcinome métaplasique** !

| Profil IHC | Orientation diagnostique |
|------------|---------------------------|
| **Pancytokératine +** | **Carcinome métaplasique** à cellules fusiformes |
| **Pancytokératine −** + **bêta-caténine nucléaire +** | **Fibromatose** |
| **Pancytokératine −** + autres marqueurs | Tumeur mésenchymateuse (CD34, PS100, αSMA, CD31, ERG…) |

## 6. Cancer primitif mammaire vs métastase

### Marqueurs en faveur d’une origine mammaire

| Marqueur | Sensibilité | Spécificité |
|----------|:---:|:---:|
| **GATA3** | **Le plus sensible** | Aussi positif dans **K vessie**, rares autres tumeurs |
| **Mammaglobine** | Moindre dans tumeurs RH− | Bonne |
| **GCDFP-15** (gross cystic disease fluid protein 15) | Moindre dans tumeurs RH− | Bonne |

### Marqueurs en faveur d’une origine extra-mammaire

| Origine suspectée | Anticorps |
|-------------------|-----------|
| **Mélanome** | PS100, HMB45, Melan-A, SOX10 |
| **Ovarien séreux** | **WT1**, **PAX8** |
| **Rénal à cellules claires** | **CD10**, **PAX8**, RCC |
| **Digestif (côlon)** | CDX2, CK20+ / CK7− |
| **Pulmonaire (ADK)** | **TTF1**, Napsine A |

### Quand penser métastase ?

- Tumeur de **morphologie inhabituelle**
- **Sans composante in situ**
- Phénotype **triple négatif** inattendu

> Voir [[01_METAS_INTRA_MAMMAIRES]].

## Récapitulatif — Anticorps clés en pathologie mammaire

| Anticorps | Indication principale | À retenir |
|-----------|-----------------------|-----------|
| **CK5/6** | HCS vs HCA / CCIS bas grade | Patchwork+ dans HCS |
| **P63** | In situ vs infiltrant | **2 exceptions** : adénose microglandulaire, papillaire encapsulé/solide |
| **αSMA** | Myofibroblastome, PASH, tumeurs musculaires lisses | |
| **PS100** | Adénose microglandulaire, tumeur à cellules granuleuses, mélanome | |
| **E-cadhérine** | Lobulaire vs canalaire (in situ et infiltrant) | Perte = lobulaire |
| **GATA3 / mammaglobine / GCDFP-15** | Origine mammaire (vs métastase) | GATA3 le plus sensible |
| **PAX8** | Origine müllérienne, rénale, thyroïdienne, thymique | **Toujours négatif** dans le sein |
| **β-caténine nucléaire** | Fibromatose | |
| **Pancytokératine** | Toujours sur tumeurs à cellules fusiformes | Élimine carcinome métaplasique |

## 🔑 Points clés à retenir

1. La **plupart des lésions mammaires** sont diagnostiquées sur **HES seul** ; IHC = appui ciblé.
2. **P63** + **αSMA** = couple recommandé pour distinguer **in situ** vs **infiltrant**.
3. **2 exceptions à P63 négatif** : **adénose microglandulaire** et **carcinome papillaire encapsulé/solide**.
4. **CK5/6** : **patchwork+** dans **HCS**, négatif dans **HCA** et **CCIS bas grade**.
5. CK5/6 NE distingue PAS HCA vs CCIS bas grade ni métaplasie cylindrique simple vs atypique.
6. **Adénose microglandulaire** : pas de cellules myoépithéliales mais **PS100+** ; bénigne.
7. **E-cadhérine perdue** dans **90 %** des lobulaires classiques, dès le stade **HLA**.
8. CCIS vs CLIS hésitant : combiner **E-cadhérine + CK 34βE12**.
9. Lésions papillaires : **P63 axes + paroi** (papillome) ; **axes − / paroi +** (CCIS papillaire) ; **axes − / paroi −** (papillaire encapsulé).
10. Tumeurs fusiformes : **TOUJOURS pancytokératine** (carcinome métaplasique) + **β-caténine nucléaire** (fibromatose).
11. Origine mammaire : **GATA3** (le plus sensible), **mammaglobine**, **GCDFP-15**.
12. **PAX8 toujours négatif** dans le sein → marqueur clé pour exclure une métastase müllérienne / rénale / thyroïdienne.
